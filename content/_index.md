# 정보관리기술사 학습 허브

개념을 읽고, 답안 구조로 압축하고, 기출을 시간 안에 풀고, 간격 반복으로 다시 꺼내는 학습 공간입니다.

## 오늘의 20분 루틴

1. **5분 — 개념 연결**: [기출문제 노트]({{< relref "/docs/notes" >}})에서 토픽 하나를 읽습니다.
2. **7분 — 답안 압축**: [서브노트]({{< relref "/docs/subnotes" >}})의 정의·개념도·비교·차별화 포인트를 손으로 재현합니다.
3. **5분 — 실전 적용**: [핵심토픽 200제]({{< relref "/docs/problems" >}})에서 같은 토픽의 문제 목차를 3단락으로 설계합니다.
4. **3분 — 회상 복습**: [🧠 Flashcards](/flashcards/)에서 오늘 복습 카드만 평가합니다.

## 자료를 사용하는 순서

| 자료 | 언제 쓰나 | 목표 |
|---|---|---|
| [기출문제 노트]({{< relref "/docs/notes" >}}) | 처음 이해할 때 | 개념·배경·출제 포인트 연결 |
| [서브노트]({{< relref "/docs/subnotes" >}}) | 회독·암기 때 | 1장 답안 구조와 현출 키워드 확보 |
| [핵심토픽 200제]({{< relref "/docs/problems" >}}) | 시간 제한 풀이 때 | 질문 분해와 답안 목차 설계 |
| [용어집]({{< relref "/docs/glossary" >}}) | 빈틈 점검 때 | 정의를 한 문장으로 즉시 회상 |

## 답안 훈련 기준

- 문제를 읽으면 먼저 **정의–구성도/비교–실무 적용**의 뼈대를 1분 안에 잡습니다.
- 숫자·법령·표준·Top 10은 출처와 버전을 확인한 사실만 씁니다.
- 작성 뒤에는 [실전 답안 템플릿과 자가 채점표]({{< relref "/docs/posts/practice-answer-template" >}})로 스스로 점검합니다.

## 신뢰도와 최신성

법령·표준·정책·보안 위협은 자주 바뀝니다. 각 문서의 기준일과 원문 출처를 확인하고, 최신성 표기가 없는 자료는 개념 학습용으로 우선 활용하세요. 자세한 작성 규칙은 [콘텐츠 출처·최신성 기준]({{< relref "/docs/posts/content-standards" >}})에서 확인할 수 있습니다.
