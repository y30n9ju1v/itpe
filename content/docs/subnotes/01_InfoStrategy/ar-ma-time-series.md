# 자기회귀모형(AR)과 이동평균모형(MA) 서브노트

> **두음 머리에 박기 🧠**
> - **AR = 과거값, MA = 과거오차** (AR은 과거 관측값의 선형결합, MA는 과거 오차항의 선형결합)
> - **AR: ACF서서히·PACF절단 / MA: ACF절단·PACF서서히** (ACF·PACF 패턴이 서로 대칭적으로 반대)
> - **시·정·AP·적·잔** (모형선택 5절차: **시**각화 → ADF **정**상성확인 → **A**CF/**P**ACF분석 → **적**합(AIC/BIC) → **잔**차검정)

| 분류 | 기술 기술사 서브노트 작성 예시 (1교시형 포맷) |
| :--- | :--- |
| **토픽명** | **자기회귀모형(AR)과 이동평균모형(MA)** |
| **정의** | 시계열 데이터 분석의 핵심 모형으로, AR(Autoregressive)은 과거 값들의 선형결합으로, MA(Moving Average)는 과거 오차항들의 선형결합으로 현재 값을 예측하며, 두 모형을 결합한 ARIMA가 실무에서 널리 사용됨 |
| **키워드** | AR(p), MA(q), ACF/PACF, ARIMA(p,d,q), 정상성(Stationarity) |
| **개념도** | `AR(p): X_t = c + φ₁X_{t-1} + ... + φ_pX_{t-p} + ε_t   (과거 "값")`<br>`MA(q): X_t = μ + ε_t + θ₁ε_{t-1} + ... + θ_qε_{t-q}   (과거 "오차")`<br>`ARIMA(p,d,q) = d차 차분(비정상→정상화) + AR(p) + MA(q)` |
| **구성요소** | 1. **AR(p)**: p=차수(사용하는 과거 시점 수), ACF 서서히 감소·PACF는 p 이후 절단, 관성이 큰 시계열에 적합<br>2. **MA(q)**: q=차수(사용하는 과거 오차 수), ACF는 q 이후 절단·PACF 서서히 감소, 외부 충격 반응 시계열에 적합<br>3. **ARMA(p,q)**: AR+MA 결합<br>4. **ARIMA(p,d,q)**: d차 차분으로 비정상 시계열 정상화 후 ARMA 적용<br>5. **SARIMA**: 계절성(Seasonality) 요소 추가 |
| **비교** | **AR(p)**<br>- 구성요소: 과거 관측값<br>- ACF: 서서히 감소 / PACF: p 이후 절단<br><br>**MA(q)**<br>- 구성요소: 과거 오차항<br>- ACF: q 이후 절단 / PACF: 서서히 감소 |
| **차별화** | **모형 선택 5단계 절차의 실무 적용**<br>1. **시각화·정상성 확인 우선**: 원시계열을 시각화하여 추세·계절성을 육안 확인 후, ADF 검정으로 정상성을 통계적으로 검증.<br>2. **비정상 시 차분 후 ACF/PACF 재분석**: 비정상 판정 시 d차 차분을 적용해 정상화한 뒤 ACF/PACF 패턴으로 p, q 후보를 결정.<br>3. **AIC/BIC 비교와 잔차 백색잡음 검정으로 모형 확정**: 복수 후보 모형을 AIC/BIC로 비교해 최적 모형을 선정하고, 잔차가 백색잡음(자기상관 없음)인지 최종 검정하여 모형 적합성을 확인. |
