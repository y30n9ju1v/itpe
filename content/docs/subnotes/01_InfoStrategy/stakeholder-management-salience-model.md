# 이해관계자 관리 절차와 현저성 모델(Salience Model) 서브노트

> **두음 머리에 박기 🧠**
> - **식·분·계·관·감** (PMBOK 이해관계자 관리 절차: **식**별 ➔ **분**석 ➔ 참여**계**획 ➔ 참여**관**리 ➔ **감**시)
> - **권·정·긴** (Salience Model 3속성: **권**력 Power, **정**당성 Legitimacy, **긴**급성 Urgency)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **프로젝트 이해관계자 관리(Stakeholder Management)와 현저성 모델(Salience Model)** |
| **정의** | 이해관계자 관리는 프로젝트에 영향을 미치거나 영향을 받는 개인·집단·조직을 식별하고 그들의 기대와 영향력을 분석하여 효과적인 참여 전략을 수립·실행·감시하는 PMBOK 프로세스이며, Salience Model은 이해관계자가 지닌 권력(Power)·정당성(Legitimacy)·긴급성(Urgency) 3속성의 보유 여부와 조합에 따라 이해관계자의 현저성(주목해야 할 정도)을 판별하는 3차원 분류 모델이다 |
| **키워드** | PMBOK 이해관계자 관리, Power-Interest Grid, 권·정·긴 3속성, 8가지 이해관계자 유형 |
| **개념도** | `[ 식별 ] ➔ [ 분석(Power-Interest Grid / Salience Model) ] ➔ [ 참여계획 ] ➔ [ 참여관리 ] ➔ [ 감시 ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`     권력(Power) ∩ 정당성(Legitimacy) ∩ 긴급성(Urgency) = 확정적(Definitive, 3속성 모두 보유, 최우선)`<br>`     3속성 중 1개만 보유 = 잠재적/재량적/요구적 (관리 우선순위 낮음)`<br>`     3속성 중 2개 보유 = 지배적/위험한/의존적 (관리 우선순위 중간)` |
| **구성요소** | **이해관계자 관리 절차(식·분·계·관·감)**: 식별(모든 이해관계자 목록화)→분석(영향력·기대 분석)→참여계획 수립→참여관리(실행)→감시(모니터링)<br>**Salience Model 3속성(권·정·긴)**: 권력(Power, 의지를 강제할 능력), 정당성(Legitimacy, 요구의 사회적·법적 타당성), 긴급성(Urgency, 즉각 대응 요하는 시간적 민감성)<br>**8가지 이해관계자 유형**: ①잠재적(Dormant, 권력만) ②재량적(Discretionary, 정당성만) ③요구적(Demanding, 긴급성만) ④지배적(Dominant, 권력+정당성) ⑤위험한(Dangerous, 권력+긴급성) ⑥의존적(Dependent, 정당성+긴급성) ⑦확정적(Definitive, 3속성 모두, 최우선 관리) ⓪비이해관계자(속성 없음) |
| **비교** | **Power-Interest Grid**<br>- 분석축: 권력, 관심도(2차원)<br>- 성격: 정태적(고정 매트릭스)<br>- 강점: 직관적, 적용 간편<br>- 약점: 정당성 없는 이해관계자의 위험성을 놓칠 수 있음<br>- 적합상황: 소규모·단기 프로젝트<br><br>**Salience Model**<br>- 분석축: 권력, 정당성, 긴급성(3차원)<br>- 성격: 동태적(속성 변화에 따라 유형 이동)<br>- 강점: 정당성·시급성까지 반영한 정교한 우선순위화<br>- 약점: 3속성 판단 기준의 주관성<br>- 적합상황: 다수 이해관계자·이해상충이 큰 대규모/공공 프로젝트 |
| **차별화** | **대규모 공공 프로젝트의 이해관계자 동적 관리 전략**<br>1. **속성 변화 모니터링을 통한 유형 재분류**: 이해관계자의 권력·정당성·긴급성은 프로젝트 진행 중 변화하므로(예: 재량적→위험한 유형으로 이동), 정기적으로 Salience 속성을 재평가해 참여전략을 갱신.<br>2. **위험한(Dangerous) 유형의 선제적 리스크 관리**: 정당성 없이 권력과 긴급성만 보유한 이해관계자(예: 정치적 압력)는 법적·절차적 대응 준비를 사전에 갖춰 리스크를 관리.<br>3. **확정적(Definitive) 유형에 집중된 자원 배분**: 제한된 PM 리소스를 3속성을 모두 보유한 확정적 이해관계자에게 우선 배분하고, 잠재적·재량적 유형은 최소 대응으로 효율화. |
