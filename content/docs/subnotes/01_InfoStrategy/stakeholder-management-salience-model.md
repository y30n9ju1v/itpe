# 이해관계자 관리 절차와 현저성 모델(Salience Model) 서브노트

> **두음 머리에 박기 🧠**
> - **식·분·계·관·감** (PMBOK 이해관계자 관리 절차: **식**별 ➔ **분**석 ➔ 참여**계**획 ➔ 참여**관**리 ➔ **감**시)
> - **권·정·긴** (Salience Model 3속성: **권**력 Power, **정**당성 Legitimacy, **긴**급성 Urgency)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **프로젝트 이해관계자 관리(Stakeholder Management)와 현저성 모델(Salience Model)** |
| **정의** | 이해관계자 관리 = 프로젝트 영향을 주고받는 개인·집단·조직 식별 → 기대·영향력 분석 → 참여전략 수립·실행·감시하는 PMBOK 프로세스 / Salience Model = 권력(Power)·정당성(Legitimacy)·긴급성(Urgency) 3속성 보유조합으로 이해관계자 현저성(주목도) 판별하는 3차원 분류모델 |
| **키워드** | PMBOK 이해관계자 관리, Power-Interest Grid, 권·정·긴 3속성, 8가지 이해관계자 유형 |
| **개념도** | `[ 식별 ] ➔ [ 분석(Power-Interest Grid / Salience Model) ] ➔ [ 참여계획 ] ➔ [ 참여관리 ] ➔ [ 감시 ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`     권력(Power) ∩ 정당성(Legitimacy) ∩ 긴급성(Urgency) = 확정적(Definitive, 3속성 모두 보유, 최우선)`<br>`     3속성 중 1개만 보유 = 잠재적/재량적/요구적 (관리 우선순위 낮음)`<br>`     3속성 중 2개 보유 = 지배적/위험한/의존적 (관리 우선순위 중간)` |
| **구성요소** | **이해관계자 관리 절차(식·분·계·관·감)**: 식별(전체 목록화)→분석(영향력·기대 분석)→참여계획 수립→참여관리(실행)→감시(모니터링)<br>**Salience Model 3속성(권·정·긴)**: 권력(Power, 의지 강제능력), 정당성(Legitimacy, 요구의 사회적·법적 타당성), 긴급성(Urgency, 즉각대응 요하는 시간적 민감성)<br>**8가지 이해관계자 유형**: ①잠재적(Dormant, 권력만) ②재량적(Discretionary, 정당성만) ③요구적(Demanding, 긴급성만) ④지배적(Dominant, 권력+정당성) ⑤위험한(Dangerous, 권력+긴급성) ⑥의존적(Dependent, 정당성+긴급성) ⑦확정적(Definitive, 3속성 모두, 최우선관리) ⓪비이해관계자(속성 없음) |
| **비교** | **Power-Interest Grid**<br>- 분석축: 권력, 관심도(2차원)<br>- 성격: 정태적(고정 매트릭스)<br>- 강점: 직관적, 적용간편<br>- 약점: 정당성 없는 이해관계자 위험성 누락 가능<br>- 적합상황: 소규모·단기 프로젝트<br><br>**Salience Model**<br>- 분석축: 권력, 정당성, 긴급성(3차원)<br>- 성격: 동태적(속성변화 따라 유형이동)<br>- 강점: 정당성·시급성 반영한 정교한 우선순위화<br>- 약점: 3속성 판단기준의 주관성<br>- 적합상황: 다수 이해관계자·이해상충 큰 대규모/공공 프로젝트 |
| **차별화** | **대규모 공공 프로젝트의 이해관계자 동적 관리 전략**<br>1. **속성변화 모니터링 → 유형 재분류**: 권력·정당성·긴급성은 진행중 변화(예: 재량적→위험한 이동) → 정기적 Salience 재평가 → 참여전략 갱신<br>2. **위험한(Dangerous) 유형 선제적 리스크 관리**: 정당성 없이 권력+긴급성만 보유(예: 정치적 압력) → 법적·절차적 대응 사전준비<br>3. **확정적(Definitive) 유형 집중 자원배분**: 3속성 모두 보유한 확정적 이해관계자에 PM리소스 우선배분, 잠재적·재량적은 최소대응으로 효율화 |
