# IT 감리 및 PMO 서브노트

> **두음 머리에 박기 🧠**
> - **예·대·비** (공공 정보화 의무 감리 대상 사업: **예**산 5억 이상 구축, **대**국민 서비스 관련, **비**효율 우려 사업)
> - **예·현·시** (감리 수행 3단계 절차: **예**비조사 ➔ **현**장감리 ➔ **시**정조치 확인)
> - **지·통·지** (PMO의 3가지 유형: **지**원형 Supportive, **통**제형 Controlling, **지**시형 Directive)

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **정보시스템 감리 (IT Audit) 및 사업관리조직 (PMO)** |
| **정의** | 전자정부법 근거 독립적 제3자 시각 정보화사업 효율성/안전성 평가 **IT 감리** + 발주처 관점 프로젝트관리 상시 지원·통제 **PMO 조직** |
| **키워드** | 전자정부법, 의무감리(예대비), 예·현·시, PMO(지·통·지), 상주감리, 클라우드 감리 가이드라인 |
| **개념도** | `[ 발주기관 (Client) ] ────── 사업 대행 및 관리 위임 ──────➔ [ PMO 조직 (지·통·지) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`│&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;│`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼ 제3자 독립 감사 의뢰&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;▼ (상시 의사소통 및 위험 공조)`<br>`[ 감리 법인 (예·현·시) ] ──── 개선 권고 요구 ───➔ [ 프로젝트 수행팀 (SI) ] ── (상주감리 모니터링)` |
| **구성요소** | 1. **의무 감리 대상 (예·대·비)**: 5억 원 이상 구축(예), 대국민 서비스(대), 국가재정 효율화 필요사업(비)<br>2. **감리 3단계**: 예비조사(계획수립) → 현장감리(인스펙션·감리보고서 제출) → 시정조치 확인(조치여부 검토)<br>3. **PMO(전자정부사업관리위탁)**: 발주기관 관리전문성 부족 보완 → 전문기관 위탁. 자원배분·일정/품질/원가관리·위험관리·이해관계자소통·산출물검토 대행<br>4. **상주 감리(Resident Audit)**: 대형 고위험 프로젝트 → 감리원 상주, 실시간 위험 밀착통제<br>5. **법적 근거**: 전자정부법 제57조(감리 의무화) + SW진흥법 제48조(감리법인등록·감리원자격) / **PMO 대상: 추정가격 20억 이상**(시행령) 또는 전략적중요도·복잡도 높은 사업<br>6. **현장감리 6대 절차**: ①사전준비(점검항목확정) ②개시회의(Kick-off) ③현장점검(산출물검토·인터뷰·시연) ④문제점확인·협의(소명청취) ⑤종료회의(개선권고 발표) ⑥감리보고서 작성 → 착수-중간(1·2차)-종료감리 매핑<br>7. **전수점검 한계·개선**: 위험기반 표본조사 원칙이나 전수조사 요구시 형식적 점검 우려 → **문서검토확인**(수행사 체크리스트 사전제출, 감리는 정합성 재검증) + **제3자검증**(독립 QA팀 사전검증, 감리는 신뢰성 재확인)<br>8. **감리 프레임워크 V3.0**: 구조적/정보공학모델 → SDLC 단계경계 고정 감리시점, DFD/ERD 정합성·추적성 중심 / 객체지향/컴포넌트모델 → 반복주기별 유동적 감리시점, 아키텍처일관성·인터페이스계약 중심 (리스크: 요구사항누락 vs 아키텍처표류) |
| **비교** | **정보시스템 감리 (Audit)**<br>- 관점/위치: 제3자 독립관점 / 외부 독립조직<br>- 수행방식: 주기적/사후적 진단(3단계 핵심시점)<br>- 법적근거: 전자정부법 제57조 + SW진흥법 제48조 (강제성)<br><br>**PMO (사업관리조직)**<br>- 관점/위치: 발주처·사업자 동반관점 / 프로젝트 내부조직<br>- 수행방식: 상시적/지속적 위험관리·의사결정<br>- 법적근거: 전자정부법 시행령, 추정가격 20억 이상 |
| **차별화** | **PMO+상주감리 병행 R&R 정립 및 클라우드 감리 전략**<br>1. **R&R 갈등방지 RACI 구축**: PMO는 '해결·대책실행(Action)' 집중, 상주감리는 '독립성·아키텍처정합성 검증(Verification)' 역할 → 영역갈등 예방<br>2. **클라우드/MSA 감리 관점전환**: 종이문서 감리 지양 → IaC 설정파일 분석, 공동책임모델(Shared Responsibility) 기반 CSP↔사용자 책임분할 적합성, CI/CD 자동 취약점진단 여부 중점 프레임워크화<br>3. **상주감리 기반 기민한 위험통제**: 애자일(주단위 릴리즈) → 3단계 정기감리 무력화 → 상주감리원 매 스프린트 데모·인수 직접입회, 시정요구 백로그 즉시피드백 |
