# 프로세스 혁신 BPR과 PI의 비교 서브노트

> **두음 머리에 박기 🧠**
> - **급·전·핵** (BPR 3대 특징: **급**진적 재설계, **전**사적 범위, IT는 **핵**심 전제조건)
> - **점·부·지** (PI 3대 특징: **점**진적·지속적 개선, **부**문별 확대, IT는 **지**원 도구)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **업무재설계(BPR, Business Process Reengineering)와 프로세스 혁신(PI, Process Innovation)** |
| **정의** | BPR: 비용·품질·서비스·속도 등 핵심성과 극적개선 위해 업무프로세스 근본재고·급진재설계 경영혁신기법(Michael Hammer, 1990) / PI: IT활용 기존프로세스 문제점 지속적·전사적 개선 → 경영성과 향상 활동(Thomas Davenport, 1993) |
| **키워드** | 급진적 재설계(Radical), 점진적 개선(Continuous), Zero-base, IT Enabler, 조직 저항 |
| **개념도** | `[ 기존 프로세스 ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;`├──➔ [ BPR: 전사 핵심 프로세스 Zero-base 재설계 ] ── 급진적·단기집중 ──➔ [ 신규 프로세스 ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;`└──➔ [ PI: 부문별 프로세스 점진 개선 ] ── 지속적·단계적 ──➔ [ 개선된 프로세스 ]` |
| **구성요소** | **BPR(급·전·핵)**: ①급진적(Radical) 혁신속도, 단기집중 ②전사적 범위, 핵심프로세스 전면재설계 ③IT는 재설계 가능케 하는 필수전제조건(Enabler), 조직저항 실패율 50~70%<br>**PI(점·부·지)**: ①점진적(Continuous)·단계적 혁신속도 ②부문별 프로세스에서 시작 → 확대가능 ③IT는 개선지원 도구, 낮은 위험·높은 조직수용성 |
| **비교** | **BPR (Michael Hammer)**<br>- 혁신강도: 급진적, 전면재설계(Zero-base)<br>- 접근범위: 전사 핵심프로세스<br>- IT위치: 재설계 가능케 하는 전제조건<br>- 조직변화: 조직구조·인력 대규모 재편<br>- 적용상황: 근본적 위기, 경쟁력상실 상황<br><br>**PI (Thomas Davenport)**<br>- 혁신강도: 점진적·지속적 개선<br>- 접근범위: 개별/부문 프로세스에서 확대<br>- IT위치: 개선지원 도구<br>- 조직변화: 유연한 조직적응<br>- 적용상황: 지속적 경쟁우위 확보 목표 |
| **차별화** | **디지털전환(DX) 환경 BPR·PI 선택적 적용전략**<br>1. **위기진단에 따른 방식선택**: 시장지위 급락·근본적 경쟁력상실 → BPR Zero-base 재설계 / 안정적 성장기 → PI 점진개선, 상황판단 기준수립<br>2. **BPR 실패위험 완화 하이브리드**: BPR 급진성 조직저항 유발 → 핵심프로세스만 BPR, 주변은 PI 병행<br>3. **애자일 시대 PI 재해석**: 클라우드·MSA 환경 → CI/CD가 PI 실행도구화, 개선주기 스프린트 단위 단축 |
