# 프로세스 혁신 BPR과 PI의 비교 서브노트

> **두음 머리에 박기 🧠**
> - **급·전·핵** (BPR 3대 특징: **급**진적 재설계, **전**사적 범위, IT는 **핵**심 전제조건)
> - **점·부·지** (PI 3대 특징: **점**진적·지속적 개선, **부**문별 확대, IT는 **지**원 도구)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **업무재설계(BPR, Business Process Reengineering)와 프로세스 혁신(PI, Process Innovation)** |
| **정의** | BPR은 비용·품질·서비스·속도 등 핵심 성과 측정치에서 극적인 개선을 이루기 위해 업무 프로세스를 근본적으로 재고하고 급진적으로 재설계하는 경영혁신 기법(Michael Hammer, 1990)이며, PI는 정보기술을 활용하여 기존 프로세스의 문제점을 지속적·전사적으로 개선함으로써 경영 성과를 향상시키는 프로세스 혁신 활동(Thomas Davenport, 1993)이다 |
| **키워드** | 급진적 재설계(Radical), 점진적 개선(Continuous), Zero-base, IT Enabler, 조직 저항 |
| **개념도** | `[ 기존 프로세스 ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;`├──➔ [ BPR: 전사 핵심 프로세스 Zero-base 재설계 ] ── 급진적·단기집중 ──➔ [ 신규 프로세스 ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;`└──➔ [ PI: 부문별 프로세스 점진 개선 ] ── 지속적·단계적 ──➔ [ 개선된 프로세스 ]` |
| **구성요소** | **BPR(급·전·핵)**: ①급진적(Radical) 혁신 속도, 단기간 집중 ②전사적 범위, 핵심 프로세스 전면 재설계 ③IT는 재설계를 가능케 하는 필수 전제조건(Enabler), 조직 저항으로 실패율 50~70% 보고<br>**PI(점·부·지)**: ①점진적(Continuous)·단계적 혁신 속도 ②부문별 프로세스에서 시작해 확대 가능 ③IT는 개선을 지원하는 도구, 상대적으로 낮은 위험과 높은 조직 수용성 |
| **비교** | **BPR (Michael Hammer)**<br>- 혁신 강도: 급진적, 전면 재설계(Zero-base)<br>- 접근 범위: 전사 핵심 프로세스<br>- IT의 위치: 재설계를 가능케 하는 전제조건<br>- 조직 변화: 조직구조·인력 대규모 재편 수반<br>- 적용 상황: 근본적 위기, 경쟁력 상실 상황<br><br>**PI (Thomas Davenport)**<br>- 혁신 강도: 점진적·지속적 개선<br>- 접근 범위: 개별/부문 프로세스에서 확대<br>- IT의 위치: 개선을 지원하는 도구<br>- 조직 변화: 상대적으로 유연한 조직 적응<br>- 적용 상황: 지속적 경쟁우위 확보가 목표 |
| **차별화** | **디지털 전환(DX) 환경에서 BPR·PI 선택적 적용 전략**<br>1. **위기 진단에 따른 방식 선택**: 시장 지위 급락·근본적 경쟁력 상실 상황에서는 BPR로 Zero-base 재설계를, 안정적 성장기에는 PI로 점진적 개선을 선택하는 상황 판단 기준 수립.<br>2. **BPR 실패 위험 완화를 위한 하이브리드 접근**: BPR의 급진성이 조직 저항을 유발하는 점을 고려해, 핵심 프로세스는 BPR로 재설계하되 주변 프로세스는 PI로 점진 개선하는 병행 전략 적용.<br>3. **애자일 시대의 PI 재해석**: 클라우드·MSA 환경에서는 지속적 배포(CI/CD)가 곧 PI의 실행 도구가 되어, 프로세스 개선 주기를 스프린트 단위로 단축하는 방식으로 PI 개념이 진화. |
