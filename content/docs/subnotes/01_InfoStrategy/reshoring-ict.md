# 리쇼어링과 제조업 혁신을 위한 ICT 활용 서브노트

> **두음 머리에 박기 🧠**
> - **인·부·환** (리쇼어링 실패 3대 원인: **인**건비 격차, **부**지비 격차, **환**경 대비 세제혜택 미흡)
> - **스·디·로** (제조업 혁신 ICT 3요소: **스**마트팩토리, **디**지털트윈, **로**봇/자동화)

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **리쇼어링(Reshoring)과 제조업 혁신을 위한 ICT 활용** |
| **정의** | 리쇼어링 = 생산비 절감 위해 해외이전했던 자국기업 생산시설·기능의 본국 회귀 (오프쇼어링 반대개념) → 코로나19發 GVC 취약성·경제안보 요구로 각국 전략추진 → 인건비 열위 상쇄 위해 스마트팩토리·디지털트윈 등 ICT 활용이 핵심 성공요건 |
| **키워드** | 오프쇼어링의 반대, 유턴법, GVC 취약성, 스마트팩토리, 제조업 혁신형 리쇼어링 |
| **개념도** | `[ 해외 이전 생산시설 ] ──인건비 상승/GVC 리스크──➔ [ 리쇼어링 결정 ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[ 국내 복귀 ] ──인건비 열위 상쇄(스·디·로)──➔ [ 제조업 혁신형 리쇼어링 ]` |
| **구성요소** | **리쇼어링 개념/배경**: 오프쇼어링 반대 → 2013년 유턴법 제정에도 실적 저조 → 코로나19發 GVC 취약성 노출 후 정책 격상<br>**과거 실패 원인**: 세제혜택 중심 지원 → 인건비·부지비 격차 극복 실패<br>**ICT 활용 방안(스·디·로)**: 스마트팩토리(생산공정 자동화·데이터 최적화), 디지털트윈(가상 시뮬레이션 생산라인 설계), 로봇/자동화(인건비 열위 상쇄)<br>**정책적 시사점**: 세제혜택 넘어 ICT 인프라 지원·인력 재교육 포괄하는 종합 지원체계 필요 |
| **비교** | **과거(2013년 유턴법)**<br>- 지원수단: 세제혜택 중심<br>- 결과: 인건비·부지비 격차 극복실패 → 실적저조<br><br>**최근(제조업 혁신형 리쇼어링)**<br>- 지원수단: ICT 기술(스마트팩토리) 결합<br>- 접근: 인건비 격차 → 자동화·생산성으로 상쇄 전략전환 |
| **차별화** | **ICT 기반 리쇼어링 실효성 제고 전략**<br>1. **스마트팩토리 투자-정책 지원 연계**: 세제혜택 넘어 구축비용 직접보조금·저리융자 결합 → 초기 자동화투자 부담 완화<br>2. **디지털트윈 기반 사전 타당성 검증**: 결정 전 국내복귀 생산라인 시뮬레이션 → 인건비 절감효과 정량검증 후 투자확정<br>3. **첨단산업 우선 리쇼어링**: 반도체·이차전지 등 전략산업 우선유도 → 경제안보·산업고도화 동시달성 |
