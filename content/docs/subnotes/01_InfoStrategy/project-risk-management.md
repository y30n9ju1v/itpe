# 프로젝트 위험관리 (PMBOK 위험관리 프로세스) 서브노트

> **두음 머리에 박기 🧠**
> - **계·식·정정·대·감** (PMBOK 위험관리 6단계: 위험관리 **계**획, 위험 **식**별, **정**성적 위험분석, **정**량적 위험분석, 위험 **대**응계획, 위험 감시·통제)
> - **회·전·완·수** (위협(Threat) 대응 4대 전략: **회**피 Avoid, **전**가 Transfer, **완**화 Mitigate, **수**용 Accept)
> - **활·공·강·수** (기회(Opportunity) 대응 4대 전략: **활**용 Exploit, **공**유 Share, **강**화 Enhance, **수**용 Accept)

| **토픽명** | **프로젝트 위험관리 (Project Risk Management, PMBOK)** |
| **정의** | 프로젝트 목표에 영향 미치는 불확실 사건·조건 → 체계적 식별·분석·대응 프로세스, PMI PMBOK **6개 프로세스(계·식·정정·대·감)**로 구성, 위협(Threat)·기회(Opportunity) 구분해 대응전략 차등 적용 |
| **키워드** | 위험관리 6단계, 정성적/정량적 위험분석, 위협 대응(회·전·완·수), 기회 대응(활·공·강·수), 위험 등록부(Risk Register) |
| **개념도** | `[ 1.위험관리계획 ] ➔ [ 2.위험식별 ] ➔ [ 3.정성적분석(P×I 매트릭스) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[ 6.위험 감시·통제 ] ◀── [ 5.위험 대응계획(회·전·완·수 / 활·공·강·수) ] ◀── [ 4.정량적분석(몬테카를로) ]` |
| **구성요소** | 1. **위험관리 계획**: 관리 접근법·활동 정의 → 위험 등록부 양식 수립<br>2. **위험 식별**: 브레인스토밍·체크리스트·SWOT → 위험 도출<br>3. **정성적 위험 분석**: 확률·영향 개별평가 → 확률-영향 매트릭스(고/중/저) → 데이터품질평가·RBS 카테고리 분석 → 신속 우선순위화<br>4. **정량적 위험 분석**: EMV(의사결정나무)·민감도분석(토네이도)·몬테카를로(S-Curve)·PERT 3점추정((O+4M+P)/6) → 고위험군 정밀 계량화<br>5. **위험 대응 계획**: 회피·전가·완화·수용(위협) / 활용·공유·강화·수용(기회) 전략 수립<br>6. **위험 감시·통제**: 잔존위험 모니터링 → 신규위험 식별<br>7. **위험 등록부(Risk Register)**: ID·확률·영향도·위험점수(P×I)·대응전략·담당자(Owner)·잔존위험 기록 핵심 산출물<br>8. **Boehm의 10대 위험(1991)**: ①인력부족 ②비현실적 일정·예산 ③잘못된 기능개발 ④잘못된 UI ⑤도금(Gold Plating) ⑥요구사항 지속변경 ⑦외부공급 컴포넌트결함 ⑧외부수행 작업결함 ⑨실시간 성능문제 ⑩컴퓨터과학 한계도전<br>9. **위험 vs 이슈**: 위험=발생불확실 미래사건(사전/Proactive, 확률×영향 정량평가, Risk Register) / 이슈=발생확정 현재문제(사후/Reactive, 즉시조치·담당자배정, Issue Log) → 조기경보지표 임계치 초과 시 이슈로 자동승격(Escalation) |
| **비교** | **위협(Threat) 대응 전략**<br>- 회피(Avoid): 위험원인 제거 (일정변경·범위축소)<br>- 전가(Transfer): 보험·계약 → 제3자 이전<br>- 완화(Mitigate): 확률·영향도 감소 (프로토타입·추가테스트)<br>- 수용(Accept): 능동적(예비비)/수동적(발생시 대응)<br><br>**기회(Opportunity) 대응 전략**<br>- 활용(Exploit): 기회실현 확정화 (우수인력 배치)<br>- 공유(Share): 파트너와 기회 공동추구 (조인트벤처)<br>- 강화(Enhance): 발생확률·영향도 증가<br>- 수용(Accept): 별도조치 없이 발생시 혜택수용 |
| **차별화** | **위험 대응 실행력 확보를 위한 실무 전략**<br>1. **Risk Owner 명시 지정**: 담당자 미지정 시 대응전략 문서화에 그침 → 식별 즉시 담당자·대응시한 확정<br>2. **정성→정량 단계적 적용**: 전건 몬테카를로 적용 시 비용과다 → P×I 매트릭스로 상위위험 선별 후 정량분석하는 2단계 필터링<br>3. **잔존·2차 위험 추적 체계화**: 대응 후 잔존위험(Residual)·대응유발 2차위험(Secondary) → 등록부 별도컬럼 관리 → 감시·통제 단계 누락방지 |
