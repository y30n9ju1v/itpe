# IT 프로젝트/프로그램/포트폴리오 관리와 PMBOK 프로세스 서브노트

> **두음 머리에 박기 🧠**
> - **착·기·실·감·종** (PMBOK 5대 프로세스 그룹: **착**수 Initiating, **기**획 Planning, **실**행 Executing, **감**시·통제 Monitoring&Controlling, **종**료 Closing)
> - **통·범·일·비·품·자·의·위·조·이** (PMBOK 10대 지식 영역: **통**합, **범**위, **일**정, **비**용, **품**질, **자**원, **의**사소통, **위**험, **조**달, **이**해관계자)
> - **프·프·포** (관리 3계층: **프**로젝트관리, **프**로그램관리, **포**트폴리오관리)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **IT 프로젝트 관리 (PMBOK) 및 프로젝트·프로그램·포트폴리오 3계층 관리 체계** |
| **정의** | IT 프로젝트 관리 → 범위·일정·비용·품질·자원·위험 계획·실행·통제 (PMBOK **5대 프로세스(착·기·실·감·종) × 10대 지식영역(통·범·일·비·품·자·의·위·조·이)**) → 단일 프로젝트/연관 프로젝트군/전략적 투자묶음의 **3계층(프로젝트-프로그램-포트폴리오)** 구조 |
| **키워드** | PMBOK, 5대 프로세스 그룹, 10대 지식 영역, 프로젝트/프로그램/포트폴리오, PM/PgM/PMO, EVM |
| **개념도** | `[ 착수 Initiating ] ➔ [ 기획 Planning ] ➔ [ 실행 Executing ] ⇄ [ 감시·통제 M&C ] ➔ [ 종료 Closing ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;`프로젝트 헌장 승인    WBS·일정·비용·위험계획   팀관리·품질보증·의사소통   실적추적·EVM분석·변경통제   인수인계·교훈문서화`<br>`──────────────────────────────────────────────────────────────────`<br>`[ 포트폴리오 관리 (PMO·경영진) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;`└── [ 프로그램 관리 (PgM) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`└── [ 프로젝트 관리 (PM) ] × N개` |
| **구성요소** | 1. **착수(Initiating)**: 프로젝트 헌장 승인 → 이해관계자 식별<br>2. **기획(Planning)**: WBS 작성 → 일정·비용·위험 계획 수립<br>3. **실행(Executing)**: 팀 관리·품질 보증·의사소통<br>4. **감시·통제(M&C)**: 실적 추적 → 변경 통제 → EVM 분석<br>5. **종료(Closing)**: 인수·인계 → 교훈 문서화 → 계약 종료<br>6. **10대 지식 영역**: 통합·범위·일정·비용·품질·자원·의사소통·위험·조달·이해관계자 (PMBOK 7판→성과 도메인 중심 전환) |
| **비교** | **프로젝트 관리 (PM)**<br>- 범위: 단일 프로젝트<br>- 목표: 산출물 납기·예산 준수<br>- 기간: 한시적(Temporary)<br>- 초점: 실행 효율성<br><br>**포트폴리오 관리 (PMO·경영진)**<br>- 범위: 전략적 투자 묶음<br>- 목표: ROI·우선순위 → 전략 목표 극대화<br>- 기간: 지속적<br>- 초점: 상호의존성 조율(프로그램)·투자 우선순위 결정(포트폴리오) — PgM은 프로젝트 군 시너지·편익 실현 담당하는 중간 계층 |
| **차별화** | **3계층 거버넌스와 감사·PMO 연계 실무 전략**<br>1. **계층별 KPI 분리**: 프로젝트→EVM(SV/CV) 일정·비용 준수율 / 프로그램→시너지·자원재배분 효율 / 포트폴리오→ROI·전략정렬도 → 상위계층의 실행 세부매몰 방지<br>2. **PMO 전 구간 개입**: 착수 헌장검토~종료 교훈자산화까지 5대 프로세스 전구간 표준템플릿·게이트리뷰 → 관리성숙도 일관유지<br>3. **IT 감리와 역할분담**: PMO=상시 지원·통제조직 vs IT감리=제3자 특정시점 효율성·안전성 점검 → 이해상충 방지 |
