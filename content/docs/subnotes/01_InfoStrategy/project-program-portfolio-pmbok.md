# IT 프로젝트/프로그램/포트폴리오 관리와 PMBOK 프로세스 서브노트

> **두음 머리에 박기 🧠**
> - **착·기·실·감·종** (PMBOK 5대 프로세스 그룹: **착**수 Initiating, **기**획 Planning, **실**행 Executing, **감**시·통제 Monitoring&Controlling, **종**료 Closing)
> - **통·범·일·비·품·자·의·위·조·이** (PMBOK 10대 지식 영역: **통**합, **범**위, **일**정, **비**용, **품**질, **자**원, **의**사소통, **위**험, **조**달, **이**해관계자)
> - **프·프·포** (관리 3계층: **프**로젝트관리, **프**로그램관리, **포**트폴리오관리)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **IT 프로젝트 관리 (PMBOK) 및 프로젝트·프로그램·포트폴리오 3계층 관리 체계** |
| **정의** | IT 프로젝트 관리는 정보기술 프로젝트의 목표 달성을 위해 범위·일정·비용·품질·자원·위험을 계획·실행·통제하는 체계적 활동으로, PMBOK의 **5대 프로세스 그룹(착·기·실·감·종) × 10대 지식 영역(통·범·일·비·품·자·의·위·조·이)** 체계를 따르며, 관리 범위에 따라 단일 프로젝트(프로젝트관리)-연관 프로젝트군(프로그램관리)-전략적 투자묶음(포트폴리오관리)의 **3계층 구조**로 확장된다 |
| **키워드** | PMBOK, 5대 프로세스 그룹, 10대 지식 영역, 프로젝트/프로그램/포트폴리오, PM/PgM/PMO, EVM |
| **개념도** | `[ 착수 Initiating ] ➔ [ 기획 Planning ] ➔ [ 실행 Executing ] ⇄ [ 감시·통제 M&C ] ➔ [ 종료 Closing ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;`프로젝트 헌장 승인    WBS·일정·비용·위험계획   팀관리·품질보증·의사소통   실적추적·EVM분석·변경통제   인수인계·교훈문서화`<br>`──────────────────────────────────────────────────────────────────`<br>`[ 포트폴리오 관리 (PMO·경영진) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;`└── [ 프로그램 관리 (PgM) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`└── [ 프로젝트 관리 (PM) ] × N개` |
| **구성요소** | 1. **착수(Initiating)**: 프로젝트 헌장 승인, 이해관계자 식별<br>2. **기획(Planning)**: WBS 작성, 일정·비용·위험 계획 수립<br>3. **실행(Executing)**: 팀 관리, 품질 보증, 의사소통<br>4. **감시·통제(M&C)**: 실적 추적, 변경 통제, EVM 분석<br>5. **종료(Closing)**: 인수·인계, 교훈 문서화, 계약 종료<br>6. **10대 지식 영역**: 통합·범위·일정·비용·품질·자원·의사소통·위험·조달·이해관계자 관리 (PMBOK 7판은 성과 도메인 중심으로 전환) |
| **비교** | **프로젝트 관리 (PM)**<br>- **범위**: 단일 프로젝트<br>- **목표**: 산출물 납기·예산 준수<br>- **기간**: 한시적(Temporary)<br>- **관리 초점**: 실행 효율성<br><br>**포트폴리오 관리 (PMO·경영진)**<br>- **범위**: 전략적 투자 묶음<br>- **목표**: ROI·우선순위 결정을 통한 전략 목표 달성 극대화<br>- **기간**: 지속적<br>- **관리 초점**: 상호의존성 조율(프로그램) 및 투자 우선순위 결정(포트폴리오) — 프로그램관리(PgM)는 연관 프로젝트 군의 시너지·편익 실현을 담당하는 중간 계층 |
| **차별화** | **3계층 거버넌스와 감사·PMO 연계 실무 전략**<br>1. **계층별 KPI 분리 설계**: 프로젝트 단계는 EVM(SV/CV) 기반 일정·비용 준수율을, 프로그램 단계는 프로젝트 간 시너지·자원 재배분 효율을, 포트폴리오 단계는 ROI·전략 정렬도를 KPI로 분리하여 상위 계층이 하위 실행 세부사항에 매몰되지 않도록 통제.<br>2. **PMO의 프로세스 그룹 전 구간 개입**: PMO는 착수 단계의 헌장 검토부터 종료 단계의 교훈(Lessons Learned) 자산화까지 5대 프로세스 그룹 전 구간에 표준 템플릿·게이트 리뷰를 적용해 조직 전체의 프로젝트 관리 성숙도를 일관되게 유지.<br>3. **IT 감리와의 역할 분담**: PMO가 상시적 지원·통제 조직이라면, IT 감리는 독립된 제3자가 특정 시점에 사업의 효율성·안전성을 점검하는 것으로 역할을 구분하여 이해상충을 방지. |
