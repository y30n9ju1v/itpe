# 표본추출과 기술통계·추론통계 서브노트

> **두음 머리에 박기 🧠**
> - **단·층·계·집·유·판·할·편·눈** (표본추출 9대 기법: 확률적 **단**순임의·**층**화·**계**통·**집**락 추출 / 비확률적 **유**의·**판**단·**할**당·**편**의·**눈**덩이 추출)
> - **점·구** (추정 2대 유형: **점**추정(하나의 값) vs **구**추정(구간·신뢰수준))

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **표본추출(Sampling) 및 기술통계(Descriptive) vs 추론통계(Inferential Statistics)** |
| **정의** | 모집단으로부터 대표성 있는 표본을 추출하는 **표본추출 기법**과, 표본의 대푯값·산포·형태를 요약하는 **기술통계**, 표본 정보로 모집단을 추정·검정하는 **추론통계**(점추정·구간추정)를 아우르는 통계 분석의 기초 체계 |
| **키워드** | 확률적/비확률적 표본추출, 왜도(Skewness)·첨도(Kurtosis), 점추정·구간추정, IQR 이상치 탐지, 백분위(Percentile) |
| **개념도** | `[모집단] ──표본추출(확률적/비확률적)──➔ [표본] ──기술통계(요약)──➔ 대표값·산포·왜도·첨도`<br>`                                          │`<br>`                                     추론통계(모집단 추정)`<br>`                                          ├─➔ 점추정: θ̂ (하나의 값)`<br>`                                          └─➔ 구간추정: [하한, 상한] (신뢰수준 90/95/99%)`<br><br>`Outliers ←●●│◀──IQR──▶│●●→ Outliers`<br>`      (Q1-1.5·IQR)  Q1 Median Q3  (Q3+1.5·IQR)` |
| **구성요소** | 1. **확률적 표본추출**: 단순임의추출(모든 표본이 동일확률), 층화추출(층으로 나눈 후 각 층에서 임의추출), 계통추출(등간격 추출), 집락추출(군집 단위 추출 후 일부/전부 조사)<br>2. **비확률적 표본추출**: 유의추출, 판단추출, 할당추출, 편의추출, 눈덩이추출 — 조사원의 주관·편의에 의존, 표본오차 통제 어려움<br>3. **왜도(Skewness)**: 분포가 기울어진 방향·정도, S=0(좌우대칭), S>0(우측꼬리), S<0(좌측꼬리)<br>4. **첨도(Kurtosis)**: 분포의 뾰족한 정도, K=0(표준정규분포와 동일), K>0(뾰족함), K<0(납작함)<br>5. **점추정 vs 구간추정**: 점추정은 모수를 하나의 값(불편성·효율성·일치성 만족)으로, 구간추정은 신뢰구간·신뢰수준으로 불확실성까지 표현<br>6. **IQR 기반 이상치 탐지**: Inner fence(Q1-1.5IQR, Q3+1.5IQR) 밖은 Mild Outlier, Outer fence(Q1-3IQR, Q3+3IQR) 밖은 Extreme Outlier |
| **비교** | **기술통계 (Descriptive Statistics)**<br>- 정의: 표본의 대푯값·산포·빈도를 요약·도식화<br>- 활용기법: 평균, 최빈값, 범위, 표준편차<br><br>**추론통계 (Inferential Statistics)**<br>- 정의: 표본 정보로 모집단 특성을 추측<br>- 활용기법: 점추정, 구간추정, 가설검정, 차이검정<br><br>**점추정**<br>- 장점: 직관적 해석 / 단점: 신뢰성 정도 표현 불가<br><br>**구간추정**<br>- 장점: 신뢰수준으로 신뢰성 표현 가능 / 단점: 상대적으로 많은 표본 필요 |
| **차별화** | **표본설계·전처리 단계의 실무 적용**<br>1. **표본추출 기법 선택 기준**: 모집단이 이질적 하위그룹으로 구성되면 층화추출로 대표성을 확보하고, 지리적으로 분산된 대규모 모집단은 비용 효율을 위해 집락추출을, 모집단 명부가 없거나 특수집단(예: 특정 질환자) 조사 시에는 눈덩이추출을 사용.<br>2. **왜도·첨도를 활용한 정규성 사전진단**: 회귀분석·t검정 등 정규분포를 가정하는 기법 적용 전, 왜도·첨도로 데이터 분포 형태를 사전 진단하여 정규성 위반 시 로그변환·Box-Cox 변환 또는 비모수 검정으로 전환.<br>3. **Percentile 기반 IQR 이상치 탐지와 Z-score 병행**: IQR 방식은 분포 형태에 강건(Robust)하여 비정규 데이터에 적합하고, Z-score(평균±3σ) 방식은 정규분포 가정 시 유효하므로, 데이터 특성에 맞춰 두 기법을 병행 적용해 이상치 탐지 신뢰도를 높임. |
