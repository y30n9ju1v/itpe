# PCA와 LDA 차원축소 서브노트

> **두음 머리에 박기 🧠**
> - **PCA=비·분 / LDA=지·클** (**PCA**는 **비**지도학습으로 **분**산 최대화 축 탐색, **LDA**는 **지**도학습으로 **클**래스 분리 최대화)
> - **S(W)↓·S(B)↑** (LDA 최적화 기준: 클래스내 산포행렬 S(W)는 최소화, 클래스간 산포행렬 S(B)는 최대화)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **PCA(Principal Component Analysis)와 LDA(Linear Discriminant Analysis)** |
| **정의** | 고차원 데이터의 차원의 저주(Curse of Dimensionality)를 해결하기 위한 대표적 차원축소 기법으로, **PCA**는 클래스 정보 없이 데이터 분산이 최대가 되는 축을 찾는 비지도학습, **LDA**는 클래스 레이블을 활용해 클래스 간 분리를 최대화하는 축을 찾는 지도학습 |
| **키워드** | 고유값·고유벡터(Eigenvalue/Eigenvector), 공분산행렬, 클래스간/클래스내 산포행렬(S(B)/S(W)), 커널 PCA |
| **개념도** | `[원본 고차원 데이터]`<br>`   ├─ PCA(비지도) ──➔ 분산 최대 방향의 축으로 차원 축소 (클래스 정보 미사용)`<br>`   └─ LDA(지도)   ──➔ 클래스간분산(S(B))↑ / 클래스내분산(S(W))↓ 방향으로 차원 축소`<br>`                         │`<br>`                    [저차원 특성 공간]` |
| **구성요소** | 1. **PCA**: 공분산행렬을 고유값 분해하여 분산이 가장 큰 순서로 주성분(PC1, PC2...)을 추출, 데이터 압축·노이즈 제거·시각화에 활용<br>2. **LDA**: 클래스간 산포행렬(S(B))과 클래스내 산포행렬(S(W))을 구성 후 $S(W)^{-1}S(B)$의 고유벡터로 판별축(LD) 추출, 클래스 수-1개 이하로만 축소 가능<br>3. **분석절차(공통)**: ①데이터 정규화(평균0,분산1) → ②행렬 계산(공분산행렬 / 산포행렬) → ③고유값분해 → ④상위 k개 벡터로 투영<br>4. **PCA 변형 알고리즘**: 랜덤 PCA(대용량 근사), 점진적 PCA(미니배치), 커널 PCA(비선형 매핑) |
| **비교** | **PCA (Principal Component Analysis)**<br>- 학습 방식: 비지도학습, 레이블 미사용<br>- 목적: 데이터 분산 최대화<br>- 최적화 기준: 공분산행렬의 고유벡터<br>- 활용: 노이즈 제거, 시각화, 압축<br><br>**LDA (Linear Discriminant Analysis)**<br>- 학습 방식: 지도학습, 클래스 레이블 사용<br>- 목적: 클래스 분리 최대화<br>- 최적화 기준: $S(W)^{-1}S(B)$의 고유벡터<br>- 활용: 분류 전처리, 특성 추출 (클래스 수−1 이하로 축소 제한) |
| **차별화** | **실무 파이프라인 설계 시 PCA/LDA 선택 및 결합 전략**<br>1. **선택 기준**: 레이블이 있고 분류 성능 향상이 목적이면 LDA, 레이블이 없거나 압축·시각화·노이즈 제거가 목적이면 PCA를 선택.<br>2. **PCA+LDA 파이프라인**: 고차원 이미지 데이터(얼굴 인식 등)에서 먼저 PCA로 노이즈를 제거한 후 LDA로 클래스를 분리하는 하이브리드 접근이 실무에서 효과적.<br>3. **LDA 축소 제한 보완**: LDA는 클래스 수−1 차원까지만 축소 가능하므로, 클래스 수가 적을 때는 PCA로 보완하거나 커널 LDA(KLDA)를 검토. |
