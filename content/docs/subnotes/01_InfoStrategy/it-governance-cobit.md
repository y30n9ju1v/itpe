# IT 거버넌스 및 COBIT 서브노트

> **두음 머리에 박기 🧠**
> - **이·디·엠** (ISO 38500 거버넌스 3대 프로세스: 평가 **E**valuate ➔ 지시 **D**irect ➔ 모니터링 **M**onitor)
> - **아·바·디·엠** (COBIT 매니지먼트 4대 도메인: **A**PO 정렬/기획, **B**AI 구축/도입, **D**SS 운영/지원, **M**EA 평가/감사)
> - **전·가·리·자·수** (IT 거버넌스 5대 도메인: **전**략적 정렬, **가**치 전달, **리**스크 관리, **자**원 관리, **수**행 측정)

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **IT 거버넌스 (IT Governance) 및 COBIT 2019 프레임워크** |
| **정의** | 기업의 비즈니스 목표 달성을 위해 IT 투자를 통제하고 위험을 관리하며, IT와 비즈니스를 정렬하는 **의사결정 및 책임 프레임워크(IT 거버넌스)**와 이를 구현하는 글로벌 통제 아키텍처 **COBIT** |
| **키워드** | IT 거버넌스 5대 영역, ISO/IEC 38500 (EDM), COBIT 2019 (EDM/PBRM), Design Factors (디자인 요소) |
| **개념도** | `[ 주주 / 이해관계자 요구사항 ] ➔ 가치 증대 및 위험 관리 요구`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`│`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼ (평가 Evaluate)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`[ 거버넌스 (Governance - 이사회) ] ◀─── (모니터링 Monitor)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`│ (지시 Direct)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`[ 매니지먼트 (Management - 경영진) ] ➔ 실행 (Plan ➔ Build ➔ Run)` |
| **구성요소** | 1. **거버넌스 5대 영역 (전·가·리·자·수)**: 전략적정렬, 가치전달, 리스크관리, 자원관리, 수행측정<br>2. **ISO/IEC 38500**: 책책·전·획·성·준·인 6대 원칙 및 EDM(평가, 지시, 모니터링) 3대 프로세스 모델 제공<br>3. **COBIT 2019 거버넌스 영역 (EDM)**: 이사회 수준의 평가(Evaluate), 지시(Direct), 모니터링(Monitor) 목표<br>4. **COBIT 2019 매니지먼트 영역 (PBRM)**: APO(정렬/기획), BAI(구축/인수), DSS(운영/지원), MEA(측정/평가)<br>5. **디자인 요소 (Design Factors)**: 기업 전략, 리스크 프로필, 규제 등 거버넌스를 테일러링하기 위한 11개 요소<br>6. **효과 측정 지표 3분류**: 재무적 지표(IT ROI, IT비용비율, TCO, IT Value Realization), 운영 지표(시스템 가용성·SLA준수율, IT프로젝트 완수율, 변경 성공률, 보안사고 건수), 전략 정렬 지표(IT전략목표 달성율, 업무 자동화율)<br>7. **효과 측정 방법론**: BSC(재무·고객·내부프로세스·학습성장 4관점에 IT 거버넌스 지표 매핑), CMMI(프로세스 성숙도 5단계로 거버넌스 수준 측정), IT 감사(내부감사=COBIT 통제목적 기준 점검, 외부감사=ISO 27001·SOC 2 인증) |
| **비교** | **거버넌스 (Governance)**<br>- **주체/역할**: 이사회 및 감사기구 / 기업의 방향성 설정, 의사결정 통제, 이해관계자 대변<br>- **핵심 목표**: 평가(Evaluate), 지시(Direct), 모니터링(Monitor) 수행<br><br>**매니지먼트 (Management)**<br>- **주체/역할**: CEO, CIO 등 고위 경영진 / 거버넌스가 설정한 방향에 맞춘 실행 및 운영 지휘<br>- **핵심 목표**: 계획(Plan), 구축(Build), 실행(Run), 모니터링(Monitor) 수행 |
| **차별화** | **IT 거버넌스 내재화 및 IT-비즈니스 정렬(Alignment) 촉진 실무 방안**<br>1. **IT-BSC(Balanced Scorecard) 연계 구축**: IT 투자가 단순 비용(Cost)이 아닌 비즈니스 가치로 연계되도록 재무, 고객, 프로세스, 학습/성장 관점의 비즈니스 KPI와 IT 지표를 상호 정렬(Strategic Alignment)하는 BSC 대시보드 운영.<br>2. **COBIT 2019 디자인 요소(Design Factors) 기반 맞춤 설계**: 조직의 산업군 규제 수준(예: 금융권 컴플라이언스) 및 비즈니스 위험 수준을 디자인 요소 시트에 대입하여, 거버넌스 프로세스의 목표 수준(Capability Level 1~5)을 점진적으로 튜닝하여 비즈니스 적합성 확보.<br>3. **IT 투자 위원회(IT Steering Committee) 활성화**: 현업 비즈니스 부서장과 IT 임원이 공동 참여하는 정기적 의사결정 기구를 제도화하여, IT 프로젝트 투자 타당성을 다차원(ROI, 리스크, 전략 정합성)으로 정형화 평가 및 통제. |
