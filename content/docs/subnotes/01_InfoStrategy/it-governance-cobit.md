# IT 거버넌스 및 COBIT 서브노트

> **두음 머리에 박기 🧠**
> - **이·디·엠** (ISO 38500 거버넌스 3대 프로세스: 평가 **E**valuate ➔ 지시 **D**irect ➔ 모니터링 **M**onitor)
> - **아·바·디·엠** (COBIT 매니지먼트 4대 도메인: **A**PO 정렬/기획, **B**AI 구축/도입, **D**SS 운영/지원, **M**EA 평가/감사)
> - **전·가·리·자·수** (IT 거버넌스 5대 도메인: **전**략적 정렬, **가**치 전달, **리**스크 관리, **자**원 관리, **수**행 측정)

| **토픽명** | **IT 거버넌스 (IT Governance) 및 COBIT 2019 프레임워크** |
| **정의** | 비즈니스 목표 달성 위한 IT투자 통제·위험관리·IT-비즈니스 정렬 **의사결정/책임 프레임워크(IT거버넌스)** + 이를 구현하는 글로벌 통제아키텍처 **COBIT** |
| **키워드** | IT 거버넌스 5대 영역, ISO/IEC 38500 (EDM), COBIT 2019 (EDM/PBRM), Design Factors (디자인 요소) |
| **개념도** | `[ 주주 / 이해관계자 요구사항 ] ➔ 가치 증대 및 위험 관리 요구`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`│`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼ (평가 Evaluate)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`[ 거버넌스 (Governance - 이사회) ] ◀─── (모니터링 Monitor)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`│ (지시 Direct)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`[ 매니지먼트 (Management - 경영진) ] ➔ 실행 (Plan ➔ Build ➔ Run)` |
| **구성요소** | 1. **거버넌스 5대(전·가·리·자·수)**: 전략적정렬, 가치전달, 리스크관리, 자원관리, 수행측정<br>2. **ISO/IEC 38500**: 6대 원칙 + EDM(평가·지시·모니터링) 3대 프로세스모델<br>3. **COBIT 2019 거버넌스(EDM)**: 이사회수준 평가(Evaluate)·지시(Direct)·모니터링(Monitor)<br>4. **COBIT 2019 매니지먼트(PBRM)**: APO(정렬/기획), BAI(구축/인수), DSS(운영/지원), MEA(측정/평가)<br>5. **디자인 요소**: 기업전략·리스크프로필·규제 등 거버넌스 테일러링용 11개 요소<br>6. **효과측정 지표 3분류**: 재무(IT ROI·비용비율·TCO·Value Realization), 운영(가용성·SLA준수율·프로젝트완수율·변경성공률·보안사고건수), 전략정렬(목표달성율·업무자동화율)<br>7. **효과측정 방법론**: BSC(4관점→IT지표 매핑), CMMI(성숙도 5단계), IT감사(내부=COBIT 통제목적 점검, 외부=ISO27001·SOC2 인증) |
| **비교** | **거버넌스 (Governance)**<br>- 주체/역할: 이사회·감사기구 / 방향성설정·의사결정통제·이해관계자대변<br>- 핵심목표: 평가(Evaluate)·지시(Direct)·모니터링(Monitor)<br><br>**매니지먼트 (Management)**<br>- 주체/역할: CEO·CIO 등 경영진 / 거버넌스 방향 맞춘 실행·운영지휘<br>- 핵심목표: 계획(Plan)·구축(Build)·실행(Run)·모니터링(Monitor) |
| **차별화** | **IT거버넌스 내재화 및 IT-비즈니스 정렬 촉진 방안**<br>1. **IT-BSC 연계 구축**: IT투자→비즈니스가치 연계 위해 재무·고객·프로세스·학습성장 KPI와 IT지표 상호정렬 → BSC 대시보드 운영<br>2. **COBIT Design Factors 맞춤설계**: 산업군 규제수준·비즈니스 위험수준 대입 → 거버넌스 목표수준(Capability Level 1~5) 점진 튜닝<br>3. **IT투자위원회 활성화**: 현업부서장+IT임원 공동참여 정기 의사결정기구 → 투자타당성 다차원(ROI·리스크·전략정합성) 평가·통제 |
