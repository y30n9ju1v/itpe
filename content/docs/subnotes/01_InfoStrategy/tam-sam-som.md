# TAM-SAM-SOM 시장 규모 추정 서브노트

> **두음 머리에 박기 🧠**
> - **TAM⊃SAM⊃SOM** (Total → Serviceable Addressable → Serviceable Obtainable, 동심원 축소 구조)
> - **Top·Bottom** (추정 2방법: Top-Down(시장조사 보고서에서 필터링) vs Bottom-Up(고객수×객단가))

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **TAM-SAM-SOM 시장 규모 추정 프레임워크** |
| **정의** | 신규 사업·제품 시장규모 → 전체시장(TAM)→공략가능시장(SAM)→단기획득가능시장(SOM) 3단계 계층화 추정 프레임워크; ISP 수립·투자검토·공공정보화 기획 시 시장기회 현실성 평가 |
| **키워드** | TAM, SAM, SOM, Top-Down, Bottom-Up, 시장 세그멘테이션 |
| **개념도** | `┌─────────────── TAM (이론적 전체 시장) ───────────────┐`<br>`│  ┌───────── SAM (현재 비즈니스모델로 공략 가능) ─────┐  │`<br>`│  │   ┌──── SOM (단기 실현 가능 목표) ────┐   │  │`<br>`│  │   └─────────────────────────────────┘   │  │`<br>`│  └───────────────────────────────────────────┘  │`<br>`└───────────────────────────────────────────────────┘` |
| **구성요소** | 1. **TAM(Total Addressable Market)**: 이론적 전체 점유가능시장, 경쟁무관 최대 잠재시장<br>2. **SAM(Serviceable Addressable Market)**: 현 비즈니스모델·지역·채널 기준 TAM 내 타깃 세그먼트<br>3. **SOM(Serviceable Obtainable Market)**: SAM 내 단기 현실적 획득가능 점유율 목표 |
| **비교** | **Top-Down 추정**<br>- 국가통계·시장조사보고서(IDC·Gartner)에서 TAM→SAM→SOM 순 필터링<br>- 신속하나 정밀도 낮음<br><br>**Bottom-Up 추정**<br>- 잠재고객수 × 객단가 × 구매빈도 = SAM<br>- 신뢰성 높으나 데이터 확보 비용 큼 |
| **차별화** | **ISP/ISMP 및 공공 정보화 기획 활용 전략**<br>1. **ISP 사업타당성 정량근거 활용**: 정보전략계획 단계 → TAM-SAM-SOM으로 신규 IT서비스 시장기회 현실성 사전검증<br>2. **Top-Down·Bottom-Up 병행검증**: 초기 Top-Down 신속 규모추정 → 사업확정단계 Bottom-Up 재검증 → 예산편성 정확도 제고<br>3. **공공 정보화 수요예측 적용**: 이용대상 국민수→SAM, 시범사업 목표이용자→SOM 설정 → 예산근거 구체화 |
