# TAM-SAM-SOM 시장 규모 추정 서브노트

> **두음 머리에 박기 🧠**
> - **TAM⊃SAM⊃SOM** (Total → Serviceable Addressable → Serviceable Obtainable, 동심원 축소 구조)
> - **Top·Bottom** (추정 2방법: Top-Down(시장조사 보고서에서 필터링) vs Bottom-Up(고객수×객단가))

---

| 분류 | 기술 기술사 서브노트 작성 예시 (1교시형 포맷) |
| :--- | :--- |
| **토픽명** | **TAM-SAM-SOM 시장 규모 추정 프레임워크** |
| **정의** | 신규 사업·제품의 시장 규모를 전체 시장(TAM)→실제 공략 가능 시장(SAM)→단기 획득 가능 시장(SOM) 3단계로 계층화하여 추정하는 프레임워크로, ISP 수립·투자 검토·공공 정보화 사업 기획 시 시장 기회의 현실성을 평가 |
| **키워드** | TAM, SAM, SOM, Top-Down, Bottom-Up, 시장 세그멘테이션 |
| **개념도** | `┌─────────────── TAM (이론적 전체 시장) ───────────────┐`<br>`│  ┌───────── SAM (현재 비즈니스모델로 공략 가능) ─────┐  │`<br>`│  │   ┌──── SOM (단기 실현 가능 목표) ────┐   │  │`<br>`│  │   └─────────────────────────────────┘   │  │`<br>`│  └───────────────────────────────────────────┘  │`<br>`└───────────────────────────────────────────────────┘` |
| **구성요소** | 1. **TAM(Total Addressable Market)**: 제품·서비스가 이론적으로 점유 가능한 전체 시장, 경쟁 무관 최대 잠재 시장<br>2. **SAM(Serviceable Addressable Market)**: 현재 비즈니스 모델·지역·채널로 실제 공략 가능한 TAM 내 타깃 세그먼트<br>3. **SOM(Serviceable Obtainable Market)**: SAM 내에서 단기적으로 현실적으로 획득 가능한 점유율 목표 |
| **비교** | **Top-Down 추정**<br>- 국가통계·시장조사보고서(IDC·Gartner)에서 TAM→SAM→SOM 순 필터링<br>- 신속하나 정밀도 낮음<br><br>**Bottom-Up 추정**<br>- 잠재고객수 × 객단가 × 구매빈도 = SAM<br>- 신뢰성 높으나 데이터 확보 비용 큼 |
| **차별화** | **ISP/ISMP 및 공공 정보화 기획에서의 활용 전략**<br>1. **ISP 수립 시 사업 타당성 정량 근거로 활용**: 정보전략계획 단계에서 TAM-SAM-SOM을 통해 신규 IT 서비스의 시장 기회 현실성을 사전 검증.<br>2. **Top-Down·Bottom-Up 병행 검증**: 초기에는 Top-Down으로 신속히 시장 규모를 가늠하고, 사업 확정 단계에서 Bottom-Up으로 재검증하여 예산 편성의 정확도를 높임.<br>3. **공공 정보화 수요 예측 적용**: 디지털 서비스 이용 대상 국민 수를 SAM으로, 초기 시범사업 목표 이용자를 SOM으로 설정해 예산 근거를 구체화. |
