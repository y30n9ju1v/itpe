# SCM 공급망관리와 화이트 레이블 마케팅 서브노트

> **두음 머리에 박기 🧠**
> - **수·재·공·물·가** (SCM 5대 구성요소: **수**요계획, **재**고관리, **공**급자관리, **물**류최적화, **가**시성확보)
> - **생·판·소** (화이트 레이블 3주체: **생**산자(Provider), **판**매자(Reseller), **소**비자)

---

| 분류 | 기술 기술사 서브노트 작성 예시 (1교시형 포맷) |
| :--- | :--- |
| **토픽명** | **공급망관리(SCM)와 화이트 레이블 마케팅(White Label)** |
| **정의** | SCM은 원자재 조달부터 최종 소비자 납품까지 물자·정보·자금 흐름을 통합 계획·실행·통제하는 경영전략이며, 화이트 레이블은 한 기업(생산자)이 만든 제품·서비스를 다른 기업(판매자)이 자사 브랜드로 재판매하는 공급망 파트너십 전략의 한 형태 |
| **키워드** | 효과성·효율성, 채찍효과(Bullwhip Effect), 화이트레이블, OEM/ODM, SaaS 재판매 |
| **개념도** | `[ 공급자 ] → [ 제조 ] → [ 유통 ] → [ 소매 ] → [ 소비자 ]  (SCM 전체 흐름, 수·재·공·물·가 관리)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▲ 파트너십 계약`<br>`[ 생산자(무브랜드 공급) ] ──브랜드 부착──➔ [ 판매자(자사브랜드) ] ──➔ [ 소비자 ]` |
| **구성요소** | **SCM**: 1. 수요계획 2. 재고관리 3. 공급자관리(SRM) 4. 물류 최적화 5. 가시성 확보 + 채찍효과(수요 변동이 상위 공급망으로 갈수록 증폭)<br>**화이트 레이블**: 1. 생산자(브랜드 없이 공급) 2. 판매자(자사 브랜드 부착 판매) 3. SW/SaaS 분야 적용(클라우드 PBX, AI 챗봇 엔진, 결제 게이트웨이 OEM 공급) |
| **비교** | **SCM의 효과성 vs 효율성**<br>- 효과성: 목표 달성(납기준수율·고객만족), 재고↑ 시 효과성↑ 효율성↓<br>- 효율성: 자원 최소투입(재고회전율·물류비용), 재고↓ 시 효율성↑ 품절리스크↑<br><br>**화이트 레이블 vs OEM/ODM**<br>- 화이트 레이블: 완제품을 브랜드만 교체해 재판매<br>- OEM/ODM: 주문자 사양대로 제조·설계까지 위탁 |
| **차별화** | **공급망 파트너십 관점의 SCM-화이트레이블 통합 전략**<br>1. **채찍효과 완화를 위한 정보공유 파트너십**: 화이트 레이블 재판매 구조에서도 판매자-생산자 간 실시간 수요 데이터 공유(S&OP)로 채찍효과를 억제.<br>2. **SaaS 화이트레이블의 SLA·품질책임 명확화**: 화이트 레이블 계약 시 품질관리 책임 소재를 SLA로 명문화하고, 지적재산권·라이선스 계약을 SCM 공급자 관리(SRM) 프로세스에 편입.<br>3. **디지털 SCM 기술(AI·IoT·블록체인)의 화이트레이블 적용**: AI 기반 수요예측·실시간 재고 가시성 시스템을 화이트 레이블 형태로 재판매하여 개발기간 단축과 공급망 최적화를 동시 달성. |
