# 데이터 경제와 데이터 가치사슬 서브노트

> **두음 머리에 박기 🧠**
> - **수·저·분·유·활** (데이터 가치사슬 5단계: **수**집 ➔ **저**장/관리 ➔ **분**석 ➔ **유**통 ➔ **활**용)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **데이터 경제(Data Economy)와 데이터 가치사슬(Data Value Chain)** |
| **정의** | 데이터 생산·수집·유통·분석·활용 全과정 → 경제적 가치창출, 데이터=핵심 생산요소인 경제체제. 포터 가치사슬 모델을 데이터에 적용한 데이터 가치사슬 모델이 핵심 분석틀 |
| **키워드** | 21세기의 원유, 데이터 3법, 데이터 거래소, 마이데이터, 가명정보 |
| **개념도** | `[ 수집(IoT/로그/설문) ] ➔ [ 저장/관리(정제·표준화) ] ➔ [ 분석(통계·AI) ] ➔ [ 유통(거래소/API마켓) ] ➔ [ 활용(신규서비스/정책) ]` |
| **구성요소** | **데이터경제 vs 전통경제**: 핵심자원(데이터 ↔ 노동·자본·토지), 가치창출(수집·분석·활용 ↔ 물리적 생산·유통), 대표사업자(플랫폼기업 ↔ 제조·유통기업), 규제이슈(개인정보보호·데이터주권 ↔ 독과점·노동)<br>**데이터 가치사슬 5단계(수·저·분·유·활)**: 수집(IoT·플랫폼기업) → 저장/관리(클라우드·DB벤더) → 분석(데이터분석·AI스타트업) → 유통(데이터거래소·API마켓) → 활용(全산업 신규서비스·정책반영)<br>**데이터경제 활성화 전략**: 제도/법(데이터3법 개정·가명정보), 인프라(공공데이터 개방·빅데이터플랫폼), 유통(데이터거래소·바우처), 인력(데이터사이언티스트 양성), 신뢰(마이데이터=자기결정권) |
| **비교** | **전통 경제**<br>- 핵심자원: 노동, 자본, 토지<br>- 가치창출: 물리적 생산·유통<br><br>**데이터 경제**<br>- 핵심자원: 데이터<br>- 가치창출: 데이터 수집·분석·활용의 가치사슬 |
| **차별화** | **국내 데이터경제 활성화 실무 로드맵**<br>1. **데이터3법 이후 가명정보 활용 정착**: 개보법·정통망법·신용정보법 개정 가명정보 결합근거 → 데이터결합 전문기관 절차 표준화<br>2. **공공-민간 데이터 유통 생태계 연계**: 공공데이터 개방 + 데이터바우처 연계 → 중소기업 공공·민간데이터 결합 신규서비스 지원<br>3. **가치사슬 단계별 병목 진단**: 5단계 중 침체 원인단계(유통시장 미성숙 등) 진단 → 정책자원 병목해소 집중투입 |
