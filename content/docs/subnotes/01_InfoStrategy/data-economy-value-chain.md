# 데이터 경제와 데이터 가치사슬 서브노트

> **두음 머리에 박기 🧠**
> - **수·저·분·유·활** (데이터 가치사슬 5단계: **수**집 ➔ **저**장/관리 ➔ **분**석 ➔ **유**통 ➔ **활**용)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **데이터 경제(Data Economy)와 데이터 가치사슬(Data Value Chain)** |
| **정의** | 데이터 경제란 데이터의 생산·수집·유통·분석·활용 전 과정에서 경제적 가치가 창출되고 데이터 자체가 핵심 생산요소로 기능하는 경제 체제로, 마이클 포터의 전통적 가치사슬 모델을 데이터라는 자원에 적용하여 수집부터 활용까지 부가가치 창출 단계를 설명하는 데이터 가치사슬 모델이 그 핵심 분석틀이다 |
| **키워드** | 21세기의 원유, 데이터 3법, 데이터 거래소, 마이데이터, 가명정보 |
| **개념도** | `[ 수집(IoT/로그/설문) ] ➔ [ 저장/관리(정제·표준화) ] ➔ [ 분석(통계·AI) ] ➔ [ 유통(거래소/API마켓) ] ➔ [ 활용(신규서비스/정책) ]` |
| **구성요소** | **데이터 경제 vs 전통 경제**: 핵심자원(데이터 vs 노동·자본·토지), 가치창출(수집·분석·활용 vs 물리적 생산·유통), 대표사업자(플랫폼기업 vs 제조·유통기업), 규제이슈(개인정보보호·데이터주권 vs 독과점·노동)<br>**데이터 가치사슬 5단계(수·저·분·유·활)**: 수집(IoT기업·플랫폼기업), 저장/관리(클라우드사업자·DB벤더), 분석(데이터분석기업·AI스타트업), 유통(데이터거래소·API마켓플레이스), 활용(전 산업분야 신규서비스·정책반영)<br>**데이터 경제 활성화 전략**: 제도/법(데이터3법 개정, 가명정보 활용), 인프라(공공데이터 개방·분야별 빅데이터 플랫폼), 유통시장(데이터거래소·데이터바우처), 인력(데이터사이언티스트 양성), 신뢰기반(마이데이터로 개인 데이터 자기결정권 보장) |
| **비교** | **전통 경제**<br>- 핵심자원: 노동, 자본, 토지<br>- 가치창출: 물리적 생산·유통<br><br>**데이터 경제**<br>- 핵심자원: 데이터<br>- 가치창출: 데이터 수집·분석·활용의 가치사슬 |
| **차별화** | **국내 데이터 경제 활성화의 실무 로드맵**<br>1. **데이터 3법 이후 가명정보 활용 실무 정착**: 개인정보보호법·정보통신망법·신용정보법 개정으로 마련된 가명정보 결합·활용 근거를 실제 서비스에 적용할 수 있도록, 데이터 결합 전문기관 활용 절차를 표준화.<br>2. **공공-민간 데이터 유통 생태계 연계**: 공공데이터 개방을 데이터 바우처 사업과 연계해, 중소기업이 공공데이터와 민간데이터를 결합해 신규 서비스를 개발하도록 지원.<br>3. **가치사슬 단계별 병목 진단**: 국내 데이터 경제 침체의 원인을 가치사슬 5단계 중 어느 단계(유통 시장 미성숙 등)에서 발생하는지 진단하여, 정책 자원을 병목 해소에 집중 투입. |
