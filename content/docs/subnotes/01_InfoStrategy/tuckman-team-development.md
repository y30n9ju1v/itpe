# 터크만 팀 발달 모델과 갈등관리 서브노트

> **두음 머리에 박기 🧠**
> - **형·격·규·성·해** (터크만 5단계: **형**성 Forming, **격**동 Storming, **규**범화 Norming, **성**과 Performing, **해**산 Adjourning)
> - **회·수·타·강·협** (PMI 갈등해결 5전략: **회**피, **수**용, **타**협, **강**제, **협**력)

| **토픽명** | **터크만(Tuckman)의 팀 발달 5단계 모델과 갈등관리** |
| **정의** | 팀이 고성과에 이르는 5단계(형성-격동-규범화-성과-해산) 제시 모델 → PM은 현재 단계 파악 후 단계별 리더십·갈등관리 전략 적용 |
| **키워드** | Forming-Storming-Norming-Performing-Adjourning, 역U자형 갈등-성과 관계, PMI 갈등해결 5전략 |
| **개념도** | `[형성 Forming] → [격동 Storming] → [규범화 Norming] → [성과 Performing] → [해산 Adjourning]`<br>`  방향제시        갈등조정          자율성 위임        코칭/장애제거      성과인정/지식이전` |
| **구성요소** | **5단계와 PM 역할**: ①형성(역할불명확·상호탐색 → 방향제시·목표명확화) ②격동(갈등·경쟁 표면화 → 갈등조정·의사결정지원) ③규범화(규칙·역할합의 → 팀 자율성위임) ④성과(고성과·자기조직화 → 장애제거·코칭) ⑤해산(프로젝트종료 → 성과인정·지식이전)<br>**PMI 갈등해결 5전략**: 회피(Avoiding, 단기 임시방편), 수용(Accommodating, 관계유지 우선), 타협(Compromising, 양측 일부양보), 강제(Forcing, 긴급시 권한강압), 협력(Collaborating, Win-Win 최선·시간소요)<br>**RACI 차트(책임배정매트릭스, RAM)**: R(Responsible, 실행책임자, 1명 이상), A(Accountable, 최종승인책임자, 반드시 1명), C(Consulted, 자문대상, 양방향소통), I(Informed, 통보대상, 일방향소통) — 형성기 역할·책임 불명확 해소 도구<br>**동기부여 이론**: 매슬로우 욕구5단계(생리→안전→소속→존중→자아실현), 허츠버그 2요인이론(위생요인: 급여·근무환경·정책 - 불만족예방만 가능 / 동기요인: 성취감·인정·책임감·성장기회 - 실제 만족·동기유발) |
| **비교** | **기능적 갈등**<br>- 적정 수준의 갈등<br>- 창의성·혁신 촉진<br><br>**역기능적 갈등**<br>- 과도하거나 회피된 갈등<br>- 성과 저하, 역U자형 관계(강도 너무 낮거나 높으면 성과↓) |
| **차별화** | **팀 발달 단계별 갈등해결 전략 매칭 실무 전략**<br>1. **격동기(Storming) 집중대응**: 갈등표면화 단계에서 협력(Collaborating) 우선적용 → Win-Win 시도, 일정긴급 시에만 강제(Forcing) 전환 판단기준 수립<br>2. **역U자형 갈등-성과 곡선 모니터링**: 갈등강도 정기측정(팀만족도·이슈로그) → 무기력/붕괴위험 구간 조기감지 → 규범화 전환 촉진<br>3. **해산(Adjourning) 단계 지식자산화**: 종료 시 회고(Retrospective)로 갈등관리 경험·팀학습 문서화 → 차기 프로젝트 팀구성 반영 |
