# 터크만 팀 발달 모델과 갈등관리 서브노트

> **두음 머리에 박기 🧠**
> - **형·격·규·성·해** (터크만 5단계: **형**성 Forming, **격**동 Storming, **규**범화 Norming, **성**과 Performing, **해**산 Adjourning)
> - **회·수·타·강·협** (PMI 갈등해결 5전략: **회**피, **수**용, **타**협, **강**제, **협**력)

| :--- | :--- |
| **토픽명** | **터크만(Tuckman)의 팀 발달 5단계 모델과 갈등관리** |
| **정의** | 팀이 고성과를 내기까지 거치는 5단계(형성-격동-규범화-성과-해산)를 제시한 모델로, PM은 팀의 현재 단계를 파악하고 단계별 리더십·갈등관리 전략을 적용해야 함 |
| **키워드** | Forming-Storming-Norming-Performing-Adjourning, 역U자형 갈등-성과 관계, PMI 갈등해결 5전략 |
| **개념도** | `[형성 Forming] → [격동 Storming] → [규범화 Norming] → [성과 Performing] → [해산 Adjourning]`<br>`  방향제시        갈등조정          자율성 위임        코칭/장애제거      성과인정/지식이전` |
| **구성요소** | **5단계와 PM 역할**: ①형성(역할 불명확·상호탐색 → 방향제시·목표명확화) ②격동(갈등·경쟁 표면화 → 갈등조정·의사결정지원) ③규범화(규칙·역할 합의 → 팀 자율성 위임) ④성과(고성과·자기조직화 → 장애제거·코칭) ⑤해산(프로젝트 종료 → 성과인정·지식이전)<br>**PMI 갈등해결 5전략**: 회피(Avoiding, 단기 임시방편), 수용(Accommodating, 관계유지 우선), 타협(Compromising, 양측 일부 양보), 강제(Forcing, 긴급시 권한 강압), 협력(Collaborating, Win-Win 최선이나 시간 소요) |
| **비교** | **기능적 갈등**<br>- 적정 수준의 갈등<br>- 창의성·혁신 촉진<br><br>**역기능적 갈등**<br>- 과도하거나 회피된 갈등<br>- 성과 저하, 역U자형 관계(강도 너무 낮거나 높으면 성과↓) |
| **차별화** | **팀 발달 단계별 갈등해결 전략 매칭 실무 전략**<br>1. **격동기(Storming) 집중 대응**: 팀 발달 5단계 중 갈등이 표면화되는 격동 단계에서 PM이 협력(Collaborating) 전략을 우선 적용해 Win-Win 해결을 시도하되, 일정이 긴급한 경우에만 강제(Forcing)로 전환하는 단계적 판단기준을 수립.<br>2. **역U자형 갈등-성과 곡선 모니터링**: 갈등 강도를 정기적으로 측정(팀 만족도·이슈 로그)하여 지나치게 낮거나(무기력) 높은(붕괴위험) 구간을 조기 감지, 규범화 단계로의 전환을 촉진.<br>3. **해산(Adjourning) 단계의 지식 자산화**: 프로젝트 종료 시 단순 해체가 아닌 회고(Retrospective)를 통해 갈등관리 경험과 팀 학습을 조직 자산으로 문서화하여 차기 프로젝트 팀 구성에 반영. |
