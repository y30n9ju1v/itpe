# IT 투자관리, BSC 전략맵, IT 생산성 패러독스와 운영성과관리 서브노트

> **두음 머리에 박기 🧠**
> - **선·통·평** (IT투자관리 3단계: **선**정 ➔ **통**제 ➔ **평**가)
> - **재·고·프·학** (BSC/IT-BSC 4대 관점: **재**무, **고**객, **프**로세스(내부프로세스), **학**습과 성장)
> - **측·시·재·관** (IT 생산성 패러독스 4대 원인: **측**정오류, **시**차, **재**분배, 관리실패(**관**리))

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **IT 투자관리(IT Investment Management), IT-BSC 성과평가, IT 생산성 패러독스 및 정보시스템 운영성과관리** |
| **정의** | IT 투자관리는 IT 투자의 계획-실행-평가 전 과정을 체계적으로 관리하여 투자 대비 최대 사업가치를 실현하고 위험을 최소화하는 경영관리 활동이며, IT-BSC는 일반 BSC 4대 관점(재무·고객·프로세스·학습성장)을 IT 조직에 맞게 재해석한 성과평가 체계이다. IT 생산성 패러독스는 대규모 IT투자에도 생산성 지표가 개선되지 않는 역설적 현상이며, 정보시스템 운영성과관리는 구축 완료된 시스템의 활용도·효율성을 측정해 계속유지·고도화·폐기를 결정하는 활동이다 |
| **키워드** | ROI/NPV/IRR/TCO, 정량·정성 평가, BSC 전략맵(Cause-Effect Chain), IT 생산성 패러독스(Solow), IT-BSC 4대 관점, 정보시스템 운영성과측정 매뉴얼 |
| **개념도** | `[ IT투자관리(선·통·평) ] ➔ [ 정량평가(ROI/NPV/IRR/TCO) + 정성평가(고객가치/조직역량/전략기여) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[ BSC 전략맵(재·고·프·학) ] ──인과관계 사슬──➔ [ IT-BSC 4대 관점 KPI ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[ 운영 중 시스템 ] ──정기 성과측정──➔ [ 계속유지 / 기능고도화 / 폐기 ]` |
| **구성요소** | 1. **IT투자관리 추진단계(선·통·평)**: 선정(사업발굴·CBA·포트폴리오 우선순위화)-통제(진도·위험·변경관리)-평가(성과측정·사후평가·환류)<br>2. **정량적 평가지표**: ROI(=(효과-비용)/비용), NPV(현금흐름 현재가치-투자비용), IRR(NPV=0 할인율), TCO(도입+운영+유지보수 총비용), Payback Period<br>3. **정성적 평가지표**: 고객가치(만족도·충성도), 조직역량(프로세스 혁신), 전략기여도(사업전략 정렬성), 리스크 관리(규제준수·보안)<br>4. **BSC 전략맵**: 재무(매출증대) ← 고객(배송시간 절감·만족도) ← 내부프로세스(WMS/TMS 최적화) ← 학습과 성장(AI 수요예측 역량)의 인과관계 사슬(Cause-Effect Chain)<br>5. **IT 생산성 패러독스 원인**: 측정오류(무형효과 미반영), 시차(학습곡선 지연), 재분배(산업내 상쇄), 관리실패(프로세스 혁신 미병행)<br>6. **IT-BSC 4대 관점**: 경영기여(IT ROI, 신사업 기여매출), 사용자 관점(CSAT, SLA 준수율), 운영 우수성(가용률, MTTR), 미래 지향(IT인력 교육시간, 신기술 도입건수)<br>7. **정보시스템 운영성과 측정 기준**: 활용성(이용률), 효율성(운영비 대비 효과), 안정성(장애율·가용률), 만족도, 노후도<br>8. **운영성과 측정 방법**: 정량측정(로그 기반 자동수집), 정성측정(만족도 설문), 비교분석(벤치마킹), 종합평가(가중합산 등급) |
| **비교** | **BSC (일반 경영)**<br>- 대상: 조직 전체의 전략 실행 성과<br>- 관점: 재무·고객·프로세스·학습성장의 일반 경영 KPI<br><br>**IT-BSC**<br>- 대상: IT 조직의 사업 기여도<br>- 관점: 경영기여·사용자·운영우수성·미래지향의 IT 특화 KPI |
| **차별화** | **투자평가-성과관리-운영성과의 전주기(Full Lifecycle) 연계 전략**<br>1. **투자 승인 단계의 BSC 전략맵 사전 검증**: 신규 IT 투자를 승인할 때 BSC 전략맵으로 재무목표까지의 인과관계 사슬을 사전에 도식화하여, 정성적 기대효과가 실제 재무성과로 이어지는 논리를 검증한 뒤 투자 확정.<br>2. **생산성 패러독스 완화를 위한 프로세스 혁신 병행 원칙**: IT 투자만으로는 생산성이 개선되지 않는다는 패러독스의 교훈에 따라, 모든 IT 투자 사업에 BPR/PI 등 프로세스 재설계를 필수 병행 과제로 지정.<br>3. **운영성과관리와 IT투자평가의 환류(Feedback) 연계**: 정보시스템 운영성과측정에서 저활용·고비용으로 판정된 시스템의 결과를 차기 IT투자관리 선정 단계의 포트폴리오 우선순위화에 반영하여, 신규 투자와 기존 자산 관리를 하나의 순환 체계로 통합. |
