# IT 투자관리, BSC 전략맵, IT 생산성 패러독스와 운영성과관리 서브노트

> **두음 머리에 박기 🧠**
> - **선·통·평** (IT투자관리 3단계: **선**정 ➔ **통**제 ➔ **평**가)
> - **재·고·프·학** (BSC/IT-BSC 4대 관점: **재**무, **고**객, **프**로세스(내부프로세스), **학**습과 성장)
> - **측·시·재·관** (IT 생산성 패러독스 4대 원인: **측**정오류, **시**차, **재**분배, 관리실패(**관**리))

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **IT 투자관리(IT Investment Management), IT-BSC 성과평가, IT 생산성 패러독스 및 정보시스템 운영성과관리** |
| **정의** | IT투자관리: 투자 계획-실행-평가 전과정 관리 → 사업가치 최대화·위험최소화 / IT-BSC: 일반BSC 4관점을 IT조직에 재해석한 성과평가체계 / IT생산성패러독스: 대규모 IT투자에도 생산성 미개선 역설현상 / 운영성과관리: 구축완료 시스템 활용도·효율성 측정 → 유지/고도화/폐기 결정 |
| **키워드** | ROI/NPV/IRR/TCO, 정량·정성 평가, BSC 전략맵(Cause-Effect Chain), IT 생산성 패러독스(Solow), IT-BSC 4대 관점, 정보시스템 운영성과측정 매뉴얼 |
| **개념도** | `[ IT투자관리(선·통·평) ] ➔ [ 정량평가(ROI/NPV/IRR/TCO) + 정성평가(고객가치/조직역량/전략기여) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[ BSC 전략맵(재·고·프·학) ] ──인과관계 사슬──➔ [ IT-BSC 4대 관점 KPI ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[ 운영 중 시스템 ] ──정기 성과측정──➔ [ 계속유지 / 기능고도화 / 폐기 ]` |
| **구성요소** | 1. **IT투자관리 추진단계(선·통·평)**: 선정(사업발굴·CBA·포트폴리오 우선순위화) → 통제(진도·위험·변경관리) → 평가(성과측정·사후평가·환류)<br>2. **정량 평가지표**: ROI(=(효과-비용)/비용), NPV(현금흐름 현재가치-투자비용), IRR(NPV=0 할인율), TCO(도입+운영+유지보수 총비용), Payback Period<br>3. **정성 평가지표**: 고객가치(만족도·충성도), 조직역량(프로세스혁신), 전략기여도(사업전략 정렬성), 리스크관리(규제준수·보안)<br>4. **BSC 전략맵**: 재무(매출증대) ← 고객(배송시간절감·만족도) ← 내부프로세스(WMS/TMS 최적화) ← 학습성장(AI수요예측 역량) 인과관계사슬(Cause-Effect Chain)<br>5. **IT생산성패러독스 원인**: 측정오류(무형효과 미반영), 시차(학습곡선 지연), 재분배(산업내 상쇄), 관리실패(프로세스혁신 미병행)<br>6. **IT-BSC 4대 관점**: 경영기여(IT ROI·신사업기여매출), 사용자(CSAT·SLA준수율), 운영우수성(가용률·MTTR), 미래지향(IT인력교육시간·신기술도입건수)<br>7. **운영성과 측정기준**: 활용성(이용률), 효율성(운영비 대비 효과), 안정성(장애율·가용률), 만족도, 노후도<br>8. **운영성과 측정방법**: 정량측정(로그 자동수집), 정성측정(만족도설문), 비교분석(벤치마킹), 종합평가(가중합산 등급) |
| **비교** | **BSC (일반 경영)**<br>- 대상: 조직 전체 전략실행 성과<br>- 관점: 재무·고객·프로세스·학습성장 일반경영 KPI<br><br>**IT-BSC**<br>- 대상: IT조직 사업기여도<br>- 관점: 경영기여·사용자·운영우수성·미래지향 IT특화 KPI |
| **차별화** | **투자평가-성과관리-운영성과 전주기(Full Lifecycle) 연계 전략**<br>1. **투자승인 단계 BSC 전략맵 사전검증**: 신규투자 승인시 재무목표까지 인과관계사슬 사전 도식화 → 정성적 기대효과의 재무성과 연결논리 검증 후 확정<br>2. **생산성패러독스 완화 위한 프로세스혁신 병행원칙**: IT투자만으로 생산성 미개선 교훈 → 모든 투자사업에 BPR/PI 등 프로세스재설계 필수 병행<br>3. **운영성과-IT투자평가 환류연계**: 저활용·고비용 판정 시스템 결과 → 차기 IT투자관리 선정단계 포트폴리오 우선순위화 반영 → 신규투자·기존자산관리 순환체계 통합 |
