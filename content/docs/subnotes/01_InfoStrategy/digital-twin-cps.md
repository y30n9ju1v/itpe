# 디지털트윈과 CPS, 스마트시티 적용 서브노트

> **두음 머리에 박기 🧠**
> - **실·삼·시·양·데** (디지털트윈 플랫폼 5대 특징: **실**시간동기화, **3**D시각화, **시**뮬레이션·예측, **양**방향 상호작용, **데**이터통합)
> - **비·아·데·오·오** (스마트시티 디지털트윈 5대 기술: **B**IM/GIS, **I**oT센서, **데**이터허브, AI/빅**데**이터, 5G/엣지)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **디지털트윈(Digital Twin)과 사이버물리시스템(CPS, Cyber-Physical System)** |
| **정의** | 디지털트윈은 현실 세계의 사물·공간·프로세스를 가상 공간에 동일하게 복제하고 실시간 데이터로 동기화하여 시뮬레이션·분석·예측을 수행하는 기술로, 물리적 실체와 가상 모델을 실시간 연동하는 CPS의 핵심 구현체이며, 정부는 2018년 스마트시티 국가전략에서 이를 도시 단위 운영 플랫폼의 핵심 기술로 지정하였다 |
| **키워드** | CPS, IoT 실시간 동기화, BIM/GIS 3D 공간정보, What-if 시뮬레이션, 스마트시티(세종 5-1, 부산 에코델타시티) |
| **개념도** | `[ 물리 세계(공장/도시) ] ──IoT 센서 실시간 수집──➔ [ 가상 모델(디지털트윈) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▲ ◀── 양방향 제어 피드백 ──┘`<br>`(What-if 시뮬레이션·예측 결과가 물리 객체 제어에 반영, CPS 완성)` |
| **구성요소** | **디지털트윈 플랫폼 5대 특징(실·삼·시·양·데)**: 실시간 동기화(IoT 센서→가상모델 반영), 3D 시각화(BIM/GIS 렌더링), 시뮬레이션·예측(What-if 시나리오), 양방향 상호작용(가상 제어→물리 피드백), 데이터 통합(이기종 센서·행정·민간 데이터)<br>**스마트시티 5대 기술(비·아·데·오·오)**: BIM/GIS(3D 정밀모델), IoT 센서네트워크(교통·대기질·에너지), 데이터허브(이기종 통합), AI/빅데이터 분석(교통혼잡·재난확산 예측), 5G/엣지컴퓨팅(저지연 처리)<br>**적용 영역**: 교통(신호체계 최적화, 자율주행 테스트베드), 에너지(스마트그리드 연계 수요예측), 재난안전(침수·화재 확산 시뮬레이션), 도시계획(일조권·교통영향 사전검증), 환경(미세먼지 저감정책 검증) |
| **비교** | **공장 단위 디지털트윈**<br>- 대상: 단일 설비·생산라인<br>- 데이터: 동질적 센서 데이터 중심<br><br>**도시 단위 디지털트윈(스마트시티)**<br>- 대상: 교통·에너지·재난·환경 등 이종 데이터 통합<br>- 데이터: 대규모 3D 공간정보(BIM/GIS) + 실시간 IoT 센서 연동으로 훨씬 복잡 |
| **차별화** | **도시 디지털트윈의 데이터 거버넌스 및 확장 전략**<br>1. **데이터허브 표준화를 통한 이종 데이터 통합**: 교통·환경·행정 등 부서별로 분산된 데이터를 도시데이터센터로 표준화 수집하여, 개별 디지털트윈 프로젝트마다 데이터 재수집하는 중복 투자를 방지.<br>2. **재난안전 시뮬레이션의 실시간성 확보**: 5G/엣지컴퓨팅을 결합해 침수·화재 확산 시뮬레이션의 연산 지연을 최소화, 실제 대피 경로 안내 등 골든타임 대응에 활용.<br>3. **민간 데이터 연계를 통한 확장성 확보**: 공공 IoT 데이터에 더해 통신사 유동인구, 카드사 소비 데이터 등 민간 데이터를 마이데이터 체계로 연계해 도시 디지털트윈의 예측 정확도를 향상. |
