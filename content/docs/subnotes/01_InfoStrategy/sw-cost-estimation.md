# 소프트웨어 사업 대가산정 서브노트

> **두음 머리에 박기 🧠**
> - **FP·MM·요** (3대 전통적 대가산정 방식: **F**unction **P**oint, **M**an-**M**onth, **요**율제 유지관리)
> - **규·연·성·다·보** (기능점수 5대 보정계수: **규**모, **연**계복잡성, **성**능요구, **다**중사이트, **보**안성)
> - **ILF·EIF / EI·EO·EQ** (FP 기능 구성: 데이터 기능 2종 vs 트랜잭션 기능 3종)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **소프트웨어 사업 대가산정 (SW 대가산정 가이드)** |
| **정의** | 과학기술정보통신부 고시에 따라 SW 개발·유지보수·운영 사업의 대가를 합리적으로 산정하는 기준으로, SW 기업의 적정 이윤 보장과 발주기관의 합리적 예산 편성을 목적으로 하며 2025년 개정판부터 AI 서비스 도입 사업 유형이 추가됨 |
| **키워드** | 기능점수(FP), 투입공수(M/M), 요율제, 5대 보정계수(규·연·성·다·보), AI 서비스 도입 사업 |
| **개념도** | `[ 요구사항 규모/복잡도 ] ──➔ [ UFP 산정 ] ──➔ [ DFP = UFP × K1×K2×K3×K4×K5 ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`개발원가 = DFP × 기능점수당 단가` |
| **구성요소** | 1. **기능점수(FP) 방식**: 데이터 기능(ILF·EIF) + 트랜잭션 기능(EI·EO·EQ) 5요소 기준 정량 산정, 간이법(설계 전)·상세법(설계 후) 구분<br>2. **5대 보정계수**: 규모(K1)·연계복잡성(K2)·성능요구수준(K3)·다중사이트운영성(K4)·보안성수준(K5)<br>3. **투입공수(M/M) 방식**: 등급별 기술자 노임단가 기준, ISP/ISMP 등 FP 산정이 어려운 기획·설계 단계에 적용<br>4. **요율제 유지관리**: 개발원가(또는 솔루션 가격)의 10~22% 내외를 연간 유지관리 대가로 적용 |
| **비교** | **기존(개발비 중심) 대가산정**<br>- 주요 원가: 인력 투입(M/M), FP<br>- 산정 단위: 기능점수·맨먼스<br>- 변동성 낮음<br><br>**AI 서비스 도입 사업 대가산정 (2025 개정)**<br>- 주요 원가: AI 이용료 + 연동 개발비<br>- 산정 단위: 토큰 수·API 호출 수<br>- 사용량 기반으로 변동성 높음 |
| **차별화** | **AI 서비스 도입 사업비 산정 5단계 절차 적용 전략**<br>1. **사업 유형 우선 식별**: SaaS형 AI 도입·온프레미스 AI 모델·AI 기능 내재화·AI 솔루션 커스터마이징 4유형 중 정확한 분류가 선행되어야 원가구조(구독료 vs 개발비)가 결정됨.<br>2. **구성요소별 원가 분리 산정**: AI 이용료(API·구독)·인프라비용·개발비(파인튜닝·RAG구축)·운영비(모니터링·모델갱신)를 분리 산정해 사용량 변동 리스크를 예산에 반영.<br>3. **전통 방식과의 하이브리드 적용**: AI 통합을 포함한 대형 사업은 시스템 개발 부분은 FP/M·M, AI 연동 부분은 사용량 기반으로 이원화 산정하여 정확도를 높임. |
