| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **다크패턴 (Dark Pattern)** |
| **정의** | UI/UX 설계를 통해 사용자가 의도하지 않은 행동(불필요한 구매, 개인정보 제공, 구독 해지 방해 등)을 유도하여 기업 이익을 편취하는 기만적 설계 기법으로, 개인정보보호법·공정거래법 위반과 직결됨 |
| **키워드** | 기만적 UI/UX, 숨겨진 구독, 로치모텔, 확인수치심, GDPR, 전자상거래법 |
| **개념도** | `[ 사용자 화면 ] ──기만적 설계(숨·확·속·바·가·사·우·숨)──➔ [ 의도치 않은 행동(구매/동의/해지실패) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[ 대응(기·정·설) ] ──➔ [ 규제(개인정보보호법·GDPR·공정위 가이드라인) ]` |
| **구성요소** | 1. **숨겨진 구독**: 무료체험 후 자동 유료전환<br>2. **확인 수치심(Confirmshaming)**: 거부 선택지에 죄책감 문구<br>3. **속임수 질문**: 이중부정 등 혼란스러운 레이블<br>4. **바퀴벌레 트랩(Roach Motel)**: 가입은 쉽고 해지는 극도로 복잡<br>5. **가짜 긴박감**: 인위적 마감·희소성 표시<br>6. **사생활 주커링**: 개인정보 공유 기본값 설정<br>7. **우선 강조(Misdirection)**: 특정 선택지 시각적 유도<br>8. **숨겨진 비용**: 결제 마지막 단계에 추가비용 노출 |
| **비교** | **국내 규제**<br>- 개인정보보호법: 기만적 동의 설계 금지<br>- 전자상거래법: 청약철회·해지방해 금지<br>- 공정위 가이드라인(2023)<br><br>**해외 규제**<br>- EU GDPR: 쿠키 동의 다크패턴 금지, 최대 글로벌 매출 4% 과징금<br>- FTC(미국): 구독취소 방해 행위 집행 |
| **차별화** | **디지털 소비자 보호 관점의 통합 대응 전략**<br>1. **기술적 대응**: ML 기반 UI 패턴 자동 탐지 시스템과 브라우저 확장 경고 기능으로 사전 차단.<br>2. **정책적 대응**: 유형별 금지 규정 법제화, 위반 과징금 강화, 플랫폼 사전 신고·심사 제도 도입.<br>3. **설계 윤리(Design Ethics) 내재화**: 가격·조건의 투명한 제공, opt-out 기본값 채택, 해지 프로세스를 가입과 동등한 단계 수로 설계하여 근본적으로 재발을 방지. |
