# 베이즈 정리 서브노트

> **두음 머리에 박기 🧠**
> - **사·전 ➔ 우·도 ➔ 사·후** (베이즈 확률 갱신 루프: 관측 전 **사**전 확률에 새로운 증거와 가설의 정합성인 **우**도를 곱하여 갱신된 **사**후 확률 도출)
> - **사·우·전** (베이즈 계산 3대 요소: **사**전 확률 $P(A)$, **우**도 $P(B|A)$, 분모의 **전**체 확률 $P(B)$)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **베이즈 정리 (Bayes' Theorem) 및 베이지안 확률 통계학** |
| **정의** | 사건 발생 조건 하 가설확률 계산 → 새 증거로 **기존 믿음(사전확률) 갱신 → 최종확률(사후확률) 도출**하는 조건부확률 이론 |
| **키워드** | 사전 확률 (Prior), 사후 확률 (Posterior), 우도 (Likelihood), 나이브 베이즈 분류기, 베이지안 최적화 |
| **개념도** | `[ 사전 확률 P(A) ]` ── 초기 믿음 / 통계적 기본 확률<br>&nbsp;&nbsp;&nbsp;&nbsp;`│`<br>&nbsp;&nbsp;&nbsp;&nbsp;`├─────────➔ [ 새로운 증거 B 관측 ] ➔ 우도 P(B|A) 적용`<br>&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[ 사후 확률 P(A|B) ]` ── 증거 B를 반영하여 업데이트된 최종 확률<br>&nbsp;&nbsp;&nbsp;&nbsp;**수식**: $P(A|B) = \frac{P(B|A)P(A)}{P(B)} = \frac{P(B|A)P(A)}{P(B|A)P(A) + P(B|\neg A)P(\neg A)}$ |
| **구성요소** | 1. **사전 확률 (Prior, $P(A)$)**: 증거 $B$ 얻기 전 가설 $A$의 초기 확률값<br>2. **우도 (Likelihood, $P(B|A)$)**: 가설 $A$ 참일 때 증거 $B$ 관측될 조건부확률(일치도)<br>3. **사후 확률 (Posterior, $P(A|B)$)**: 증거 $B$ 반영 후 갱신된 가설 $A$의 확률(목표값)<br>4. **정규화 상수 (Evidence, $P(B)$)**: 가설무관 증거 $B$ 발생 전체확률(전확률공식 산출) |
| **비교** | **빈도주의 통계학 (Frequentist)**<br>- 모수 관점: 모집단 모수(평균 등)는 고정 상수<br>- 확률 정의: 무한반복 시행 시 장기 상대빈도<br><br>**베이지안 통계학 (Bayesian)**<br>- 모수 관점: 모수는 불확실성 가진 확률변수(Distribution)<br>- 확률 정의: 주관·객관적 믿음척도(Degree of Belief), 상시 업데이트 |
| **차별화** | **나이브 베이즈·베이지안 최적화 실무 적용**<br>1. **나이브베이즈 조건부독립 가정·텍스트분류**: 특징(Feature) 상호독립 가정 → $P(X_1,X_2|Y)=P(X_1|Y)P(X_2|Y)$ 단순화 → 스팸필터링·감성분석, 파라미터 폭발 방지<br>2. **베이지안 최적화 하이퍼파라미터 튜닝**: 블랙박스 목적함수 탐색 시 가우시안프로세스 사전확률 모델링 → 평가점수로 사후확률 갱신 → 최적 튜닝조합(Acquisition Function) 탐색<br>3. **가짜양성(False Positive) 역설**: 검사정확도 99%·유병률(사전확률) 0.1% → 양성판정자 실제환자확률(사후확률) 약 9%에 불과, 임상설계 유의사항 |
