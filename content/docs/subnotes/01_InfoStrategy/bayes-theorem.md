# 베이즈 정리 서브노트

> **두음 머리에 박기 🧠**
> - **사·전 ➔ 우·도 ➔ 사·후** (베이즈 확률 갱신 루프: 관측 전 **사**전 확률에 새로운 증거와 가설의 정합성인 **우**도를 곱하여 갱신된 **사**후 확률 도출)
> - **사·우·전** (베이즈 계산 3대 요소: **사**전 확률 $P(A)$, **우**도 $P(B|A)$, 분모의 **전**체 확률 $P(B)$)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **베이즈 정리 (Bayes' Theorem) 및 베이지안 확률 통계학** |
| **정의** | 어떤 사건이 발생했다는 조건 하에 가설의 확률을 계산하기 위해, 새로운 관측 데이터(증거)를 바탕으로 **기존의 믿음(사전 확률)을 갱신하여 최종 확률(사후 확률)을 구하는 조건부 확률 이론** |
| **키워드** | 사전 확률 (Prior), 사후 확률 (Posterior), 우도 (Likelihood), 나이브 베이즈 분류기, 베이지안 최적화 |
| **개념도** | `[ 사전 확률 P(A) ]` ── 초기 믿음 / 통계적 기본 확률<br>&nbsp;&nbsp;&nbsp;&nbsp;`│`<br>&nbsp;&nbsp;&nbsp;&nbsp;`├─────────➔ [ 새로운 증거 B 관측 ] ➔ 우도 P(B|A) 적용`<br>&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[ 사후 확률 P(A|B) ]` ── 증거 B를 반영하여 업데이트된 최종 확률<br>&nbsp;&nbsp;&nbsp;&nbsp;**수식**: $P(A|B) = \frac{P(B|A)P(A)}{P(B)} = \frac{P(B|A)P(A)}{P(B|A)P(A) + P(B|\neg A)P(\neg A)}$ |
| **구성요소** | 1. **사전 확률 (Prior, $P(A)$)**: 새로운 데이터나 증거 $B$를 얻기 전 가설 $A$에 부여된 초기의 확률값<br>2. **우도 (Likelihood, $P(B|A)$)**: 가설 $A$가 실제로 참일 때 증거 $B$가 관측될 수 있는 조건부 확률 (일치도)<br>3. **사후 확률 (Posterior, $P(A|B)$)**: 증거 $B$가 발생한 후 갱신된 가설 $A$의 확률 (목표 조건부 확률)<br>4. **정규화 상수 (Evidence, $P(B)$)**: 가설에 무관하게 증거 $B$가 일어날 수 있는 전체 확률 (전확률 공식으로 산출) |
| **비교** | **빈도주의 통계학 (Frequentist)**<br>- **모수 관점**: 모집단의 모수(평균 등)는 고정된 하나의 절대적 상수임<br>- **확률 정의**: 무한히 반복 시행했을 때 발생하는 장기적인 상대적 빈도<br><br>**베이지안 통계학 (Bayesian)**<br>- **모수 관점**: 모집단의 모수는 불확실성을 가진 확률 변수(Distribution)임<br>- **확률 정의**: 주관적 혹은 객관적 믿음의 척도(Degree of Belief), 상시 업데이트 |
| **차별화** | **나이브 베이즈 분류(Naive Bayes) 및 베이지안 최적화(Bayesian Optimization) 실무 적용 방안**<br>1. **나이브 베이즈 분류기(Naive Bayes Classifier)의 조건부 독립 가정과 텍스트 분류**: 모든 특징(Feature)이 상호 독립적이라는 나이브(Naive)한 가정 하에 $P(X_1, X_2|Y) = P(X_1|Y)P(X_2|Y)$로 단순화하여 스팸 필터링 및 텍스트 감성 분석에서 파라미터 폭발을 막고 연산 속도 극대화.<br>2. **베이지안 최적화(Bayesian Optimization)를 통한 하이퍼파라미터 튜닝**: 머신러닝의 블랙박스 목적 함수(Objective Function) 탐색 시, 미지의 함수 구조를 가우시안 프로세스(Gaussian Process) 사전확률로 모델링하고, 새로운 평가 점수를 바탕으로 사후확률을 갱신하면서 최대 효율을 내는 최적 튜닝 조합(Acquisition Function) 탐색.<br>3. **질병 검사 시 가짜 양성(False Positive)의 역설 이해**: 검사 정확도가 $99\%$이고 대상 질병의 유병률(사전확률)이 $0.1\%$일 때, 실제 양성 판정을 받은 사람이 진짜 환자일 확률(사후확률)은 약 $9\%$에 불과함을 수학적으로 입증하여 임상/통제 설계 시 유의사항으로 활용. |
