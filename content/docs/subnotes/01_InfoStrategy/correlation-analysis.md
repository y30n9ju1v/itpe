# 상관 분석과 인과관계 서브노트

> **두음 머리에 박기 🧠**
> - **피·스·켄** (상관계수 3대 유형: **피**어슨(간격·비율척도, 모수), **스**피어만(서열척도, 비모수), **켄**달(서열척도·소표본·동률多, 비모수))
> - **선·등** (상관분석 2대 전제조건: **선**형성, **등**분산성)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **상관 분석 (Correlation Analysis) 및 상관관계 vs 인과관계** |
| **정의** | 두 변수 간 상관계수(correlation coefficient)를 통해 데이터 안의 선형 관계를 측정하는 통계 기법으로, 대칭적 관계인 **상관관계**와 원인-결과의 비대칭적 관계인 **인과관계**는 별개 개념이며 혼동해서는 안 됨 |
| **키워드** | 피어슨/스피어만/켄달 상관계수, 상관계수 해석기준, 교란변수(Confounding Variable), 허위상관 |
| **개념도** | `상관계수(r)`<br>`-1 ─────────── 0 ─────────── +1`<br>`강한음의상관    상관없음    강한양의상관`<br><br>`[상관관계] X ←──────→ Y (대칭, 선형관계성 파악)`<br>`[인과관계] X ──────→ Y (비대칭, 원인이 결과에 영향)`<br><br>`[교란변수 함정] 스트레스 → 커피섭취 ↘`<br>`                         → 심장병발생  (실제 원인은 스트레스)` |
| **구성요소** | 1. **피어슨(Pearson) 상관계수**: 간격·비율척도, 연속형 변수의 선형관계 측정, $r = \frac{\Sigma(X_i-\bar X)(Y_i-\bar Y)}{\sqrt{\Sigma(X_i-\bar X)^2 \Sigma(Y_i-\bar Y)^2}}$, 모수 검정<br>2. **스피어만(Spearman) 상관계수**: 서열척도, 값 대신 순위 이용, $\rho = 1-\frac{6\Sigma d_i^2}{n(n^2-1)}$, 비모수 검정<br>3. **켄달(Kendall) 타우**: 서열척도, 표본이 적거나 동률이 많을 때 유용, $\tau=(C-D)/(C+D)$ (C=일치쌍, D=불일치쌍)<br>4. **상관계수 해석기준**: r≤.1 거의 무시, .1<r≤.3 약함, .3<r≤.7 뚜렷함, r>.7 강함<br>5. **전제조건**: 선형성(두 연속형 변수가 선형관계), 등분산성(독립변수 어느 지점에서도 종속변수 산포가 동일) |
| **비교** | **상관관계 (Correlation)**<br>- 관계: X↔Y 대칭적, 관련성 정도만 파악<br>- 원인-결과 관련성: 불필요<br>- 분석기법: 시계열분석, 생존분석 / 상관계수(피어슨·스피어만·켄달)<br><br>**인과관계 (Causation)**<br>- 관계: X→Y 비대칭적, X가 Y에 미치는 영향 설명<br>- 원인-결과 관련성: 필수<br>- 분석기법: 회귀분석, A/B 테스트, 도구변수(IV) |
| **차별화** | **빅데이터 환경에서 상관관계의 오용 방지 전략**<br>1. **교란변수(Confounding Variable) 통제**: 두 변수가 상관관계를 보여도 제3의 변수(교란변수)가 공통 원인일 수 있으므로(예: 커피 섭취-심장병의 실제 원인은 스트레스), 회귀분석 시 교란변수를 통제변수로 포함하거나 층화분석으로 배제.<br>2. **허위 상관(Spurious Correlation) 경계**: 변수 수가 많아지는 빅데이터 환경에서는 우연히 높은 상관계수가 발견될 확률이 높아지므로, 상관관계를 인과관계로 곧바로 해석하지 않고 무작위 배정 A/B 테스트나 도구변수법으로 인과를 검증.<br>3. **척도·표본 특성에 따른 상관계수 선정**: 연속형·정규성 만족 시 피어슨을, 순위형이거나 이상치·비선형이 우려될 때는 스피어만·켄달을 선택하며, 사전에 정규성 검정(Shapiro-Wilk 등)으로 모수/비모수 방법을 결정. |
