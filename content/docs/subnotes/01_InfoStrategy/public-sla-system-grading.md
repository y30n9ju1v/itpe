# 공공 SLA와 정보시스템 등급제 서브노트

> **두음 머리에 박기 🧠**
> - **최·우·일** (정보시스템 3등급 분류: 1등급 **최**우선, 2등급 **우**선, 3등급 **일**반)
> - **가·조·위** (공공 SLA 표준안 3대 구성: **가**용률 기준, **조**치시간(RTO), **위**약금 체계)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **공공 SLA(Service Level Agreement)와 정보시스템 등급제** |
| **정의** | 반복되는 행정·공공기관 전산망 장애를 계기로 「전자정부법」 개정을 통해 도입된, 정보시스템을 중요도별로 등급화하고 등급별 가용률·복구시간·위약금을 명문화한 공공 부문 서비스수준협약 표준 체계 (2027년 의무화 추진) |
| **키워드** | 전자정부법, 정보시스템 등급제(최·우·일), 가용률, RTO, 위약금, 운영 품질 중심 계약 |
| **개념도** | `[ 반복 전산장애 ] ──➔ [ 전자정부법 개정 ] ──➔ [ 등급 분류(최·우·일) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[ 공공 SLA 표준(가·조·위) ] ──➔ [ 위약금·재계약 반영 ]` |
| **구성요소** | 1. **등급 분류 (최·우·일)**: 1등급(국민생활·국가안전 직결, 정부24·건강보험·금융망), 2등급(행정업무 필수), 3등급(내부 업무 일반)<br>2. **가용률 기준**: 1등급 99.9%↑(연 8.76시간 이하 중단), 2등급 99.5%↑, 3등급 99.0%↑<br>3. **장애조치 시간(RTO)**: 1등급 2시간, 2등급 4시간, 3등급 8시간 이내 복구<br>4. **위약금 체계**: 가용률 미달 시 계약금액 대비 시간당 0.1~0.5% 부과, 반복 장애 가중 |
| **비교** | **민간 SLA**<br>- 계약 당사자 간 자율 협상, 강제성 낮음<br>- 위약금 수준·측정방법 사업자 재량<br><br>**공공 SLA**<br>- 전자정부법 근거 표준 등급·수치 강제<br>- 국민 서비스 연속성 관점의 위약금·재계약 연동 |
| **차별화** | **레거시 시스템의 현실적 SLA 이행 로드맵**<br>1. **단계적 목표치 설정**: 노후 레거시 시스템은 즉시 1등급 가용률 충족이 어려우므로, 현행 수준 진단 → 단계별 목표 가용률 상향 → 최종 등급 기준 도달의 로드맵을 별도 수립.<br>2. **SLA 이행을 위한 투자 비용의 사업비 반영**: 이중화·모니터링 대시보드 구축 등 가용률 확보 비용을 초기 사업비 산정(대가산정) 단계에 명시적으로 반영해 미달 리스크 최소화.<br>3. **CSP 연계 등급별 SLA 체결**: 클라우드 전환 시 CSP와 등급별 SLA를 별도 체결하고 실시간 모니터링 대시보드로 가용률·RTO를 측정하여 위약금 판단 근거를 자동화. |
