# 공공 SLA와 정보시스템 등급제 서브노트

> **두음 머리에 박기 🧠**
> - **최·우·일** (정보시스템 3등급 분류: 1등급 **최**우선, 2등급 **우**선, 3등급 **일**반)
> - **가·조·위** (공공 SLA 표준안 3대 구성: **가**용률 기준, **조**치시간(RTO), **위**약금 체계)

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **공공 SLA(Service Level Agreement)와 정보시스템 등급제** |
| **정의** | 반복되는 행정·공공기관 전산망 장애 계기 → 「전자정부법」 개정 도입, 정보시스템 중요도별 등급화 + 등급별 가용률·복구시간·위약금 명문화한 공공부문 SLA 표준체계 (2027년 의무화 추진) |
| **키워드** | 전자정부법, 정보시스템 등급제(최·우·일), 가용률, RTO, 위약금, 운영 품질 중심 계약 |
| **개념도** | `[ 반복 전산장애 ] ──➔ [ 전자정부법 개정 ] ──➔ [ 등급 분류(최·우·일) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[ 공공 SLA 표준(가·조·위) ] ──➔ [ 위약금·재계약 반영 ]` |
| **구성요소** | 1. **등급 분류(최·우·일)**: 1등급(국민생활·국가안전 직결, 정부24·건강보험·금융망), 2등급(행정업무 필수), 3등급(내부업무 일반)<br>2. **가용률 기준**: 1등급 99.9%↑(연 8.76h↓중단), 2등급 99.5%↑, 3등급 99.0%↑<br>3. **장애조치시간(RTO)**: 1등급 2h, 2등급 4h, 3등급 8h 이내 복구<br>4. **위약금 체계**: 가용률 미달 시 계약금액 대비 시간당 0.1~0.5% 부과, 반복장애 가중 |
| **비교** | **민간 SLA**<br>- 계약당사자 간 자율협상, 강제성 낮음<br>- 위약금수준·측정방법 사업자 재량<br><br>**공공 SLA**<br>- 전자정부법 근거 표준등급·수치 강제<br>- 국민 서비스연속성 관점 위약금·재계약 연동 |
| **차별화** | **레거시 시스템의 현실적 SLA 이행 로드맵**<br>1. **단계적 목표치 설정**: 레거시 즉시 1등급 충족 곤란 → 현행수준 진단→단계별 목표가용률 상향→최종등급 도달 로드맵 별도수립<br>2. **투자비용 사업비 반영**: 이중화·모니터링 대시보드 구축비 → 초기 대가산정 단계 명시반영 → 미달리스크 최소화<br>3. **CSP 연계 등급별 SLA 체결**: 클라우드 전환 시 CSP와 등급별 SLA 체결 → 실시간 모니터링 대시보드로 가용률·RTO 측정 → 위약금 판단근거 자동화 |
