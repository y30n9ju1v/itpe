# 공공기관 정보화사업 예비타당성 조사 서브노트

> - **경·정·기·재** (예타 4대 조사항목: **경**제성분석, **정**책성분석, **기**술성분석, **재**원조달가능성)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **예비타당성 조사 (예타, Preliminary Feasibility Study)** |
| **정의** | 대규모 신규사업 착수전 경제성·정책성·기술성 등 종합검토 → 사업추진 여부 사전판단 제도(국가재정법 제38조, KDI 공공투자관리센터 주관) / 대상: 총사업비 500억↑(국고 300억↑) 신규사업, 정보화사업도 포함 |
| **키워드** | 국가재정법 제38조, B/C 비율, AHP 종합평가, 신속예타(패스트트랙) |
| **개념도** | `[ 대규모 신규 정보화사업 계획 ] ➔ [ 예타 대상 판정(총사업비 500억↑) ] ➔ [ 경·정·기·재 4대 분석 ] ➔ [ AHP 종합평가 ] ➔ [ 추진/보류 결정 ]` |
| **구성요소** | **예타 4대 조사항목(경·정·기·재)**: 경제성분석(B/C比·NPV, 정량 재무타당성), 정책성분석(국정과제 부합성·지역균형발전, 정성 정책우선순위), 기술성분석(기술성숙도·상용화가능성·표준준수, 정보화 특화항목), 재원조달가능성(예산확보계획 현실성·중기재정계획 연계), AHP 종합평가(항목별 가중치 반영 종합점수 산출)<br>**문제점·개선방향**: 조사기간 장기화(6개월~1년, IT주기보다 김 → 정보화 전용 패스트트랙), 경제성 편향평가(B/C 중심 공공성사업 불리 → 정책성·기술성 가중치 상향), 기술변화 반영지연(조사완료시 기술노후화 → 사업계획 재검토 활성화), 클라우드·SaaS 부적합(대규모투자 전제모델 vs 구독형 OPEX 불일치 → 대상기준 개편), 조사 전문성 한계(IT전문인력 부족 → 정보화 전담 조사패널 확충) |
| **비교** | **전통 IT 구축사업(대규모 CAPEX)**<br>- 예타 적합성: 초기 대규모투자 전제모델과 부합<br><br>**클라우드·SaaS 구독형 사업(OPEX)**<br>- 예타 적합성: 총사업비 산정방식이 구독형과 안맞아 제도개편 필요 |
| **차별화** | **정보화사업 특화 예타 개선 실무전략**<br>1. **신속예타(패스트트랙) 적극활용**: IT기술주기가 예타 조사기간보다 짧음 → 정보화 전용 신속예타 우선신청 → 기술노후화 리스크 최소화<br>2. **기술성분석 조기착수**: 경제성분석(B/C) 앞서 기술성(표준준수·상용화가능성) 사전검증 → 통과후 기술재검토로 인한 사업지연 방지<br>3. **클라우드형 사업 총사업비 재산정 전략**: 구독형(OPEX)은 초기 대규모CAPEX 아님 → 연간이용료 사업기간 환산 총사업비 산정방식 KDI 사전협의 → 예타대상 예측가능성 확보 |
