# 공공기관 정보화사업 예비타당성 조사 서브노트

> **두음 머리에 박기 🧠**
> - **경·정·기·재** (예타 4대 조사항목: **경**제성분석, **정**책성분석, **기**술성분석, **재**원조달가능성)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **예비타당성 조사 (예타, Preliminary Feasibility Study)** |
| **정의** | 예비타당성 조사는 대규모 신규 사업 착수 전 경제성·정책성·기술성 등을 종합 검토하여 사업 추진 여부를 사전 판단하는 제도(국가재정법 제38조, KDI 공공투자관리센터 주관)로, 총사업비 500억 원 이상(국고 300억 원 이상) 신규 사업이 대상이며 정보화사업도 예외가 아니다 |
| **키워드** | 국가재정법 제38조, B/C 비율, AHP 종합평가, 신속예타(패스트트랙) |
| **개념도** | `[ 대규모 신규 정보화사업 계획 ] ➔ [ 예타 대상 판정(총사업비 500억↑) ] ➔ [ 경·정·기·재 4대 분석 ] ➔ [ AHP 종합평가 ] ➔ [ 추진/보류 결정 ]` |
| **구성요소** | **예타 4대 조사항목(경·정·기·재)**: 경제성분석(B/C比, NPV, 정량적 재무 타당성), 정책성분석(국정과제 부합성·지역균형발전, 정성적 정책우선순위), 기술성분석(기술성숙도·상용화가능성·표준준수, 정보화사업 특화항목), 재원조달가능성(예산확보계획의 현실성, 중기재정계획 연계), AHP 종합평가(계층화분석기법으로 항목별 가중치 반영 종합점수 산출)<br>**문제점 및 개선방향**: 조사기간 장기화(6개월~1년, IT기술주기보다 김 → 정보화 전용 패스트트랙 도입), 경제성 편향평가(B/C 중심으로 공공성 사업 불리 → 정책성·기술성 가중치 상향), 기술변화 반영지연(조사완료 시 기술 노후화 → 사업계획 적정성 재검토 활성화), 클라우드·SaaS 부적합(초기 대규모투자 전제모델이 구독형 OPEX와 안맞음 → 예타대상 기준 개편), 조사 전문성 한계(IT전문인력 부족 → 정보화 전담 조사패널 확충) |
| **비교** | **전통 IT 구축사업(대규모 CAPEX)**<br>- 예타 적합성: 초기 대규모 투자 전제 모델과 부합<br><br>**클라우드·SaaS 구독형 사업(OPEX)**<br>- 예타 적합성: 총사업비 산정방식이 구독형과 안 맞아 제도 개편 필요 |
| **차별화** | **정보화사업 특화 예타 개선 실무 전략**<br>1. **신속예타(패스트트랙) 적극 활용**: IT 기술주기가 예타 조사기간보다 짧은 특성을 고려해, 정보화 전용 신속예타 트랙을 우선 신청하여 기술 노후화 리스크를 최소화.<br>2. **기술성 분석의 조기 착수**: 경제성 분석(B/C)에 앞서 기술성 분석(표준 준수·상용화 가능성)을 사전 검증해, 예타 통과 후 기술 재검토로 인한 사업 지연을 방지.<br>3. **클라우드형 사업의 총사업비 재산정 전략**: 구독형(OPEX) 사업은 초기 대규모 CAPEX가 아니므로, 연간 이용료를 사업기간으로 환산한 총사업비 산정 방식을 사전에 KDI와 협의해 예타 대상 여부 판단의 예측가능성을 확보. |
