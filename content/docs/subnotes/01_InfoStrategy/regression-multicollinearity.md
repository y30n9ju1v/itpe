# 회귀 분석 및 다중공선성 서브노트

> **두음 머리에 박기 🧠**
> - **선·독·등·정** (선형 회귀의 잔차(오차)에 대한 4대 기본 가정: **선**형성, **독**립성, **등**분산성, **정**규성)
> - **VIF 10 이상** (다중공선성 진단 임계치: 분산팽창인자 VIF 값이 10 이상일 때 공선성 심각으로 판정)
> - **라·원 / 릿·투** (규제화 기법 매핑: **라**쏘(Lasso)는 L**1** 규제 / **릿**지(Ridge)는 L**2** 규제)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **다중 선형 회귀 분석 (Linear Regression) 및 다중공선성 (Multicollinearity)** |
| **정의** | 독립·종속변수 간 인과관계 수식화 예측 **선형 회귀** + 독립변수 간 과도한 상관관계 → 회귀계수 분산 폭증·신뢰성 붕괴 **다중공선성 현상** |
| **키워드** | 잔차 기본 가정(선·독·등·정), OLS (최소자승법), VIF (분산팽창인자), 차원축소(PCA), L1/L2 Regularization |
| **개념도** | `[ 독립변수 X1, X2, X3 ]` ➔ `[ 다중 회귀 모델 : Y = β0 + β1X1 + β2X2 + β3X3 + ε ]` ➔ `[ 종속변수 Y ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▲&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;▲`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`└─ 강한 선형 상관성 관계 존재 (X1 ↔ X2) ➔ 다중공선성 발생`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`│`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼ 진단 및 통제 거버넌스`<br>`[ VIF 산정 ] ➔ VIF 10 이상 변수 선별 ➔ [ 변수 제거 / PCA 차원축소 / L1-L2 Regularization 규제 적용 ]` |
| **구성요소** | 1. **회귀 기본가정(선·독·등·정)**: 선형성(산점도)·독립성(더빈왓슨)·등분산성(잔차플롯)·정규성(Q-Q Plot)<br>2. **다중공선성**: 변수 간 공선성 → OLS 회귀계수 분산 증가 → 개별 유의성검정 무력화<br>3. **VIF(분산팽창인자)**: $VIF_i = \frac{1}{1-R_i^2}$ ($R_i^2$=$X_i$를 타 독립변수로 회귀한 결정계수)<br>4. **L1 규제(Lasso)**: 비용함수에 계수 절대값합 패널티 → 계수 0 수축 → 자동 변수선택<br>5. **L2 규제(Ridge)**: 비용함수에 계수 제곱합 패널티 → 계수 균등 축소 → 다중공선성 완화 |
| **비교** | **라쏘 회귀 (Lasso - L1)**<br>- 패널티 공식: $\lambda \sum |\beta_j|$ (절대값의 합)<br>- 특징: 계수 0으로 완전축소 → 불필요변수 자동제거 (Feature Selection)<br><br>**릿지 회귀 (Ridge - L2)**<br>- 패널티 공식: $\lambda \sum \beta_j^2$ (제곱의 합)<br>- 특징: 계수 0 근처 균등축소 → 전변수 유지하되 공선성 영향 감쇄 (안정적 예측) |
| **차별화** | **현업 빅데이터 분석 모델 설계 시 다중공선성 극복 및 알고리즘 조율 전략**<br>1. **ElasticNet 하이브리드 최적화**: 변수多(p>n)+강한 상관 그룹多 → L1 변수선택 + L2 그룹축소 결합한 **ElasticNet** → L1 ratio 튜닝으로 강건성 확보<br>2. **단계적 변수제거 프로토콜**: (1)VIF 10 초과 변수군 식별 (2)도메인지식으로 기여도 최저변수 순차제거 (3)Stepwise/전진·후진선택 결합 → 잔여변수 재진단<br>3. **PCA·PLS 연계**: 변수탈락 없이 정보유실 최소화 필요 시 → PCA로 독립 주성분 재생성 후 회귀, 또는 종속변수 공분산까지 고려하는 PLS 회귀 적용<br>4. **4대 척도 & 다중회귀 vs 로지스틱 선택기준**: 명목·서열(범주형)=순위·분류정보만 / 등간·비율(연속형)=간격·비율정보 포함 → 종속변수 연속값(매출액 예측)엔 최소제곱 다중회귀, 범주분류(대출 승인/거절)엔 최대우도 로지스틱회귀(시그모이드 확률출력, 혼동행렬·ROC로 검증) |
