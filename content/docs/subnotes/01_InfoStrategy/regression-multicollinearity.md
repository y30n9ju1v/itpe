# 회귀 분석 및 다중공선성 서브노트

> **두음 머리에 박기 🧠**
> - **선·독·등·정** (선형 회귀의 잔차(오차)에 대한 4대 기본 가정: **선**형성, **독**립성, **등**분산성, **정**규성)
> - **VIF 10 이상** (다중공선성 진단 임계치: 분산팽창인자 VIF 값이 10 이상일 때 공선성 심각으로 판정)
> - **라·원 / 릿·투** (규제화 기법 매핑: **라**쏘(Lasso)는 L**1** 규제 / **릿**지(Ridge)는 L**2** 규제)

---

| 분류 | 기술 기술사 서브노트 작성 예시 (1교시형 포맷) |
| :--- | :--- |
| **토픽명** | **다중 선형 회귀 분석 (Linear Regression) 및 다중공선성 (Multicollinearity)** |
| **정의** | 독립변수와 종속변수 간 인과관계를 수식화하여 예측하는 **선형 회귀**와, 독립변수 간 상관관계가 지나치게 높아 회귀 계수의 분산을 폭증시키고 신뢰성을 무너뜨리는 **다중공선성 현상** |
| **키워드** | 잔차 기본 가정(선·독·등·정), OLS (최소자승법), VIF (분산팽창인자), 차원축소(PCA), L1/L2 Regularization |
| **개념도** | `[ 독립변수 X1, X2, X3 ]` ➔ `[ 다중 회귀 모델 : Y = β0 + β1X1 + β2X2 + β3X3 + ε ]` ➔ `[ 종속변수 Y ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▲&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;▲`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`└─ 강한 선형 상관성 관계 존재 (X1 ↔ X2) ➔ 다중공선성 발생`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`│`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼ 진단 및 통제 거버넌스`<br>`[ VIF 산정 ] ➔ VIF 10 이상 변수 선별 ➔ [ 변수 제거 / PCA 차원축소 / L1-L2 Regularization 규제 적용 ]` |
| **구성요소** | 1. **회귀 기본가정 (선·독·등·정)**: 선형성(산점도), 독립성(더빈왓슨 검정), 등분산성(잔차 플롯), 정규성(Q-Q Plot)<br>2. **다중공선성 (Multicollinearity)**: 변수 간 공선성으로 OLS 회귀계수 분산이 커져 개별 통계적 유의성 검정이 무력화됨<br>3. **VIF (Variance Inflation Factor)**: 분산팽창인자. $VIF_i = \frac{1}{1-R_i^2}$. $R_i^2$은 $X_i$를 타 독립변수로 회귀분석한 결정계수<br>4. **L1 규제 (Lasso)**: 비용함수에 회귀 계수 절대값의 합 패널티 추가. 가중치 계수를 0으로 수축시켜 자동 변수 선택<br>5. **L2 규제 (Ridge)**: 비용함수에 회귀 계수 제곱합 패널티 추가. 가중치 계수를 고르게 작게 만들어 다중공선성 완화 |
| **비교** | **라쏘 회귀 (Lasso - L1)**<br>- **패널티 공식**: $\lambda \sum |\beta_j|$ (절대값의 합)<br>- **핵심 특징**: 가중치를 0으로 완전히 축소하여 불필요한 독립변수 자동 제거 (Feature Selection)<br><br>**릿지 회귀 (Ridge - L2)**<br>- **패널티 공식**: $\lambda \sum \beta_j^2$ (제곱의 합)<br>- **핵심 특징**: 가중치를 0 근처로 작게 조율하여 모든 변수를 유지하되 공선성 영향력을 감쇄 (안정적 예측) |
| **차별화** | **현업 빅데이터 분석 모델 설계 시 다중공선성 극복 및 알고리즘 조율 전략**<br>1. **ElasticNet을 통한 하이브리드 최적화**: 변수가 매우 많고(p > n) 변수 간 강한 상관관계 그룹이 여러 개 존재할 때는, L1 규제의 성긴 변수 선택과 L2 규제의 그룹별 가중치 축소 기능을 합친 **ElasticNet** 모델을 하이퍼파라미터 튜닝(L1 ratio)하여 강건성 확보.<br>2. **다중공선성 진단 시 단계적 변수 제거 프로토콜**: (1) VIF가 10을 초과하는 변수군 식별, (2) 도메인 지식을 활용해 기여도가 가장 낮은 변수 순차 제거, (3) 단계적 선택법(Stepwise Selection)이나 전진/후진 선택법을 결합하여 잔여 변수 간 다중공선성 재진단.<br>3. **차원 축소(PCA)와 부분최소자승(PLS) 연계**: 변수 탈락 없이 정보 유실을 최소화해야 할 때는 주성분 분석(PCA)을 통해 독립적인 주성분(Principal Component)을 재생성하여 회귀 분석을 돌리거나, 종속변수와의 공분산까지 함께 고려하는 PLS 회귀 분석을 적용. |
