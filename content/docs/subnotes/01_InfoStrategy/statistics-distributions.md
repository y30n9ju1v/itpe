# 통계 분석용 확률 분포 모델 서브노트

> **두음 머리에 박기 🧠**
> - **베·이·포·기** (대표적 이산 확률 분포 4종: **베**르누이 Bernoulli, **이**항 Binomial, **포**아송 Poisson, **기**하 Geometric)
> - **정·지·티·에프** (대표적 연속 확률 분포 4종: **정**규 Normal, **지**수 Exponential, **T**-분포 Student's t, **F**-분포/카이제곱)
> - **횟·시·연** (포아송과 지수분포의 상대적 관계: 사건 발생 **횟**수 확률은 포아송 분포 ➔ 다음 사건까지의 대기 **시**간 및 간격은 지수 분포 ➔ 두 분포는 상호 **연**계 관계)

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **확률 분포 (Probability Distributions) 분류 및 비즈니스 분석 활용** |
| **정의** | 확률 변수가 가질 수 있는 값과 그 값이 나타날 확률을 수학적으로 매핑한 함수 구조로, 변수의 연속성에 따라 **이산 확률 분포(베·이·포·기)와 연속 확률 분포(정·지·티·에프)**로 대별되는 통계학적 기초 모형 |
| **키워드** | 확률 질량/밀도 함수, 이항 분포, 포아송 분포, 정규 분포, 지수 분포 (무기억성), 대기행렬 ($M/M/1$) |
| **개념도** | **[ 포아송 분포(사건 횟수)와 지수 분포(대기 시간)의 상호 변환 루프 ]**<br>단위 시간 (예: 1시간)<br>`├─────────★─────────────★───────────────★─────────┤` (★: 패킷/고객 유입 사건)<br>&nbsp;&nbsp;&nbsp;&nbsp;`│`<br>&nbsp;&nbsp;&nbsp;&nbsp;`├─➔ [ 1시간 동안 유입된 건수 (횟수) ] ➔ 포아송 분포 (Poisson Distribution) : P(X=k) = e^-λ * λ^k / k!`<br>&nbsp;&nbsp;&nbsp;&nbsp;`│`<br>&nbsp;&nbsp;&nbsp;&nbsp;`└─➔ [ 고장/유입 사건 간의 시간 간격 (대기시간) ] ➔ 지수 분포 (Exponential Distribution) : f(t) = λ * e^-λt`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`└─ (무기억성 Memoryless 특징 제공 : 과거 사건이 미래 대기에 영향을 주지 않음)` |
| **구성요소** | 1. **이항 분포**: 결과가 독립적인 성공/실패인 베르누이 시행을 $n$번 반복 시 성공 횟수의 분포. $E(X)=np$, $V(X)=npq$<br>2. **포아송 분포**: 일정한 시간/공간 내에서 아주 드물게 일어나는 희귀 사건(예: 접속 폭증)의 발생 횟수 분포<br>3. **정규 분포**: 자연계의 표본 데이터가 수렴하는 좌우대칭의 종 모양 연속 분포. 중심극한정리(CLT)의 근본 모형<br>4. **지수 분포**: 사건과 사건 사이의 시간적 대기 간격을 모형화하는 분포. 부품 수명 주기 및 고장 간격(MTBF)에 활용 |
| **비교** | **이항 분포 (Binomial Distribution)**<br>- **변수 특징**: 이산 확률 변수 (시행 횟수 $n$이 유한함)<br>- **수학적 전제**: 각 시행이 베르누이 독립 시행을 만족해야 함<br>- **핵심 파라미터**: 시행 횟수 $n$, 성공 확률 $p$<br><br>**포아송 분포 (Poisson Distribution)**<br>- **변수 특징**: 이산 확률 변수 (이항분포의 $n \rightarrow \infty$, $p \rightarrow 0$ 인 극한치)<br>- **수학적 전제**: 단위 시간당 평균 발생 빈도($\lambda$)가 고정되어야 함<br>- **핵심 파라미터**: 단위 시간당 평균 발생 횟수 $\lambda$ |
| **차별화** | **IT 시스템 가용성 설계 및 대기행렬(Queueing Theory)에서의 확률 분포 실무 응용**<br>1. **$M/M/1$ 큐잉 모델을 이용한 시스템 대기 오버헤드 산정**: 웹 서버의 요청 도달률을 포아송($M$), 서비스 처리 성능을 지수 분포($M$), 처리 서버 대수 1대($1$)로 세팅하여 평균 대기 큐 크기와 시스템 내 총 대기 시간 계산 및 인프라 스펙 튜닝에 적용.<br>2. **지수 분포의 무기억성 (Memoryless Property) 한계와 베이불(Weibull) 분포 보완**: 지수 분포는 "기존에 아무리 오래 작동했어도 지금 당장 고장 날 확률은 항상 같다"는 무기억성을 가져 부품 마모 현상을 반영하지 못함. 따라서 시간이 흐름에 따라 고장률이 증가하는 실제 물리 서버의 수명 평가는 **베이불 분포**를 대안으로 모델링.<br>3. **6시그마 제품 공정 불량률 검정**: 정규분포의 꼬리 면적을 활용하여, 제품 규격 한계치가 평균으로부터 $6\sigma$(불량률 100만 개당 3.4개) 범위 내에 안착하도록 관리 상하한선(LSL, USL)을 수립하여 정밀 공정 제어 실천. |
