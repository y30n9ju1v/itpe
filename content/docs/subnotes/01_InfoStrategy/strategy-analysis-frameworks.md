# 경영전략 분석 프레임워크: SWOT/STP/3C/PEST/MECE/LISS 서브노트

> **두음 머리에 박기 🧠**
> - **강·약·기·위** (SWOT 4요소: **강**점 Strengths, **약**점 Weaknesses, **기**회 Opportunities, **위**협 Threats)
> - **세·타·포** (마케팅 STP 3단계: **세**분화 Segmentation, **타**게팅 Targeting, **포**지셔닝 Positioning)
> - **자·고·경** (3C 3주체: **자**사 Company, **고**객 Customer, **경**쟁사 Competitor)
> - **정·경·사·기** (PEST 4대 거시환경: **정**치 Political, **경**제 Economic, **사**회 Social, **기**술 Technological)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **경영환경 분석 프레임워크 (SWOT, STP, 3C, PEST) 및 컨설팅 구조화 원리 (MECE, LISS)** |
| **정의** | 조직 내부 강약점과 외부 기회·위협을 통합 분석하는 SWOT, 시장을 세분화·타겟팅·포지셔닝하는 마케팅 STP, 자사·고객·경쟁사 관점의 미시적 3C 분석, 정치·경제·사회·기술의 거시환경을 분석하는 PEST를 아우르는 경영전략 분석기법군이며, MECE(상호배타·전체포괄)와 LISS(선형독립·전체공간생성)는 이러한 분석을 구조적으로 빠짐없이 중복 없이 수행하기 위한 컨설팅 기본 원리이다 |
| **키워드** | SO/ST/WO/WT 매트릭스, 세분화-타겟팅-포지셔닝, 미시(3C) vs 거시(PEST), 집합론(MECE) vs 선형대수(LISS), 로직트리 |
| **개념도** | `[ PEST(거시환경) ] ─┐`<br>`[ 3C(미시시장) ]   ─┼─➔ [ SWOT(O/T 입력값) ] ──SO/ST/WO/WT──➔ [ 전략 대안 ]`<br>`[ 내부 역량 ]     ─┘                                              │`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`[ STP(세·타·포) 마케팅 전략 수립 ]`<br>`※ MECE(집합론) / LISS(선형대수)는 위 각 분석의 항목·요인 분해가 중복·누락 없도록 검증하는 메타 원리` |
| **구성요소** | **SWOT**: 강점(S)·약점(W, 내부) × 기회(O)·위협(T, 외부)를 매트릭스로 정리, SO/ST/WO/WT 4대 전략 도출<br>**STP**: Segmentation(시장 세분화)-Targeting(목표시장 선정)-Positioning(차별적 위치 설정)<br>**3C**: Company(자사)·Customer(고객)·Competitor(경쟁사) 3주체의 상대적 역학관계 분석(오마에 겐이치), 신제품 출시 전 시장 포지셔닝에 적합<br>**PEST**: 정치·경제·사회·기술 4대 거시환경 요인, 신시장/국가 진출 등 장기 전략 수립에 적합<br>**MECE**: 상호배타적(Mutually Exclusive, 중복없음) + 전체포괄적(Collectively Exhaustive, 누락없음) 분류 원칙(McKinsey)<br>**LISS**: 요인들이 선형적으로 독립(서로 다른 차원)이면서 전체 해공간을 생성(Span)해야 한다는 원리(선형대수학 차용)<br>**MECE/LISS 적용 방법론**: 로직트리(MECE), 밸류체인 분석(MECE), 가설 트리(MECE+LISS), 요인분석(LISS) |
| **비교** | **SWOT**<br>- 분석범위: 내부+외부 통합<br>- 초점: 전략 대안 도출<br><br>**3C**<br>- 분석범위: 시장 내 미시적 3주체<br>- 초점: 시장 포지셔닝<br><br>**PEST**<br>- 분석범위: 거시적 외부환경<br>- 초점: 장기 리스크/기회<br>- 상호관계: PEST/3C 결과가 SWOT의 O/T 입력값이 됨<br><br>**MECE (집합론 기반)**<br>- 핵심조건: 상호배타성 + 전체포괄성<br>- 정량화: 정성적 분류 중심<br><br>**LISS (선형대수 기반)**<br>- 핵심조건: 선형 독립성 + 전체공간 생성<br>- 정량화: 정량적 요인분석(회귀분석 등)에 적합 |
| **차별화** | **다층 프레임워크의 순차적 연계 활용 전략**<br>1. **거시(PEST)→미시(3C)→통합(SWOT)→실행(STP)의 계층적 적용**: 신사업 진출 시 PEST로 장기 거시 리스크를 먼저 스크리닝하고, 3C로 시장 내 경쟁 구도를 분석한 뒤, 그 결과를 SWOT의 O/T로 입력하여 SO/ST/WO/WT 전략을 도출하고, 최종적으로 STP로 실행 전략을 구체화하는 순차적 워크플로우 구축.<br>2. **MECE 검증을 전 분석 단계에 내재화**: SWOT/3C/PEST 각 항목을 도출할 때마다 MECE 체크리스트(중복·누락 여부)를 적용해 분석의 논리적 완결성을 사전 검증.<br>3. **정량 데이터 분석 시 LISS로 다중공선성 방지**: IT 성과 지표처럼 다수의 변수를 동시에 고려하는 정량 분석에서는 LISS 원리로 변수 간 독립성을 사전 검증하여 회귀분석의 다중공선성 문제를 예방. |
