# AI 신뢰성 검인증 제도 (CAT) 서브노트

> **두음 머리에 박기 🧠**
> - **가·견·공·설·투·안·개** (AI 신뢰성 7대 요건: **가**용성, **견**고성, **공**정성, **설**명가능성, **투**명성, **안**전성, **개**인정보보호)
> - **신·예·기·현·인·발** (검인증 6단계: **신**청 → **예**비검토 → **기**술평가 → **현**장심사 → **인**증결정 → **발**급)

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **AI 신뢰성 검인증 제도 (CAT: Certified AI Trustworthiness)** |
| **정의** | 과기정통부+TTA 주관 → AI 신뢰성·안전성·공정성 객관평가·인증 국내제도, 일정기준 충족 보증 |
| **키워드** | TTA, 7대 신뢰성 요건, 검인증 절차, ISO/IEC 42001, 인공지능기본법 |
| **개념도** | `[ AI 사업자 신청 ] → [ 예비검토(서류) ] → [ 기술평가(7대요건) ] → [ 현장심사(운영환경) ] → [ 인증결정(심의) ] → [ 인증서 발급(유효 2년) ]` |
| **구성요소** | 1. **7대 신뢰성 요건**: 가용성·견고성·공정성·설명가능성·투명성·안전성·개인정보보호<br>2. **검인증 절차 6단계**: 신청→예비검토→기술평가→현장심사→인증결정→발급(유효 2년, 사후관리)<br>3. **주관기관**: 과기정통부(정책) + TTA(기술평가·인증)<br>4. **제도 목적**: 신뢰성 객관검증체계, 공공·민간 도입판단기준, 국제표준 대응 |
| **비교** | **ISO/IEC 42001**<br>- AI 관리시스템(경영시스템) 국제표준 인증<br>- 조직 AI 거버넌스 프로세스 인증<br><br>**CAT (국내)**<br>- AI 제품·서비스 자체 신뢰성 인증<br>- 상호보완적 취득 가능 |
| **차별화** | **고위험 AI 규제 연계 CAT 인증 전략**<br>1. **인공지능기본법 고위험 AI 대응**: 사전 영향평가 논의 → CAT 선제확보로 법적리스크 관리<br>2. **AI RMF·ISO 42001 3단 인증체계**: NIST AI RMF(위험관리) → ISO 42001(관리시스템) → CAT(제품신뢰성), 계층적 로드맵<br>3. **기술평가 중심 신뢰성 내재화**: 설명가능성·공정성 → 개발초기 XAI·편향감사 내재화 → 현장심사 통과율 제고 |
