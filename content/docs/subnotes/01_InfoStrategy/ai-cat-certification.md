# AI 신뢰성 검인증 제도 (CAT) 서브노트

> **두음 머리에 박기 🧠**
> - **가·견·공·설·투·안·개** (AI 신뢰성 7대 요건: **가**용성, **견**고성, **공**정성, **설**명가능성, **투**명성, **안**전성, **개**인정보보호)
> - **신·예·기·현·인·발** (검인증 6단계: **신**청 → **예**비검토 → **기**술평가 → **현**장심사 → **인**증결정 → **발**급)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **AI 신뢰성 검인증 제도 (CAT: Certified AI Trustworthiness)** |
| **정의** | 과학기술정보통신부와 한국정보통신기술협회(TTA)가 주관하여 AI 시스템의 신뢰성·안전성·공정성을 객관적으로 평가·인증하는 국내 제도로, AI 제품·서비스가 일정 수준의 신뢰성 기준을 충족함을 보증 |
| **키워드** | TTA, 7대 신뢰성 요건, 검인증 절차, ISO/IEC 42001, 인공지능기본법 |
| **개념도** | `[ AI 사업자 신청 ] → [ 예비검토(서류) ] → [ 기술평가(7대요건) ] → [ 현장심사(운영환경) ] → [ 인증결정(심의) ] → [ 인증서 발급(유효 2년) ]` |
| **구성요소** | 1. **7대 신뢰성 요건**: 가용성, 견고성, 공정성, 설명가능성, 투명성, 안전성, 개인정보보호<br>2. **검인증 절차 6단계**: 신청 → 예비검토 → 기술평가 → 현장심사 → 인증결정 → 인증서 발급(유효기간 2년, 사후관리)<br>3. **주관기관**: 과학기술정보통신부(정책) + TTA(기술평가·인증)<br>4. **제도 목적**: AI 신뢰성 객관적 검증체계 마련, 공공·민간 AI 도입 판단기준 제공, 국제표준 대응 |
| **비교** | **ISO/IEC 42001**<br>- AI 관리시스템(경영시스템) 국제표준 인증<br>- 조직의 AI 거버넌스 프로세스 인증<br><br>**CAT (국내)**<br>- AI 제품·서비스 자체의 신뢰성 인증<br>- 두 인증은 상호 보완적으로 취득 가능 |
| **차별화** | **고위험 AI 규제와 연계한 CAT 인증 전략**<br>1. **인공지능기본법 고위험 AI 의무화 대응**: 고위험 AI 사전 영향평가 의무화 논의와 맞물려, CAT 인증을 사전 확보함으로써 법적 리스크를 선제적으로 관리.<br>2. **AI RMF·ISO 42001과의 3단 인증 체계 구축**: NIST AI RMF(위험관리 프로세스) → ISO/IEC 42001(관리시스템) → CAT(제품 신뢰성)의 계층적 인증 로드맵을 수립해 국내외 규제에 동시 대응.<br>3. **기술 평가 중심의 신뢰성 내재화**: 7대 요건 중 설명가능성·공정성 항목을 개발 초기 단계부터 XAI·편향감사 기법으로 내재화하여 현장심사 통과율을 제고. |
