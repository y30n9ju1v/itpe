# 내부통제 COSO 프레임워크와 위험관리 ISO 31000 서브노트

> **두음 머리에 박기 🧠**
> - **통·위·통·정·모** (COSO 내부통제 5대 구성요소: **통**제환경, **위**험평가, **통**제활동, **정**보와 의사소통, **모**니터링)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **COSO(Committee of Sponsoring Organization) 내부통제 프레임워크 및 ISO 31000 위험관리 표준** |
| **정의** | COSO: 재무보고 신뢰성·법규준수·운영효율성 확보 위한 내부통제 체계 프레임워크(1992 COSO Cube, 2013 개정) / ISO 31000: 조직 전 활동 리스크 식별·분석·평가·처리 원칙·프로세스 국제표준(2009 제정, 2018 개정) |
| **키워드** | 통·위·통·정·모, COSO ERM, SOX법, 원칙 기반(Principle-based), 리스크관리 프로세스 |
| **개념도** | `[ 이사회/경영진 의지 ] ──➔ [ COSO 내부통제 5대 구성요소(통·위·통·정·모) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼ (위험평가 단계에 적용)`<br>`[ ISO 31000 리스크관리 프로세스 ] ──➔ 식별→분석→평가→처리→모니터링` |
| **구성요소** | **COSO 내부통제 5대 구성요소(통·위·통·정·모)**: ①통제환경(윤리·가치관, 이사회감독) ②위험평가(목표저해 위험 식별·분석) ③통제활동(승인·검증·직무분리 등 정책·절차) ④정보와 의사소통(내부통제정보 적시공유) ⑤모니터링(통제 지속적 유효성평가)<br>**COSO ERM(2017) 확장**: 재무보고 통제중심 → 전략수립·성과-리스크 통합(가치창출 관점)으로 확장<br>**ISO 31000 프로세스**: 범위·상황·기준설정 → 리스크식별 → 리스크분석 → 리스크평가 → 리스크처리 → 모니터링·검토·의사소통 |
| **비교** | **COSO**<br>- 발행기관: 미국 민간단체(COSO)<br>- 목적: 내부통제+전사리스크관리, 재무보고 신뢰성 기원<br>- 적용범위: 미국 상장기업(SOX법 연계) 중심→확대<br><br>**ISO 31000**<br>- 발행기관: ISO(국제표준화기구)<br>- 목적: 조직 전반 모든유형 리스크관리 원칙·프로세스<br>- 적용범위: 업종·규모 무관 범용, 원칙기반(Principle-based) 유연 |
| **차별화** | **IT 리스크관리 두 표준 결합적용 실무전략**<br>1. **COSO 위험평가 단계에 ISO 31000 프로세스 이식**: COSO 5대요소 중 '위험평가' 수행 시 ISO 31000 식별-분석-평가-처리 프로세스 세부절차로 적용 → 상호보완 운용<br>2. **IT 장애·정보유출의 전사 리스크 편입**: 기술부서 문제국한 관행 탈피 → COSO ERM 가치창출 관점, 이사회 수준 전사 리스크등록부 통합관리<br>3. **감사위원회 보고체계 이원화 방지**: 재무보고 내부통제(COSO)·전사 리스크관리(ISO 31000) 별도채널 중복·누락 방지 → 단일 리스크대시보드 통합보고 |
