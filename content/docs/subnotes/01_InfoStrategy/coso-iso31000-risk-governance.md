# 내부통제 COSO 프레임워크와 위험관리 ISO 31000 서브노트

> **두음 머리에 박기 🧠**
> - **통·위·통·정·모** (COSO 내부통제 5대 구성요소: **통**제환경, **위**험평가, **통**제활동, **정**보와 의사소통, **모**니터링)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **COSO(Committee of Sponsoring Organization) 내부통제 프레임워크 및 ISO 31000 위험관리 표준** |
| **정의** | COSO는 재무보고의 신뢰성·법규 준수·운영 효율성을 확보하기 위해 조직이 갖추어야 할 내부통제 체계를 정의한 프레임워크(1992년 COSO Cube, 2013년 개정)이며, ISO 31000은 조직의 모든 활동에서 발생하는 리스크를 식별·분석·평가·처리하는 원칙과 프로세스를 규정한 국제 표준(2009년 제정, 2018년 개정)이다 |
| **키워드** | 통·위·통·정·모, COSO ERM, SOX법, 원칙 기반(Principle-based), 리스크관리 프로세스 |
| **개념도** | `[ 이사회/경영진 의지 ] ──➔ [ COSO 내부통제 5대 구성요소(통·위·통·정·모) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼ (위험평가 단계에 적용)`<br>`[ ISO 31000 리스크관리 프로세스 ] ──➔ 식별→분석→평가→처리→모니터링` |
| **구성요소** | **COSO 내부통제 5대 구성요소(통·위·통·정·모)**: ①통제환경(윤리·가치관, 이사회 감독) ②위험평가(목표 저해 위험 식별·분석) ③통제활동(승인·검증·직무분리 등 정책·절차) ④정보와 의사소통(내부통제 정보의 적시 공유) ⑤모니터링(통제의 지속적 유효성 평가)<br>**COSO ERM(2017) 확장**: 재무보고 통제 중심에서 전략 수립·성과와 리스크의 통합(가치 창출 관점)으로 확장<br>**ISO 31000 프로세스**: 범위·상황·기준 설정 → 리스크 식별 → 리스크 분석 → 리스크 평가 → 리스크 처리 → 모니터링·검토·의사소통 |
| **비교** | **COSO**<br>- 발행기관: 미국 민간단체(COSO)<br>- 목적: 내부통제 + 전사 리스크관리, 재무보고 신뢰성이 기원<br>- 적용범위: 미국 상장기업(SOX법 연계) 중심에서 확대<br><br>**ISO 31000**<br>- 발행기관: ISO(국제표준화기구)<br>- 목적: 조직 전반의 모든 유형 리스크관리 원칙·프로세스<br>- 적용범위: 업종·규모 무관 범용 적용, 원칙 기반(Principle-based)으로 유연 |
| **차별화** | **IT 리스크 관리에 두 표준을 결합 적용하는 실무 전략**<br>1. **COSO 위험평가 단계에 ISO 31000 프로세스 이식**: COSO의 5대 구성요소 중 '위험평가'를 수행할 때, ISO 31000의 식별-분석-평가-처리 프로세스를 세부 절차로 적용하여 두 표준을 상호 보완적으로 운용.<br>2. **IT 시스템 장애·정보유출을 전사 리스크로 편입**: 과거 IT 리스크를 기술 부서의 문제로 국한하던 관행에서 벗어나, COSO ERM의 가치 창출 관점에 따라 IT 리스크를 이사회 수준의 전사 리스크 등록부에 통합 관리.<br>3. **감사위원회 보고체계 이원화 방지**: 재무보고 내부통제(COSO 기준 보고)와 전사 리스크관리(ISO 31000 기준 보고)가 별도 채널로 운영되어 중복·누락이 발생하지 않도록, 단일 리스크 대시보드로 통합 보고. |
