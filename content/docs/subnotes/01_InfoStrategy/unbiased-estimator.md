# 불편추정량 서브노트

> **두음 머리에 박기 🧠**
> - **E(T̂) = θ** (불편추정량의 정의식: 추정량의 기댓값이 모수와 일치)
> - **불·효·일** (좋은 추정량의 3요건: **불**편성, **효**율성, **일**치성)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **불편추정량 (Unbiased Estimator)** |
| **정의** | 모수(θ) 추정 시 추정량(T̂)의 기댓값이 모수와 일치(E(T̂)=θ) → 반복 표본추출 시 추정오차가 한 방향으로 치우치지 않는 성질 |
| **키워드** | E(T̂)=θ, 편향(Bias), 표본분산(n-1), MSE, 일치추정량 |
| **개념도** | `표본평균 X̄ ──➔ E(X̄) = μ  (불편)`<br>`표본분산 S² = Σ(Xi-X̄)²/(n-1) ──➔ E(S²) = σ²  (불편)`<br>`MLE 분산 = Σ(Xi-X̄)²/n ──➔ E(<σ²)  (과소추정, 편향)` |
| **구성요소** | 1. **정의**: 추정량 T̂가 θ의 불편추정량 ⟺ E(T̂) = θ, 편향 B(T̂) = E(T̂) - θ = 0<br>2. **대표적 불편추정량**: 모평균→표본평균 X̄, 모분산→표본분산 S²=Σ(Xi-X̄)²/(n-1), 모비율→표본비율 p̂<br>3. **(n-1) 사용 이유**: 표본평균 사용 시 자유도 1 감소 → n으로 나누면 E(S²)<σ² 과소추정 → (n-1) 보정으로 불편성 확보<br>4. **좋은 추정량 요건**: 불편성(편향 없음), 효율성(MSE=Bias²+Variance 최소화), 일치성(n→∞ 시 확률수렴) |
| **비교** | **불편추정량**<br>- 조건: E(T̂) = θ<br>- 특징: 편향 없음, 그러나 분산이 클 수 있음<br><br>**일치추정량(Consistent Estimator)**<br>- 조건: n→∞ 시 T̂→θ (확률수렴)<br>- 특징: 불편이라도 비일치 가능, 일치라도 편향 가능 |
| **차별화** | **편향-분산 트레이드오프 관점의 추정량 선택 전략**<br>1. **MSE 기준 적용**: 불편추정량도 분산 크면 부정확 가능 → MSE(=Bias²+Variance) 종합기준 → 편향 일부 허용해도 분산 작은 추정량(예: Ridge 회귀) 선택 유리<br>2. **자유도 보정의 일반화**: 표본분산 (n-1) 보정원리 → 회귀분석 잔차자유도(n-p-1) 등 타 통계량 불편성 확보에도 동일적용<br>3. **불편성·일치성 동시검증**: 대표본에서는 일치성이 더 중요할 수 있음 → 두 성질 함께 검증 → 표본크기별 추정량 신뢰도 판단 |
