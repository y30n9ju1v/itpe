# 불편추정량 서브노트

> **두음 머리에 박기 🧠**
> - **E(T̂) = θ** (불편추정량의 정의식: 추정량의 기댓값이 모수와 일치)
> - **불·효·일** (좋은 추정량의 3요건: **불**편성, **효**율성, **일**치성)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **불편추정량 (Unbiased Estimator)** |
| **정의** | 모수(θ)를 추정할 때 추정량(T̂)의 기댓값이 실제 모수와 일치(E(T̂) = θ)하는 추정량으로, 반복 표본추출 시 추정 오차가 체계적으로 한 방향으로 치우치지 않는 성질을 가짐 |
| **키워드** | E(T̂)=θ, 편향(Bias), 표본분산(n-1), MSE, 일치추정량 |
| **개념도** | `표본평균 X̄ ──➔ E(X̄) = μ  (불편)`<br>`표본분산 S² = Σ(Xi-X̄)²/(n-1) ──➔ E(S²) = σ²  (불편)`<br>`MLE 분산 = Σ(Xi-X̄)²/n ──➔ E(<σ²)  (과소추정, 편향)` |
| **구성요소** | 1. **정의**: 추정량 T̂가 θ의 불편추정량 ⟺ E(T̂) = θ, 편향 B(T̂) = E(T̂) - θ = 0<br>2. **대표적 불편추정량**: 모평균→표본평균 X̄, 모분산→표본분산 S²=Σ(Xi-X̄)²/(n-1), 모비율→표본비율 p̂<br>3. **(n-1) 사용 이유**: 표본평균 사용 시 자유도 1 감소, n으로 나누면 E(S²)<σ²로 과소추정되므로 (n-1)로 보정해야 불편성 확보<br>4. **좋은 추정량 요건**: 불편성(편향 없음), 효율성(MSE=Bias²+Variance 최소화), 일치성(n→∞ 시 확률수렴) |
| **비교** | **불편추정량**<br>- 조건: E(T̂) = θ<br>- 특징: 편향 없음, 그러나 분산이 클 수 있음<br><br>**일치추정량(Consistent Estimator)**<br>- 조건: n→∞ 시 T̂→θ (확률수렴)<br>- 특징: 불편이라도 비일치 가능, 일치라도 편향 가능 |
| **차별화** | **편향-분산 트레이드오프 관점의 추정량 선택 전략**<br>1. **불편성만으로 판단하지 않는 MSE 기준 적용**: 불편추정량이라도 분산이 크면 실무적으로 부정확할 수 있으므로, MSE(=Bias²+Variance)를 종합 기준으로 삼아 편향을 약간 허용하더라도 분산이 작은 추정량(예: Ridge 회귀 추정량)을 선택하는 것이 유리할 수 있음.<br>2. **자유도 보정의 일반화**: 표본분산의 (n-1) 보정 원리를 회귀분석의 잔차자유도(n-p-1) 등 다른 통계량의 불편성 확보에도 동일하게 적용.<br>3. **불편성·일치성 동시 확보 검증**: 대표본 상황에서는 일치성 확보가 실무적으로 더 중요할 수 있으므로, 두 성질을 함께 검증해 표본크기에 따른 추정량 신뢰도를 판단. |
