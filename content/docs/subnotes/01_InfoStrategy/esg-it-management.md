# ESG 경영과 정보기술 서브노트

> **두음 머리에 박기 🧠**
> - **E·S·G** (환경 Environment, 사회 Social, 지배구조 Governance 3대 축)
> - **에·탄·그·디** (환경(E) 지원 IT: **에**너지관리시스템, **탄**소회계 플랫폼, **그**린 클라우드, **디**지털 트윈)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **ESG(Environment·Social·Governance) 경영과 IT** |
| **정의** | 재무성과 + 환경·사회·지배구조 지속가능성 통합관리 경영 패러다임, IT는 ESG 데이터 수집·분석·자동화 수단이자 그 자체 환경영향 관리대상 |
| **키워드** | E·S·G 3대 축, Scope 1·2·3 배출량, GHG Protocol, 그린 클라우드, PUE·WUE |
| **개념도** | `[ E 환경 ] ──탄소중립/에너지효율──➔`<br>`[ S 사회 ] ──공급망윤리/정보보안──➔  [ ESG 데이터 플랫폼(IT) ] ──➔ [ 통합 공시(GRI·SASB·TCFD) ]`<br>`[ G 지배구조 ] ──이사회독립성/공시투명성──➔` |
| **구성요소** | 1. **환경(E) 지표/IT**: Scope 1·2·3 배출량, 에너지집약도, WUE / EMS·탄소회계 플랫폼·그린 클라우드·디지털 트윈<br>2. **사회(S) 지표/IT**: 정보보안 사고 건수, 디지털 포용 지수 / PET(개인정보보호기술)·AI 공정성 도구·웹 접근성(WCAG)<br>3. **지배구조(G) 지표/IT**: IT거버넌스 성숙도(COBIT), 사이버보안 투자비율 / ESG 데이터 플랫폼·블록체인·IT감사 자동화(SIEM·SOAR) |
| **비교** | **전통적 IT 경영**<br>- 목표: 비용 효율·서비스 품질<br>- 평가: 재무 성과 중심<br><br>**ESG 지원 IT**<br>- 목표: 비재무(환경·사회·지배구조) 성과까지 통합<br>- 평가: GRI·SASB·TCFD 기준 비재무 공시 품질 포함 |
| **차별화** | **IT 자체 환경영향 관리 포함 ESG-IT 전략 로드맵**<br>1. **데이터센터 환경영향 관리**: PUE(전력효율)·WUE(수자원효율) 도입 → 그린클라우드 단계적 전환, IT인프라=ESG 대상+수단 동시반영<br>2. **탄소회계 자동화 플랫폼 구축**: Scope 1·2·3 배출량 자동수집·산출 → 공시 신뢰도·속도 개선<br>3. **G(지배구조)축-IT거버넌스 연계**: COBIT 기반 IT거버넌스 성숙도 → ESG 공시지표 편입, 이사회 IT리스크 관리책임 명문화 |
