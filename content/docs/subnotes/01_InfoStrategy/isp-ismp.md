# ISP 및 ISMP 서브노트

> **두음 머리에 박기 🧠**
> - **환·현·미·이** (ISP 추진 4단계: **환**경 분석 ➔ **현**행 As-Is 분석 ➔ **미**래 To-Be 설계 ➔ **이**행 계획 수립)
> - **상·명·합·조** (ISMP 추진 성과 요건: 요구사항 **상**세화, 사업 범위 **명**확화, 예산 **합**리화, 이해관계자 **조**율)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **정보전략계획 (ISP) 및 정보시스템 마스터플랜 (ISMP)** |
| **정의** | 경영비전 지원 중장기 IT 로드맵 수립 **ISP**와, 개별 정보화사업 발주요건 도출 위해 요구사항을 정밀화하는 **ISMP 수립 기술** |
| **키워드** | As-Is/To-Be, 이행계획, 요구사항 상세화, 기능점수(FP) 예산 산정, RFP (제안요청서) 도출, 소프트웨어 안전성 |
| **개념도** | `[ 경영 전략 및 정보화 비전 ]` (비즈니스 Alignment)<br>&nbsp;&nbsp;&nbsp;&nbsp;`│`<br>&nbsp;&nbsp;&nbsp;&nbsp;`▼ 중장기 로드맵 수립 (3~5년 주기)`<br>`[ ISP (정보전략계획) ]` ── As-Is 분석 ➔ To-Be 설계 ➔ 이행 로드맵 도출 (거시적)<br>&nbsp;&nbsp;&nbsp;&nbsp;`│`<br>&nbsp;&nbsp;&nbsp;&nbsp;`▼ 개별 구축 사업 발주 준비 (1년 주기)`<br>`[ ISMP (마스터플랜) ]` ── 현황 세부 진단 ➔ 기능 요건 정의 ➔ RFP 도출 (미시적 상세화)<br>&nbsp;&nbsp;&nbsp;&nbsp;`│`<br>&nbsp;&nbsp;&nbsp;&nbsp;`▼ 발주 및 개발 집행`<br>`[ 시스템 구축 (SI) ]` ── FP 기반 정밀 예산 확보 및 조달 청약 |
| **구성요소** | 1. **ISP 환경분석**: 내·외부 메가트렌드 분석(PEST, 3C), 경영목표·IT역량 성숙도 분석<br>2. **ISP 미래 아키텍처**: 정보시스템·기술인프라·데이터 아키텍처 To-Be 모델 및 과제(Gap) 도출<br>3. **ISMP 현황 세부진단**: 개별 타겟시스템 중심 상세 업무프로세스 분석 + 사용자요구 조사<br>4. **ISMP 요구사항 상세화**: 요구사항 기능명세 + 기능점수(FP) 산출 → 발주예산 합리적 산정<br>5. **ISMP 발주 준비**: RFP 초안 작성, 사업기간 산정모델 활용한 적정 사업기간 산정 |
| **비교** | **ISP (정보전략계획)**<br>- 관점/범위: 전사·범정부 관점 / 중장기(3~5년) IT 로드맵·투자방향성 정의<br>- 결과물: 전사 정보화 마스터플랜·이행계획서, EA 연계모델<br><br>**ISMP (정보시스템 마스터플랜)**<br>- 관점/범위: 특정 단일사업 관점 / 즉시발주 가능한 미시적 기능명세·아키텍처 설계<br>- 결과물: 요구사항 상세정의서, 기능별 예산산정서, RFP |
| **차별화** | **공공 정보화사업 요구사항 불명확 장애극복 ISMP 실무전략**<br>1. **FP 기반 정밀 사업대가 산정**: ISP의 거시적/임의적 예산산정(빅뱅식 일정지연 유발) 지양 → ISMP 요구사항 상세화로 논리파일(ILF/EIF)·트랜잭션(EI/EO/EQ) 기반 기능점수 예산 정밀산정, 예산부족 리스크 원천통제<br>2. **설계단계 SW 안전(Safety) 요건 반영**: 국방·항공·철도 등 기능안전(Functional Safety) 필수분야는 ISMP 단계부터 위해성분석(HARA)·기능격리(Memory/Process Isolation) 설계 명세화 → 개발중 규제미준수 재설계 리스크 방지<br>3. **애자일 발주 대응 백로그 테일러링**: 애자일 발주 시 ISMP 단계에서 MVP 단위 명확화 + User Story 형태 초기 제품백로그 구축 → 계약 유연성 확보 |
