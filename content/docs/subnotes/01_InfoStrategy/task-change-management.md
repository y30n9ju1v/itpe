# 공공SW사업 과업변경 문제점과 판단기준, 절차 서브노트

> **두음 머리에 박기 🧠**
> - **판·대·서·협·하** (과업변경 기존 5대 문제점: **판**단기준 부재, **대**가 미지급 관행, 협의체(**협**) 부재, **서**면화 미흡, **하**도급 전이)
> - **접·영·협·대·계·이** (과업변경 6단계 절차: **접**수 ➔ **영**향도분석 ➔ **협**의·심의 ➔ **대**가산정 ➔ **계**약변경 ➔ **이**행·기록)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **공공SW사업 과업변경가이드 (과기정통부)** |
| **정의** | 과업변경이란 계약 체결 후 사업 범위·내용·일정 등 계약사항을 변경하는 것으로, 과기정통부는 공정하고 합리적인 과업변경이 이루어지도록 공공소프트웨어사업 과업변경가이드를 수립·배포하여, 판단 권고기준과 변경 절차를 표준화하였다 |
| **키워드** | 과업변경심의위원회, SIRS 명세, 기능점수(FP) 대가산정, 하도급 전이 |
| **개념도** | `[ 변경요청 접수 ] ➔ [ 영향도분석(일정·비용·품질) ] ➔ [ 협의·심의(CCB) ] ➔ [ 대가산정(FP기준) ] ➔ [ 계약변경 ] ➔ [ 이행·기록 ]` |
| **구성요소** | **기존 과업변경 5대 문제점(판·대·서·협·하)**: 판단기준 부재(계약범위 내/외 객관적 기준 없음), 대가 미지급 관행(무상처리 관행화), 협의체 부재(공식 조정채널 없음), 서면화 미흡(구두지시로 분쟁 시 입증곤란), 하도급 전이(원사업자가 부담 전가)<br>**적정 과업변경 판단 권고기준**: ①계약목적 부합성(원 계약 목적·범위 이탈 여부) ②요구사항 명확성(RFP/SIRS 미명시 여부) ③기술적 난이도 변화(공수 증가폭) ④원인 제공자(발주기관 요구 vs 수행사 귀책)<br>**과업변경 6단계 절차(접·영·협·대·계·이)**: ①변경요청 접수(변경요청서) ②영향도분석(영향분석보고서) ③협의·심의(과업변경심의위원회/CCB, 심의결과서) ④대가산정(FP 기준 대가산정내역서) ⑤계약변경(변경계약서) ⑥이행·기록(변경이력대장) |
| **비교** | **기존 관행**<br>- 판단: 담당자 개인 재량<br>- 대가: 무상 처리 관행<br>- 기록: 구두 지시, 분쟁 시 입증 곤란<br><br>**과업변경가이드 적용 후**<br>- 판단: 4대 권고기준(계약목적·요구사항명확성·난이도변화·원인제공자)<br>- 대가: FP 기준 객관적 산정<br>- 기록: 6단계 절차의 문서화(서면화) |
| **차별화** | **과업변경 분쟁 최소화를 위한 실무 로드맵**<br>1. **RFP/SIRS 단계에서의 사전 예방**: 과업변경 분쟁의 근본 원인이 RFP 단계 요구사항 불명확성에 있으므로, RFP 작성 단계에서 SIRS 고유번호·수용기준을 명확히 하여 착수 이후 판단기준 부재 문제를 최소화.<br>2. **하도급 전이 방지를 위한 대가 연동 조항**: 원사업자-하도급업체 계약에 과업변경 대가산정 결과가 자동 반영되는 조항을 명문화하여, 원사업자가 변경 부담을 하도급업체에 일방 전가하는 관행 차단.<br>3. **PMO/감리와 과업변경심의위원회의 연계**: 영향도분석 단계에서 PMO의 사업관리 데이터를 활용하고, 심의 결과를 감리 점검항목에 반영해 과업변경 관리의 객관성과 추적성을 강화. |
