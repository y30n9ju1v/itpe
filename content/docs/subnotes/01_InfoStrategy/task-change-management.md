# 공공SW사업 과업변경 문제점과 판단기준, 절차 서브노트

> **두음 머리에 박기 🧠**
> - **판·대·서·협·하** (과업변경 기존 5대 문제점: **판**단기준 부재, **대**가 미지급 관행, 협의체(**협**) 부재, **서**면화 미흡, **하**도급 전이)
> - **접·영·협·대·계·이** (과업변경 6단계 절차: **접**수 ➔ **영**향도분석 ➔ **협**의·심의 ➔ **대**가산정 ➔ **계**약변경 ➔ **이**행·기록)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **공공SW사업 과업변경가이드 (과기정통부)** |
| **정의** | 계약체결 후 사업범위·내용·일정 등 계약사항 변경 → 과기정통부가 공정·합리적 변경을 위해 공공SW사업 과업변경가이드 수립·배포, 판단 권고기준·변경절차 표준화 |
| **키워드** | 과업변경심의위원회, SIRS 명세, 기능점수(FP) 대가산정, 하도급 전이 |
| **개념도** | `[ 변경요청 접수 ] ➔ [ 영향도분석(일정·비용·품질) ] ➔ [ 협의·심의(CCB) ] ➔ [ 대가산정(FP기준) ] ➔ [ 계약변경 ] ➔ [ 이행·기록 ]` |
| **구성요소** | **기존 과업변경 5대 문제점(판·대·서·협·하)**: 판단기준 부재(계약범위 내/외 객관기준 無), 대가 미지급 관행(무상처리 관행), 협의체 부재(공식조정채널 無), 서면화 미흡(구두지시→분쟁 시 입증곤란), 하도급 전이(원사업자 부담전가)<br>**적정 과업변경 판단 권고기준**: ①계약목적 부합성(원계약 목적·범위 이탈여부) ②요구사항 명확성(RFP/SIRS 미명시여부) ③기술적 난이도변화(공수 증가폭) ④원인제공자(발주기관 요구 vs 수행사 귀책)<br>**과업변경 6단계 절차(접·영·협·대·계·이)**: ①접수(변경요청서) ②영향도분석(영향분석보고서) ③협의·심의(CCB, 심의결과서) ④대가산정(FP기준 산정내역서) ⑤계약변경(변경계약서) ⑥이행·기록(변경이력대장) |
| **비교** | **기존 관행**<br>- 판단: 담당자 개인 재량<br>- 대가: 무상 처리 관행<br>- 기록: 구두 지시, 분쟁 시 입증 곤란<br><br>**과업변경가이드 적용 후**<br>- 판단: 4대 권고기준(계약목적·요구사항명확성·난이도변화·원인제공자)<br>- 대가: FP 기준 객관적 산정<br>- 기록: 6단계 절차의 문서화(서면화) |
| **차별화** | **과업변경 분쟁 최소화 실무 로드맵**<br>1. **RFP/SIRS 단계 사전예방**: 분쟁 근본원인=RFP 요구사항 불명확 → SIRS 고유번호·수용기준 명확화 → 판단기준부재 문제 최소화<br>2. **하도급 전이방지 대가연동 조항**: 원사업자-하도급 계약에 과업변경 대가산정 결과 자동반영 조항 명문화 → 부담 일방전가 차단<br>3. **PMO/감리와 CCB 연계**: 영향도분석 시 PMO 사업관리데이터 활용 → 심의결과 감리 점검항목 반영 → 객관성·추적성 강화 |
