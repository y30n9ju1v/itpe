# 클라우드·빅데이터 지능정보기술 감리 서브노트

> **두음 머리에 박기 🧠**
> - **계·이·운** (클라우드 전환 3단계 감리: **계**획설계 → **이**전구현 → **운**영안정화)
> - **수·저·처·분·시** (빅데이터 분석단계 5단계 점검: **수**집 → **저**장 → **처**리 → **분**석 → **시**각화)
> - **신·이·활·하** (클라우드 정보화사업 4유형: **신**규개발, **이**관, **활**용(서비스구독), **하**이브리드)
> - **6R** (전환 전략: Rehost·Replatform·Repurchase·Refactor·Retire·Retain)

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **클라우드 전환·활용 및 빅데이터 사업 감리 (지능정보기술 감리)** |
| **정의** | 「지능정보기술 감리 실무 가이드」및 NIA 점검가이드에 근거하여, 빅데이터 분석 파이프라인과 클라우드 전환·활용 사업의 특수성(데이터 주권, CSAP 인증, 공동책임모델)을 반영한 감리 점검 체계 |
| **키워드** | CSAP 인증, 공동책임모델(Shared Responsibility), 6R 전략, 데이터 레이크, 비식별화 |
| **개념도** | `[ 클라우드 전환 3단계(계·이·운) ] ─┬─➔ 계획설계: 6R전략·CSAP·보안아키텍처`<br>`                                  ├─➔ 이전구현: 데이터이전완결성·IaC·보안설정`<br>`                                  └─➔ 운영안정화: SLA준수·비용최적화·백업복구`<br>`[ 빅데이터 분석 5단계(수·저·처·분·시) ] ─➔ 단계별 품질·보안·편향방지 점검` |
| **구성요소** | **클라우드 전환 3단계 감리**: ①계획설계(6R전략, CSAP인증, 책임공유모델, 데이터분류) ②이전구현(데이터이전 완결성 Hash검증, IaC, 블루/그린 배포) ③운영안정화(SLA·RTO/RPO 달성, 비용최적화, 통합모니터링)<br>**빅데이터 분석 5단계 점검**: 수집(적법성·품질기준)→저장(데이터레이크·보안레벨)→처리(파이프라인 신뢰성)→분석(알고리즘·편향방지)→시각화(대시보드 정확성)<br>**클라우드 정보화사업 4유형**: 신규개발, 기존시스템 이관, 클라우드서비스 활용(SaaS구독), 하이브리드 — 착수·중간·종료 3단계별 감리(CSAP·IAM·SLO·백업) |
| **비교** | **전통 IT 감리**<br>- 온프레미스 인프라 점검, 정적 문서 기반<br><br>**지능정보기술(클라우드·빅데이터) 감리**<br>- CSAP 인증·공동책임모델 등 클라우드 특유 항목 추가<br>- 데이터 파이프라인 편향·비식별화 등 빅데이터 특유 항목 추가<br>- IaC 코드 분석 등 현대적 점검 기법 활용 |
| **차별화** | **클라우드/빅데이터 융합 사업의 통합 감리 프레임워크**<br>1. **공동책임모델 기반 책임경계 명확화**: IaaS는 인프라 이상 전부 기관 책임, SaaS는 데이터·접근관리만 기관 책임으로 구분해, 감리 시 CSP와 기관 간 점검항목을 분리 배정.<br>2. **6R 전략과 데이터 이전 완결성의 연계 검증**: Rehost/Replatform 등 선택 전략에 따라 데이터 이전 검증 난이도가 달라지므로, 전략 선정 근거와 Hash 비교·레코드수 검증 절차를 함께 감리.<br>3. **빅데이터 편향(Bias) 방지와 개인정보 비식별화의 상시 점검화**: 분석단계 감리에서 결과 검증·편향방지 조치를 정기 점검항목으로 고정하여, 1회성 감리가 아닌 지속적 데이터 거버넌스 체계로 발전. |
