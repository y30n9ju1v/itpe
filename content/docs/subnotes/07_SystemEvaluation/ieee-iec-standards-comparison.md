| **토픽명** | **IEEE 표준과 IEC 국제표준 비교 (IEEE vs IEC Standards)** |
| **정의** | 정보통신·전기전자 분야 양대 국제표준기관 → IEEE(정보통신·컴퓨팅 기술표준), IEC(전기·전자기기 안전·상호운용성 표준) 담당 |
| **키워드** | IEEE 802.x/1588/730, IEC 62443/61508/61850, ISO/IEC JTC1, 개인회원 vs 국가회원, 표준 범위 비교 |
| **개념도** | **[ 표준 기관 및 공동 표준 체계 ]**<br>`[ IEEE (1963, 미국, 전문가협회) ]`&nbsp;&nbsp;&nbsp;&nbsp;`[ IEC (1906, 스위스, 국가회원기구) ]`<br>`통신·컴퓨팅·SW공학 표준`&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`전기·전자·안전·에너지 표준`<br>`└──────────────┬───────────────┘`<br>`[ ISO/IEC JTC1 (합동기술위원회) ] → IT 분야 공동표준 (ISO/IEC 27001, 42001)` |
| **구성요소** | 1. **IEEE**: 1963년 설립, 미국, 개인회원 160만명+ 전문가협회 겸 표준화기구. 대표표준: 802.3(이더넷), 802.11(Wi-Fi), 802.15.4(ZigBee/IoT), 1588(PTP 시각동기화), 730(SW품질보증)<br>2. **IEC**: 1906년 설립, 스위스 제네바, 93개국 국가위원회 순수 국제표준기구. 대표표준: 62443(ICS/SCADA 보안), 61508(기능안전성), 61850(변전소통신), 27001(정보보안관리, ISO공동)<br>3. **ISO/IEC JTC1**: ISO+IEC 합동기술위원회 → IT분야 공동표준 발행. ISO/IEC 27001(ISMS), ISO/IEC 42001(AI 관리시스템) |
| **비교** | **IEEE**<br>- 성격: 전문가협회+표준화기구<br>- 회원: 개인회원 기반<br>- 범위: 전기·전자·컴퓨팅·통신(네트워크, SW공학, 전력)<br>- 형식: IEEE 802.11, IEEE 1588<br><br>**IEC**<br>- 성격: 순수 국제표준기구<br>- 회원: 국가회원(국가위원회) 기반<br>- 범위: 전기·전자·에너지·안전(산업제어보안, 스마트그리드)<br>- 형식: IEC 62443, IEC 61508 |
| **차별화** | **표준 적용 실무 및 상호연계 전략**<br>1. **네트워크·보안 표준 계층적 결합**: IEEE 802.11(무선LAN 물리·MAC계층)+IEC 62443(ICS보안, 네트워크세그멘테이션) → 스마트팩토리·SCADA 통신+보안 계층별 통합설계<br>2. **ISO/IEC 공동표준 활용 확장**: ISO/IEC 27001(ISMS)+ISO/IEC 42001(AI관리시스템) → AI도입기업 정보보호+AI거버넌스 통합인증체계<br>3. **기능안전 표준 산업적용**: IEC 61508 → 원자력·철도·의료기기 SW/HW 개발생명주기 적용, SIL등급별 검증절차 수립 |
