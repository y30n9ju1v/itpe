# 전자정부 정보시스템 성과 측정지표 서브노트

> **두음 머리에 박기 🧠**
> - **업·운** (운영성과평가 2대 차원: **업**무 적합성, **운**영 효율성)
> - **재·고·내·학** (BSC 4대 관점: **재**무, **고**객, **내**부 프로세스, **학**습·성장)
> - **전·중·후** (성과 측정 3단계 시점: **전**-계획, **중**-진행, **후**-완료)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **전자정부 정보시스템 성과 측정지표 (e-Government Performance Metrics)** |
| **정의** | 공공기관 정보화사업 효과 정량·정성 평가지표 체계 → 「전자정부법」·「정보화사업 성과관리 지침」 근거, ROI 측정 → 사업 지속·개선·종료 결정 |
| **키워드** | BSC 4관점, 운영성과평가 지침(업무적합성/운영효율성), 4분면 포트폴리오 분석, KPI, 정량·정성지표 |
| **개념도** | **[ 성과 측정 4분면 포트폴리오 분석 모형 ]**<br>`[업무적합성 High]`<br>`│ (2사분면) 기능재구축·효율화 │ (1사분면) 지속 유지`<br>`├──────────────────────────┼──────────────────────────▶ [유지관리비용 Low]`<br>`[유지관리비용 High]│ (3사분면) 폐기·재개발 │ (4사분면) 기능고도화·통폐합`<br>`[업무적합성 Low]` |
| **구성요소** | 1. **업무 적합성**: 현행 비즈니스요건 지원도 → 업무지원도·이용률·사용자만족도 측정<br>2. **운영 효율성**: 운영·유지보수 비용·기술효율 → 유지관리비 효율·시스템품질(신뢰성·가용성)·자원효율<br>3. **4분면 포트폴리오 분석**: 업무적합성×유지관리비용 매트릭스 → 차기진로(유지/재구축/폐기/통폐합) 결정<br>4. **BSC 4관점**: 재무(ROI, 비용절감률), 고객(민원처리시간, 만족도), 내부프로세스(자동화율, 오류율), 학습·성장(IT역량, 장애복구시간)<br>5. **측정 시점 3단계**: 전(계획·기준값설정)·중(진행)·후(완료·달성도분석) |
| **비교** | **전통적 성과지표 분류**<br>- 효율성·효과성·접근성·신뢰성(가용성·MTBF)·보안(사고건수·조치율) 지표<br><br>**행정안전부 운영성과평가 모델**<br>- 업무적합성·운영효율성 2대차원 4분면 매트릭스 → 시스템 존속여부까지 의사결정 직결 (전통분류와 차이) |
| **차별화** | **공공 정보화 성과관리 실무 적용 심화 포인트**<br>1. **BSC+행안부지침 결합**: 민간 BSC 4관점 → 「정보시스템 운영성과평가 지침」 업무적합성/운영효율성 매핑, KPI설계 → 4분면분석 → 예산·조직 의사결정 반영<br>2. **성과측정 파이프라인**: 사업계획→KPI정의→Baseline설정→중간측정→최종측정→달성도분석→차기피드백, PDCA 지속개선<br>3. **IT감리·거버넌스 연계**: 성과측정 결과 → IT감리 점검항목·IT투자 의사결정 연계, 정보화사업 전주기관리 완성 |
