# 전자정부 정보시스템 성과 측정지표 서브노트

> **두음 머리에 박기 🧠**
> - **업·운** (운영성과평가 2대 차원: **업**무 적합성, **운**영 효율성)
> - **재·고·내·학** (BSC 4대 관점: **재**무, **고**객, **내**부 프로세스, **학**습·성장)
> - **전·중·후** (성과 측정 3단계 시점: **전**-계획, **중**-진행, **후**-완료)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **전자정부 정보시스템 성과 측정지표 (e-Government Performance Metrics)** |
| **정의** | 공공기관이 정보화 사업의 효과를 정량·정성적으로 평가하기 위한 지표 체계로, 「전자정부법」 및 「정보화사업 성과관리 지침」에 근거하여 투자 대비 효과(ROI)를 측정하고 사업의 지속·개선·종료를 결정하는 데 활용된다 |
| **키워드** | BSC 4관점, 운영성과평가 지침(업무적합성/운영효율성), 4분면 포트폴리오 분석, KPI, 정량·정성지표 |
| **개념도** | **[ 성과 측정 4분면 포트폴리오 분석 모형 ]**<br>`[업무적합성 High]`<br>`│ (2사분면) 기능재구축·효율화 │ (1사분면) 지속 유지`<br>`├──────────────────────────┼──────────────────────────▶ [유지관리비용 Low]`<br>`[유지관리비용 High]│ (3사분면) 폐기·재개발 │ (4사분면) 기능고도화·통폐합`<br>`[업무적합성 Low]` |
| **구성요소** | 1. **업무 적합성 (Business Suitability)**: 시스템이 현행 비즈니스 요건을 얼마나 지원하는지, 업무지원도·이용률·사용자만족도로 측정<br>2. **운영 효율성 (Operational Efficiency)**: 운영·유지보수의 비용·기술적 효율성, 유지관리비 효율성·시스템 품질(신뢰성·가용성)·자원 효율성으로 측정<br>3. **4분면 포트폴리오 분석**: 업무 적합성×유지관리비용 매트릭스로 시스템의 차기 진로(유지/기능재구축/폐기/통폐합)를 결정<br>4. **BSC 4관점**: 재무(ROI, 비용절감률), 고객(민원처리시간, 만족도), 내부프로세스(자동화율, 오류율), 학습·성장(IT역량, 장애복구시간)<br>5. **측정 시점 3단계**: 사업 전(계획, 기준값 설정)·중(진행)·후(완료, 목표 대비 달성도 분석) |
| **비교** | **전통적 성과지표 분류**<br>- 효율성 지표(동일 자원 대비 성과), 효과성 지표(목표 달성도), 접근성 지표(서비스 이용 편의성), 신뢰성 지표(가용성·MTBF), 보안 지표(사고 건수·조치율)<br><br>**행정안전부 운영성과평가 모델**<br>- 업무 적합성·운영 효율성 2대 차원의 4분면 매트릭스로 시스템 존속 여부까지 의사결정에 직결시키는 것이 전통적 분류와의 차이 |
| **차별화** | **공공 정보화 성과관리의 실무 적용 및 심화 포인트**<br>1. **일반 BSC와 행정안전부 지침의 결합**: 민간 BSC 4관점 지표를 공공 부문 「정보시스템 운영성과평가 지침」의 업무적합성/운영효율성 2대 차원에 매핑하여, 사업별 KPI를 설계하고 4분면 분석 결과를 예산·조직 의사결정(차기 사업 지속·폐기)에 직접 반영<br>2. **성과 측정 프로세스 파이프라인**: 사업계획 수립 → KPI 정의 → Baseline 설정 → 중간 측정 → 최종 측정 → 달성도 분석 → 차기 사업 피드백의 순환 구조로 설계하여 단순 사후 평가가 아닌 지속적 개선(PDCA) 체계로 운영<br>3. **IT 감리·거버넌스와의 연계**: 성과 측정 결과를 IT 감리의 점검 항목 및 IT 투자 의사결정(거버넌스)과 연계하여 정보화 사업 전주기 관리 체계를 완성 |
