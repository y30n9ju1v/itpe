# 소프트웨어 신뢰성 및 가동율 평가 서브노트

> **두음 머리에 박기 🧠**
> - **엠·엠·엠** (가용성 평가 3대 실측 지표: 평균고장간격 **MTBF**, 평균고장시간 **MTTF**, 평균수리시간 **MTTR**)
> - **엠·엠·플러스·엠** (시스템 가동율 가용도 공식: $A = \frac{MTBF}{MTBF + MTTR}$ 또는 $\frac{MTTF}{MTTF + MTTR}$)
> - **파이브 나인스 (99.999%)** (미션 크리티컬 가용성 극대 지표: 연간 고장 허용 한계 시간이 단 **5.26분** 이내인 등급)

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **시스템 신뢰성 (Reliability) 및 고가용성 (HA, High Availability) 가동율 평가** |
| **정의** | 오작동없이 연속동작하는 신뢰도 + 장애대비 즉시복구되는 가용성 → **MTBF/MTTR 기반 정량평가, 직/병렬 수학적 가동율 산출** |
| **키워드** | MTBF, MTTF, MTTR, 가용율 공식 (A), 직렬 vs 병렬 신뢰성, SRE (사이트 신뢰성 공학), 에러 버짓 (Error Budget) |
| **개념도** | **[ 시스템 고장 및 복구 생명주기 타임라인과 가용성 수식 구조 ]**<br>`├─────── 가동 동작 (UP) ───────┤ (고장 발생) ├── 수리 (DOWN) ──┤ (복구 완료) ├────── 가동 동작 (UP) ──────┤`<br>`│◀──────────  MTTF  ──────────▶│◀─────  MTTR  ─────▶│◀──────────  MTTF  ──────────▶│`<br>`│◀───────────────────────────────────────  MTBF  ──────────────────────────────────────▶│`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;**[ 가중 신뢰성 계산 구조 ]**<br>&nbsp;&nbsp;&nbsp;&nbsp;`[ 직렬 구조 : A ➔ B ] ➔ 가동율 = A * B` &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`[ 병렬 이중화 구조 (Parallel) ] ➔ 가동율 = 1 - (1 - A)(1 - B)` |
| **구성요소** | 1. **MTTF**: 평균고장시간, 수리불가 장비수명 또는 최초고장까지 평균동작시간<br>2. **MTTR**: 평균수리시간, 고장시점→탐지→복구완료 소요시간 평균<br>3. **MTBF**: 평균고장간격, $MTBF = MTTF + MTTR$, 고장~다음고장 사이시간<br>4. **고가용성(HA)**: Active-Active 클러스터링, 무중단 백업장치 → 다운타임 수분이내 제어 |
| **비교** | **직렬 시스템 신뢰성**<br>- 연결: 단일경로 구성<br>- 가동율: $A_1 \times A_2 \times A_3$ (각 가동율 곱)<br>- 가용성: 개별보다 전체 반드시 감쇄<br><br>**병렬 시스템 신뢰성**<br>- 연결: 이중화/삼중화 우회경로 존재<br>- 가동율: $1 - (1-A_1)(1-A_2)$ (동시고장확률 차감)<br>- 가용성: 개별보다 전체 비약적 상향 |
| **차별화** | **SRE 관점 에러버짓 도입 및 시스템 모니터링 전략**<br>1. **에러버짓 거버넌스**: 100% 가용성=비용낭비·릴리즈속도 저해 → SLO(예 99.9%) 제외 불가동허용범위(에러버짓 0.1%, 연간8.76시간) 정립, 소진 시 신규배포 중단·장애안정화 집중<br>2. **Active-Active 멀티리전 설계**: 대형물리장애 대응 → 이종리전 분산배포, GSLB 헬스체크 연동 무정지 Failover<br>3. **SLA 컴플라이언스 관리**: 배상·패널티 기준 SLA지표 → 실시간 모니터링툴(Datadog, Prometheus) 연동, 위험임계치 사전알림 |
