# 연관 규칙 분석: 지지도·신뢰도·향상도 서브노트

> **두음 머리에 박기 🧠**
> - **지·신·향** (연관 규칙 3대 지표: **지**지도 Support, **신**뢰도 Confidence, **향**상도 Lift)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **연관 규칙 분석 (Association Rule Analysis) 및 Apriori 알고리즘** |
| **정의** | 트랜잭션 내 동시출현 패턴(A→B)을 지지도·신뢰도·향상도로 정량화하는 데이터마이닝 기법 → 장바구니분석·추천시스템 활용 |
| **키워드** | Support, Confidence, Lift, Apriori 알고리즘, 선험적 원리, 빈발 항목 집합 |
| **개념도** | `A → B (지지도, 신뢰도, 향상도)`<br>`Support(A→B) = P(A∩B)` ➔ `Confidence(A→B) = P(B\|A) = P(A∩B)/P(A)` ➔ `Lift(A→B) = Confidence/P(B)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`Lift>1: 양의 연관 / Lift=1: 독립 / Lift<1: 음의 연관` |
| **구성요소** | 1. **지지도(Support)**: A와 B 동시 포함 거래 수/전체 거래 수, 규칙의 빈도·중요도<br>2. **신뢰도(Confidence)**: A 구매 시 B도 구매할 조건부 확률, P(B) 편향 단점 존재<br>3. **향상도(Lift)**: A·B의 독립 대비 실제 연관 강도, 신뢰도의 편향을 보정<br>4. **Apriori 알고리즘**: 빈발 항목 집합을 상향식으로 확장 후 min_confidence 이상 규칙 추출<br>5. **선험적 원리**: 빈발하지 않은 항목 집합의 상위 집합도 빈발하지 않음 → 탐색 공간 축소 |
| **비교** | **신뢰도(Confidence) 단독 평가**<br>- A→B의 조건부 확률만 측정<br>- B 자체가 인기 상품이면 신뢰도가 높게 나오는 편향 존재<br><br>**향상도(Lift) 보정 평가**<br>- Confidence/P(B)로 독립 대비 실제 연관성 측정<br>- Lift=1 기준으로 양/음의 연관을 명확히 구분 |
| **차별화** | **연관 규칙 분석 실무 적용·확장 전략**<br>1. **임계값 튜닝**: min_support 낮음→계산량 폭증, 높음→유의미 규칙 누락 → 데이터규모별 단계조정<br>2. **Lift 기반 추천**: Confidence만 사용 시 인기상품 편향 → Lift>1 규칙 우선 → 실질 연관 교차추천<br>3. **대규모 확장**: Apriori 반복스캔 비용 ↑ → FP-Growth 등 트리기반 알고리즘 대체, 확장성 확보 |
