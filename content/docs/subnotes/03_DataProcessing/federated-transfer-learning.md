# 연합학습과 전이학습 서브노트

> **두음 머리에 박기 🧠**
> - **배·로·전·집·반** (연합학습 5단계: 모델 **배**포, **로**컬 학습, 파라미터 **전**송, **집**계, **반**복)
> - **F·E** (전이학습 2대 전략: **F**eature Extraction(출력층만 학습), **F**ine-tuning(전체/일부 재학습) — 목표 데이터량에 따라 선택)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **연합학습(Federated Learning) 및 전이학습(Transfer Learning)** |
| **정의** | 연합학습: 원본 데이터 미전송, 로컬학습 결과(가중치/그래디언트)만 서버 전송 → 통합모델 구축하는 분산 협업학습<br>전이학습: 소스 태스크 학습모델 지식(가중치) → 관련 타겟 태스크에 재사용 → 적은 데이터·자원으로 고성능 달성<br>공통점: 이미 학습된 모델 자산 재활용 |
| **키워드** | FedAvg, 차등 프라이버시, Secure Aggregation, Pre-trained Model, Fine-tuning, Feature Extraction, 부정적 전이 |
| **개념도** | **[연합학습]**<br>`[중앙 서버: 글로벌 모델]` → ①초기 모델 배포 → `[Device A/B/C: 로컬학습(원본데이터 미이동)]` → ②가중치/그래디언트만 전송 → `[중앙 서버: 가중치 집계(FedAvg)]` → ③통합 모델 갱신 후 재배포<br><br>**[전이학습]**<br>`[Source Task: 대규모 데이터]` → Pre-training(범용 특징 학습) → `[사전학습 모델]` → 가중치 이전 → `[Target Task: 소량 데이터]` → Fine-tuning(일부 계층 재학습) → `[특화된 모델]` |
| **구성요소** | 1. **연합학습 절차**: ①모델배포 → ②로컬학습 → ③파라미터 전송(가중치/그래디언트만) → ④집계(FedAvg: 데이터수 비례 가중평균) → ⑤반복<br>2. **연합학습 핵심기술**: 차등프라이버시(그래디언트 노이즈 추가), 동형암호(암호화 상태 집계연산), Secure Aggregation(개별값 비공개 안전합산)<br>3. **연합학습 유형**: 수평적(특징 동일·샘플 상이, 예: 여러 병원 진료데이터), 수직적(샘플 동일·특징 상이, 예: 은행+쇼핑몰)<br>4. **전이학습 전략**: Feature Extraction(사전학습계층 Freeze, 출력층만 학습 - 목표데이터 매우 적을 때), Fine-tuning(사전학습 가중치 초기값 → 전체/일부 재학습 - 데이터 어느정도 확보 시)<br>5. **CNN 계층별 전이학습**: 하위계층(엣지·색상 등 범용특징) Freeze, 상위계층(도메인 특화 고차특징) Fine-tuning |
| **비교** | **연합학습(Federated Learning)**<br>- 목적: 데이터 프라이버시 보존("데이터는 머물고 모델이 이동")<br>- 다수 디바이스/기관 분산데이터 → 원본이동 없이 공동학습<br>- 핵심이슈: 통신 오버헤드, Non-IID 수렴불안정, Gradient Leakage/Poisoning 공격<br><br>**전이학습(Transfer Learning)**<br>- 목적: 적은 데이터·자원으로 빠른 성능("밑바닥부터 학습 안 함")<br>- 단일기관 내 사전학습모델 → 다른 태스크 재사용<br>- 핵심이슈: 도메인 유사도 낮을 때 부정적 전이(Negative Transfer) 위험 |
| **차별화** | **모델 재활용 기법 실무 적용 및 최신 확장**<br>1. **연합학습 신뢰성 확보**: Non-IID 환경 → FedProx로 수렴안정성, Byzantine-robust FedAvg 등 Robust Aggregation → 참여자 신뢰성(Poisoning 방지)<br>2. **전이학습 적용 판단**: 목표 데이터량·도메인 유사도 매트릭스 - 데이터 적고 유사도 높음 → Feature Extraction, 데이터 많음 → 전체 Fine-tuning, 유사도 낮음 → 부정적 전이 위험 고려<br>3. **LLM 시대 경량화 결합**: LLM 파인튜닝 - LoRA·Prompt Tuning 등 PEFT 결합 → 연산·저장비용 절감, 온디바이스 연합학습(구글 Gboard)+전이학습 결합 개인화 모델 확산 |
