# 연합학습과 전이학습 서브노트

> **두음 머리에 박기 🧠**
> - **배·로·전·집·반** (연합학습 5단계: 모델 **배**포, **로**컬 학습, 파라미터 **전**송, **집**계, **반**복)
> - **F·E** (전이학습 2대 전략: **F**eature Extraction(출력층만 학습), **F**ine-tuning(전체/일부 재학습) — 목표 데이터량에 따라 선택)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **연합학습(Federated Learning) 및 전이학습(Transfer Learning)** |
| **정의** | 연합학습은 각 디바이스·기관이 보유한 원본 데이터를 중앙 서버로 전송하지 않고 로컬에서 모델을 학습한 후 그 결과(가중치/그래디언트)만 서버에 전송해 통합 모델을 구축하는 분산 협업 학습 기법이며, 전이학습은 특정 소스 태스크에서 학습된 모델의 지식(가중치)을 관련성 있는 타겟 태스크에 재사용하여 적은 데이터와 자원으로 높은 성능을 달성하는 학습 기법으로, 둘 다 이미 학습된 모델 자산을 재활용한다는 공통점을 가진다 |
| **키워드** | FedAvg, 차등 프라이버시, Secure Aggregation, Pre-trained Model, Fine-tuning, Feature Extraction, 부정적 전이 |
| **개념도** | **[연합학습]**<br>`[중앙 서버: 글로벌 모델]` → ①초기 모델 배포 → `[Device A/B/C: 로컬학습(원본데이터 미이동)]` → ②가중치/그래디언트만 전송 → `[중앙 서버: 가중치 집계(FedAvg)]` → ③통합 모델 갱신 후 재배포<br><br>**[전이학습]**<br>`[Source Task: 대규모 데이터]` → Pre-training(범용 특징 학습) → `[사전학습 모델]` → 가중치 이전 → `[Target Task: 소량 데이터]` → Fine-tuning(일부 계층 재학습) → `[특화된 모델]` |
| **구성요소** | 1. **연합학습 절차**: ①모델 배포 → ②로컬 학습 → ③파라미터 전송(원본 데이터 대신 가중치/그래디언트만) → ④집계(FedAvg: 데이터 수 비례 가중평균) → ⑤반복<br>2. **연합학습 핵심 기술**: 차등 프라이버시(그래디언트에 노이즈 추가), 동형암호(암호화 상태 집계 연산), Secure Aggregation(개별 값 비공개 안전 합산)<br>3. **연합학습 유형**: 수평적 연합학습(특징 동일·샘플 상이, 예: 여러 병원 진료 데이터), 수직적 연합학습(샘플 동일·특징 상이, 예: 은행+쇼핑몰)<br>4. **전이학습 전략**: Feature Extraction(사전학습 계층 고정(Freeze), 출력층만 새로 학습, 목표 데이터 매우 적을 때 유리), Fine-tuning(사전학습 가중치를 초기값으로 전체/일부 재학습, 데이터 어느 정도 확보 시 유리)<br>5. **CNN 계층별 전이학습**: 하위 계층(엣지·색상 등 범용 특징)은 Freeze, 상위 계층(도메인 특화 고차 특징)은 Fine-tuning 대상 |
| **비교** | **연합학습(Federated Learning)**<br>- 목적: 데이터 프라이버시 보존("데이터는 머물고 모델이 이동")<br>- 다수 디바이스/기관의 분산 데이터를 원본 이동 없이 공동 학습<br>- 핵심 이슈: 통신 오버헤드, Non-IID 수렴 불안정, Gradient Leakage/Poisoning 공격<br><br>**전이학습(Transfer Learning)**<br>- 목적: 적은 데이터·자원으로 빠른 성능 확보("밑바닥부터 학습 안 함")<br>- 단일 기관 내 사전학습 모델을 다른 태스크에 재사용<br>- 핵심 이슈: 도메인 유사도 낮을 때 부정적 전이(Negative Transfer) 위험 |
| **차별화** | **모델 재활용 기법의 실무 적용 및 최신 확장**<br>1. **연합학습 신뢰성 확보**: Non-IID 데이터 환경에는 FedProx 등으로 수렴 안정성을 확보하고, Byzantine-robust FedAvg 등 Robust Aggregation으로 참여자 신뢰성(Poisoning 공격 방지)을 관리.<br>2. **전이학습 적용 판단**: 목표 데이터량과 도메인 유사도를 기준으로 매트릭스 판단 - 데이터 적고 유사도 높으면 Feature Extraction, 데이터 많으면 전체 Fine-tuning, 유사도 낮으면 부정적 전이 위험을 고려해 신중 적용.<br>3. **LLM 시대 경량화 결합**: 최근 LLM 파인튜닝에서는 LoRA·Prompt Tuning 등 PEFT(Parameter-Efficient Fine-Tuning) 기법과 결합해 연산·저장 비용을 줄이는 추세이며, 온디바이스 연합학습(구글 Gboard 등)과 전이학습을 결합한 개인화 모델 구축도 확산. |
