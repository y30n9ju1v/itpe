# 공공데이터 품질인증 서브노트

> **두음 머리에 박기 🧠**
> - **정·완·일·유·유·적** (품질 심사 6개 영역: **정**확성, **완**전성, **일**관성, **유**효성, **유**일성, **적**시성)
> - **신·서·현·심·인** (인증 절차 5단계: **신**청 ➔ **서**류검토 ➔ **현**장심사 ➔ **심**의위원회 ➔ **인**증서발급)
> - **생·관·활** (공공데이터 정보 생명주기 3단계: **생**산(표준정의·입력검증) ➔ **관**리(정기진단·정제) ➔ **활**용(개방검증·피드백))

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **공공데이터 품질인증 (Public Data Quality Certification)** |
| **정의** | 공공데이터법 제22조의2 근거 - 행안부(NIA 위탁)가 공공기관 보유 데이터 품질 심사·인증 - 목적: 공공데이터 신뢰성·활용성 제고 |
| **키워드** | 공공데이터법 제22조의2, NIA, 6개 품질영역, 인증 유효기간 2년, data.go.kr |
| **개념도** | `[신청]` ➔ `[서류검토]` ➔ `[현장심사]` ➔ `[심의위원회]` ➔ `[인증서 발급(유효 2년)]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼ (심사 항목)`<br>`[관리체계: 조직·정책·절차] + [데이터 품질: 샘플 검증] + [개방수준: 범위·형식·주기]` |
| **구성요소** | 1. **법적 근거**: 공공데이터법 제22조의2, 인증기관 NIA(한국지능정보사회진흥원)<br>2. **6개 품질영역**: 정확성, 완전성, 일관성, 유효성, 유일성, 적시성<br>3. **인증 절차**: 신청→서류검토→현장심사→심의위원회→인증서 발급(유효 2년, 갱신가능)<br>4. **공공데이터 개방 플랫폼**: 공공데이터포털(data.go.kr), CSV/JSON/XML 표준 포맷, REST API 제공<br>5. **정보 생명주기별 품질관리 (생·관·활)**: 생산(표준·입력검증규칙·메타데이터 등록)→관리(정기 품질진단·오류정제·갱신)→활용(개방 전 품질검증 게이트·사용자 피드백·포털 연계)<br>6. **K-DATA DQ 인증**: 데이터산업진흥법 근거 - K-DATA(한국데이터산업진흥원)가 민간·공공 조직 전반 품질(관리체계 8대영역+값품질 6대지표) 심사·인증하는 별도 제도 |
| **비교** | **K-DATA DQ 인증 (민간 대상)**<br>- 법적 근거: 데이터산업진흥법, 인증기관 K-DATA<br>- 심사 대상: 관리체계(8대영역) + 값품질(6대지표), 조직 전반 데이터 자산<br><br>**공공데이터 품질인증 (공공기관 대상)**<br>- 법적 근거: 공공데이터법 제22조의2, 인증기관 NIA(행안부 위탁)<br>- 심사 대상: 관리체계 + 값품질(6개영역) + 개방수준, 개방 대상 공공데이터셋 |
| **차별화** | **공공데이터 신뢰성·활용성 제고 전략**<br>1. **6대 품질영역 상시 관리 체계화**: 인증 시점 심사에 그치지 않고 옵저버빌리티·프로파일링 상시 운영 → 정확성·적시성 지속 유지<br>2. **개방 표준 준수로 활용성 극대화**: CSV/JSON/XML 표준 포맷 + REST API → 민간 개발자 재사용성·2차 활용 촉진<br>3. **거버넌스 성숙도 연계**: 인증 심사 "관리체계" 항목 ↔ 데이터 오너십·품질기준 수립 등 조직 거버넌스 체계와 연동 → 지속가능한 품질 유지 기반 |
