# 공공데이터 품질인증 서브노트

> **두음 머리에 박기 🧠**
> - **정·완·일·유·유·적** (품질 심사 6개 영역: **정**확성, **완**전성, **일**관성, **유**효성, **유**일성, **적**시성)
> - **신·서·현·심·인** (인증 절차 5단계: **신**청 ➔ **서**류검토 ➔ **현**장심사 ➔ **심**의위원회 ➔ **인**증서발급)
> - **생·관·활** (공공데이터 정보 생명주기 3단계: **생**산(표준정의·입력검증) ➔ **관**리(정기진단·정제) ➔ **활**용(개방검증·피드백))

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **공공데이터 품질인증 (Public Data Quality Certification)** |
| **정의** | 「공공데이터의 제공 및 이용 활성화에 관한 법률」 제22조의2에 근거하여 행정안전부(NIA 위탁)가 공공기관 보유 데이터의 품질 수준을 심사·인증하는 제도로, 공공데이터의 신뢰성과 활용성 제고가 목적 |
| **키워드** | 공공데이터법 제22조의2, NIA, 6개 품질영역, 인증 유효기간 2년, data.go.kr |
| **개념도** | `[신청]` ➔ `[서류검토]` ➔ `[현장심사]` ➔ `[심의위원회]` ➔ `[인증서 발급(유효 2년)]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼ (심사 항목)`<br>`[관리체계: 조직·정책·절차] + [데이터 품질: 샘플 검증] + [개방수준: 범위·형식·주기]` |
| **구성요소** | 1. **법적 근거**: 공공데이터법 제22조의2, 인증기관 NIA(한국지능정보사회진흥원)<br>2. **6개 품질영역**: 정확성, 완전성, 일관성, 유효성, 유일성, 적시성<br>3. **인증 절차**: 신청→서류검토→현장심사→심의위원회→인증서 발급(유효 2년, 갱신 가능)<br>4. **공공데이터 개방 플랫폼**: 공공데이터포털(data.go.kr), CSV/JSON/XML 표준 포맷, REST API 제공<br>5. **정보 생명주기별 품질관리 (생·관·활)**: 생산(데이터 표준·입력검증규칙·메타데이터 등록)→관리(정기 품질진단, 오류 정제, 갱신·최신화)→활용(개방 전 품질검증 게이트, 사용자 피드백 수집, 공공데이터포털 연계)<br>6. **K-DATA DQ 인증**: 「데이터산업진흥법」 근거로 K-DATA(한국데이터산업진흥원)가 민간·공공 조직 전반의 데이터 품질 수준(관리체계 8대 영역 + 값 품질 6대 지표)을 심사·인증하는 별도 제도 |
| **비교** | **K-DATA DQ 인증 (민간 대상)**<br>- 법적 근거: 데이터산업진흥법, 인증기관 K-DATA<br>- 심사 대상: 데이터 관리체계(8대 영역) + 데이터 값 품질(6대 지표), 조직 전반 데이터 자산<br><br>**공공데이터 품질인증 (공공기관 대상)**<br>- 법적 근거: 공공데이터법 제22조의2, 인증기관 NIA(행안부 위탁)<br>- 심사 대상: 관리체계 + 데이터 값 품질(6개 영역) + 개방수준, 개방 대상 공공데이터셋 |
| **차별화** | **공공데이터 신뢰성·활용성 제고 전략**<br>1. **6대 품질영역의 상시 관리 체계화**: 인증 시점 심사에 그치지 않고, 데이터 옵저버빌리티·프로파일링을 상시 운영해 정확성·적시성을 지속 유지.<br>2. **개방 표준 준수로 활용성 극대화**: CSV/JSON/XML 표준 포맷과 REST API 제공을 통해 민간 개발자의 재사용성과 2차 활용을 촉진.<br>3. **거버넌스 성숙도와의 연계**: 인증 심사의 "관리체계" 항목을 데이터 오너십·품질 기준 수립 등 조직 차원의 데이터 거버넌스 체계 구축과 연동하여 지속가능한 품질 유지 기반을 마련. |
