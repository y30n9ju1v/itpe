| **키워드** | 탐색적/설명적 시각화, 막대·선·산점도·히트맵·트리맵, Tableau/Power BI, D3.js, Grafana/Kibana |
| **개념도** | `[1.목적정의]` ➔ `[2.데이터 수집·전처리]` ➔ `[3.시각화 유형 선택]` ➔ `[4.구현]` ➔ `[5.검증·배포]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[시계열→선차트] [범주비교→막대] [상관관계→산점도] [2D밀도→히트맵]` |
| **구성요소** | 1. **탐색적 시각화**: 데이터 내 패턴·이상치 발견(분석가 대상)<br>2. **설명적 시각화**: 인사이트를 청중에게 전달(의사결정자 대상)<br>3. **시각화 유형**: 막대(범주 비교), 선(시계열), 산점도(상관관계), 히트맵(2D 밀도), 트리맵(계층 비율), 네트워크 그래프(관계), 워드클라우드(텍스트 빈도)<br>4. **도구**: BI(Tableau, Power BI), 오픈소스(D3.js, Plotly), Python(Matplotlib, Seaborn), 스트리밍(Grafana, Kibana) |
| **비교** | **탐색적 시각화(Exploratory)**<br>- 분석가 대상, 데이터 내 패턴·이상치 발견 목적<br>- 다양한 차트를 빠르게 시도하는 반복 탐색 과정<br><br>**설명적 시각화(Explanatory)**<br>- 의사결정자·청중 대상, 인사이트 전달 목적<br>- 핵심 메시지에 맞춰 정제된 대시보드·리포트 형태 |
| **차별화** | **대규모 데이터 시각화의 실무 과제 대응 전략**<br>1. **볼륨 대응**: 수십억건 실시간 렌더링 → 사전집계·샘플링·GPU가속 적용<br>2. **속도 대응**: 스트리밍 실시간 시각화 → Lambda/Kappa 파이프라인 + Grafana/Kibana 결합<br>3. **차트 매핑 표준화**: 시계열→선차트, 범주비교→막대, 상관관계→산점도, 공간데이터→지리시각화 → 오독 방지 |
