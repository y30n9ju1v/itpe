# 텍스트 마이닝과 오피니언 마이닝: 비정형 데이터 분석 서브노트

> **두음 머리에 박기 🧠**
> - **수·전·의·의·패·정** (텍스트 마이닝 분석절차 6단계: **수**집, **전**처리, **의**미변환, **의**미추출, **패**턴분석, **정**보표현·평가)
> - **분·문·정·문** (텍스트 마이닝 4대 기능: **분**류, **문**서군집, **정**보추출, **문**서요약)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **텍스트 마이닝(Text Mining)과 오피니언 마이닝(Opinion Mining), 데이터마이닝 vs 통계분석** |
| **정의** | 자연어로 구성된 비정형 텍스트 데이터에서 NLP 기술로 패턴·관계를 추출해 가치 있는 정보를 찾는 텍스트 마이닝과, 그중 긍/부정 감성 판별에 특화된 오피니언 마이닝을 포괄하며, 귀납적(데이터 주도) 접근인 데이터마이닝과 연역적(가설 주도) 접근인 통계분석의 철학적 차이를 포함하는 비정형 데이터 분석 체계 |
| **키워드** | NLP, TF-IDF, 형태소 분석, 감성분석, 정보추출, KDD, 정형 vs 비정형 마이닝 |
| **개념도** | `[사용자]`▶`텍스트 수집/전처리`▶`[NLP 기반 온톨로지/색인/지식DB]`▶`텍스트 자료 처리`▶`[텍스트 분석·가시화·평가]`<br>`데이터마이닝(귀납적, 패턴발견)` ⟷ `통계분석(연역적, 가설검정)` |
| **구성요소** | 1. **텍스트 마이닝 기능**: 텍스트 분류·문서 군집(Document Clustering)·정보 추출·문서 요약(Document Summarization)<br>2. **분석절차 6단계**: 문서 선정/수집→전처리(불용어 제거·형태소 분석·토큰화)→의미정보 변환(TF-IDF/Word2Vec)→의미정보 추출(개체명 인식·핵심어·감성 분류)→패턴 및 경향 분석(연관규칙·군집·분류)→정보 표현 및 평가(워드클라우드·정밀도/재현율)<br>3. **오피니언 마이닝**: 텍스트 마이닝의 하위 분야로 긍/부정 판별·감성사전 기반 감성 점수·트렌드 산출에 특화<br>4. **데이터마이닝 vs 통계분석**: 데이터마이닝은 대용량·비정형 데이터에서 패턴/규칙을 귀납적으로 발견(블랙박스, 도메인지식 불필요), 통계분석은 정형화된 데이터로 가설을 연역적으로 검정(화이트박스, 분포가정 필요)<br>5. **정형 vs 비정형 마이닝**: 정형은 연관규칙·분류·군집(ETL/정규화 전처리), 비정형은 텍스트마이닝·오피니언마이닝·SNA(NLP/형태소분석/이미지처리 전처리) |
| **비교** | **텍스트 마이닝**<br>- 비정형 텍스트 전반 분석(분류·군집·요약·정보추출)<br>- 출력: 주제 분류, 요약, 관계 맵<br>- 활용: 뉴스 요약, 문서 분류<br><br>**오피니언 마이닝**<br>- 감성·의견 분석에 특화(긍/부정 판별)<br>- 출력: 감성 점수, 감성 트렌드<br>- 활용: 제품 리뷰 분석, 브랜드 모니터링 |
| **차별화** | **비정형 데이터 마이닝 실무 적용 전략** <br>1. **형태소 분석기 선정**: 한국어 텍스트는 Mecab·Kiwi·KoNLPy 등 도메인 맞춤 사전을 구축해야 전처리 품질과 감성 분류 정확도가 확보됨<br>2. **부정어·반어 처리**: 오피니언 마이닝에서 부정어·반어 표현을 별도 로직으로 처리하지 않으면 감성 분류 정확도가 크게 저하됨<br>3. **SNA 연계 활용**: 텍스트 마이닝으로 추출한 개체·관계를 노드·엣지로 모델링해 SNA와 결합, 인플루언서 식별·구전 효과 분석에 시너지 창출<br>4. **도메인별 감성사전**: 감성사전은 도메인별로 어휘 극성이 달라지므로 금융·의료·커머스 등 분야에 맞는 전문 사전을 별도 구축하여 정확도 확보 |
