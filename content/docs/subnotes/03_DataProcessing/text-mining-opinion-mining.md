# 텍스트 마이닝과 오피니언 마이닝: 비정형 데이터 분석 서브노트

> **두음 머리에 박기 🧠**
> - **수·전·의·의·패·정** (텍스트 마이닝 분석절차 6단계: **수**집, **전**처리, **의**미변환, **의**미추출, **패**턴분석, **정**보표현·평가)
> - **분·문·정·문** (텍스트 마이닝 4대 기능: **분**류, **문**서군집, **정**보추출, **문**서요약)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **텍스트 마이닝(Text Mining)과 오피니언 마이닝(Opinion Mining), 데이터마이닝 vs 통계분석** |
| **정의** | 비정형 텍스트에서 NLP로 패턴·관계 추출 → 정보 도출하는 텍스트 마이닝 + 긍/부정 감성판별 특화 오피니언 마이닝 포괄, 귀납적(데이터주도) 데이터마이닝 vs 연역적(가설주도) 통계분석 철학차이 포함 |
| **키워드** | NLP, TF-IDF, 형태소 분석, 감성분석, 정보추출, KDD, 정형 vs 비정형 마이닝 |
| **개념도** | `[사용자]`▶`텍스트 수집/전처리`▶`[NLP 기반 온톨로지/색인/지식DB]`▶`텍스트 자료 처리`▶`[텍스트 분석·가시화·평가]`<br>`데이터마이닝(귀납적, 패턴발견)` ⟷ `통계분석(연역적, 가설검정)` |
| **구성요소** | 1. **텍스트 마이닝 4대 기능**: 텍스트 분류·문서군집(Clustering)·정보추출·문서요약(Summarization)<br>2. **분석절차 6단계**: 문서선정/수집→전처리(불용어제거·형태소분석·토큰화)→의미정보변환(TF-IDF/Word2Vec)→의미정보추출(개체명인식·핵심어·감성분류)→패턴/경향분석(연관규칙·군집·분류)→정보표현·평가(워드클라우드·정밀도/재현율)<br>3. **오피니언 마이닝**: 텍스트마이닝 하위분야, 긍/부정판별·감성사전기반 감성점수·트렌드산출 특화<br>4. **데이터마이닝 vs 통계분석**: 데이터마이닝→대용량·비정형 귀납적 패턴발견(블랙박스, 도메인지식불요) / 통계분석→정형데이터 연역적 가설검정(화이트박스, 분포가정필요)<br>5. **정형 vs 비정형 마이닝**: 정형→연관규칙·분류·군집(ETL/정규화 전처리) / 비정형→텍스트·오피니언마이닝·SNA(NLP/형태소분석/이미지처리 전처리) |
| **비교** | **텍스트 마이닝**<br>- 비정형 텍스트 전반 분석(분류·군집·요약·정보추출)<br>- 출력: 주제 분류, 요약, 관계 맵<br>- 활용: 뉴스 요약, 문서 분류<br><br>**오피니언 마이닝**<br>- 감성·의견 분석에 특화(긍/부정 판별)<br>- 출력: 감성 점수, 감성 트렌드<br>- 활용: 제품 리뷰 분석, 브랜드 모니터링 |
| **차별화** | **비정형 데이터 마이닝 실무 적용 전략** <br>1. **형태소 분석기 선정**: 한국어 텍스트 → Mecab·Kiwi·KoNLPy 등 도메인맞춤 사전구축 → 전처리품질·감성분류 정확도 확보<br>2. **부정어·반어 처리**: 별도 로직 미처리 시 감성분류 정확도 크게저하 → 전용 처리 필요<br>3. **SNA 연계 활용**: 추출 개체·관계 → 노드·엣지 모델링, SNA 결합 → 인플루언서 식별·구전효과 분석 시너지<br>4. **도메인별 감성사전**: 어휘극성 도메인별 상이 → 금융·의료·커머스 등 전문사전 별도구축 필요 |
