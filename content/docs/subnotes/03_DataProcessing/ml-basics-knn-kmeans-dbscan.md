# 기계학습 기초와 KNN·K-means·DBSCAN 비교 서브노트

> **두음 머리에 박기 🧠**
> - **지·비·강** (학습데이터 제공방식 3분류: **지**도학습, **비**지도학습, **강**화학습)
> - **거·할·중** (K-means 알고리즘 절차: 초기중심 설정 → 데이터 **거**리계산·할당 → **중**심점 갱신 반복)
> - **핵·경·노** (DBSCAN 점 3분류: **핵**심점(Core), 경계점(Border), **노**이즈점(Noise))

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **기계학습(Machine Learning) 기초 및 KNN·K-means·DBSCAN 알고리즘 비교** |
| **정의** | 기계학습: 명시적 프로그래밍 없이 데이터→패턴 학습 → 예측·분류·군집화 수행하는 AI 하위분야<br>K-NN: 새 데이터를 K개 이웃 다수결로 분류하는 지도학습<br>K-means: K개 군집 중심점까지 거리 최소화하는 중심기반 비지도 군집화<br>DBSCAN: 밀도 높은 영역 군집·낮은 점 노이즈로 분류하는 밀도기반 비지도 군집화 |
| **키워드** | 지도/비지도/강화학습, K-NN, K-means, DBSCAN, Lazy/Eager Learning, 밀도 기반, 차원의 저주 |
| **개념도** | `[학습 데이터]` → `[특징 추출/전처리]` → `[모델 학습(가설함수 최적화)]` → `[손실함수 최소화]` → `[학습된 모델]`<br><br>`[K-NN]` 새 데이터 주변 K개 이웃 다수결 → 분류<br>`[K-means]` 초기중심 설정 → 할당 → 중심 갱신 반복 → 구형 군집<br>`[DBSCAN]` 반경 ε 내 MinPts 이상 밀집 영역 확장 → 임의 형태 군집 + 노이즈 분리 |
| **구성요소** | 1. **학습데이터 제공방식 3분류**: 지도학습(입력-정답쌍, 회귀/분류), 비지도학습(레이블 없음, 군집화/차원축소), 강화학습(상태-행동-보상, Q-Learning/DQN)<br>2. **K-NN**: 지도학습·Lazy Learning(예측시 전체탐색), 거리계산→K개 이웃선정→다수결/평균, 유클리드/맨해튼/코사인 거리<br>3. **K-means**: 비지도학습·Eager Learning(사전 모델구축), 초기중심 설정→할당→중심갱신 반복, 유클리드거리(제곱합), K-means++로 초기화 안정성<br>4. **DBSCAN**: 밀도기반, 파라미터 ε(반경)·MinPts(최소점), Core/Border/Noise Point 3분류, 군집개수 사전지정 불필요<br>5. **K값 선정**: K-NN은 교차검증, K-means/DBSCAN 계열 군집수는 엘보우 기법·실루엣 계수로 결정 |
| **비교** | **K-NN vs K-means**<br>- K-NN: 지도학습, 분류/회귀 목적, K=이웃개수, Lazy Learning, 정답레이블 필요, 예측시 O(N)<br>- K-means: 비지도학습, 군집화 목적, K=군집개수, Eager Learning, 레이블 불필요, 학습시 O(N·K·I·d)<br>- 공통한계: K-NN 차원의저주(KD-Tree/Ball-Tree 가속), K-means 초기중심점 Local Optimum(K-means++ 대응)<br><br>**K-means vs DBSCAN**<br>- K-means: 중심점 기반분할, 군집수 K 사전지정 필요, 원형/구형 군집 유리, 이상치도 강제 할당(중심왜곡), O(N·K·I)<br>- DBSCAN: 밀도기반 확장, 군집수 자동결정(ε, MinPts만 지정), 임의형태 군집 탐색가능, 이상치 노이즈 자동배제(강건성↑), 공간인덱스 시 O(N log N)<br>- 선택기준: 균일 군집·대용량 속도중요 → K-means, 밀도 편차큰 비구형 → DBSCAN(k-distance 그래프로 ε 산정, 대안 HDBSCAN) |
| **차별화** | **알고리즘 선택 및 실무 적용 로드맵**<br>1. **파이프라인 설계**: 주차수요 예측처럼 초기 비지도학습(군집)→이용패턴 발견, 데이터 축적 시 지도학습(회귀/분류) 전환하는 단계적 접근, k-fold로 과적합 방지<br>2. **거리기반 알고리즘 공통대응**: K-NN·K-means 모두 고차원 거리왜곡(차원의 저주) → PCA 차원축소·정규화 전처리 병행<br>3. **군집 형태별 선택**: 고객세분화·이미지압축 등 균일 구형군집 → K-means, 지리공간·이상거래탐지 등 밀도불균일·임의형태 → DBSCAN(또는 HDBSCAN) |
