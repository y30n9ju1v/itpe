# 기계학습 기초와 KNN·K-means·DBSCAN 비교 서브노트

> **두음 머리에 박기 🧠**
> - **지·비·강** (학습데이터 제공방식 3분류: **지**도학습, **비**지도학습, **강**화학습)
> - **거·할·중** (K-means 알고리즘 절차: 초기중심 설정 → 데이터 **거**리계산·할당 → **중**심점 갱신 반복)
> - **핵·경·노** (DBSCAN 점 3분류: **핵**심점(Core), 경계점(Border), **노**이즈점(Noise))

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **기계학습(Machine Learning) 기초 및 KNN·K-means·DBSCAN 알고리즘 비교** |
| **정의** | 기계학습은 명시적 프로그래밍 없이 데이터로부터 패턴을 학습하여 예측·분류·군집화를 수행하는 AI의 하위 분야이며, K-NN은 새 데이터를 K개 이웃의 다수결로 분류하는 지도학습, K-means는 K개 군집의 중심점까지 거리를 최소화하는 중심 기반 비지도 군집화, DBSCAN은 밀도가 높은 영역을 군집·낮은 점을 노이즈로 분류하는 밀도 기반 비지도 군집화 기법이다 |
| **키워드** | 지도/비지도/강화학습, K-NN, K-means, DBSCAN, Lazy/Eager Learning, 밀도 기반, 차원의 저주 |
| **개념도** | `[학습 데이터]` → `[특징 추출/전처리]` → `[모델 학습(가설함수 최적화)]` → `[손실함수 최소화]` → `[학습된 모델]`<br><br>`[K-NN]` 새 데이터 주변 K개 이웃 다수결 → 분류<br>`[K-means]` 초기중심 설정 → 할당 → 중심 갱신 반복 → 구형 군집<br>`[DBSCAN]` 반경 ε 내 MinPts 이상 밀집 영역 확장 → 임의 형태 군집 + 노이즈 분리 |
| **구성요소** | 1. **학습데이터 제공방식 3분류**: 지도학습(입력-정답 쌍, 회귀/분류), 비지도학습(레이블 없음, 군집화/차원축소), 강화학습(상태-행동-보상, Q-Learning/DQN)<br>2. **K-NN**: 지도학습·Lazy Learning(예측 시 전체 탐색), 거리계산→K개 이웃 선정→다수결/평균, 유클리드/맨해튼/코사인 거리<br>3. **K-means**: 비지도학습·Eager Learning(사전 모델 구축), 초기중심 설정→할당→중심 갱신 반복, 유클리드 거리(제곱합), K-means++로 초기화 안정성 확보<br>4. **DBSCAN**: 밀도 기반, 파라미터 ε(반경)·MinPts(최소점), Core/Border/Noise Point 3분류, 군집 개수 사전 지정 불필요<br>5. **K값 선정**: K-NN은 교차검증, K-means/DBSCAN 계열 군집 수는 엘보우 기법·실루엣 계수로 결정 |
| **비교** | **K-NN vs K-means**<br>- K-NN: 지도학습, 분류/회귀 목적, K=이웃 개수, Lazy Learning, 정답 레이블 필요, 예측 시 O(N)<br>- K-means: 비지도학습, 군집화 목적, K=군집 개수, Eager Learning, 레이블 불필요, 학습 시 O(N·K·I·d)<br>- 공통 한계: K-NN은 차원의 저주(KD-Tree/Ball-Tree로 가속), K-means는 초기 중심점에 따른 Local Optimum(K-means++로 대응)<br><br>**K-means vs DBSCAN**<br>- K-means: 중심점 기반 분할, 군집 개수 K 사전 지정 필요, 원형/구형 군집 유리, 이상치도 강제 군집 할당(중심 왜곡), 시간복잡도 O(N·K·I)<br>- DBSCAN: 밀도 기반 확장, 군집 개수 자동 결정(ε, MinPts만 지정), 임의 형태 군집 탐색 가능, 이상치를 노이즈로 자동 배제(강건성 높음), 공간 인덱스 활용 시 O(N log N)<br>- 선택 기준: 군집이 균일하고 대용량 속도가 중요하면 K-means, 밀도 편차 큰 비구형 데이터는 DBSCAN(k-distance 그래프로 ε 산정, 대안으로 HDBSCAN) |
| **차별화** | **알고리즘 선택 및 실무 적용 로드맵**<br>1. **파이프라인 설계**: 주차 수요 예측처럼 초기엔 비지도학습(군집)으로 이용 패턴을 발견하고, 데이터가 축적되면 지도학습(회귀/분류)으로 전환하는 단계적 접근이 효과적이며, k-fold 교차검증으로 과적합을 방지.<br>2. **거리 기반 알고리즘 공통 대응**: K-NN·K-means 모두 고차원에서 거리 왜곡(차원의 저주)이 발생하므로 PCA 등 차원축소·정규화를 전처리에 병행.<br>3. **군집 형태에 따른 선택**: 고객 세분화·이미지 압축처럼 균일한 구형 군집은 K-means, 지리공간 데이터·이상거래 탐지처럼 밀도가 불균일하고 임의 형태인 경우는 DBSCAN(또는 HDBSCAN)을 채택. |
