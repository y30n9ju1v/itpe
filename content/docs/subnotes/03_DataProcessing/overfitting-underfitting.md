# 과적합과 과소적합 서브노트

> **두음 머리에 박기 🧠**
> - **규·드·조·데·앙·교** (과적합 해결책 6가지: **규**제(L1/L2), **드**롭아웃, **조**기 종료, **데**이터 증강, **앙**상블, **교**차 검증)

---

| 분류 | 기술 기술사 서브노트 작성 예시 (1교시형 포맷) |
| :--- | :--- |
| **토픽명** | **과적합(Overfitting)과 과소적합(Underfitting)** |
| **정의** | 과적합은 모델이 훈련 데이터의 노이즈까지 학습하여 일반화되지 않는 현상이고, 과소적합은 모델이 너무 단순하여 훈련 데이터의 패턴조차 학습하지 못하는 현상으로, 편향-분산 트레이드오프의 양극단 |
| **키워드** | 편향(Bias), 분산(Variance), 규제(L1/L2), 드롭아웃, 조기 종료, 학습곡선 |
| **개념도** | `[모델 복잡도 낮음]` ➔ `과소적합(High Bias, Low Variance)`<br>`[모델 복잡도 적정]` ➔ `최적 지점(편향+분산 최소)`<br>`[모델 복잡도 높음]` ➔ `과적합(Low Bias, High Variance)` |
| **구성요소** | 1. **과적합 원인**: 모델 복잡도 과다, 훈련 데이터 부족, 피처 수 과다<br>2. **과소적합 원인**: 모델 복잡도 부족, 피처 부족, 과도한 규제<br>3. **과적합 해결**: 규제(L1/L2), 드롭아웃, 조기 종료, 데이터 증강, 앙상블, 교차검증<br>4. **과소적합 해결**: 모델 복잡도 증가, 피처 엔지니어링, 규제 완화, 에포크 증가 |
| **비교** | **과적합(Overfitting)**<br>- 훈련 오차 낮음, 검증 오차 높음<br>- 낮은 편향, 높은 분산<br><br>**과소적합(Underfitting)**<br>- 훈련·검증 오차 모두 높음<br>- 높은 편향, 낮은 분산 |
| **차별화** | **모델 복잡도 최적화를 위한 실무 진단·대응 전략**<br>1. **학습곡선(Learning Curve) 진단**: 훈련·검증 오차의 격차와 추세를 관찰하여 과적합/과소적합 여부를 조기 판별.<br>2. **단계적 규제 적용**: 먼저 조기 종료·교차 검증으로 과적합 신호를 확인한 뒤, L1/L2 규제·드롭아웃·앙상블을 순차 적용해 분산을 낮춤.<br>3. **데이터 품질과의 연계**: 데이터 부족·레이블 노이즈가 과적합의 근본 원인인 경우가 많으므로, 데이터 증강 및 AI 학습 데이터 품질관리 활동과 병행하여 근본적으로 해결. |
