# SVM: 마진 분류와 커널 트릭 서브노트

> **두음 머리에 박기 🧠**
> - **하·소** (선형 SVM 마진 분류 2가지: **하**드 마진, **소**프트 마진)
> - **마·소·커·최** (SVM 동작 4단계: **마**진 최대화, **소**프트 마진 적용, **커**널 트릭 적용, **최**적화(라그랑주·QP))
> - **L·P·R·S** (커널 함수 4종: **L**inear, **P**olynomial, **R**BF, **S**igmoid)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **서포트 벡터 머신(Support Vector Machine, SVM) - 마진 분류 및 커널 트릭** |
| **정의** | 클래스 간 마진(결정경계-서포트벡터 거리) 최대화 → 최적 결정경계(초평면) 탐색하는 지도학습 이진분류 알고리즘, 선형분리 곤란 시 커널 트릭으로 고차원 매핑 → 비선형 확장 |
| **키워드** | 마진(Margin), 서포트 벡터, 하드/소프트 마진, 슬랙 변수, 규제 파라미터 C, 커널 트릭 |
| **개념도** | `●  ●   ★     ★   ○  ○` (★=서포트 벡터)<br>`───────────┼───────────` ← 최적 결정경계(초평면)<br>`  ●  ★         ★   ○`<br>↕margin↕ 서포트 벡터-경계 간 최단거리 = 마진<br><br>`저차원(선형분리 불가)` --커널 트릭(φ(x))--> `고차원(선형분리 가능)` |
| **구성요소** | 1. **마진(Margin)**: 결정경계-최근접데이터(서포트벡터) 거리, 클수록 일반화성능↑<br>2. **하드 마진**: 오분류 불허용. `min(1/2)‖w‖² s.t. yᵢ(w·xᵢ+b)≥1`, 완벽 선형분리 전제, 이상치 매우취약<br>3. **소프트 마진**: 슬랙변수(ξᵢ)로 일부 오분류 허용. `min(1/2)‖w‖²+C·Σξᵢ s.t. yᵢ(w·xᵢ+b)≥1-ξᵢ, ξᵢ≥0`. C↑→패널티강함(마진↓, 과적합↑), C↓→허용도↑(마진↑, 과소적합↑)<br>4. **커널 함수**: Linear(텍스트분류), Polynomial(이미지특징), RBF/Gaussian(범용, 비선형복잡경계), Sigmoid(신경망유사경계) - 커널함수(내적)만으로 계산량 절감<br>5. **최적화 절차**: 라그랑주 승수법 → 쌍대문제 변환 → QP(Quadratic Programming)로 해 도출 |
| **비교** | **하드 마진(Hard Margin)**<br>- 여유변수 없음, 규제 파라미터 없음<br>- 실무 적용성 낮음(현실데이터 노이즈 포함)<br><br>**소프트 마진(Soft Margin)**<br>- 슬랙변수(ξ) + 규제파라미터 C 도입<br>- 실무 적용성 높음(대부분 실무 SVM)<br><br>**SVM 장단점**<br>- 장점: 고차원·소량데이터 일반화성능↑, 마진최대화로 과적합 강함, 서포트벡터만으로 결정경계 설명가능<br>- 단점: 대용량 학습속도↓(O(N²)~O(N³)), 커널·C·감마 튜닝복잡, 다중클래스 One-vs-Rest 확장필요, 클래스불균형 취약 |
| **차별화** | **실무 하이퍼파라미터 튜닝 및 확장 전략**<br>1. **C값 최적화**: 교차검증(Grid Search/Bayesian Optimization)으로 탐색, class_weight 조정 → 클래스불균형 대응<br>2. **대용량 확장**: O(N²) 이상 급증 시 SGD기반 Linear SVC, 근사커널(Nystrom) 적용 → 확장성 한계 극복<br>3. **활용 사례**: 텍스트/문서분류(스팸필터, 감성분석), 이미지인식(얼굴인식, 초기OCR), 생물정보학(유전자발현 암진단), 이상탐지(One-Class SVM 금융이상거래) - 딥러닝 시대에도 고차원·소량데이터 환경 우수 대안 |
