# SVM: 마진 분류와 커널 트릭 서브노트

> **두음 머리에 박기 🧠**
> - **하·소** (선형 SVM 마진 분류 2가지: **하**드 마진, **소**프트 마진)
> - **마·소·커·최** (SVM 동작 4단계: **마**진 최대화, **소**프트 마진 적용, **커**널 트릭 적용, **최**적화(라그랑주·QP))
> - **L·P·R·S** (커널 함수 4종: **L**inear, **P**olynomial, **R**BF, **S**igmoid)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **서포트 벡터 머신(Support Vector Machine, SVM) - 마진 분류 및 커널 트릭** |
| **정의** | SVM은 클래스 간 마진(Margin, 결정경계와 서포트 벡터 간 거리)을 최대화하는 최적의 결정경계(초평면)를 찾아 데이터를 분류하는 지도학습 기반 이진 분류 알고리즘이며, 선형 분리가 어려운 경우 커널 트릭으로 고차원 공간에 매핑해 비선형 문제로 확장한다 |
| **키워드** | 마진(Margin), 서포트 벡터, 하드/소프트 마진, 슬랙 변수, 규제 파라미터 C, 커널 트릭 |
| **개념도** | `●  ●   ★     ★   ○  ○` (★=서포트 벡터)<br>`───────────┼───────────` ← 최적 결정경계(초평면)<br>`  ●  ★         ★   ○`<br>↕margin↕ 서포트 벡터-경계 간 최단거리 = 마진<br><br>`저차원(선형분리 불가)` --커널 트릭(φ(x))--> `고차원(선형분리 가능)` |
| **구성요소** | 1. **마진(Margin)**: 결정경계와 가장 가까운 데이터(서포트 벡터) 간 거리, 클수록 일반화 성능 향상<br>2. **하드 마진**: 오분류를 전혀 허용하지 않음. `min(1/2)‖w‖² s.t. yᵢ(w·xᵢ+b)≥1`, 완벽 선형 분리 가능한 데이터 전제, 이상치에 매우 민감<br>3. **소프트 마진**: 슬랙 변수(ξᵢ)로 일부 오분류 허용. `min(1/2)‖w‖²+C·Σξᵢ s.t. yᵢ(w·xᵢ+b)≥1-ξᵢ, ξᵢ≥0`. C가 클수록 오분류 패널티 강함(마진 좁아짐, 과적합↑), C가 작을수록 오분류 허용도 높음(마진 넓어짐, 과소적합↑)<br>4. **커널 함수**: Linear(텍스트 분류), Polynomial(이미지 특징), RBF/Gaussian(가장 범용적, 비선형 복잡 경계), Sigmoid(신경망 유사 경계) - 실제 고차원 매핑 없이 커널 함수(내적)만으로 계산량 절감<br>5. **최적화 절차**: 라그랑주 승수법으로 쌍대문제 변환 후 QP(Quadratic Programming)로 해 도출 |
| **비교** | **하드 마진(Hard Margin)**<br>- 여유변수 없음, 규제 파라미터 없음<br>- 실무 적용성 낮음(현실 데이터는 노이즈 포함)<br><br>**소프트 마진(Soft Margin)**<br>- 슬랙 변수(ξ) + 규제 파라미터 C 도입<br>- 실무 적용성 높음(대부분 실무 SVM은 소프트 마진)<br><br>**SVM 장단점**<br>- 장점: 고차원·소량 데이터에서 높은 일반화 성능, 마진 최대화로 과적합에 강함, 서포트 벡터만으로 결정경계 설명 가능<br>- 단점: 대용량 데이터 학습속도 저하(O(N²)~O(N³)), 커널·C·감마 튜닝 복잡, 다중 클래스는 One-vs-Rest 확장 필요, 클래스 불균형에 취약 |
| **차별화** | **실무 하이퍼파라미터 튜닝 및 확장 전략**<br>1. **C값 최적화**: 최적 C값은 교차검증(Grid Search/Bayesian Optimization)으로 탐색하며, class_weight 조정으로 클래스 불균형 데이터에 대응.<br>2. **대용량 확장**: O(N²) 이상 급증하는 대용량 데이터에는 SGD 기반 Linear SVC, 근사 커널(Nystrom) 기법을 적용해 확장성 한계를 극복.<br>3. **활용 사례**: 텍스트/문서 분류(스팸 필터링, 감성 분석), 이미지 인식(얼굴 인식, 초기 OCR), 생물정보학(유전자 발현 기반 암 진단), 이상탐지(One-Class SVM 기반 금융 이상거래 탐지)에 폭넓게 적용되며, 딥러닝 시대에도 고차원·소량 데이터 환경에서는 여전히 우수한 대안. |
