# 아웃라이어(이상치) 탐지 서브노트

> **두음 머리에 박기 🧠**
> - **전·맥·군** (아웃라이어 3대 유형: **전**역 이상치, **맥**락 이상치, **군**집 이상치)
> - **통·거·밀·모** (탐지 기법 4대 접근: **통**계 기반(IQR·Z-score), **거**리 기반(KNN), **밀**도 기반(LOF), **모**델 기반(Isolation Forest·AutoEncoder))

| 분류 | 기술 기술사 서브노트 작성 예시 (1교시형 포맷) |
| :--- | :--- |
| **토픽명** | **아웃라이어(Outlier) 탐지** |
| **정의** | 데이터 집합에서 다른 데이터와 현저히 다른 패턴을 보이는 관측값으로, 통계적으로는 평균 ±2σ(3σ) 범위 밖의 값이며 금융 사기·장비 이상 감지 등에서 그 자체가 분석 목표가 되는 데이터마이닝 대상 |
| **키워드** | 전역/맥락/군집 이상치, IQR, Z-score, LOF, Isolation Forest, 노이즈와의 구분 |
| **개념도** | `[데이터 관측값]` ➔ `[통계 기반: IQR/Z-score]` ➔ `[거리 기반: KNN]` ➔ `[밀도 기반: LOF]` ➔ `[모델 기반: Isolation Forest/AutoEncoder]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[전역/맥락/군집 이상치로 분류]` ➔ `[보존·별도 모델링 or 제거]` |
| **구성요소** | 1. **전역 이상치**: 전체 데이터셋 관점에서 명백히 다른 값(체온 60°C)<br>2. **맥락 이상치**: 특정 맥락(시간·위치)에서만 이상(겨울철 30°C)<br>3. **군집 이상치**: 개별로는 정상이나 집합적으로 이상(ECG 비정상 패턴)<br>4. **탐지 기법**: 통계(IQR/Z-score), 거리(KNN), 밀도(LOF), 모델(Isolation Forest, AutoEncoder) |
| **비교** | **아웃라이어(Outlier)**<br>- 정상 범위를 벗어난 의미 있는 관측값<br>- 분석 가치 높음(사기·장비고장·실제 이상), 보존하여 별도 모델링<br><br>**노이즈(Noise)**<br>- 측정 오차·무작위 변동<br>- 분석 가치 낮음(센서 오류·입력 실수), 전처리 단계에서 제거 |
| **차별화** | **이상 탐지 실무 적용 및 유형별 대응 전략**<br>1. **유형 판별 후 기법 선택**: 전역 이상치는 통계·거리 기반으로 단순 탐지, 맥락 이상치는 시계열·위치 컨텍스트를 반영한 밀도 기반(LOF), 군집 이상치는 시퀀스 패턴 모델(AutoEncoder)로 탐지.<br>2. **실시간 사기 탐지 적용**: 신용카드 이상 거래에서 평소와 다른 지역·시간·금액 조합(맥락 이상치)을 LOF로 실시간 탐지하여 즉시 거래 차단.<br>3. **데이터 품질 연계**: 아웃라이어 탐지 결과는 데이터 옵저버빌리티의 Distribution 지표와 연동하여 파이프라인 이상을 조기에 식별하는 데 활용. |
