# 아웃라이어(이상치) 탐지 서브노트

> **두음 머리에 박기 🧠**
> - **전·맥·군** (아웃라이어 3대 유형: **전**역 이상치, **맥**락 이상치, **군**집 이상치)
> - **통·거·밀·모** (탐지 기법 4대 접근: **통**계 기반(IQR·Z-score), **거**리 기반(KNN), **밀**도 기반(LOF), **모**델 기반(Isolation Forest·AutoEncoder))
> - **인·숨·표·롱·고** (편향(Bias) 5대 유형: **인**간의 편향, **숨**겨진 편향, **표**본 편향, **롱**테일 편향, **고**의적 편향)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **아웃라이어(Outlier) 탐지** |
| **정의** | 다른 데이터와 현저히 다른 패턴 보이는 관측값 - 통계적으로 평균 ±2σ(3σ) 범위 밖 - 금융 사기·장비 이상 감지 등에서 그 자체가 분석 목표인 데이터마이닝 대상 |
| **키워드** | 전역/맥락/군집 이상치, IQR, Z-score, LOF, Isolation Forest, 노이즈와의 구분 |
| **개념도** | `[데이터 관측값]` ➔ `[통계 기반: IQR/Z-score]` ➔ `[거리 기반: KNN]` ➔ `[밀도 기반: LOF]` ➔ `[모델 기반: Isolation Forest/AutoEncoder]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[전역/맥락/군집 이상치로 분류]` ➔ `[보존·별도 모델링 or 제거]` |
| **구성요소** | 1. **전역 이상치**: 전체 데이터셋 관점에서 명백히 다른 값(체온 60°C)<br>2. **맥락 이상치**: 특정 맥락(시간·위치)에서만 이상(겨울철 30°C)<br>3. **군집 이상치**: 개별은 정상, 집합적으로 이상(ECG 비정상 패턴)<br>4. **탐지 기법**: 통계(IQR/Z-score), 거리(KNN), 밀도(LOF), 모델(Isolation Forest, AutoEncoder)<br>5. **편향(Bias)**: 수집·처리·알고리즘 설계 과정 치우침 → 결과 객관성·공정성 저해. 5대 유형 - 인간의 편향(수집자 주관)·숨겨진 편향(구조적)·표본 편향(특정 집단 과대/과소 대표)·롱테일 편향(소수 극단값 왜곡)·고의적 편향(의도적 조작) |
| **비교** | **아웃라이어(Outlier)**<br>- 정상 범위 벗어난 의미 있는 관측값<br>- 분석 가치 높음(사기·장비고장·실제 이상) → 보존·별도 모델링<br><br>**노이즈(Noise)**<br>- 측정 오차·무작위 변동<br>- 분석 가치 낮음(센서 오류·입력 실수) → 전처리 단계 제거<br><br>**편향(Bias)**<br>- 데이터·알고리즘 구조적 치우침 → 모집단 대표성 상실·차별 고착화<br>- 처리: 기술적(SMOTE 재샘플링·재가중치·L1/L2 정규화·GAN 편향제거·XAI)+제도적(설명요구권, AI윤리, 데이터품질 감리) 병행 |
| **차별화** | **이상 탐지·편향 대응 실무 전략**<br>1. **유형별 기법 선택**: 전역→통계·거리 기반 단순탐지, 맥락→시계열·위치 반영 밀도기반(LOF), 군집→시퀀스 패턴 모델(AutoEncoder)<br>2. **실시간 사기 탐지 적용**: 이상 지역·시간·금액 조합(맥락 이상치) → LOF 실시간 탐지 → 즉시 거래 차단<br>3. **데이터 품질 연계**: 탐지 결과 → 옵저버빌리티 Distribution 지표 연동 → 파이프라인 이상 조기 식별<br>4. **편향·이상치 구분 대응**: 이상치=통계기법(IQR·Z-score·Isolation Forest) / 편향=기술적기법(SMOTE·재가중치)+XAI·법적규제(EU AI Act, 인공지능기본법) 병행 → 신용평가·채용 AI 차별 고착화 방지 |
