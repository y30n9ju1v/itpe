# 확장성 해싱과 다차원 색인구조 서브노트

> **두음 머리에 박기 🧠**
> - **디·버·전·지** (확장성 해싱 4대 구성요소: **디**렉토리, **버**킷, **전**역 깊이, **지**역 깊이)
> - **K·R·Q·H** (다차원 색인 4대 유형: **K**D-Tree, **R**-Tree, **Q**uadtree, **H**NSW)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **확장성 해싱(Extendible Hashing) 및 다차원 색인구조(Multidimensional Index Structure)** |
| **정의** | 확장성 해싱: 전체 재해싱 없이 디렉토리·버킷 분할로 동적 확장하는 해시 기법<br>다차원 색인구조: 2차원 이상 공간·고차원 벡터 데이터 효율 탐색용 색인 기법 |
| **키워드** | 전역/지역 깊이, 버킷 분할, 디렉토리 확장, K-D Tree, R-Tree(MBR), Quadtree, HNSW, 차원의 저주 |
| **개념도** | `[삽입] 버킷 오버플로우` ➔ `{지역깊이<전역깊이: 버킷만 분할} / {지역깊이=전역깊이: 디렉토리 2배 확장+분할}`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`│`<br>`[다차원 질의: Range Query / KNN]` ➔ `저차원: K-D Tree` ➔ `공간객체: R-Tree(MBR)` ➔ `고차원 벡터: HNSW(ANN)` |
| **구성요소** | 1. **디렉토리(Directory)**: 전역깊이 d 포인터 배열, 크기 2^d<br>2. **버킷(Bucket)**: 실제 레코드 저장블록, 지역깊이 d' 보유<br>3. **K-D Tree**: 레벨마다 교대 축분할, 저차원 탐색·그래픽스용<br>4. **R-Tree**: MBR(최소경계 직사각형) 기반 계층구조, GIS·지도서비스<br>5. **HNSW**: 그래프 기반 ANN, 다층그래프 O(log n) 근사탐색, AI 벡터DB(FAISS, Pinecone) |
| **비교** | **정적 해싱(Static Hashing)**<br>- 파일크기 고정, 오버플로우 시 전체 재해싱 필요<br>- 공간효율 낮음(예약공간), 성능저하 발생<br><br>**확장성 해싱(Extendible Hashing)**<br>- 파일크기 동적확장, 부분분할만 수행<br>- 공간효율 높음, 일정 성능 유지 |
| **차별화** | **대규모/고차원 데이터 탐색 색인 전략 로드맵**<br>1. **1차원 한계 극복**: 단일 B-Tree → 위도+경도 등 다차원 비효율, 범위질의·KNN용 K-D Tree/R-Tree 도입<br>2. **동적 갱신 대응**: K-D Tree는 삽입/삭제 시 불균형 발생 → 실시간 갱신 잦은 공간데이터는 R-Tree 채택<br>3. **AI 벡터 DB 확장**: RAG - 수백~수천 차원 임베딩 유사문서 검색 → HNSW(ANN) 채택, 정확도-속도 트레이드오프 관리 |
