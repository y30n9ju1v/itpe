# 확장성 해싱과 다차원 색인구조 서브노트

> **두음 머리에 박기 🧠**
> - **디·버·전·지** (확장성 해싱 4대 구성요소: **디**렉토리, **버**킷, **전**역 깊이, **지**역 깊이)
> - **K·R·Q·H** (다차원 색인 4대 유형: **K**D-Tree, **R**-Tree, **Q**uadtree, **H**NSW)

---

| 분류 | 기술 기술사 서브노트 작성 예시 (1교시형 포맷) |
| :--- | :--- |
| **토픽명** | **확장성 해싱(Extendible Hashing) 및 다차원 색인구조(Multidimensional Index Structure)** |
| **정의** | 확장성 해싱은 전체 재해싱 없이 디렉토리와 버킷의 분할로 동적 확장하는 해시 기법이며, 다차원 색인구조는 2차원 이상 공간·고차원 벡터 데이터를 효율적으로 탐색하기 위한 색인 기법 |
| **키워드** | 전역/지역 깊이, 버킷 분할, 디렉토리 확장, K-D Tree, R-Tree(MBR), Quadtree, HNSW, 차원의 저주 |
| **개념도** | `[삽입] 버킷 오버플로우` ➔ `{지역깊이<전역깊이: 버킷만 분할} / {지역깊이=전역깊이: 디렉토리 2배 확장+분할}`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`│`<br>`[다차원 질의: Range Query / KNN]` ➔ `저차원: K-D Tree` ➔ `공간객체: R-Tree(MBR)` ➔ `고차원 벡터: HNSW(ANN)` |
| **구성요소** | 1. **디렉토리(Directory)**: 전역 깊이 d를 가진 포인터 배열, 크기 2^d<br>2. **버킷(Bucket)**: 실제 레코드 저장 블록, 지역 깊이 d' 보유<br>3. **K-D Tree**: 레벨마다 교대 축 분할, 저차원 탐색·컴퓨터 그래픽스<br>4. **R-Tree**: MBR(최소 경계 직사각형) 기반 계층 구조, GIS·지도 서비스<br>5. **HNSW**: 그래프 기반 ANN, 다층 그래프로 O(log n) 근사 탐색, AI 벡터 DB(FAISS, Pinecone) |
| **비교** | **정적 해싱(Static Hashing)**<br>- 파일 크기 고정, 오버플로우 시 전체 재해싱 필요<br>- 공간 효율 낮음(예약 공간), 성능 저하 발생<br><br>**확장성 해싱(Extendible Hashing)**<br>- 파일 크기 동적 확장, 부분 분할만 수행<br>- 공간 효율 높음, 일정 성능 유지 |
| **차별화** | **대규모/고차원 데이터 탐색을 위한 색인 전략 로드맵**<br>1. **1차원 한계 극복**: 단일 B-Tree는 위도+경도 같은 다차원 데이터에서 비효율 → 범위 질의·KNN 지원을 위해 K-D Tree/R-Tree 도입.<br>2. **동적 갱신 요구 대응**: K-D Tree는 삽입/삭제 시 불균형이 발생하므로, 실시간 갱신이 잦은 공간 데이터는 R-Tree(동적 지원)를 채택.<br>3. **AI 벡터 DB로의 확장**: RAG 시스템에서 수백~수천 차원 임베딩 벡터의 유사 문서 검색을 위해 근사 최근접 이웃(HNSW)을 채택하여 정확도와 속도의 트레이드오프를 관리. |
