# 의사결정나무: 형성절차와 지니·엔트로피 지수 서브노트

> **두음 머리에 박기 🧠**
> - **형·가·타·해** (의사결정나무 형성 4단계: **형**성, **가**지치기, **타**당성 평가, **해**석 및 예측)
> - **G·E·C** (불순도 지표: **G**ini Index(CART), **E**ntropy(C4.5), **C**hi-square(CHAID))

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **의사결정나무 (Decision Tree)와 불순도 지표 (Gini Index, Entropy Index)** |
| **정의** | 속성별 분할기준 판별 → 트리형태 분류·예측 기법. 자식마디 불순도 최소화 변수를 분리기준 선택, CART=지니지수 / C4.5=엔트로피지수 사용 |
| **키워드** | 분리기준, 정지규칙, 가지치기, Gini Index, Entropy Index, 정보이득, CART/C4.5/CHAID |
| **개념도** | `[루트 노드]`<br>&nbsp;&nbsp;&nbsp;├─▶`[내부 노드A]`─▶`[단말: 분류결과]`<br>&nbsp;&nbsp;&nbsp;└─▶`[내부 노드B]`─▶`[단말: 분류결과]`<br>`G(A)=1-Σpk²` (지니), `E(A)=-Σpk·log₂pk` (엔트로피) → 불순도 최소화 변수로 분리 |
| **구성요소** | 1. **형성 단계**: 분리기준(Split Criterion)·정지규칙(Stopping Rule)으로 트리구축<br>2. **가지치기(Pruning)**: 분류오류 위험 큰 가지 제거 → 과적합 방지<br>3. **타당성 평가**: 이익도표·위험도표·교차타당성(CV)으로 검증<br>4. **지니 지수**: G(A)=1-Σpk², CART 사용, 복원추출 기반 이질성 측정, 0=완전순수<br>5. **엔트로피 지수**: E(A)=-Σpk·log₂(pk), C4.5 사용, 무질서도 측정, IG(정보이득)=부모-자식 엔트로피 |
| **비교** | **CART (지니 지수)**<br>- 이지분리(Binary Split), 범주/수치 변수 모두 지원<br>- 분류+회귀나무 가능, Breiman 개발<br>- 완전모형 개발 후 학습/검증 비교 가지치기<br><br>**C4.5 (엔트로피 지수)**<br>- 다지분리(Multiway Split), 범주/수치 변수 지원<br>- 분류+회귀나무 가능, Quinlan 개발<br>- 완전형 개발, log연산 무질서도 계산 |
| **차별화** | **의사결정나무 실무 적용 및 개선 전략** <br>1. **단점 보완**: 레코드수 변화에 민감·특정데이터 편향 한계 → 다수트리 앙상블+복원샘플링 랜덤포레스트로 극복<br>2. **연속형 변수 처리**: 분리경계점 부근 예측오류 확대 가능 → 구간화(Binning) 전략 신중설계<br>3. **CHAID 활용**: 범주형 변수만 지원하나 Chi-square 다지분리 → 마케팅 세그먼트 분석 활용<br>4. **XGBoost/LightGBM 연계**: 단일트리 정확도 한계 → 부스팅 앙상블로 보완, 실무 예측성능 극대화 |
