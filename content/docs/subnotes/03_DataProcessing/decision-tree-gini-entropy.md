# 의사결정나무: 형성절차와 지니·엔트로피 지수 서브노트

> **두음 머리에 박기 🧠**
> - **형·가·타·해** (의사결정나무 형성 4단계: **형**성, **가**지치기, **타**당성 평가, **해**석 및 예측)
> - **G·E·C** (불순도 지표: **G**ini Index(CART), **E**ntropy(C4.5), **C**hi-square(CHAID))

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **의사결정나무 (Decision Tree)와 불순도 지표 (Gini Index, Entropy Index)** |
| **정의** | 데이터 속성으로부터 분할 기준을 판별하여 트리 형태로 모델링하는 분류·예측 기법으로, 자식마디의 불순도(이질성)를 가장 낮추는 변수를 분리 기준으로 선택하며 CART는 지니 지수, C4.5는 엔트로피 지수를 불순도 측정 지표로 사용 |
| **키워드** | 분리기준, 정지규칙, 가지치기, Gini Index, Entropy Index, 정보이득, CART/C4.5/CHAID |
| **개념도** | `[루트 노드]`<br>&nbsp;&nbsp;&nbsp;├─▶`[내부 노드A]`─▶`[단말: 분류결과]`<br>&nbsp;&nbsp;&nbsp;└─▶`[내부 노드B]`─▶`[단말: 분류결과]`<br>`G(A)=1-Σpk²` (지니), `E(A)=-Σpk·log₂pk` (엔트로피) → 불순도 최소화 변수로 분리 |
| **구성요소** | 1. **형성 단계**: 분리 기준(Split Criterion)·정지 규칙(Stopping Rule)으로 트리 구축<br>2. **가지치기(Pruning)**: 분류 오류 위험이 큰 가지 제거로 과적합 방지<br>3. **타당성 평가**: 이익도표·위험도표·교차 타당성(Cross Validation)으로 검증<br>4. **지니 지수**: G(A)=1-Σpk², CART가 사용, 복원추출 기반 이질성 측정, 0이면 완전 순수<br>5. **엔트로피 지수**: E(A)=-Σpk·log₂(pk), C4.5가 사용, 무질서도 측정, 정보이득(IG)=부모 엔트로피-자식 엔트로피로 분리 변수 선택 |
| **비교** | **CART (지니 지수)**<br>- 이지분리(Binary Split), 범주/수치 예측변수 모두 지원<br>- 분류나무+회귀나무 모두 가능, Breiman 개발<br>- 완전모형 개발 후 학습/검증 데이터 비교로 가지치기<br><br>**C4.5 (엔트로피 지수)**<br>- 다지분리(Multiway Split), 범주/수치 예측변수 지원<br>- 분류나무+회귀나무 가능, Quinlan 개발<br>- 완전형 개발, log 연산으로 무질서도 계산 |
| **차별화** | **의사결정나무 실무 적용 및 개선 전략** <br>1. **단점 보완**: 레코드 수 변화에 트리 모양이 민감하고 특정 데이터 군에 편향되는 한계를, 다수 트리를 앙상블·복원 샘플링으로 결합하는 랜덤포레스트로 극복<br>2. **연속형 변수 처리**: 분리 경계점 부근에서 예측 오류가 커질 수 있으므로 구간화(Binning) 전략을 신중히 설계<br>3. **CHAID 활용**: 범주형 예측변수만 지원하지만 Chi-square 통계량 기반 다지분리로 마케팅 세그먼트 분석에 널리 활용<br>4. **XGBoost/LightGBM 연계**: 단일 트리의 정확도 한계를 부스팅 계열 앙상블로 보완하여 실무 예측 성능 극대화 |
