# 데이터 분석 Flow: EDA-전처리-모델링-평가 서브노트

> **두음 머리에 박기 🧠**
> - **E·전·모·평** (데이터 분석 Flow 4단계: **E**DA, **전**처리, **모**델링, **평**가)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **데이터 분석 Flow (EDA → 전처리 → 분석 모델링 → 모델 평가)** |
| **정의** | EDA·전처리·모델링·평가가 순환 연결된 체계적 분석프로세스 → 인사이트 도출·비즈니스가치 창출, 지도/비지도학습·평가지표 활용 포함 |
| **키워드** | EDA, 데이터 전처리, 지도학습/비지도학습, Confusion Matrix, 실루엣 계수, 순환 구조 |
| **개념도** | `데이터 EDA`──▶`데이터 전처리`──▶`분석 모델링`──▶`모델 평가`<br>&nbsp;&nbsp;&nbsp;▲──────────────────────────────────┘ (순환·반복) |
| **구성요소** | 1. **데이터 EDA**: 시각화·통계 지표·변수 간 상관관계 파악으로 데이터 특성 이해<br>2. **데이터 전처리**: 결측치·이상치 대체, 스케일링·인코딩 등 모델링 활용 수준으로 가공<br>3. **분석 모델링**: 학습/테스트 데이터 분할 후 지도학습(선형/로지스틱 회귀, 의사결정나무, SVM)·비지도학습(계층적 군집, K-Means, DBSCAN, EM)으로 예측 모델 생성<br>4. **분석 모델 평가**: 테스트 데이터로 예측 모델 적용, 예측값 타입·목적에 따라 분류(Confusion Matrix 기반 Accuracy/Precision/Recall/F1/ROC-AUC)·군집(실루엣 계수, ARI) 지표 활용 |
| **비교** | **분류 모델 평가**<br>- Confusion Matrix(TP/FN/FP/TN) 기반<br>- Accuracy/Precision/Recall/F1/ROC-AUC, 불균형 데이터는 F1·AUC 우선<br><br>**군집 모델 평가**<br>- 정답 레이블 없이 평가<br>- 실루엣 계수 Si=(bi-ai)/max(ai,bi), -1~1 범위, ARI(정답 있을 때 보정지수) |
| **차별화** | **데이터 분석 Flow 실무 적용 전략** <br>1. **순환 피드백**: 단계 간 독립 아님 → 평가결과 기반 전처리 재조정·Feature Engineering 반복이 실무표준<br>2. **불균형 대응**: Accuracy만 사용 시 다수클래스 편향 → 불균형데이터는 F1·AUC 우선 활용<br>3. **최적 K 탐색**: 군집모델은 정답레이블 없음 → 실루엣계수로 최적 K(군집수) 탐색 |
