# 데이터 가치평가 서브노트

> **두음 머리에 박기 🧠**
> - **비·시·수·옵** (가치평가 4대 모델: **비**용 접근법, **시**장 접근법, **수**익 접근법, **옵**션 가치법)
> - **비·복·네·시** (데이터 재화의 4대 특성: **비**경합성, **복**제 가능성, **네**트워크 효과, **시**간 가치 감소)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **데이터 가치평가 (Data Valuation)** |
| **정의** | 데이터 거래·활용 시 자산 경제가치를 비용·시장·수익·옵션 접근법으로 객관 산정하는 체계 → 데이터산업진흥법(2022) 시행과 함께 거래소 활성화 위해 제도화 |
| **키워드** | 비경합성, 데이터산업진흥법, 비용/시장/수익/옵션 접근법, K-DATA, DCF, 무형자산 |
| **개념도** | `[데이터 식별·범위설정]` ➔ `[품질평가: 정확성·완전성·최신성]` ➔ `[가치평가 방법 선택: 비용/시장/수익/옵션]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[가치 산정·검증]` ➔ `[보고서 작성]` ➔ `[거래·자산인식·담보·M&A 실사에 활용]` |
| **구성요소** | 1. **데이터 재화 특성**: 비경합성, 비배제성 극복(DRM), 복제가능성, 네트워크효과, 시간가치 감소<br>2. **비용 접근법**: 생성·수집·처리 비용 합산 (시장가격 없는 신규데이터)<br>3. **시장 접근법**: 유사 데이터거래 사례비교 (활성거래시장 존재 시)<br>4. **수익 접근법**: 미래수익 현재가치(DCF) (활용수익 예측가능 시)<br>5. **옵션 가치법**: 미래 활용가능성 실물옵션 평가 (잠재가치 높은 데이터) |
| **비교** | **비용 접근법(Cost Approach)**<br>- 데이터 생성 투입비용 기준<br>- 시장가격 없는 신규·희소 데이터에 적합<br><br>**수익 접근법(Income Approach)**<br>- 활용으로 창출될 미래수익 현재가치(DCF)<br>- 활용수익 예측가능 데이터에 적합 |
| **차별화** | **데이터 자산화 위한 가치평가 활용 전략**<br>1. **거래소 연계 가격산정**: K-DATA 등 시장접근법 기본 + 활성거래 없는 데이터는 비용·수익 접근법 병행 → 공정가격 도출<br>2. **무형자산 재무제표 반영**: 기업 무형자산 인식 → 재무제표 반영, 담보 기반 금융조달 활용<br>3. **공공데이터 개방 우선순위**: 가치평가 결과 활용 → 민간 활용도 높은 데이터 우선개방 → 생태계 활성화 |
