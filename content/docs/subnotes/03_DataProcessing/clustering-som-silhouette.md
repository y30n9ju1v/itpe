# 비지도 군집분석: SOM과 실루엣 계수 서브노트

> **두음 머리에 박기 🧠**
> - **초·경·협·수** (SOM 학습 4단계: **초**기화, **경**쟁(BMU 선정), **협**력(이웃 갱신), **수**렴)
> - **a·b·s** (실루엣 계수 구성: **a**(i) 응집도, **b**(i) 분리도, **s**(i)=(b-a)/max(a,b))

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **SOM(Self Organizing Map)과 실루엣 계수(Silhouette Coefficient)** |
| **정의** | SOM: 경쟁학습으로 고차원데이터 2D격자 위상보존 투영하는 비지도 군집화 신경망 / 실루엣계수: 응집도·분리도 정량화하는 클러스터링 품질지표 |
| **키워드** | BMU(Best Matching Unit), 경쟁 학습, 위상 보존, U-Matrix, a(i)/b(i), 최적 K 결정, 엘보우법 |
| **개념도** | `[입력 벡터]` ➔ `[SOM: BMU 경쟁 선정→이웃 협력 갱신→수렴]` ➔ `[2D 격자 군집 시각화]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼ (품질 평가)`<br>`s(i) = (b(i)-a(i)) / max(a(i),b(i))` ➔ `{0.7~1.0: 매우 좋음, 0~0.25: 약함, 0 이하: 잘못된 할당}` |
| **구성요소** | 1. **SOM 구성**: 입력층(n차원), 경쟁층(m×m 격자), BMU, 이웃 함수 h(t), 학습률 α(t)<br>2. **SOM 4단계 학습**: 초기화→경쟁(BMU 선정)→협력(이웃 갱신)→수렴<br>3. **실루엣 계수**: a(i)=클러스터 내 평균거리(응집도), b(i)=최근접 이웃 클러스터 평균거리(분리도)<br>4. **최적 K 결정**: K별 실루엣 계수 계산 후 최댓값을 갖는 K 선택 |
| **비교** | **SOM (비지도 신경망)**<br>- 경쟁 학습, 레이블 불필요, 역전파 없음<br>- 목적: 군집화·시각화·비선형 차원 축소<br><br>**MLP/BP 신경망 (지도학습)**<br>- 레이블 필요, 역전파로 가중치 갱신<br>- 목적: 분류·회귀 예측 |
| **차별화** | **비지도 군집분석의 평가·활용 로드맵**<br>1. **SOM 세그먼트 도출**: 고객구매패턴 군집화 → 위상보존 타겟마케팅 세그먼트, U-Matrix로 군집경계 시각화<br>2. **실루엣계수 K검증**: 군집화결과 K를 실루엣계수 최댓값 기준 객관 결정 → 엘보우법 주관성 한계 보완<br>3. **이상탐지 응용**: 정상패턴 학습 SOM맵 이탈 데이터 → 비지도 이상탐지로 확장 적용 |
