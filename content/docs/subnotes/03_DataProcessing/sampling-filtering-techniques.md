# 랜덤 샘플링과 필터링 기법 서브노트

> **두음 머리에 박기 🧠**
> - **단·계·2·층·집** (랜덤 샘플링 5대 유형: **단**순랜덤, **계**통, **2**단계, **층**별, **집**락 샘플링)
> - **베·내·칼 vs 해·질·블** (필터링: 학습기반=**베**이지안·**내**용기반·**칼**만 / 비학습기반=**해**시·**질**의·**블**룸)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **랜덤 샘플링(Random Sampling)과 필터링(Filtering) 기법** |
| **정의** | 빅데이터 스트림 급증으로 전체 데이터 처리가 불가능한 환경에서, 모집단 대표성을 확보하기 위해 각 구성요소가 동일 확률로 추출되도록 하는 랜덤 샘플링과, 데이터 활용 목적에 맞는 유의미한 데이터를 추출해 품질을 개선하는 필터링 기법 |
| **키워드** | 단순랜덤샘플링, 계통샘플링, 층별샘플링, 집락샘플링, 학습기반 필터링, 블룸 필터 |
| **개념도** | `[모집단]`▶`[동일확률 추출: 랜덤 샘플링]`▶`[유의미 데이터 추출: 필터링]`▶`[분석·처리 가능 데이터]`<br>`[학습기반 필터링]` 베이지안/내용기반/칼만 (모델 학습 필요)<br>`[비학습기반 필터링]` 해시/질의(Query)/블룸 (규칙·구조 기반) |
| **구성요소** | 1. **단순 랜덤 샘플링**: N개 중 n개를 동일 확률로 무작위 추출<br>2. **계통 샘플링**: 랜덤 출발점 이후 매 k번째 간격으로 추출<br>3. **2단계 샘플링**: 모집단을 1차 단위로 나눠 추출 후, 1차 시료 내 2차 단위 재추출<br>4. **층별 샘플링(Stratified)**: 겹치지 않는 층으로 나눠 각 층에서 랜덤 추출 (층별/네이만/데밍 샘플링)<br>5. **집락 샘플링(Cluster)**: 층으로 나눈 뒤 일부 층을 랜덤 선택해 해당 층 전수 조사<br>6. **학습기반 필터링**: 베이지안 필터링(조건부 확률 기반 스팸 분류)·내용기반 필터링(콘텐츠 속성 유사 추천)·칼만 필터링(잡음 측정값 상태 추정)<br>7. **비학습기반 필터링**: 해시 필터링(중복 제거)·질의(Query) 필터링(조건식 추출)·블룸 필터링(확률적 자료구조 기반 원소 포함 판단) |
| **비교** | **층별 샘플링(Stratified)**<br>- 모집단을 이질적 하위 그룹(층)으로 구분 후 각 층에서 추출<br>- 층 내 동질성·층 간 이질성이 클 때 대표성 우수<br><br>**집락 샘플링(Cluster)**<br>- 하위 그룹(집락) 중 일부를 선택해 해당 집락 전수 조사<br>- 집락 내 이질성·집락 간 동질성이 클 때 비용 효율적 |
| **차별화** | **빅데이터 파이프라인 샘플링·필터링 전략** <br>1. **스트리밍 환경 적용**: Kafka·Flink 등 스트리밍 환경은 전체 데이터 보관이 어려워, 블룸 필터·해시 필터링 기반 실시간 중복 제거와 계통 샘플링 기반 대표 데이터 추출이 핵심<br>2. **데이터 특성별 선택**: 이질적 하위집단이 뚜렷하면 층별 샘플링, 지리적·물리적으로 군집화된 데이터는 집락 샘플링이 비용 효율적<br>3. **품질-비용 균형**: 학습기반 필터링(베이지안·칼만)은 정교하나 모델 학습 비용이 발생하므로, 실시간성이 중요한 경우 비학습기반 필터링(해시·블룸)과 병행 적용 |
