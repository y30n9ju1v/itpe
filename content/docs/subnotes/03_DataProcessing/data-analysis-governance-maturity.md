# 데이터 분석 거버넌스: CoA·준비도·성숙도 서브노트

> **두음 머리에 박기 🧠**
> - **프·인·조·진·교** (분석 거버넌스 5대 구성요소: **프**로세스, **인**력, **조**직, 수준**진**단, **교**육)
> - **도·활·확·최** (분석 성숙도 4단계: **도**입, **활**용, **확**산, **최**적화)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **데이터 분석 거버넌스(Data Analysis Governance)와 분석 준비도·성숙도 모델** |
| **정의** | 전사 차원의 데이터 분석 정책·지침·표준화·전략을 수립하고 이를 관리할 조직·프로세스를 구축해 고품질 데이터 기반 가치 창출을 지원하는 체계로, CoA(Center of Analytics)를 중심으로 분석 프로세스·인력·조직·수준진단·교육의 5대 구성요소와, 조직의 분석 역량을 진단하는 준비도(6기준)·성숙도(4단계) 모델을 포함 |
| **키워드** | CoA(Center of Analytics), 분석 준비도, 분석 성숙도, 2×2 매트릭스, 데이터 컨트롤타워 |
| **개념도** | `[CoA]`─┬─▶`분석 프로세스`<br>&nbsp;&nbsp;&nbsp;&nbsp;├─▶`분석 전문인력`(+분석조직)<br>&nbsp;&nbsp;&nbsp;&nbsp;├─▶`분석수준 진단`<br>&nbsp;&nbsp;&nbsp;&nbsp;└─▶`분석 교육`<br>`준비도(낮음/높음)×성숙도(낮음/높음)` = `준비형/정착형/도입형/확산형` 4유형 |
| **구성요소** | 1. **분석 프로세스**: 요건정의→모델링→검증/테스트→적용(EDA/CDA 방법론 기반)<br>2. **분석 전문 인력**: 기초통계학·분석 방법 지식을 갖춘 데이터 사이언티스트<br>3. **분석 조직**: 분석 가치 발견·과제 정의·인사이트 실행을 총괄하는 컨트롤 타워<br>4. **분석수준 진단**: 분석 준비도·성숙도 점검<br>5. **분석 교육**: 데이터 훈련 프로그램 운영, 전사 분석 문화 확산<br>6. **분석 준비도(6기준)**: 분석 업무 파악·인력 및 조직·분석 기법·분석 데이터·분석 문화·IT 인프라<br>7. **분석 성숙도(4단계)**: 도입(환경 구축)→활용(결과 적용)→확산(전사 관리)→최적화(지속 혁신) |
| **비교** | **분석 준비도(Readiness)**<br>- 현재 시점의 분석 수행 여건(6기준) 평가<br>- 인력·데이터·기법·문화·인프라 구비 여부 진단<br><br>**분석 성숙도(Maturity)**<br>- 분석 활용의 발전 단계(4단계) 평가<br>- 도입→활용→확산→최적화의 시계열적 진화 정도 |
| **차별화** | **분석 거버넌스 실무 적용 전략** <br>1. **CoA의 역할**: 단순 분석 조직이 아닌 비즈니스 전략과 데이터 분석을 연결하는 컨트롤 타워로 포지셔닝해야 전사 확산이 가능<br>2. **2×2 매트릭스 진단**: 준비형(기반 확보 우선)·정착형(1차 정착 후 준비도 향상)·도입형(기법 즉시 도입)·확산형(전사 확산·최적화) 중 현재 위치를 파악해 단계별 목표를 수립<br>3. **단계적 고도화**: 인프라 구축→업무 적용→전사 확산→혁신의 순서로 체계적 로드맵을 설계하는 것이 성공적인 분석 거버넌스 정착의 핵심 |
