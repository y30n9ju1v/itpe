# 데이터 분석 거버넌스: CoA·준비도·성숙도 서브노트

> **두음 머리에 박기 🧠**
> - **프·인·조·진·교** (분석 거버넌스 5대 구성요소: **프**로세스, **인**력, **조**직, 수준**진**단, **교**육)
> - **도·활·확·최** (분석 성숙도 4단계: **도**입, **활**용, **확**산, **최**적화)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **데이터 분석 거버넌스(Data Analysis Governance)와 분석 준비도·성숙도 모델** |
| **정의** | 전사 분석 정책·지침·표준·조직·프로세스 구축 체계 → CoA 중심 5대 구성요소(프로세스·인력·조직·수준진단·교육) + 준비도(6기준)·성숙도(4단계) 진단모델 |
| **키워드** | CoA(Center of Analytics), 분석 준비도, 분석 성숙도, 2×2 매트릭스, 데이터 컨트롤타워 |
| **개념도** | `[CoA]`─┬─▶`분석 프로세스`<br>&nbsp;&nbsp;&nbsp;&nbsp;├─▶`분석 전문인력`(+분석조직)<br>&nbsp;&nbsp;&nbsp;&nbsp;├─▶`분석수준 진단`<br>&nbsp;&nbsp;&nbsp;&nbsp;└─▶`분석 교육`<br>`준비도(낮음/높음)×성숙도(낮음/높음)` = `준비형/정착형/도입형/확산형` 4유형 |
| **구성요소** | 1. **분석 프로세스**: 요건정의→모델링→검증/테스트→적용 (EDA/CDA 기반)<br>2. **분석 전문 인력**: 기초통계·분석기법 보유 데이터 사이언티스트<br>3. **분석 조직**: 가치발견·과제정의·인사이트실행 총괄 컨트롤타워<br>4. **분석수준 진단**: 준비도·성숙도 점검<br>5. **분석 교육**: 데이터 훈련 프로그램 → 전사 분석문화 확산<br>6. **분석 준비도(6기준)**: 업무파악·인력조직·기법·데이터·문화·IT인프라<br>7. **분석 성숙도(4단계)**: 도입(환경구축)→활용(결과적용)→확산(전사관리)→최적화(지속혁신) |
| **비교** | **분석 준비도(Readiness)**<br>- 현시점 분석 수행여건(6기준) 평가<br>- 인력·데이터·기법·문화·인프라 구비여부 진단<br><br>**분석 성숙도(Maturity)**<br>- 분석활용 발전단계(4단계) 평가<br>- 도입→활용→확산→최적화 시계열 진화도 |
| **차별화** | **분석 거버넌스 실무 적용 전략** <br>1. **CoA 역할**: 단순 분석조직 아닌 비즈니스전략-데이터분석 연결 컨트롤타워 포지셔닝 → 전사확산<br>2. **2×2 매트릭스 진단**: 준비형(기반확보 우선)·정착형(1차정착 후 준비도 향상)·도입형(기법 즉시도입)·확산형(전사확산·최적화) → 현위치 파악·단계별 목표수립<br>3. **단계적 고도화**: 인프라구축→업무적용→전사확산→혁신 순 로드맵 설계 (핵심)|
