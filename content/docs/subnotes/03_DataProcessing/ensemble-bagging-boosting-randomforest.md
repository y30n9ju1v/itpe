# 앙상블 기법: 배깅·부스팅·랜덤포레스트 서브노트

> **두음 머리에 박기 🧠**
> - **훈·집·결·앙** (앙상블 학습절차 4단계: **훈**련집합 도출, **집**합별 모델 학습, **결**과 조합, **앙**상블 도출)
> - **배·부·랜** (앙상블 3대 알고리즘: **배**깅 Bagging, **부**스팅 Boosting, **랜**덤포레스트 Random Forest)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **앙상블(Ensemble) 기법: 배깅(Bagging), 부스팅(Boosting), 랜덤포레스트(Random Forest)** |
| **정의** | 다수 모형 학습 → 예측·분류 결과 종합 → 단일모형 대비 신뢰성↑·과적합↓ 기법 (샘플링 기반 배깅·부스팅, 변수 샘플링 기반 랜덤포레스트 대표) |
| **키워드** | Bootstrap, Majority Voting, 가중치 반영, Random Forest, 분산 감소, 편향 감소 |
| **개념도** | `[훈련 데이터]`▶`[모델A][모델B][모델C]`(병렬/직렬 학습)▶`[결과 조합: Voting/평균]`▶`[앙상블 최종 모델]`<br>`[배깅]` Bootstrap 복원추출→병렬학습→분산 감소<br>`[부스팅]` 가중치 순차반영→직렬학습→편향 감소 |
| **구성요소** | 1. **학습절차 4단계**: 훈련집합 도출(하위집합 다수 생성)→집합별 모델학습(독립모델 구축)→결과조합(투표/평균)→앙상블 도출(최종모델 확정)<br>2. **배깅(Bagging)**: N개 Bootstrap 추출 → N개 단일분류자 생성 → Majority Voting 최종모델, 병렬학습·분산 감소<br>3. **부스팅(Boosting)**: 동일가중치 분류자 생성 → 이전 오분류 결과에 가중치 부여 → N회 반복 최종분류자, 직렬학습·편향 감소<br>4. **랜덤포레스트**: N개 Bootstrap 추출 → 대표 변수샘플 도출 → 의사결정나무 Leaf Node 분류 → 선형결합 최종모델<br>5. **선택 고려사항**: 분류기 신뢰도 기반 조합, 훈련오차 아닌 예측성능 기준 평가 |
| **비교** | **배깅(Bagging)**<br>- Bootstrap 복원추출 → 병렬 독립학습<br>- 분산(Variance) 감소 효과적, 과적합 방지<br>- 랜덤포레스트 대표사례<br><br>**부스팅(Boosting)**<br>- 이전 오분류 데이터 가중치 부여 → 순차학습<br>- 편향(Bias) 감소 효과적<br>- XGBoost·LightGBM·AdaBoost 대표사례 |
| **차별화** | **앙상블 기법 실무 적용 전략**<br>1. **성능 대회 실적**: XGBoost·LightGBM 등 부스팅 계열 → Kaggle 등 경진대회 최고성능 다수<br>2. **해석 가능성**: 랜덤포레스트 → Feature Importance 산출 용이, 금융·의료 XAI 적합<br>3. **의사결정나무 편향 극복**: 단일 의사결정나무 특정데이터 편향 한계 → 앙상블+복원샘플링(랜덤포레스트)로 보완<br>4. **속도 vs 정확도**: 배깅 병렬처리 → 속도↑, 부스팅 순차처리 → 느리나 정확도↑ 경향 |
