# 앙상블 기법: 배깅·부스팅·랜덤포레스트 서브노트

> **두음 머리에 박기 🧠**
> - **훈·집·결·앙** (앙상블 학습절차 4단계: **훈**련집합 도출, **집**합별 모델 학습, **결**과 조합, **앙**상블 도출)
> - **배·부·랜** (앙상블 3대 알고리즘: **배**깅 Bagging, **부**스팅 Boosting, **랜**덤포레스트 Random Forest)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **앙상블(Ensemble) 기법: 배깅(Bagging), 부스팅(Boosting), 랜덤포레스트(Random Forest)** |
| **정의** | 기계학습에서 다수의 모형을 학습시켜 예측·분류 결과를 종합함으로써 단일 모형보다 높은 신뢰성을 확보하고 과적합을 최소화하는 기법으로, 샘플링 기반 배깅·부스팅과 변수 샘플링 기반 랜덤포레스트가 대표적 |
| **키워드** | Bootstrap, Majority Voting, 가중치 반영, Random Forest, 분산 감소, 편향 감소 |
| **개념도** | `[훈련 데이터]`▶`[모델A][모델B][모델C]`(병렬/직렬 학습)▶`[결과 조합: Voting/평균]`▶`[앙상블 최종 모델]`<br>`[배깅]` Bootstrap 복원추출→병렬학습→분산 감소<br>`[부스팅]` 가중치 순차반영→직렬학습→편향 감소 |
| **구성요소** | 1. **학습절차 4단계**: 훈련 집합 도출(다수 하위집합 생성)→집합별 모델 학습(독립 모델 구축)→결과 조합(투표/평균)→앙상블 도출(최종 모델 확정)<br>2. **배깅(Bagging)**: N개 Bootstrap 데이터 추출→N개 단일 분류자 생성→Majority Voting으로 최종 모델, 병렬 학습·분산 감소 효과<br>3. **부스팅(Boosting)**: 동일 가중치로 분류자 생성→이전 분류 결과에 따라 가중치 부여→N회 반복 후 최종 분류자, 직렬 학습·편향 감소 효과<br>4. **랜덤포레스트**: N개 Bootstrap 데이터 추출→대표 변수 샘플 도출→의사결정나무 Leaf Node로 분류→Leaf Node 선형결합으로 최종 모델<br>5. **선택 시 고려사항**: 분류기 신뢰도 기반 조합, 훈련 집합 오차가 아닌 예측 성능 기준 평가 |
| **비교** | **배깅(Bagging)**<br>- Bootstrap 복원추출로 병렬 독립 학습<br>- 분산(Variance) 감소에 효과적, 과적합 방지<br>- 랜덤포레스트가 대표 사례<br><br>**부스팅(Boosting)**<br>- 이전 오분류 데이터에 가중치를 부여해 순차 학습<br>- 편향(Bias) 감소에 효과적<br>- XGBoost·LightGBM·AdaBoost가 대표 사례 |
| **차별화** | **앙상블 기법 실무 적용 전략** <br>1. **성능 대회 실적**: XGBoost·LightGBM 등 부스팅 계열은 Kaggle 등 데이터 경진대회에서 최고 성능을 보이는 경우가 많음<br>2. **해석 가능성**: 랜덤포레스트는 피처 중요도(Feature Importance) 산출이 용이해 금융·의료 분야 설명가능 AI(XAI) 구현에 적합<br>3. **의사결정나무 편향 극복**: 단일 의사결정나무는 특정 데이터 군에 편향되는 한계가 있어, 앙상블·복원 샘플링을 결합한 랜덤포레스트로 이를 보완<br>4. **속도 vs 정확도 트레이드오프**: 배깅은 병렬 처리로 학습 속도가 빠르고, 부스팅은 순차 처리로 느리지만 정확도가 높은 경향 |
