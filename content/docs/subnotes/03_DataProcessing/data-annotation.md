# 이미지 데이터 어노테이션 서브노트

> - **분·바·폴·시·인·키·3D** (이미지 어노테이션 7유형: **분**류, **바**운딩박스, **폴**리곤, **시**맨틱분할, **인**스턴스분할, **키**포인트, **3D**어노테이션)
> - **수·반·크** (어노테이션 3대 기법: **수**동 라벨링, **반**자동 어노테이션, **크**라우드소싱)

| **정의** | AI/ML 모델 학습을 위해 원시 이미지 데이터에 레이블·메타데이터·주석을 부착하는 작업으로, 컴퓨터 비전 모델(분류·탐지·분할)의 품질을 결정하는 핵심 전처리 과정 |
| **키워드** | 바운딩 박스, 시맨틱/인스턴스 분할, 키포인트, IAA(Inter-Annotator Agreement), 골든 셋, 액티브 러닝 |
| **개념도** | `[원시 이미지]` ➔ `[어노테이션 기법 선택: 수동/반자동/크라우드소싱]` ➔ `[레이블 부착: 분류·박스·폴리곤·마스크 등]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼ (품질 보증)`<br>`[IAA 측정] + [골든 셋 검증] + [액티브 러닝으로 비용 절감]` ➔ `[AI 모델 학습 데이터셋]` |
| **구성요소** | 1. **분류/바운딩박스/폴리곤/시맨틱분할/인스턴스분할/키포인트/3D 어노테이션**: 태스크별 7가지 유형<br>2. **수동 라벨링**: 전문가 직접 표시(고품질·고비용)<br>3. **반자동 어노테이션**: AI 초안 생성 후 사람이 수정<br>4. **크라우드소싱**: 다수 작업자 활용(저비용, 품질 편차)<br>5. **품질 보증**: IAA(Cohen's Kappa), 골든 셋, 액티브 러닝 |
| **비교** | **수동 라벨링**<br>- 전문 어노테이터가 직접 수행<br>- 고품질이나 고비용·저속<br><br>**크라우드소싱**<br>- Amazon MTurk 등 다수 작업자 활용<br>- 저비용·고속이나 품질 편차 발생, IAA로 보정 필요 |
| **차별화** | **AI 학습 데이터 품질 확보를 위한 어노테이션 운영 전략**<br>1. **품질 이슈 대응**: 레이블 노이즈는 Noise Learning 기법으로, 클래스 불균형은 오버샘플링·GAN 합성 데이터로 보완.<br>2. **가이드라인 표준화**: 어노테이터 간 기준 차이(일관성 문제)를 줄이기 위해 상세한 어노테이션 가이드라인과 정기 캘리브레이션 세션 운영.<br>3. **비용 효율화**: 액티브 러닝으로 모델이 불확실해하는 샘플만 선별 라벨링하여 전체 어노테이션 비용을 절감하면서 성능 향상 속도를 유지. |
