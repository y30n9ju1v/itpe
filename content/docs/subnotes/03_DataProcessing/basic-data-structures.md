# 기본 자료구조: 연결 리스트와 이진 탐색 트리 서브노트

> **두음 머리에 박기 🧠**
> - **단·이·원** (연결 리스트 3종: **단**순 연결, **이**중 연결, **원**형 연결)
> - **리·자·후** (BST 삭제 3가지 경우: **리**프 노드 제거, **자**식 1개는 자식으로 대체, **자**식 2개는 오른쪽 서브트리 최솟값(**후**계자)으로 대체)
> - **A·R·B** (편향 트리 문제의 균형 트리 해법: **A**VL 트리, **R**ed-Black 트리, **B**-트리)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **연결 리스트(Linked List) 및 이진 탐색 트리(Binary Search Tree)** |
| **정의** | 연결 리스트는 노드가 포인터로 논리적으로 연결되는 동적 자료구조이며, 이진 탐색 트리는 좌 < 부모 < 우 속성을 만족하는 이진 트리로 평균 O(log n) 탐색을 지원하는 자료구조 |
| **키워드** | 단순·이중·원형 연결(단·이·원), 포인터, 중위 순회, AVL, Red-Black, B-트리, 편향 트리 |
| **개념도** | `[배열] 연속 메모리 O(1) 접근` ➔ `[연결 리스트] 비연속 포인터 O(1) 삽입/삭제`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`│`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼ (탐색 효율화)`<br>`[이진 탐색 트리] 좌<부모<우, O(log n)` ➔ `[편향 시 O(n) 저하]` ➔ `[AVL/Red-Black/B-트리로 균형 유지]` |
| **구성요소** | 1. **연결 리스트 노드**: Data + Next 포인터(이중은 Prev 포인터 추가)<br>2. **단순/이중/원형 연결 리스트**: 순방향만/양방향/마지막→첫 노드 순환<br>3. **BST 노드**: 좌 서브트리 < 노드값 < 우 서브트리<br>4. **순회**: 전위(루트→좌→우), 중위(좌→루트→우, 정렬 출력), 후위(좌→우→루트)<br>5. **균형 트리**: AVL(엄격 균형, |좌우 높이차|≤1), Red-Black(느슨한 균형), B-트리(모든 리프 동일 깊이, 디스크 기반 DB 인덱스) |
| **비교** | **배열 리스트(Array List)**<br>- 메모리: 연속 배치, 캐시 지역성 높음<br>- 임의 접근 O(1), 삽입·삭제 O(n)(이동 필요)<br>- 적합: 읽기·검색 빈번<br><br>**연결 리스트(Linked List)**<br>- 메모리: 비연속 배치, 캐시 지역성 낮음<br>- 임의 접근 O(n), 삽입·삭제 O(1)(포인터 변경)<br>- 적합: 삽입·삭제 빈번(OS Ready Queue, LRU 캐시, FAT 파일시스템) |
| **차별화** | **자료구조 선택 및 실무 적용 전략**<br>1. **적용 분야별 선택 기준**: OS 프로세스 관리(Ready/Wait Queue), 메모리 Free List, 그래프 인접 리스트, LRU 캐시(이중 연결 리스트)는 연결 리스트가 적합, 정렬된 데이터의 빈번한 탐색·범위 질의는 BST 계열이 적합.<br>2. **편향 트리 방지**: 순차 삽입 시 BST가 연결 리스트처럼 편향(O(n))되므로 실무 DB 인덱스는 B-트리/B+Tree를 채택하여 모든 리프 동일 깊이를 보장.<br>3. **해시 테이블과의 결합**: 해시 충돌 시 체이닝(Chaining) 기법에서 연결 리스트를 버킷 내부 구조로 활용하여 삽입·삭제 효율을 확보. |
