# AI 학습용 데이터 품질관리 서브노트

> **두음 머리에 박기 🧠**
> - **대·다·대·레·균·시** (AI 학습 데이터 6대 특성: **대**규모성, **다**양성, **대**표성, **레**이블 정확성, **균**형성, **시**의성)
> - **수·전·어·검·관** (품질관리 5단계: **수**집, **전**처리, **어**노테이션, **검**증, **관**리)

---

| 분류 | 기술 기술사 서브노트 작성 예시 (1교시형 포맷) |
| :--- | :--- |
| **토픽명** | **AI 학습용 데이터 품질관리 (AI Training Data Quality Management)** |
| **정의** | 기계학습 모델 성능을 좌우하는 훈련 데이터의 정확성·완전성·일관성·대표성을 체계적으로 확보하는 활동으로, "Garbage In, Garbage Out" 원칙에 따라 데이터 품질이 AI 모델 성능을 직접 결정 |
| **키워드** | 대규모성·다양성·대표성·레이블·균형성·시의성, Inter-Annotator Agreement, 개념 드리프트, 데이터 계보(Lineage) |
| **개념도** | `[수집] 개인정보·저작권 검토` ➔ `[전처리] 결측치·이상치·중복 제거` ➔ `[어노테이션] 가이드라인+다중 검토+IAA 측정`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[검증] 훈련/검증/테스트 분리+드리프트 모니터링` ➔ `[관리] 버전관리+Lineage+대시보드` |
| **구성요소** | 1. **6대 특성**: 대규모성, 다양성, 대표성, 레이블 정확성, 균형성, 시의성<br>2. **품질 지표**: 정확성(레이블 오류율·IAA), 완전성(결측값 비율), 일관성(레이블 일치율), 다양성/균형성(클래스 분포), 최신성(수집-배포 시점 격차)<br>3. **품질관리 5단계**: 수집→전처리→어노테이션→검증→관리<br>4. **관리 단계 활동**: 데이터 버전 관리, 데이터 계보 추적, 품질 지표 대시보드 |
| **비교** | **정형 데이터 품질관리 (전통적)**<br>- 테이블 값 오류·중복·누락 중심 진단<br>- DQC-V(값) / DQC-M(프로세스) 진단 체계<br><br>**AI 학습 데이터 품질관리**<br>- 레이블 정확성·클래스 균형·개념 드리프트까지 포괄<br>- 어노테이터 간 일치도(IAA), 데이터 증강 등 ML 특화 활동 필요 |
| **차별화** | **AI 학습 데이터 품질 확보를 위한 거버넌스 전략**<br>1. **레이블 정확성 우선 관리**: 다중 어노테이터 교차 검토와 Cohen's Kappa 기반 IAA 측정으로 레이블 오류가 모델 학습에 미치는 영향을 최소화.<br>2. **훈련/검증/테스트 누수 방지**: 데이터 분리 시점에 데이터 누수(Leakage)를 엄격히 통제하고, 배포 후 데이터 드리프트를 지속 모니터링하여 재학습 시점을 판단.<br>3. **비정형 데이터로의 품질 진단 확장**: 텍스트의 편향성(Bias), 이미지-텍스트 레이블 매칭 무결성, 증강 데이터의 노이즈까지 포함하는 다차원 품질 검증 체계로 확장. |
