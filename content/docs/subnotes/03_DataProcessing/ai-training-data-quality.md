# AI 학습용 데이터 품질관리 서브노트

> **두음 머리에 박기 🧠**
> - **대·다·대·레·균·시** (AI 학습 데이터 6대 특성: **대**규모성, **다**양성, **대**표성, **레**이블 정확성, **균**형성, **시**의성)
> - **수·전·어·검·관** (품질관리 5단계: **수**집, **전**처리, **어**노테이션, **검**증, **관**리)

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **AI 학습용 데이터 품질관리 (AI Training Data Quality Management)** |
| **정의** | 훈련데이터 정확성·완전성·일관성·대표성 체계적 확보 활동 → GIGO 원칙, 데이터품질이 AI모델 성능 직결 |
| **키워드** | 대규모성·다양성·대표성·레이블·균형성·시의성, Inter-Annotator Agreement, 개념 드리프트, 데이터 계보(Lineage) |
| **개념도** | `[수집] 개인정보·저작권 검토` ➔ `[전처리] 결측치·이상치·중복 제거` ➔ `[어노테이션] 가이드라인+다중 검토+IAA 측정`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[검증] 훈련/검증/테스트 분리+드리프트 모니터링` ➔ `[관리] 버전관리+Lineage+대시보드` |
| **구성요소** | 1. **6대 특성**: 대규모성, 다양성, 대표성, 레이블 정확성, 균형성, 시의성<br>2. **품질 지표**: 정확성(레이블 오류율·IAA), 완전성(결측값 비율), 일관성(레이블 일치율), 다양성/균형성(클래스 분포), 최신성(수집-배포 시점 격차)<br>3. **품질관리 5단계**: 수집→전처리→어노테이션→검증→관리<br>4. **관리 단계 활동**: 데이터 버전 관리, 데이터 계보 추적, 품질 지표 대시보드 |
| **비교** | **정형 데이터 품질관리 (전통적)**<br>- 테이블 값 오류·중복·누락 중심 진단<br>- DQC-V(값) / DQC-M(프로세스) 진단 체계<br><br>**AI 학습 데이터 품질관리**<br>- 레이블 정확성·클래스 균형·개념 드리프트까지 포괄<br>- 어노테이터 간 일치도(IAA), 데이터 증강 등 ML 특화 활동 추가<br><br>**생성형 AI 데이터 품질관리**<br>- 일반 품질이슈(정확성·완전성)+편향·독성·환각·저작권침해·PII 등 AI 특유 위험 추가<br>- 과기부·NIA 가이드라인v2.0(2025), EU AI Act·국내 AI기본법(2024) 준수 법적의무화 |
| **차별화** | **AI 학습 데이터 품질 확보 거버넌스 전략**<br>1. **레이블 정확성 우선**: 다중 어노테이터 교차검토 + Cohen's Kappa(IAA) → 레이블오류 영향 최소화<br>2. **누수 방지**: 훈련/검증/테스트 분리 엄격 통제 + 배포후 드리프트 지속 모니터링 → 재학습 시점 판단<br>3. **비정형 데이터 확장**: 텍스트 편향성, 이미지-텍스트 매칭 무결성, 증강 노이즈까지 다차원 검증<br>4. **생성형 AI 위험 통제**: 편향·독성·환각·저작권·PII 6대 지표(가이드라인v2.0) + 샘플링 자동필터링·RLHF 피드백 루프 정제 |
