# 경계 기반 보안 vs 제로 트러스트 성숙도 모델 2.0 (CISA) 서브노트

> **두음 머리에 박기 🧠**
> - **ID·디·네·앱·데** (CISA ZT 성숙도모델 5대 기둥: **ID**(신원), **디**바이스, **네**트워크, **앱**플리케이션·워크로드, **데**이터)
> - **전·초·고·최** (ZT 성숙도 4단계: **전**통(경계기반) → **초**기(ZT일부도입) → **고**급(전사ZT정책) → **최**적(완전자동화 AI기반))
> - **모·위·세·동·모2** (NIST SP 800-207 제로트러스트 5대 원칙: **모**든자원간주, **위**치무관보호, **세**션단위허가, **동**적정책결정, **모2**니터링(무결성상태))

| :--- | :--- |
| **토픽명** | **경계 기반 보안(Perimeter Security)과 제로 트러스트 성숙도 모델 2.0 (CISA, 2023)** |
| **정의** | 내부·외부를 물리적 경계로 구분해 내부를 전면 신뢰하는 **경계 기반 보안**의 한계를 극복하기 위해 "절대 신뢰하지 말고 항상 검증하라"는 제로 트러스트 원칙을 조직에 단계적으로 정착시키는 CISA의 **5개 기둥(ID·디·네·앱·데) × 4단계 성숙도(전·초·고·최)** 평가 모델 |
| **키워드** | Perimeter Security, CISA Maturity Model 2.0, 5 Pillars, Micro-segmentation, IAM/SASE, UEBA/XDR |
| **개념도** | **[ ZT 성숙도 4단계 진화 경로 (5개 기둥 각각에 적용) ]**<br>`[ 1.전통(Traditional) ] 경계기반·수동운영`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[ 2.초기(Initial) ] ZT 일부도입·사용자접근제어 시작 ▼`<br>`[ 3.고급(Advanced) ] 전사 ZT정책·자동화탐지 ▼`<br>`[ 4.최적(Optimal) ] 완전자동화·AI기반 동적정책`<br>&nbsp;&nbsp;`(ID/디바이스/네트워크/앱워크로드/데이터 5개 기둥 각각 독립적으로 단계 평가)` |
| **구성요소** | 1. **경계 기반 보안의 구조적 한계**: 내부망 진입 시 전면 신뢰 → 내부 침투 후 동-서(East-West) 트래픽 자유 통신 허용 → 측면 이동으로 전사 피해 확산<br>2. **NIST SP 800-207 5대 원칙**: 모든 데이터·서비스를 리소스로 간주, 위치 무관 통신 보호, 세션 단위 접근 허가, 클라이언트ID·상태 기반 동적 정책, 자산 무결성 지속 모니터링<br>3. **CISA 5개 기둥**: ID(강력한 다중 인증), 디바이스(컴플라이언스 지속검증), 네트워크(마이크로세분화), 애플리케이션·워크로드(앱별 접근제어), 데이터(분류·암호화·DLP)<br>4. **4단계 성숙도**: 전통(경계기반·수동) → 초기(ZT 일부·사용자 접근제어) → 고급(전사 ZT정책·자동화탐지) → 최적(완전자동화·AI 동적정책) |
| **비교** | **경계 기반 보안**<br>- **인증 시점**: 경계 진입 시 1회 인증<br>- **클라우드 적합성**: 낮음(고정된 물리 경계 전제) — 원격근무·SaaS 확산 환경에서 무력화<br><br>**제로 트러스트 (성숙도 최적 단계)**<br>- **인증 시점**: 매 세션·리소스 접근 시마다 재검증<br>- **클라우드 적합성**: 높음(위치 독립적 검증) — 마이크로 세분화로 내부 측면이동까지 차단 |
| **차별화** | **CISA 성숙도 모델 기반 단계적 ZT 전환 로드맵**<br>1. **기둥별 비대칭 성숙도 관리**: 5개 기둥이 동시에 최적 단계로 도약하기 어려우므로, ID(MFA)·디바이스(컴플라이언스 검증)처럼 ROI가 높은 기둥부터 우선 고급 단계로 끌어올리고 데이터·앱워크로드는 후속 단계로 배치.<br>2. **IAM 강화와 SASE 결합으로 초기→고급 전환 가속**: RBAC·MFA를 전사 IAM에 통합하고 SASE(보안+네트워크 통합 클라우드 서비스)를 도입하여 마이크로 세분화를 물리적 재구축 없이 소프트웨어적으로 구현.<br>3. **SIEM/UEBA/XDR 연동으로 최적 단계의 자동화 실현**: 4단계(최적)의 핵심인 AI 기반 동적 정책 결정을 위해, 전사 로그를 SIEM·UEBA·XDR로 통합 분석하고 이상 징후 발생 시 정책 엔진(PE)이 실시간으로 접근 권한을 자동 조정하는 폐루프 체계 구축. |
