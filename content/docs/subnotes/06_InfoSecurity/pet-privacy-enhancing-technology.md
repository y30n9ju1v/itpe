# PET (개인정보 보호 강화기술) 서브노트

> **두음 머리에 박기 🧠**
> - **암·통·분·익·합·보** (PET 6대 기술 분류: **암**호화기반(동형암호), **통**계적기반(차분프라이버시), **분**산학습(연합학습), **익**명화(가명처리·k-익명성), **합**성데이터, **보**안다자간계산(MPC))
> - **HE·DP·SD** (3대 핵심 기술 비교 축: **H**omomorphic **E**ncryption, **D**ifferential **P**rivacy, **S**ynthetic **D**ata)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **PET (Privacy Enhancing Technology, 개인정보 보호 강화기술)** |
| **정의** | 개인정보를 보호하면서도 데이터 활용성을 극대화하는 기술의 총칭으로, AI 학습·의료 데이터 공유·금융 분석 등 데이터 가치가 높은 분야에서 프라이버시-유용성 트레이드오프를 해결하기 위해 **암호화 기반(동형암호), 통계적 기반(차분 프라이버시), 분산 학습(연합학습), 익명화, 합성 데이터, 보안 다자간 계산(MPC)** 6대 기술로 구성된다 |
| **키워드** | 동형암호(HE), 차분프라이버시(DP), 연합학습(FL), 합성데이터, MPC, k-익명성 |
| **개념도** | `[ 원본 개인정보(민감데이터) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`├── 암호화기반: [ 동형암호 HE ] ── 암호화 상태로 연산 ──➔ 결과 복호화`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`├── 통계적기반: [ 차분프라이버시 DP ] ── 노이즈(Laplace/Gaussian) 추가 ──➔ 통계결과만 공유`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`├── 분산학습:   [ 연합학습 FL ] ── 데이터 이동없이 각 기기서 학습 ──➔ 그래디언트만 공유`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`└── 합성데이터: [ GAN/VAE ] ── 원본분포 학습 ──➔ 통계적으로 유사한 가상데이터 생성` |
| **구성요소** | 1. **동형암호(HE)**: 암호화된 채로 연산 수행 후 복호화, 데이터 공유 불필요, 매우 느림(수천배 오버헤드)<br>2. **차분프라이버시(DP)**: 통계 결과에 수학적 노이즈 추가, ε(프라이버시 예산) 조절, Apple iOS 키보드 학습에 적용<br>3. **연합학습(FL)**: 데이터를 중앙 서버로 이동하지 않고 각 기기에서 모델 학습 후 그래디언트만 공유, 그래디언트 역추론 공격 위험 존재 → DP와 결합 사용<br>4. **익명화**: 가명처리, k-익명성으로 식별 불가능하게 변환<br>5. **합성데이터**: GAN·VAE로 원본 분포 학습 후 통계적 특성이 유사한 가상 데이터 생성, 금융 사기 탐지 학습 데이터 등에 활용<br>6. **MPC(보안 다자간 계산)**: 여러 주체가 데이터를 비공개로 유지한 채 공동 연산 |
| **비교** | **동형암호 (Homomorphic Encryption)**<br>- **프라이버시 보장**: 매우 강함 (암호화 상태 유지)<br>- **정확도**: 완전(노이즈 없음)<br>- **성능**: 매우 느림(수천 배 오버헤드), 적용 연산 제한<br>- **적용 사례**: 의료 데이터 안전 분석<br><br>**차분 프라이버시 (Differential Privacy)**<br>- **프라이버시 보장**: 수학적으로 증명 가능<br>- **정확도**: 노이즈로 인한 오차 발생<br>- **성능**: 빠름<br>- **적용 사례**: Apple iOS 키보드 학습<br><br>**합성 데이터 (Synthetic Data)**<br>- **프라이버시 보장**: 원본 미노출<br>- **정확도**: 통계적 유사성(완전 일치 아님)<br>- **성능**: 학습 시간 필요<br>- **적용 사례**: 금융 사기 탐지 학습 데이터 |
| **차별화** | **데이터 활용 시나리오별 PET 조합 전략**<br>1. **정확도 최우선 의료·금융 분석**: 계산 비용을 감수하더라도 완전한 정확도가 필요한 의료 데이터 분석에는 동형암호를 우선 적용하고, 실시간성이 필요한 구간에는 차분 프라이버시로 대체하는 이원화 전략.<br>2. **모바일·엣지 환경의 연합학습 + DP 결합**: 스마트폰 키보드 예측처럼 기기 분산 환경에서는 연합학습으로 원본 데이터 이동을 차단하되, 그래디언트 역추론 공격에 대비해 그래디언트 자체에 차분 프라이버시 노이즈를 추가하는 이중 방어.<br>3. **학습 데이터 부족 상황의 합성 데이터 보완**: 희귀 사기 패턴처럼 실제 데이터가 부족한 경우 GAN 기반 합성 데이터로 학습셋을 보강하되, 합성 데이터의 통계적 편향이 실제 분포와 괴리되지 않도록 검증 파이프라인을 병행 구축. |
