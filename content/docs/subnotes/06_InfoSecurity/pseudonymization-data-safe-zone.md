# 가명처리 기법과 개인정보 안심구역·데이터안심구역 서브노트

> **두음 머리에 박기 🧠**
> - **가·총·삭·범·마·잡·교·토** (가명처리 8대 기법: **가**명화, **총**계처리, **삭**제(Suppression), **범**주화(Generalization), **마**스킹, **잡**음추가, **교**환(Swapping), **토**큰화)
> - **개·데** (2대 안심구역 주관기관 구분: **개**인정보안심구역=개인정보보호위원회(개인정보보호법), **데**이터안심구역=K-DATA(데이터산업법))

| **토픽명** | **가명처리 기법(Pseudonymization)과 개인정보 안심구역·데이터안심구역** |
| **정의** | 추가정보 없이 개인식별 불가하도록 일부 삭제·대체하는 가명처리(가·총·삭·범·마·잡·교·토) 8대 기법 + 가명정보 폐쇄환경 분석·활용 지원하는 개인정보 안심구역(개인정보보호위원회)·데이터안심구역(K-DATA) 제도 |
| **키워드** | 개인정보보호법 §28의2·§28의4, 재식별 금지, 결합전문기관, 반출 통제 |
| **개념도** | **[ 가명정보의 안전한 활용 흐름 ]**<br>`[ 원본 개인정보 ] ──➔ [ 가명처리(토큰화+범주화+마스킹 등 복합적용) ] ──➔ [ 가명정보 ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼ 물리적 폐쇄환경(안심구역) 반입`<br>`[ 개인정보안심구역/데이터안심구역: 인터넷차단·분석전용 환경 ] ──➔ 결과물(통계·집계)만 반출 허용`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`(원본 개인정보·가명정보 자체는 구역 밖 반출 금지)` |
| **구성요소** | 1. **가명처리 8대 기법**: 가명화(식별자→가명대체), 총계처리(집계통계변환), 삭제(민감항목 전체제거), 범주화(구체값→범위치환), 마스킹(일부문자 대체), 잡음추가(수치 랜덤노이즈), 교환(레코드간 속성값교환), 토큰화(민감데이터→토큰, 매핑테이블 별도보관)<br>2. **개인정보 안심구역**: 개인정보보호위원회 주관, 개인정보보호법§28의2 근거, 폐쇄환경 의료·금융·복지 공익연구, 통계·집계만 반출<br>3. **데이터안심구역**: K-DATA 주관, 데이터산업법 근거, 인터넷차단환경 산업데이터 결합·분석, 분석결과물만 반출<br>4. **가명정보 안전조치(§28의4)**: 가명정보-추가정보 분리보관, 재식별금지 의무, 결합전문기관 경유 데이터결합 |
| **비교** | **가명처리 (Pseudonymization)**<br>- 재식별 가능성: 추가정보 결합 시 가능(별도규정 적용, 활용성↑)<br>- 활용범위: 동의없이 통계작성·과학적연구·공익기록보존 활용가능<br><br>**익명처리 (완전 비식별화)**<br>- 재식별 가능성: 이론상 불가능(개인정보 아님, 활용성은 상대적↓)<br>- 활용범위: 법 적용대상 제외 → 제한없이 활용가능, 분석가치 저하 |
| **차별화** | **의료·금융 분야 가명정보 활용 실무 전략**<br>1. **복합 가명처리 조합**: 토큰화(환자ID)+범주화(생년월일)+삭제(희귀질환명) 복합적용 → 재식별위험 다층 저감, 연구활용성 유지<br>2. **안심구역 활용 → 반출리스크 원천차단**: 고위험 결합·분석은 폐쇄망 내부수행, 결과물만 반출 → 가명정보 외부유출 봉쇄<br>3. **결합전문기관 경유 안전결합**: 타기관 가명정보 직접결합 금지 → 법정 결합전문기관 경유 → 재식별위험·법적책임 분리 |
