# AI 시스템 취약점 분류와 모델 전도·멤버십 추론 공격 서브노트

> **두음 머리에 박기 🧠**
> - **학·추·인** (AI 시스템 취약점 3대 발생 단계: **학**습 단계, **추**론 단계, **인**프라·공급망 단계)
> - **적·모·멤·속** (모델 출력 역이용 공격 4대 유형: **적**대적 예제 Adversarial Examples, **모**델 역전 Model Inversion, **멤**버십 추론 Membership Inference, **속**성 추론 Attribute Inference)
> - **화·블** (모델 전도 공격 접근 권한 2대 구분: **화**이트박스 - 파라미터 직접 접근, **블**랙박스 - API 예측결과만 이용)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **AI 시스템 취약점 분류체계 및 모델 전도 공격(Model Inversion Attack)** |
| **정의** | AI 시스템이 학습·추론·인프라 3단계(학·추·인)에서 갖는 고유 취약점을 정리한 분류체계와, 그중 모델의 출력(예측·신뢰도)을 역방향 분석하여 학습 데이터의 민감정보를 재구성하는 **모델 전도 공격(모델이 학습 데이터를 "기억"하는 성질을 악용)** |
| **키워드** | Data Poisoning, Backdoor, Adversarial Examples, Model Inversion, Membership Inference, 화이트박스/블랙박스, Fredrikson 2015 |
| **개념도** | **[ 모델 전도 공격 동작 흐름 ]**<br>`[ 공격자 ] ──➔ [ 쿼리: 다양한 입력값 반복 전송 ] ──➔ [ AI 모델(안면인식 등) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`│ 출력: 예측 클래스 + 신뢰도 점수`<br>`[ 공격자 ] ◀── 역추론 최적화(Fredrikson 기법) ◀── [ 학습 이미지 근사 복원 ]` |
| **구성요소** | 1. **학습 단계 취약점**: 데이터 중독(악의적 샘플 주입으로 모델 편향 조작), 백도어 공격(특정 트리거에만 반응하도록 은닉 학습)<br>2. **추론 단계 취약점**: 적대적 예제(미세 노이즈로 오분류), 모델 전도(출력→학습데이터 복원), 멤버십 추론(특정 데이터의 학습 포함 여부 판별), 모델 추출(쿼리 반복으로 모델 복제)<br>3. **인프라·공급망 취약점**: 오염된 공개 사전학습 모델(허깅페이스 등), 양자화·압축 과정 백도어 삽입<br>4. **화이트박스 공격**: 모델 파라미터·그래디언트에 직접 접근 가능한 내부자/연구 시나리오<br>5. **블랙박스 공격**: API 응답(신뢰도 점수)만으로 역추론하는 실제 공격 시나리오 — 방어 시 최상위 클래스만 반환하는 정보 최소화가 효과적 |
| **비교** | **모델 전도 공격 (Model Inversion)**<br>- **목표**: 학습에 사용된 원본 데이터(예: 환자 얼굴 이미지) 자체를 재구성<br>- **활용 정보**: 모델 출력의 신뢰도 점수 분포를 최적화 기법으로 역산<br><br>**멤버십 추론 공격 (Membership Inference)**<br>- **목표**: 특정 레코드가 학습 데이터셋에 포함되었는지 여부만 판별(재구성 아님)<br>- **활용 정보**: 학습 데이터에 대한 모델의 과적합된 확신도 차이(훈련 데이터일수록 신뢰도가 비정상적으로 높음) |
| **차별화** | **모델 전도·멤버십 추론 공격에 대한 실무 방어 로드맵**<br>1. **차분 프라이버시(Differential Privacy) 학습 적용**: 그래디언트에 수학적 노이즈를 주입하여 특정 개인 데이터의 모델 기여도를 통계적으로 은폐, 역추론 정확도를 원천적으로 저하.<br>2. **쿼리 제한 및 출력 정보 최소화**: API 호출 빈도를 제한(Rate Limiting)하고, 신뢰도 점수 전체가 아닌 최상위 예측 클래스만 반환하여 공격자의 최적화 기반 역추론에 필요한 정보량을 차단.<br>3. **연합학습(Federated Learning) 결합**: 원본 데이터를 중앙 서버로 이동하지 않고 로컬에서 학습 후 가중치만 공유함으로써, 중앙 집중형 모델 전도 공격의 공격 표면 자체를 축소. |
