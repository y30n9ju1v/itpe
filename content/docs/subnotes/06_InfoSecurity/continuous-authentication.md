# 무자각 지속인증 서브노트

> **두음 머리에 박기 🧠**
> - **행보음얼위U** (지속인증 6대 기법: 행동생체, 보행패턴, 음성패턴, 얼굴인식, 위치환경, UEBA)
> - **고·중·정** (Trust Score 3단계 대응: **고**위험→차단, **중**위험→모니터링강화, **정**상→투명허용)

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **무자각 지속인증 (Transparent Continuous Authentication)** |
| **정의** | 로그인 이후 세션 내내 사용자 행동·생체·환경 데이터를 지속 분석해 신원을 자동 재검증하는 인증 방식 |
| **키워드** | Trust Score, 행동생체인식, UEBA, 세션하이재킹, Zero Trust 연계 |
| **개념도** | `[ 데이터수집: 키보드·마우스·센서·카메라·GPS ]`<br>&nbsp;&nbsp;`▼`<br>`[ 행동 프로파일링: 2~4주 학습 → 기준패턴 ]`<br>&nbsp;&nbsp;`▼`<br>`[ 실시간 분석: 기준 vs 현재 비교 → Trust Score ]`<br>&nbsp;&nbsp;`▼`<br>`[ 대응: 고위험→추가인증/세션종료, 중위험→모니터링, 정상→투명허용 ]` |
| **구성요소** | 1. 행동생체인식: 타이핑 리듬·압력, 마우스 동작<br>2. 보행패턴: 가속도계·자이로 걸음걸이<br>3. 음성패턴: 화자인식, 원격환경 적합<br>4. 얼굴인식: 카메라 기반 주기적 재인증<br>5. 위치·환경: GPS·Wi-Fi SSID 이상위치 탐지<br>6. UEBA: 사용자·엔티티 행동분석, 내부자위협 탐지 |
| **비교** | **기존 1회 인증**: 로그인 시점만 검증 → 인증 후 신원변경 감지 불가, 세션하이재킹 취약<br><br>**무자각 지속인증**: 세션 전체 지속검증 → 사용자 개입 없음, 인증우회 즉시감지 |
| **차별화** | 1. FIDO/패스키와 역할분담: 최초 강인증(FIDO) + 세션내 지속검증(지속인증) 결합 → Zero Trust "Never Trust, Always Verify" 완성<br>2. 멀티모달 융합: 단일기법 오인식 보완 → 2개 이상 기법 복합사용<br>3. 적응형 임계값: 업무중요도·위험수준별 Trust Score 기준 동적조정<br>4. 프라이버시 보호: 행동데이터 Edge AI 로컬처리 → 개인정보보호법 준수<br>5. 금융권 적용 로드맵: 타이핑·스크롤·기울기 행동생체 → 5~10분 주기 재계산 → 임계값 이하 시 OTP 자동요구 (고액거래 우선)<br>6. 학습모델 보호: Trust Score 산정모델 자체가 모델역공격(Model Inversion) 표적 → 모델 보호 병행 필요 |
