# ISMS·ISMS-P 관리체계와 간편인증 제도 서브노트

> **두음 머리에 박기 🧠**
> - **80·102** (통제항목 개수: ISMS **80**개 vs ISMS-P **102**개(80+개인정보19+α))
> - **정·범·위·구·사** (ISMS 관리과정 5단계: **정**보보호정책수립→**범**위설정→**위**험관리→**구**현→**사**후관리)
> - **사·수·비·현·유** (일반인증 vs 간편인증 5대 비교축: **사**각지대해소 목적, **수**개월→2~3개월 심사**기**간단축, **비**용대폭절감, **현**장심사최소화, **유**효기간 3년→1년)

| **토픽명** | **ISMS·ISMS-P(정보보호 관리체계 인증)와 ISMS-P 간편인증 제도** |
| **정의** | 정보보호 수준 관리 국내 인증제도 **ISMS**(80개 통제항목), 개인정보보호 통합 **ISMS-P**(102개), 소규모 사업자 부담완화용 핵심항목 간소화 **ISMS-P 간편인증**(2023년 도입) |
| **키워드** | 정보통신망법 제47조, 개인정보보호법 제32조의2, PDCA, KISA, 자가진단도구 |
| **개념도** | **[ ISMS-P 인증 대상 스펙트럼과 심사 강도 ]**<br>`[ 의무 인증대상: 매출100억↑ or 이용자100만명↑ ] ── 일반 ISMS-P(102개 통제항목, 6개월~1년, 현장심사필수, 3년유효)`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[ 자율참여 소규모 사업자: 매출100억미만 ] ── ISMS-P 간편인증(핵심항목축소, 서면심사중심, 2~3개월, 1년유효)` |
| **구성요소** | 1. 법적근거: 정보통신망법 제47조, 개인정보보호법 제32조의2<br>2. 의무 인증대상: 연매출 100억 이상 정보통신서비스 제공자, 이용자 100만명 이상, ISP<br>3. ISMS 관리과정 5단계(PDCA): 정보보호정책수립(경영진의지)→범위설정→위험관리(식별·분석·평가·처리)→구현(보호대책실행·교육)→사후관리(모니터링·내부심사)<br>4. 간편인증 목적: 인증사각지대 해소, 최소보안수준 확보, 비용·기간단축(6개월~1년→2~3개월), 자율참여 생태계 확장<br>5. 간편인증 방식: 관리체계수립+보호대책(접근통제·암호화·취약점관리·백업)+개인정보처리 핵심항목 축소, KISA 자가진단도구 활용 서면심사 중심, 유효기간 1년(재심사 용이) |
| **비교** | **일반 ISMS-P 인증**<br>- 대상: 의무 인증대상(대기업·대형플랫폼) + 자율참여<br>- 통제항목/심사/유효기간: 102개 / 현장심사 필수·6개월~1년 / 3년<br><br>**ISMS-P 간편인증**<br>- 대상: 매출 100억 미만 중소·영세 사업자(자율참여)<br>- 통제항목/심사/유효기간: 핵심항목 축소 / 서면심사 중심·2~3개월 / 1년 |
| **차별화** | **인증 사각지대 해소를 위한 정책·기술 병행 전략**<br>1. 간편인증을 일반인증 진입단계로 설계: 소규모 사업자가 최소 보안수준 우선확보 → 매출·이용자 증가 시 일반 ISMS-P로 단계적 이행 제도화<br>2. KISA 자가진단도구·서면심사 실효성 강화: 체크리스트에 실제 기술적 취약점 점검항목(접근통제 설정확인 등) 포함 → 형식심사 탈피, 실질적 보안수준 담보<br>3. 국제표준(ISO 27001) 상호인정 연계: 장기적으로 ISMS/ISMS-P를 ISO 27001과 상호인정 → 해외진출 시 이중인증 부담 완화 |
