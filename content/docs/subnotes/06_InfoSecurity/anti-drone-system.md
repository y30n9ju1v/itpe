| **토픽명** | **안티드론 시스템 프레임워크 (Anti-Drone System Framework, TTAK.KO-10.1460)** |
| **정의** | 불법·위협 드론(UAV)에 대응하기 위한 탐지·추적·식별·대응 절차와 기술 참조구조를 정의한 TTA 정보통신단체표준으로, 국가시설 보호와 개인 사생활 침해 드론 대응을 목적으로 하는 **5단계 기능계층(탐·추·식·대·C2)** 체계 |
| **키워드** | UAV, TTA표준, 레이다/RF/열화상, RF재밍/GPS스푸핑, C2(지휘통제), 위협평가 |
| **개념도** | **[ 안티드론 시스템 참조구조 ]**<br>`┌────────────────────────────┐`<br>`│      지휘·통제(C2) 계층      │ ← 상황인식·대응결정`<br>`├────────────────────────────┤`<br>`│ 탐지·추적 │ 식별·분류 │ 대응실행 │`<br>`├────────────────────────────┤`<br>`│     센서·작동기(Sensor/Actuator)   │`<br>`└────────────────────────────┘`<br>`운영절차: 탐지 → 추적 → 식별·위협평가 → 대응결정 → 대응실행 → 기록·보고` |
| **구성요소** | 1. **탐지(Detection)**: 드론 존재 여부 탐지 — 레이다(장거리·기상영향적음), RF센서(조종신호·텔레메트리), 광학카메라(주간AI영상분석), 열화상카메라(야간·저시정), 음향센서(단거리·소형드론)<br>2. **추적(Tracking)**: 드론 위치·경로 실시간 추적<br>3. **식별(Identification)**: 위협 드론과 합법 드론 구분 — 오탐 시 정상 드론 오격추 위험<br>4. **대응(Countermeasure)**: RF재밍/GPS스푸핑(조종·GPS신호 방해, 전파법 허가 필요), 사이버탈취(통신해킹 제어권 탈취), 레이저(물리무력화), 포획네트(비교적 자유), 훈련조류(실험적)<br>5. **C2(지휘통제)**: 전체 시스템 통합운영·상황인식 브레인 |
| **비교** | **합법 드론**<br>- **식별 기준**: 사전 등록된 비행계획·기체정보와 일치<br>- **대응**: 정상 운항 보장, 통제 대상 아님<br><br>**위협 드론**<br>- **식별 기준**: 미등록 비행, 금지구역 진입, 이상 비행 패턴<br>- **대응**: 위협 수준에 따라 재밍→탈취→물리무력화 단계적 적용 |
| **차별화** | **국가 중요시설 안티드론 체계 구축 3대 실무 방향**<br>1. **다중 센서 융합(Sensor Fusion) 탐지**: 레이다·RF·광학·열화상·음향을 단일 센서가 아닌 융합 운용하여 소형·저고도·저RF 드론까지 탐지 사각지대를 최소화.<br>2. **합법·규제 준수형 대응 수단 우선 적용**: RF재밍·GPS스푸핑은 전파법상 허가가 필요하므로, 민간 밀집지역에서는 포획네트 등 비규제 수단을 우선 적용하고 국가시설에서는 사전 허가된 전자전 대응을 활용하는 이원화 전략.<br>3. **C2 계층과 국가 통합 방공체계 연동**: 개별 시설의 안티드론 C2를 상위 국가 방공·재난관리 시스템과 연동하여, 광역 드론 위협 발생 시 신속한 정보 공유와 통합 대응이 가능하도록 체계 설계. |
