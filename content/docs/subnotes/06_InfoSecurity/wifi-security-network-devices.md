# 네트워크 보안 장비(방화벽/IDS/IPS/VPN)와 무선랜 보안(WEP/WPA) 서브노트

> **두음 머리에 박기 🧠**
> - **차·탐·방·암** (4대 네트워크 보안 장비 핵심 역할: 방화벽 **차**단, IDS **탐**지, IPS 탐지+**방**지, VPN **암**호화 터널)
> - **정·동·앱·차** (방화벽 4대 유형: **정**적 패킷필터링(3계층), 세션추적 상태기반(**동**적/4계층), **앱**플리케이션방화벽 WAF(7계층), **차**세대방화벽 NGFW)
> - **동·8·라** (동적 WEP 3대 요소: **동**적 키 갱신, IEEE **8**02.1X 인증, **라**디우스 RADIUS 서버 위임) — WEP→동적WEP→WPA(TKIP)→WPA2(CCMP/AES)→WPA3(SAE) 발전 계보

| 분류 | 기술 기술사 서브노트 작성 예시 (1교시형 포맷) |
| :--- | :--- |
| **토픽명** | **네트워크 보안 4대 장비(방화벽·IDS·IPS·VPN)와 무선랜 보안 발전(WEP → 동적 WEP → WPA3)** |
| **정의** | 차단·탐지·방지·암호화 역할을 계층적으로 수행하는 **4대 네트워크 보안 장비**와, IEEE 802.11 초기 무선 보안 표준인 WEP의 24bit IV 취약점을 802.1X+RADIUS 기반 **동적 키 갱신**으로 보완한 **동적 WEP** 및 이후 WPA 계보 |
| **키워드** | 패킷필터링/Stateful/WAF/NGFW, 서명기반/이상기반 IDS, IPsec/SSL-VPN, RC4/IV, 802.1X, EAP, TKIP/CCMP/SAE |
| **개념도** | **[ 다층 방어(Defense in Depth) 구성 ]**<br>`인터넷 ──➔ [ 방화벽(경계) ] ──➔ DMZ[ IDS/IPS ] ──➔ 내부망 ──➔ 호스트 기반 방화벽`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`↕ VPN 터널(재택근무자)`<br>**[ 동적 WEP 무선 인증 동작 ]**<br>`무선단말 → AP: 연결요청 ➔ AP → RADIUS: 802.1X/EAP 인증위임 ➔ RADIUS: 자격증명검증`<br>&nbsp;&nbsp;`➔ RADIUS → AP: 인증성공+동적WEP키 ➔ AP → 단말: 키배포 ➔ 세션암호화(주기적 키갱신 반복)` |
| **구성요소** | 1. **방화벽**: 규칙 기반 패킷 차단/허용, 패킷필터링(3계층)→Stateful(4계층)→WAF(7계층)→NGFW(통합) 순으로 고도화<br>2. **IDS**: 서명기반(정확·신규공격 미탐)/이상기반(신규공격 탐지·오탐 높음) 탐지 후 알림(수동대응)<br>3. **IPS**: IDS+인라인 자동 차단, 오탐 시 정상 트래픽 차단 위험<br>4. **VPN**: IPsec(네트워크계층, 사이트간)/SSL-TLS(브라우저기반, 원격접속)/WireGuard(경량고성능)<br>5. **WEP 취약점**: RC4 스트림암호 + 24bit IV 재사용으로 Aircrack 등으로 수분 내 크랙 가능<br>6. **동적 WEP**: 802.1X+RADIUS로 세션마다 키 자동 배포·갱신하여 정적 WEP의 고정키 노출 문제 완화(단, RC4 자체 한계는 잔존) |
| **비교** | **IDS (침입탐지시스템)**<br>- **위치**: 네트워크 경유 지점(비인라인 또는 미러링)<br>- **대응**: 침입 탐지 시 관리자에게 알림만 전송(수동 대응), 오탐이 알림 과부하로 이어짐<br><br>**IPS (침입방지시스템)**<br>- **위치**: 인라인(트래픽이 직접 통과)<br>- **대응**: IDS 탐지 기능 + 실시간 자동 차단, 오탐 시 정상 트래픽까지 차단되는 위험 존재 |
| **차별화** | **레거시 무선 인프라의 단계적 보안 강화 로드맵**<br>1. **동적 WEP를 과도기적 보완책으로 한정**: RC4/IV 구조적 결함이 잔존하므로 동적 WEP는 레거시 하드웨어 교체 전 임시 조치로만 활용하고, 최종적으로 WPA2(CCMP/AES) 이상으로 전환을 목표로 로드맵 수립.<br>2. **NGFW+제로트러스트 연계로 VPN 한계 극복**: 전통 VPN이 내부망 진입 후 무제한 신뢰를 부여하는 한계를 보완하기 위해, NGFW의 애플리케이션 식별 기능과 ZTNA를 결합하여 접속 이후에도 지속적으로 세션을 재검증.<br>3. **IDS/IPS 오탐 최소화를 위한 SIEM 연동**: 서명기반과 이상기반 탐지를 병행 운영하면서 발생하는 대량의 경보를 SIEM으로 상관분석하여 실제 위협만 우선순위화, IPS의 오차단으로 인한 서비스 장애를 최소화. |
