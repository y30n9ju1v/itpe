# 은닉·표적형 공격(워터링홀·스피어피싱·부채널·다크웹) 서브노트

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **은닉·표적형 공격(Covert & Targeted Attack) — 워터링홀(Watering Hole)·스피어피싱(Spear Phishing)·부채널 공격(Side-Channel Attack)·다크웹(Dark Web)/Tor** |
| **정의** | 특정 표적 겨냥 사회공학적 침투 **워터링홀·스피어피싱** + 암호시스템 물리적 구현신호 분석 → 비밀키 추출 **부채널 공격** + 익명라우팅 불법거래·정보유통 은닉 **다크웹(Tor)** — "은닉·표적" 공격군 |
| **키워드** | 사회공학(Social Engineering), Drive-by Download, 타이밍/전력분석, 상수시간 구현, Tor 양파 라우팅, .onion, 위협 인텔리전스 |
| **개념도** | **[ 표적형 침투 vs 은닉형 유통 ]**<br>`[ 워터링홀 ] 표적 방문 사이트 감염 → Drive-by Download → C&C`<br>`[ 스피어피싱 ] 표적 정보수집 → 맞춤 이메일 → 첨부/링크 클릭 → 악성코드`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼ (APT 초기침투 수단으로 활용)`<br>`[ 부채널 공격 ] 전력/타이밍/전자기 신호 측정 → 비밀키 추론`<br>`[ 다크웹/Tor ] 사용자 ──암호화3중──▶ 가드→릴레이→출구 노드 ──▶ .onion 은닉 서비스` |
| **구성요소** | 1. **워터링홀**: 표적 상시방문 정상웹사이트 사전침해 → 방문만으로 자동감염(수동 대기형, 브라우저 익스플로잇)<br>2. **스피어피싱**: SNS·조직도로 개인정보 수집 → 신뢰발신자 위장 맞춤이메일 → 첨부·링크 클릭 유도(능동형, 웨일링=고위직 변형)<br>3. **부채널 공격**: 타이밍(연산시간差) · 전력분석(SPA/DPA) · 전자기 · 캐시타이밍 · 음향분석 · 오류주입 · Spectre/Meltdown(투기적실행 캐시유출) — 물리적 구현신호 기반 키추출<br>4. **다크웹 구축기술**: Tor(3중 암호화 릴레이) → 입구·출구노드 상호익명 → 출처은닉 + .onion Hidden Service 접속<br>5. **다크웹 추적기술**: 출구노드 모니터링 · 트래픽타이밍 상관분석 · 비트코인 블록체인 추적(Chainalysis) · MLAT 국제사법공조 · 운영보안 실수 분석 |
| **비교** | **워터링홀 vs 스피어피싱**<br>- 워터링홀: 웹사이트(브라우저) 벡터 — 방문만으로 감염, 피해자 개입 최소, 사이트 방문자 전체 대상<br>- 스피어피싱: 이메일·메시지 벡터 — 첨부실행·클릭 등 개입 필요, 개인·소수 특정타깃<br><br>**부채널 공격 vs 다크웹**<br>- 부채널: 암호 수학적 안전성과 무관 → 하드웨어 구현결함으로 키유출(물리계층 공격)<br>- 다크웹(Tor): 공격기법 아닌 익명 네트워크 인프라 → 탈취정보·악성코드·RaaS 유통·거래 은닉플랫폼 악용 |
| **차별화** | **표적형·은닉형 위협의 통합 방어 실무 전략**<br>1. **초기 침투 차단**: 브라우저 격리(RBI)로 워터링홀 차단, DMARC/DKIM/SPF+이메일 샌드박스로 스피어피싱 1차 차단 → EDR·XDR 2차 방어선<br>2. **암호 구현 검증 파이프라인화**: 상수시간(Constant-Time) 구현 여부 ctgrind·dudect로 CI/CD 검증, FIPS 140-3 Level 3+ HSM에서 키연산 → 부채널 노출 최소화<br>3. **다크웹 위협 인텔리전스 연계**: Recorded Future 등 다크웹 모니터링 → 도메인·계정 유출 상시감시 → 탐지 즉시 비밀번호 초기화·IRP 가동 |
