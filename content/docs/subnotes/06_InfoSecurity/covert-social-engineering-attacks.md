# 은닉·표적형 공격(워터링홀·스피어피싱·부채널·다크웹) 서브노트

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **은닉·표적형 공격(Covert & Targeted Attack) — 워터링홀(Watering Hole)·스피어피싱(Spear Phishing)·부채널 공격(Side-Channel Attack)·다크웹(Dark Web)/Tor** |
| **정의** | 불특정 다수가 아닌 특정 표적을 겨냥하여 사회공학적으로 침투하는 **워터링홀·스피어피싱**, 암호 시스템의 물리적 구현 신호를 분석해 비밀키를 추출하는 **부채널 공격**, 익명 라우팅으로 불법 거래·정보 유통을 은닉하는 **다크웹(Tor)**을 아우르는 "은닉·표적" 공격군 |
| **키워드** | 사회공학(Social Engineering), Drive-by Download, 타이밍/전력분석, 상수시간 구현, Tor 양파 라우팅, .onion, 위협 인텔리전스 |
| **개념도** | **[ 표적형 침투 vs 은닉형 유통 ]**<br>`[ 워터링홀 ] 표적 방문 사이트 감염 → Drive-by Download → C&C`<br>`[ 스피어피싱 ] 표적 정보수집 → 맞춤 이메일 → 첨부/링크 클릭 → 악성코드`<br>&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`▼ (APT 초기침투 수단으로 활용)`<br>`[ 부채널 공격 ] 전력/타이밍/전자기 신호 측정 → 비밀키 추론`<br>`[ 다크웹/Tor ] 사용자 ──암호화3중──▶ 가드→릴레이→출구 노드 ──▶ .onion 은닉 서비스` |
| **구성요소** | 1. **워터링 홀**: 표적이 자주 방문하는 정상 웹사이트를 미리 침해하여 방문만으로 자동 감염시키는 수동적 대기형 공격(브라우저 익스플로잇)<br>2. **스피어 피싱**: SNS·조직도 등으로 개인 정보를 수집해 신뢰 발신자로 위장한 맞춤 이메일로 첨부파일·링크 클릭을 유도하는 능동적 공격(웨일링은 고위직 표적 변형)<br>3. **부채널 공격**: 타이밍 공격(연산시간 차), 전력분석(SPA/DPA), 전자기 공격, 캐시타이밍, 음향분석, 오류주입, Spectre/Meltdown(투기적 실행 캐시 유출) 등 물리적 구현 신호 기반 키 추출<br>4. **다크웹 구축기술**: Tor(The Onion Router)의 3중 암호화 릴레이로 입구·출구 노드가 서로를 모르게 하여 출처를 은닉하고 .onion 숨겨진 서비스(Hidden Service)로 접속<br>5. **다크웹 추적기술**: 출구 노드 모니터링, 트래픽 타이밍 상관분석, 비트코인 블록체인 추적(Chainalysis), MLAT 국제사법공조, 사용자 운영보안 실수 분석 |
| **비교** | **워터링홀 vs 스피어피싱**<br>- 워터링홀: 웹사이트(브라우저) 벡터, 사이트 방문만으로 감염되어 피해자 개입 최소, 특정 사이트 방문자 전체가 대상<br>- 스피어피싱: 이메일·메시지 벡터, 첨부 실행·링크 클릭 등 피해자 개입 필요, 개인·소수 특정 타깃<br><br>**부채널 공격 vs 다크웹**<br>- 부채널 공격: 암호 알고리즘의 수학적 안전성과 무관하게 하드웨어 구현 결함으로 키를 유출시키는 물리 계층 공격<br>- 다크웹(Tor): 공격 기법이 아니라 익명 네트워크 인프라로, 탈취 정보·악성코드·랜섬웨어 RaaS의 유통·거래 은닉 플랫폼으로 악용 |
| **차별화** | **표적형·은닉형 위협의 통합 방어 실무 전략**<br>1. **초기 침투 차단**: 브라우저 격리(RBI)로 워터링홀을, DMARC/DKIM/SPF와 이메일 샌드박스로 스피어피싱을 1차 차단하고 감염 성공을 가정한 EDR·XDR을 2차 방어선으로 운용.<br>2. **암호 구현 검증 파이프라인화**: 상수시간(Constant-Time) 구현 여부를 ctgrind·dudect로 CI/CD에서 검증하고, FIPS 140-3 Level 3 이상 HSM에서 키 연산을 수행해 부채널 노출을 최소화.<br>3. **다크웹 위협 인텔리전스 연계**: Recorded Future 등 다크웹 모니터링 서비스로 자사 도메인·계정 유출을 상시 감시하고, 탐지 즉시 비밀번호 초기화·IRP 가동으로 대응. |
