# 스마트시티 데이터 거버넌스 및 지속가능성 서브노트

> **두음 머리에 박기 🧠**
> - **F·A·I·R** (스마트시티 데이터 거버넌스 원칙: **F**indable 발견가능, **A**ccessible 접근가능, **I**nteroperable 상호운용, **R**eusable 재사용가능)
> - **정·조·품·보·공·윤** (데이터 거버넌스 6대 구성요소: **정**책, **조**직(CDO), **품**질, **보**안, **공**유, **윤**리)
> - **E·S·G** (스마트시티 지속가능성 3대 축: **E**환경(탄소모니터링), **S**사회(디지털포용), **G**거버넌스(데이터 투명성))

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **스마트시티 데이터 거버넌스 (FAIR 원칙) 및 지속가능한 스마트시티 (ESG)** |
| **정의** | 도시 데이터를 핵심 공공자산으로 체계관리하는 **스마트시티 데이터 거버넌스** + ICT를 도시인프라에 통합 → 환경·사회·거버넌스(ESG) 지속가능성 달성하는 **스마트시티** |
| **키워드** | FAIR 원칙, CDO(데이터책임관), 데이터 신탁, ESG, 디지털트윈, LPWAN(LoRa/NB-IoT), C-ITS |
| **개념도** | **[ 스마트시티 데이터 공유 모델 스펙트럼 ]**<br>`[오픈 데이터(전면공개: 교통/날씨)] → [선택적 공유(계약기반: 유동인구)] → [데이터 신탁(제3기관 관리: 건강데이터)] → [데이터 공유협약(공공-민간: 교통카드)]`<br><br>**[ 스마트시티 문제-해결 매핑 ]**<br>`인구고령화 → 스마트헬스케어/원격의료`<br>`기후변화 → 스마트에너지그리드/RE100`<br>`교통혼잡 → C-ITS/자율주행`<br>`자원낭비 → 스마트 수자원/폐기물관리` |
| **구성요소** | 1. **데이터 거버넌스 6대 요소**: 정책·조직(CDO)·품질·보안(비식별화)·공유·윤리(알고리즘 편향 방지)<br>2. **FAIR 원칙**: 메타데이터 발견성, 표준 프로토콜 접근성, 시스템 간 상호운용성, 라이선스 기반 재사용성<br>3. **스마트시티 5대 구성영역**: 데이터플랫폼(디지털트윈), IoT인프라(LPWAN), AI분석, 거버넌스, 시민서비스<br>4. **ESG 3대 축**: 환경(탄소배출 모니터링/신재생에너지), 사회(디지털포용/시민참여), 거버넌스(데이터투명성·위원회) |
| **비교** | **오픈 데이터 공유 모델**<br>- 방식: 공공 데이터 무조건 공개<br>- 적용: 교통·날씨·공기질 등 비민감 데이터<br><br>**데이터 신탁 모델**<br>- 방식: 제3 신뢰기관이 시민을 대신해 데이터 관리·중개<br>- 적용: 개인 건강데이터 등 민감 데이터 |
| **차별화** | **감시사회 리스크 완화 및 도시 데이터 플랫폼 고도화 전략**<br>1. **비식별화·데이터최소화 원칙 내재화**: CCTV·IoT 이동경로 데이터 → 서비스목적 최소범위 수집+즉시 비식별처리, 감시사회화 차단<br>2. **데이터신탁 기반 시민주권 강화**: 민감데이터(건강·위치) → 제3신탁기관 관리, 시민 통제권+활용편익 동시확보<br>3. **디지털트윈 기반 통합관제**: 도시데이터허브+디지털트윈 결합 → 교통·에너지·환경 실시간시뮬레이션, ESG지표 자동산출 대시보드 |
