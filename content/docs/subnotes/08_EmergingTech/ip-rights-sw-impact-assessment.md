# 지식재산권 종류 및 소프트웨어 영향평가 서브노트

> **두음 머리에 박기 🧠**
> - **산·저·신** (지식재산권 3대 분류: **산**업재산권(특허/실용신안/디자인/상표), **저**작권(저작권/저작인접권), **신**지식재산권(반도체배치설계/영업비밀/DB권))
> - **특·실·디·상** (산업재산권 4종 및 존속기간: **특**허권(20년), **실**용신안권(10년), **디**자인권(20년), **상**표권(10년 갱신)) 
> - **시·대·생** (소프트웨어 영향평가 3대 법정 기준: 민간**시**장 침해 여부, 서비스 **대**체 가능성, SW 산업 **생**태계 및 동반성장 **생**태계 영향)

| **토픽명** | **지식재산권(IP) 종류 및 소프트웨어 영향평가 제도** |
| **정의** | 지적창작물 부여 법적권리체계 **지식재산권**(산업재산권/저작권/신지식재산권) + 대기업·공공기관 SW시장 직접참여의 중소SW기업 영향 사전평가 **소프트웨어 영향평가** 제도 |
| **키워드** | 산업재산권/저작권/신지식재산권, SW 이중보호(저작권+특허), GPL/MIT 라이선스, SW영향평가위원회 |
| **개념도** | **[ 지식재산권 3대 분류 체계 ]**<br>`산업재산권(특허20년/실용신안10년/디자인20년/상표10년) | 저작권(저작권 사후70년/저작인접권 공표후70년) | 신지식재산권(반도체배치설계10년/영업비밀/DB권5년/도메인이름)`<br><br>**[ SW 영향평가 처리 절차 ]**<br>`영향평가 신청 → 과기정통부 접수 → SW영향평가위원회 심의(중소기업/학계/전문가) → 현장조사·의견수렴 → 평가결과 통보 → 조건부허용/불허` |
| **구성요소** | 1. **SW 이중보호**: 소스코드→저작권(등록불요, 창작과 동시발생), 발명아이디어→특허권 별도보호<br>2. **오픈소스 라이선스**: GPL(강한 카피레프트, 파생물도 동일라이선스) vs MIT/Apache(약한 카피레프트, 소스공개 의무無)<br>3. **SW영향평가 대상**: 대기업(SW사업 직접수행), 공공기관(민간시장 직접개발·판매), 국가·지자체(민간경쟁서비스) — 내부 행정목적SW 제외<br>4. **법정 평가항목**: 민간시장 침해여부(기개발·유통 유무), 대체가능성(민간SaaS·SW구매 대체여부), SW산업 생태계 영향(동반성장성) |
| **비교** | **저작권 (소스코드 보호)**<br>- 발생: 창작과 동시 자동발생, 등록불요<br>- 보호대상: 표현(소스코드·목적코드) 자체<br><br>**특허권 (SW 발명 보호)**<br>- 발생: 출원·등록 필요<br>- 보호대상: 기능·로직(아이디어) 구현방식, 존속 20년 |
| **차별화** | **IP 보호-SW 생태계 보호 균형 정책방향**<br>1. **오픈소스 라이선스 컴플라이언스**: GPL 등 강한 카피레프트 코드 상용결합 시 소스공개 의무전이 위험 → SBOM기반 라이선스검증체계 내재화<br>2. **SW영향평가 예외요건 명확화**: 국가안보·특수공공서비스 등 불가피성 인정 시만 조건부허용 → 엄격심사로 중소기업 시장잠식 최소화<br>3. **SW특허-영향평가 연계**: 대기업 SW특허 다수보유 상태 공공사업참여 시 → 특허포트폴리오 시장영향까지 평가항목 포함 |
