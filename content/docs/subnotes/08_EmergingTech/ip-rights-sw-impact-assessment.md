# 지식재산권 종류 및 소프트웨어 영향평가 서브노트

> **두음 머리에 박기 🧠**
> - **산·저·신** (지식재산권 3대 분류: **산**업재산권(특허/실용신안/디자인/상표), **저**작권(저작권/저작인접권), **신**지식재산권(반도체배치설계/영업비밀/DB권))
> - **특·실·디·상** (산업재산권 4종 및 존속기간: **특**허권(20년), **실**용신안권(10년), **디**자인권(20년), **상**표권(10년 갱신)) 
> - **시·대·생** (소프트웨어 영향평가 3대 법정 기준: 민간**시**장 침해 여부, 서비스 **대**체 가능성, SW 산업 **생**태계 및 동반성장 **생**태계 영향)

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **지식재산권(IP) 종류 및 소프트웨어 영향평가 제도** |
| **정의** | 지적 창작물에 부여되는 법적 권리 체계인 **지식재산권**(산업재산권/저작권/신지식재산권)과, 대기업·공공기관의 SW 시장 직접 참여가 중소 SW기업에 미치는 영향을 사전 평가하는 **소프트웨어 영향평가** 제도 |
| **키워드** | 산업재산권/저작권/신지식재산권, SW 이중보호(저작권+특허), GPL/MIT 라이선스, SW영향평가위원회 |
| **개념도** | **[ 지식재산권 3대 분류 체계 ]**<br>`산업재산권(특허20년/실용신안10년/디자인20년/상표10년) | 저작권(저작권 사후70년/저작인접권 공표후70년) | 신지식재산권(반도체배치설계10년/영업비밀/DB권5년/도메인이름)`<br><br>**[ SW 영향평가 처리 절차 ]**<br>`영향평가 신청 → 과기정통부 접수 → SW영향평가위원회 심의(중소기업/학계/전문가) → 현장조사·의견수렴 → 평가결과 통보 → 조건부허용/불허` |
| **구성요소** | 1. **SW 이중 보호**: 소스코드는 저작권(등록불필요, 창작과 동시 발생), 발명 아이디어는 특허권으로 별도 보호<br>2. **오픈소스 라이선스**: GPL(강한 카피레프트, 파생물도 동일 라이선스) vs MIT/Apache(약한 카피레프트, 소스공개 의무 없음)<br>3. **SW영향평가 대상**: 대기업(SW사업 직접수행), 공공기관(민간시장 직접개발·판매), 국가·지자체(민간경쟁 서비스) — 단 내부 행정목적 SW는 제외<br>4. **법정 평가 항목**: 민간시장 침해 여부(기개발/유통 유무), 대체 가능성(민간 SaaS/SW 구매 대체 여부), SW 산업 생태계 영향(동반성장성) |
| **비교** | **저작권 (소스코드 보호)**<br>- 발생: 창작과 동시 자동발생, 등록 불필요<br>- 보호대상: 표현(소스코드·목적코드) 자체<br><br>**특허권 (SW 발명 보호)**<br>- 발생: 출원·등록 필요<br>- 보호대상: 기능·로직(아이디어) 구현 방식, 존속 20년 |
| **차별화** | **IP 보호와 SW 산업 생태계 보호의 균형 정책 방향**<br>1. **오픈소스 라이선스 컴플라이언스 관리**: 기업이 GPL 등 강한 카피레프트 라이선스 코드를 상용 제품에 결합할 경우 소스 공개 의무가 전이될 수 있으므로, SBOM(소프트웨어 자재명세서) 기반 라이선스 검증 체계를 SW 개발 프로세스에 내재화.<br>2. **SW영향평가의 예외 요건 명확화**: 공공 목적·보안상 불가피성이 인정되는 경우(국가안보, 특수 공공서비스)에 한해 대기업·공공기관의 직접 개발을 조건부 허용하는 예외 심사 기준을 엄격 운영해 중소기업 시장 잠식 최소화.<br>3. **SW 특허와 영향평가 제도의 연계 검토**: 대기업이 SW 특허를 다수 보유한 상태에서 공공 SW 사업에 참여할 경우, 특허 포트폴리오가 시장 경쟁에 미치는 영향까지 SW영향평가 항목에 포함하는 제도 고도화 방향 제시. |
