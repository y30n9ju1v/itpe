# 머신 언러닝(Machine Unlearning): 필요성, 기법, 발전 방안 서브노트

> **두음 머리에 박기 🧠**
> - **법·보·저·비** (머신 언러닝 4대 필요성: **법**적요구(잊힐권리·삭제권), **보**안요구(포이즈닝·백도어 제거), **저**작권요구(무단수집 데이터 영향 제거), **비**용효율(전체 재학습 대비 절감))
> - **완·샤·근·증·검** (머신 언러닝 5대 기법군: **완**전 재학습(Exact), **샤**딩분할학습(SISA), **근**사적 삭제(Gradient/Fisher), 지식**증**류(Teacher-Student), **검**증(Membership Inference)) |

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **머신 언러닝 (Machine Unlearning) — 학습 완료 모델에서 특정 데이터 영향 제거 기술** |
| **정의** | 이미 학습이 완료된 모델에서 특정 데이터(또는 그 영향)를 완전 재학습(Full Retraining) 대비 낮은 비용으로 효율적으로 제거하여, 해당 데이터를 처음부터 학습하지 않은 것과 동등한 상태로 모델을 재구성하는 기술 |
| **키워드** | GDPR 잊힐 권리, 개인정보 삭제권, SISA, Influence Function, Fisher Information, Membership Inference 검증 |
| **개념도** | **[ 머신 언러닝 처리 흐름 ]**<br>`[원본 데이터셋 D] → 학습 → [모델 M]`<br>`        │(삭제 요청 데이터 Df 발생)`<br>`        ▼`<br>`[D - Df] ──언러닝──▶ [모델 M'] ≈ [D-Df로 처음부터 학습한 모델]`<br><br>- 딥러닝은 데이터가 가중치 전반에 분산 저장되어 단순 원본 삭제만으로는 정보가 사라지지 않는 것이 근본 문제 |
| **구성요소** | **[4대 필요성]**<br>1. 법적 요구: GDPR 잊힐 권리, 개인정보보호법 삭제권 이행<br>2. 보안 요구: 데이터 오염(Poisoning)·백도어 데이터 제거<br>3. 저작권 요구: 무단 수집 데이터·저작물 학습 영향 제거<br>4. 비용 효율: 데이터마다 전체 재학습 시 막대한 컴퓨팅 비용 발생<br><br>**[5대 기법군]**<br>1. 완전 재학습(Exact Unlearning): 삭제 데이터 제외 후 처음부터 재학습, 가장 정확·고비용<br>2. SISA(Sharded, Isolated, Sliced, Aggregated): 데이터 샤드 분할 학습, 삭제 시 해당 샤드만 재학습<br>3. 근사적 삭제: Gradient/Influence Function 역산 또는 Fisher Information 기반 가중치 스크러빙<br>4. 지식 증류(Teacher-Student Unlearning): 삭제 데이터 제외 지식만 학생 모델로 증류<br>5. 검증: 언러닝 후 잔존 여부를 Membership Inference 공격으로 검증 |
| **비교** | **완전 재학습(Exact Unlearning)**<br>- 정확성: 가장 높음(재학습 모델과 동일), 비용: 매우 높음(전체 재연산)<br>- 적합 대상: 소규모 데이터셋, 삭제 빈도 낮은 환경<br><br>**근사적 언러닝(Approximate Unlearning)**<br>- 정확성: 근사치(완전성 검증 어려움), 비용: 낮음(부분 연산)<br>- 적합 대상: 대규모/LLM, 빈번한 삭제 요청 환경 |
| **차별화** | **근사적 언러닝의 완전성 입증 및 LLM 확장 실무 전략**<br>1. **SISA류 아키텍처 사전 설계**: 초기 설계 단계부터 데이터를 샤드로 모듈화하는 SISA 아키텍처를 채택해 삭제 요청 발생 시 전체 재학습 없이 해당 샤드만 국소적으로 재학습함으로써 파국적 망각(Catastrophic Forgetting) 유사 성능 저하를 최소화.<br>2. **Membership Inference 사후 검증 표준화**: 근사적 기법(Influence Function, Fisher Scrubbing) 적용 후 멤버십 추론 공격으로 삭제 데이터의 잔존 여부를 정량 검증하고, 이행 로그를 감사 가능하도록 보관해 제3자 인증·감사 체계에 대비.<br>3. **LLM 대상 경량 파인튜닝 하이브리드 언러닝**: 초거대 모델은 전체 재학습이 사실상 불가능하므로 LoRA 등 경량 파인튜닝과 프롬프트 레벨 필터링을 결합한 하이브리드 언러닝을 적용하고, 표준 벤치마크·평가지표와 삭제 처리 기한을 규정하는 법·가이드라인 정비를 병행. |
