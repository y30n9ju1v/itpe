# 인공지능 영향평가(AI Impact Assessment) 총론과 수행 단계 서브노트

> **두음 머리에 박기 🧠**
> - **예·신·순·책** (AI 영향평가 4대 목적: 위험 사전**예**방, **신**뢰성 확보, 규제**순**응, **책**임성 강화)
> - **판·준·식·분·완·보·모** (AI 영향평가 7단계 수행절차: 대상 **판**별(Screening) → 사전**준**비 → 위험**식**별 → 위험**분**석·평가 → **완**화방안 수립 → **보**고·공개 → 사후**모**니터링) |

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **인공지능 영향평가 (AI Impact Assessment) — 고위험 AI 사전예방적 평가 제도** |
| **정의** | AI 개발·도입 전/운영중 인권·안전·편향·사회적 부작용 위험 사전 식별·평가·완화방안 수립 제도 → PIA 사전예방구조를 인권·안전·사회 영향 전반으로 확장 |
| **키워드** | 고위험 AI(의료·채용·신용평가·공공행정), PIA 확장, 자동화된 의사결정, Human-in-the-loop, AI 기본법 |
| **개념도** | **[ 영향평가 절차 흐름 ]**<br>`[AI 시스템 기획/도입] ──▶ 영향평가 대상 여부 판단`<br>`          │`<br>`          ▼`<br>`   [영향평가 수행] ──▶ 위험식별 → 평가 → 완화방안 → 보고서`<br>`          │`<br>`          ▼`<br>`   [운영·모니터링] ──▶ 주기적 재평가` |
| **구성요소** | **[4대 목적]**<br>1. 위험 사전예방: 기획·개발단계 부작용 선제차단(배포후 X)<br>2. 신뢰성 확보: 이용자·사회 대상 AI서비스 신뢰기반<br>3. 규제 순응: AI기본법 등 법령상 의무이행 수단<br>4. 책임성 강화: 평가결과 문서화 → 사업자 책임소재 명확화<br><br>**[7단계 수행절차]**<br>1. 대상판별(Screening): 고위험분야 해당여부·이용자규모·자동화된의사결정 여부<br>2. 사전준비: 개발·법무·윤리 등 다분야 평가팀 구성, 설계문서 확보<br>3. 위험식별: 편향·차별, 프라이버시침해, 안전사고, 설명가능성부족 목록화<br>4. 위험분석·평가: 발생가능성×심각도, 취약계층 차등영향 산정<br>5. 완화방안 수립: 데이터보정, HITL 삽입 등 저감대책<br>6. 보고·공개: 평가결과보고서 작성, 필요시 이용자·감독기관 공개<br>7. 사후 모니터링: 성능·편향지표 추적, 중대변경 시 재평가 트리거 |
| **비교** | **개인정보 영향평가(PIA)**<br>- 평가범위: 개인정보처리 위험중심, 근거법: 개인정보보호법<br>- 대상: 공공기관 개인정보파일 운용시스템<br><br>**AI 영향평가**<br>- 평가범위: 인권·안전·편향·사회적 영향 전반으로 확장, 근거: AI영향평가 가이드라인·AI기본법<br>- 대상: 고위험AI(의료·채용·신용평가·공공행정 등) |
| **차별화** | **AI 영향평가 실효성 확보 및 형식화 방지 전략**<br>1. **평가결과-개발백로그 연계 이행관리**: 완화방안(데이터보정·HITL 등) → 개발백로그 항목 연계·추적, 서류상 형식절차화 방지<br>2. **배포승인·인증·감독 연계**: 고위험AI는 평가완료를 배포전 필수절차화 + 우수사업자 신뢰인증 부여 + 규제기관 제출로 사후감독 근거화<br>3. **위험등급별 차등 적용 및 전문인력 양성**: 위험등급별 평가깊이 차등 + 표준템플릿·자동화도구로 중소기업 부담완화, 전담기관 주관 평가자 양성·민간 컨설팅 생태계 병행 육성 |
