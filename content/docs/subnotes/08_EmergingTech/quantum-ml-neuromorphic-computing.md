# 양자 머신러닝(QML) 및 뉴로모픽 컴퓨팅 서브노트

> **두음 머리에 박기 🧠**
> - **중·얽·간** (양자컴퓨팅 3대 특성: **중**첩 Superposition, **얽**힘 Entanglement, **간**섭 Interference)
> - **수·누·임·스** (SNN 스파이크 동작 4단계: 입력 **수**신 → 막전위 **누**적 → **임**계값 비교 → **스**파이크 발생)
> - **폰·뉴** (컴퓨팅 패러다임 대조축: **폰**노이만(CPU-메모리 분리, 클럭동기) vs **뉴**로모픽(연산-메모리 통합, 이벤트비동기)) |

| 분류 | 기술 기술사 서브노트 작성 예시 (1교시형 포맷) |
| :--- | :--- |
| **토픽명** | **양자 머신러닝 (QML) 및 뉴로모픽 컴퓨팅 (Neuromorphic Computing) — 차세대 AI 대안 하드웨어/알고리즘** |
| **정의** | 양자 중첩·얽힘·간섭을 머신러닝에 적용해 특정 문제의 지수적 속도향상을 노리는 **QML**과, 인간 뇌의 뉴런·시냅스를 하드웨어로 모방해 초저전력 이벤트 기반 처리를 구현하는 **뉴로모픽 컴퓨팅(SNN)** |
| **키워드** | 큐비트, NISQ, VQC/QSVM/HHL, In-Memory Computing, STDP, Intel Loihi/IBM TrueNorth |
| **개념도** | **[ QML 하이브리드 양자-고전 처리 ]**<br>`[고전 데이터] → [양자 회로 인코딩(큐비트)] → [VQC: 매개변수 양자연산] → [측정] → [고전 최적화 루프로 파라미터 갱신] (NISQ 시대는 이 하이브리드 구조가 현실적)`<br><br>**[ SNN 스파이크 처리 흐름 ]**<br>`[이전 뉴런 스파이크 입력] → [막전위 누적(가중합)] → [임계값 초과?] → Yes: [스파이크 발생 + 정보 시간부호화] → [불응기 진입]` |
| **구성요소** | 1. **양자컴퓨팅 3대 특성**: 중첩(0·1 동시상태), 얽힘(거리 무관 상태연동), 간섭(정답 확률 증폭)<br>2. **QML 대표 알고리즘**: QSVM(양자커널 고차원 분류), VQC(NISQ 적합 하이브리드), HHL(선형방정식 O(logN)), 양자PCA<br>3. **SNN 동작 원리**: 입력스파이크 수신→막전위 누적→임계값 비교→스파이크 발생→불응기, 학습은 STDP(역전파 아님)<br>4. **뉴로모픽 하드웨어**: Intel Loihi, IBM TrueNorth — In-Memory Computing으로 폰노이만 병목 제거 |
| **비교** | **폰 노이만 아키텍처**<br>- 구조: CPU+메모리 분리, 처리: 클럭 동기, 전력: 높음(항상 동작)<br>- 병목: 메모리 버스(폰노이만 병목)<br><br>**뉴로모픽 컴퓨팅**<br>- 구조: 연산·메모리 통합(In-Memory), 처리: 이벤트(스파이크) 비동기<br>- 병목: 없음(지역 처리), 전력: 매우 낮음(이벤트 발생시만 동작) |
| **차별화** | **NISQ 시대 QML 실용화 및 뉴로모픽 엣지 AI 확산 전략**<br>1. **하이브리드 양자-고전 알고리즘 우선 적용**: 큐비트 수·오류율이 제한적인 NISQ 환경에서는 순수 양자 알고리즘보다 VQC 같은 하이브리드 구조를 신약개발·금융 최적화 등 특정 고부가가치 문제에 선별 적용.<br>2. **뉴로모픽 기반 초저전력 엣지 AI 배포**: 배터리 제약이 큰 IoT·웨어러블 기기에는 SNN 기반 Loihi류 칩을 탑재해 이벤트 발생시만 연산하는 초저전력 상시 추론 구조 구현.<br>3. **이벤트 카메라+SNN 결합 실시간 처리**: 자율주행·로봇공학에서 이벤트 기반 센서와 SNN을 결합해 프레임 기반 CNN 대비 지연시간과 전력 소비를 동시에 절감하는 실시간 감각-운동 제어 파이프라인 구축. |
