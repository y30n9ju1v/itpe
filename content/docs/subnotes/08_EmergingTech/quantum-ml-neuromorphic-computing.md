# 양자 머신러닝(QML) 및 뉴로모픽 컴퓨팅 서브노트

> **두음 머리에 박기 🧠**
> - **중·얽·간** (양자컴퓨팅 3대 특성: **중**첩 Superposition, **얽**힘 Entanglement, **간**섭 Interference)
> - **수·누·임·스** (SNN 스파이크 동작 4단계: 입력 **수**신 → 막전위 **누**적 → **임**계값 비교 → **스**파이크 발생)
> - **폰·뉴** (컴퓨팅 패러다임 대조축: **폰**노이만(CPU-메모리 분리, 클럭동기) vs **뉴**로모픽(연산-메모리 통합, 이벤트비동기)) |

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **양자 머신러닝 (QML) 및 뉴로모픽 컴퓨팅 (Neuromorphic Computing) — 차세대 AI 대안 하드웨어/알고리즘** |
| **정의** | 양자 중첩·얽힘·간섭을 머신러닝에 적용해 특정 문제의 지수적 속도향상을 노리는 **QML**과, 인간 뇌의 뉴런·시냅스를 하드웨어로 모방해 초저전력 이벤트 기반 처리를 구현하는 **뉴로모픽 컴퓨팅(SNN)** |
| **키워드** | 큐비트, NISQ, VQC/QSVM/HHL/QAOA/QNN/QGAN, In-Memory Computing, STDP, Intel Loihi/IBM TrueNorth |
| **개념도** | **[ QML 하이브리드 양자-고전 처리 ]**<br>`[고전 데이터] → [양자 회로 인코딩(큐비트)] → [VQC: 매개변수 양자연산] → [측정] → [고전 최적화 루프로 파라미터 갱신] (NISQ 시대는 이 하이브리드 구조가 현실적)`<br><br>**[ SNN 스파이크 처리 흐름 ]**<br>`[이전 뉴런 스파이크 입력] → [막전위 누적(가중합)] → [임계값 초과?] → Yes: [스파이크 발생 + 정보 시간부호화] → [불응기 진입]` |
| **구성요소** | 1. **양자컴퓨팅 3대 특성**: 중첩(0·1 동시상태), 얽힘(거리 무관 상태연동), 간섭(정답 확률 증폭)<br>2. **QML 대표 알고리즘**: 양자특징맵(Encoding, 고차원 힐베르트공간 활용), QSVM(양자커널 고차원 분류), VQC/VQE(NISQ 적합 하이브리드), QAOA(조합최적화 특화), QNN(양자게이트를 뉴런처럼 배열), QGAN(양자 생성자·판별자 확률분포 학습), HHL(선형방정식 O(logN)), 양자PCA<br>3. **SNN 동작 원리**: 입력스파이크 수신→막전위 누적→임계값 비교→스파이크 발생→불응기, 학습은 STDP(역전파 아님)<br>4. **뉴로모픽 하드웨어**: Intel Loihi, IBM TrueNorth — In-Memory Computing으로 폰노이만 병목 제거 |
| **비교** | **폰 노이만 아키텍처**<br>- 구조: CPU+메모리 분리, 처리: 클럭 동기, 전력: 높음(항상 동작)<br>- 병목: 메모리 버스(폰노이만 병목)<br><br>**뉴로모픽 컴퓨팅**<br>- 구조: 연산·메모리 통합(In-Memory), 처리: 이벤트(스파이크) 비동기<br>- 병목: 없음(지역 처리), 전력: 매우 낮음(이벤트 발생시만 동작)<br><br>**고전(기존) 머신러닝**<br>- 연산단위: 비트(0 또는 1), 특징공간: 다항식적 확장, 하드웨어: GPU/TPU<br>- 성숙도: 상용화 완료, 학습방식: 역전파(Backpropagation)<br><br>**양자 머신러닝(QML)**<br>- 연산단위: 큐비트(중첩, 0과 1 동시표현), 특징공간: 큐비트 수에 지수적 확장(2ⁿ차원), 하드웨어: NISQ 양자컴퓨터<br>- 성숙도: 연구·PoC 단계, 학습방식: 파라미터 시프트 규칙 등 양자 그래디언트 추정 — 조합최적화·고차원 커널 계산에 이론적 우위, 단 큐비트 잡음·디코히런스로 실질적 양자우위 입증은 제한적 |
| **차별화** | **NISQ 시대 QML 실용화 및 뉴로모픽 엣지 AI 확산 전략**<br>1. **하이브리드 양자-고전 알고리즘 우선 적용**: NISQ(큐비트·오류율 제한) → 순수양자 대신 VQC 하이브리드, 신약개발·금융최적화 등 고부가가치 문제 선별 적용<br>2. **뉴로모픽 초저전력 엣지AI 배포**: 배터리제약 IoT·웨어러블 → SNN기반 Loihi류 칩, 이벤트발생시만 연산하는 상시추론<br>3. **이벤트카메라+SNN 결합 실시간처리**: 자율주행·로봇 → 이벤트센서+SNN, 프레임기반CNN 대비 지연시간·전력 동시절감 |
