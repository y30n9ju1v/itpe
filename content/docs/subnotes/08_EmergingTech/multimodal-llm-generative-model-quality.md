# 멀티모달 LLM, VAE 생성모델 및 학습데이터 품질검증 서브노트

> **두음 머리에 박기 🧠**
> - **인·크·프·디** (멀티모달 LLM 4대 구성요소: **인**코더(모달리티별 임베딩), **크**로스어텐션, **프**로젝션 레이어(공통 공간 정렬), **디**코더(텍스트 생성))
> - **정·완·일·다·적·윤** (TTAK.KO-10.1558 멀티모달 데이터 6대 품질특성: **정**확성, **완**전성, **일**관성, **다**양성, **적**합성, **윤**리성)
> - **μ·σ·재·KL** (VAE 핵심 메커니즘: 인코더가 평균 **μ**·표준편차 **σ** 산출 ➔ **재**매개변수화 트릭 z=μ+εσ ➔ 손실함수에 **KL** 발산 포함)

| :--- | :--- |
| **토픽명** | **멀티모달 LLM, VAE(Variational AutoEncoder) 및 생성형 AI 학습데이터 품질검증(TTAK.KO-10.1558)** |
| **정의** | 텍스트·이미지·음성·영상을 통합 처리하는 **멀티모달 LLM**, 잠재공간 확률분포 샘플링으로 신규 데이터를 생성하는 **VAE**, 그리고 이들 생성형 AI의 학습 데이터를 검증하는 **TTA 멀티모달 데이터 품질표준** |
| **키워드** | Cross-Attention, 프로젝션 레이어, CLIP, 잠재공간(Latent Space), 재매개변수화 트릭, CLIP Score/WER/Perplexity |
| **개념도** | **[ 멀티모달 LLM 처리 흐름 ]**<br>`[이미지/오디오/텍스트] → 인코더(모달리티별 임베딩) → 프로젝션 레이어(공통 표현 정렬) → 크로스어텐션(텍스트-비텍스트 관계) → LLM 디코더 → 텍스트 생성`<br><br>**[ VAE 생성 구조 ]**<br>`입력 X → 인코더 → 잠재분포(μ,σ) → 재매개변수화(z=μ+εσ) → 잠재벡터 z → 디코더 → 재구성 X'` |
| **구성요소** | 1. **크로스-어텐션**: 텍스트와 비텍스트 모달리티 간 관계 학습<br>2. **프로젝션 레이어**: 모달리티별 임베딩을 공통 표현 공간으로 정렬<br>3. **재매개변수화 트릭**: 샘플링의 역전파 불가 문제를 z=μ+ε·σ 분리로 해결<br>4. **VAE 손실함수**: 재구성 손실(MSE/BCE) + KL 발산(잠재분포를 N(0,I)에 정규화)<br>5. **데이터 품질 검증 방법**: 텍스트(Perplexity/MinHash 중복제거), 이미지(CLIP Score/BRISQUE), 음성(SNR/WER) |
| **비교** | **VAE (Variational AutoEncoder)**<br>- 학습 방식: 변분 추론(잠재분포 학습), 학습 안정적<br>- 생성 품질/잠재공간: 다소 흐림 / 구조적·연속적(보간 가능)<br><br>**GAN (Generative Adversarial Network)**<br>- 학습 방식: 적대적 학습(생성자 vs 판별자), 학습 불안정(모드 붕괴)<br>- 생성 품질/잠재공간: 선명함 / 비구조적 |
| **차별화** | **공공기관 생성형 AI 학습데이터 신뢰성 확보 전략**<br>1. **모달리티별 정량 검증 파이프라인 구축**: 텍스트는 Perplexity·중복탐지(MinHash/SimHash), 이미지는 CLIP Score(캡션 일치성)와 BRISQUE(무참조 품질), 음성은 SNR·WER을 자동 측정하는 데이터 품질 게이트를 학습 파이프라인 전단에 배치.<br>2. **윤리성·저작권 검증 강제화**: 편향·혐오 표현 및 저작권 미확인 이미지의 메타데이터 라이선스 검증을 필수 관문으로 두어 생성 AI 윤리 리스크를 사전 차단.<br>3. **멀티모달 정렬(Alignment) 단계적 학습**: CLIP류 대규모 이미지-텍스트 사전학습 → 비전 인코더와 LLM 간 프로젝션 정렬 → VQA/캡셔닝 등 태스크별 미세조정의 3단계로 멀티모달 LLM 성능을 단계적으로 고도화. |
