# 공공 클라우드 조달제도 (안전성 검토 및 디지털서비스 전문계약제도) 서브노트

> **두음 머리에 박기 🧠**
> - **상·중·하** (CSAP 인증 3등급: **상**(물리적분리+최고암호, 국가안보급), **중**(물리적분리, 일반행정), **하**(논리적분리 허용, 멀티테넌트))
> - **가·용·변·인·서·백·로·패** (클라우드 서비스운영 안전성 검토 8대 항목: **가**용성관리, **용**량관리, **변**경관리, **인**시던트관리, **서**비스수준관리, **백**업복구, **로**그관리, **패**치관리)
> - **KISA·국정원** (인증 이원화: **KISA**=CSAP 인증(CSP 대상), **국정원**=안전성 검토(공공기관 도입 시 별도 거버넌스 검토))

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **공공기관 클라우드 서비스 안전성 검토(CSAP) 및 디지털서비스 전문계약제도** |
| **정의** | 공공기관의 클라우드 도입 시 보안 기준을 규정하는 **클라우드 서비스 안전성 검토(CSAP 3등급)**와, 클라우드·SaaS 등 디지털서비스를 이용약관 기반 구독형으로 신속 조달하는 **디지털서비스 전문계약제도** |
| **키워드** | CSAP 상/중/하 등급, KISA vs 국정원 검토, BCP/DRP, DSIS(디지털서비스 이용지원시스템), 이용약관 기반 계약 |
| **개념도** | **[ 공공 클라우드 도입 절차 (CSAP 인증 → 국정원 안전성 검토 → 조달) ]**<br>`클라우드 서비스 선정 → 안전성 검토 계획 수립 → CSAP 인증 여부 확인(KISA, 필수) → 서비스 운영 8대 항목 심사 → 결과보고·기관장 승인 → 주기적 사후점검(연1회+)`<br><br>**[ 디지털서비스 전문계약 신속 조달 흐름 ]**<br>`민간 SaaS/AI서비스 등록(DSIS) → 이용약관 기반 계약(맞춤개발 없음) → 구독형 과금(월정액/종량제) → 수시 업데이트 → 수일~수주 내 도입 완료 (기존 SI 계약: 수개월 소요)` |
| **구성요소** | 1. **CSAP 3등급**: 상(국가안보급, 물리적분리+최고암호, 가상화차단), 중(일반행정, 물리적분리), 하(비민감, 논리적분리 허용)<br>2. **서비스운영 8대 검토항목**: 가용성(BCP/DRP)·용량·변경·인시던트·SLA·백업(RTO/RPO)·로그(6개월 이상)·패치관리<br>3. **인증 주체 이원화**: KISA(CSAP, CSP 대상 시스템 인증) vs 국정원(안전성 검토, 이용기관 대상 거버넌스 검토)<br>4. **디지털서비스 법정 분류**: 클라우드 컴퓨팅 서비스(IaaS/PaaS/SaaS), 클라우드 지원 서비스(컨설팅/이전구축), 서비스 간 융합 서비스 |
| **비교** | **기존 SI 계약**<br>- 계약방식: 맞춤개발계약, 과금: 프로젝트 완료 후 일시지급<br>- 소요시간: 수개월, 업데이트: 별도 유지보수 계약 필요<br><br>**디지털서비스 전문계약**<br>- 계약방식: 이용약관 기반, 과금: 구독·종량제<br>- 소요시간: 수일~수주, 업데이트: 서비스 내 자동갱신 |
| **차별화** | **공공 클라우드 조달의 보안성-신속성 균형 확보 전략**<br>1. **CSAP 인증 우선 조달**: 디지털서비스 신속도입 시에도 미인증 서비스 → 별도 집중 보안성검토 병행<br>2. **정보등급별 계약모델 매핑**: 데이터민감도(상/중/하) → CSAP등급·계약유형 매핑, 기밀=SI+상등급, 공개=디지털서비스<br>3. **보안 책임공유 명확화**: CSP(인프라·물리보안) ↔ 이용기관(데이터관리·접근제어) 책임분계선 → 계약서/SLA 명시 |
