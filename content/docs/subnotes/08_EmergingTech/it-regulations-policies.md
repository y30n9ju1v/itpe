# IT 관련 법규 및 공공 정책 서브노트

> **두음 머리에 박기 🧠**
> - **익·가·개** (개인정보 식별 통제 분류 3단계: 복원 불가 **익**명정보 ➔ 추가 정보 결합 시 복원 가능 **가**명정보 ➔ 고유한 **개**인정보)
> - **국·신·재** (공공 SW 대기업 제한 예외 승인 요건: **국**가 안보 영향, 국가 **신**기술 실증 사업, 긴급한 **재**난 대응)
> - **통·과·공** (가명정보 정보주체 동의 없이 활용 가능한 3대 법적 목적: **통**계 작성, **과**학적 연구, **공**익적 기록보존)

| **구성요소** | 1. **가명정보**: 추가정보 결합없이는 특정개인 식별불가 → 임시암호 대체정보<br>2. **안전조치 의무**: 결합가능 추가정보 별도서버 저장 + 접근권한 철저차단<br>3. **대기업 참여제한**: 공공SW 중소기업 육성 → 자산5조원+ 대기업 입찰금액 한도설정<br>4. **상용SW 분리발주**: SI사업 발주 시 상용패키지SW 별도분리 조달구매 |
| **비교** | **가명정보 (Pseudonymized)**<br>- 재식별가능성: 추가정보 결합 시 개인식별 가능 (유사식별)<br>- 법적적용: 개인정보보호법 적용범위 내 (동의면제 특례)<br><br>**익명정보 (Anonymized)**<br>- 재식별가능성: 어떤정보 결합해도 영구식별 불가 (완전비식별)<br>- 법적적용: 개인정보보호법 전면제외 (자유유통) |
| **차별화** | **대기업 참여제한 부작용 완화·상용SW 활성화 정책제언**<br>1. **대형 공공시스템 품질관리 개선**: 참여제한 시스템장애(교육망 마비 등) → 핵심기간망 예외인정(국·신·재) 절차간소화 + 대-중-소 상생컨소시엄 지분조율 제도화<br>2. **상용SW 직접구매 비율강화**: SI 하청통합 개발문화 탈피 → 나라장터 직접구매(분리발주 의무화 강화)로 국내SW 산업 체력강화<br>3. **데이터 결합 전문기관 연동**: 이종 가명정보(통신+금융) 결합 → 3대 결합전문기관(KISA 등) 승인 후 안전병합·신사업발굴 |
