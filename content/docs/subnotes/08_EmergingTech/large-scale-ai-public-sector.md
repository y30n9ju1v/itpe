# 초거대 AI 및 공공부문 LLM 도입 아키텍처·가이드라인 서브노트

> **두음 머리에 박기 🧠**
> - **책·투·공·안·데·사** (공공부문 초거대 AI 도입 6대 원칙: **책**임성, **투**명성, **공**정성, **안**전성, **데**이터 주권, **사**람 중심)
> - **보·환·편·법·비** (공공기관 LLM 적용 5대 고려사항: **보**안/프라이버시, **환**각 대응, **편**향/공정성, **법**적 규제 준수, **비**용/운영)
> - **API·오·랙·파·에** (구현 가능 5대 LLM 아키텍처: 클로즈드소스 **API**, **오**픈소스 자체구축, **랙** RAG, **파**인튜닝, **에**이전틱 AI) |

| **개념도** | **[ 공공부문 초거대 AI 도입 6단계 절차 ]**<br>`도입 필요성 검토(ROI/법적검토) → AI 서비스 유형 선정(자체구축/SaaS/온프레미스) → 데이터 준비(정제/비식별) → 시범도입(PoC) → 본격 도입(시스템 통합) → 운영·모니터링(편향점검)`<br><br>**[ 공공기관 RAG 아키텍처 ]**<br>`사용자 질의 → 벡터DB 검색(내부 문서 임베딩) → 관련 문서 청크 검색 → LLM 프롬프트(질의+검색문서) → 답변 생성(출처 포함)` |
| **구성요소** | 1. **파운데이션 모델**: GPT-4/Claude/HyperCLOVA X 등 대규모 사전학습 모델, 창발성·지시 따르기 특성<br>2. **6대 도입 원칙**: 책임성·투명성·공정성·안전성·데이터 주권·사람 중심<br>3. **5대 고려사항**: 데이터 보안, 환각 대응(RAG/출처표시), 편향 감사, 법규 준수, 운영비용<br>4. **5대 아키텍처**: 클로즈드소스 API(빠른 프로토타이핑), 오픈소스 자체구축(보안 중요기관), RAG(지식Q&A), 파인튜닝(도메인특화), 에이전틱 AI(복합 업무자동화) |
| **비교** | **소형 모델**<br>- 파라미터: 수백만~수억(BERT 110M), 학습비용: 소규모 GPU<br>- 활용 방식: 단일 태스크 특화<br><br>**초거대 AI**<br>- 파라미터: 수십억~수조(GPT-4 ~1T), 학습비용: 수천억 원 수준<br>- 활용 방식: 범용(Zero-shot/Few-shot), 창발성 발현 |
| **차별화** | **공공기관 초거대 AI 도입 데이터 주권·리스크 관리 실무 전략**<br>1. **단계적 아키텍처 전환**: API 기반 PoC 신속검증 → 민감도↑ 시 RAG → 파인튜닝 → 온프레미스 자체구축 순 전환<br>2. **외산 LLM 공급망 리스크 완화**: DPA(데이터처리계약) 체결 + 국산 sLLM·자체모델 병행검토 → 단일의존 방지<br>3. **환각·편향 상시 모니터링**: RAG 출처표시 + Human-in-the-loop 결합, 정기 Bias Audit 내재화 → 6대 원칙(책·투·공·안·데·사) 지속검증 |
