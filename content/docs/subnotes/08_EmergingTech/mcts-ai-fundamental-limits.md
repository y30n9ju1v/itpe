# 몬테카를로 트리탐색(MCTS) 및 AI의 근본적 한계 서브노트

> **두음 머리에 박기 🧠**
> - **선·확·시·역** (MCTS 4단계 반복 구조: **선**택(Selection, UCT최대) → **확**장(Expansion) → **시**뮬레이션(Rollout) → **역**전파(Backpropagation))
> - **진·암** (모라벡의 역설 2대 원인: **진**화적 기원(수억년 최적화된 신경회로), **암**묵지(Tacit Knowledge, 명시화 불가능한 경험))
> - **A·A·A** (AI 발전 3단계: **A**NI(특정과업 특화) → **A**GI(인간수준 범용) → **A**SI(초지능, 이론적)) |

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **몬테카를로 트리탐색(MCTS) 및 AI의 근본적 한계 (차원의 저주, 모라벡의 역설, ANI→AGI)** |
| **정의** | 무작위 시뮬레이션으로 게임 트리를 탐색하는 **MCTS**와, 고차원 데이터에서 알고리즘 성능이 저하되는 **차원의 저주**, 인간에게 쉬운 감각·운동이 AI에게 어려운 **모라벡의 역설**, 특화AI(ANI)가 범용AI(AGI)로 가는 발전 단계론 |
| **키워드** | UCT 수식(탐색-활용균형), 정책/가치 네트워크(AlphaGo), 공간 희소성(Sparsity), 암묵지(Tacit Knowledge), 전이학습 |
| **개념도** | **[ MCTS 4단계 반복 루프 ]**<br>`Selection(UCT=Q/N+C√(lnN_parent/N)) → Expansion(미방문 자식 추가) → Simulation(무작위 rollout) → Backpropagation(경로 전체 Q·N 갱신) → (반복)`<br><br>**[ 차원의 저주: 공간 희소화 ]**<br>`d=1,r=0.1 → 데이터 10% 포함 / d=10,r=0.1 → 0.1^10≈0% 포함 (고차원일수록 모든 점이 등거리화)`<br><br>**[ ANI→AGI 모듈 통합 ]**<br>`[비전 ANI] + [언어 ANI] + [추론 ANI] → 모듈 통합 → [AGI 범용 지능]` |
| **구성요소** | 1. **MCTS 4단계**: Selection(UCT 기준 노드 선택)→Expansion→Simulation(Rollout)→Backpropagation, AlphaGo는 정책/가치 네트워크로 Rollout 노이즈 감소<br>2. **차원의 저주 해결책**: PCA/t-SNE(차원축소), 필터/래퍼/임베디드(특징선택), SMOTE(데이터 증강)<br>3. **모라벡의 역설**: 인간에게 쉬운 것(걷기·물체인식)이 AI에겐 어렵고, 어려운 것(체스·수학)은 AI가 잘함 — 원인은 진화적 기원과 암묵지<br>4. **ANI 필요성 5가지**: 전이학습 기반 제공, 모듈형 AGI 구성요소, 실용적 가치 창출, 안전성 검증 단계, 벤치마크 체계 구축 |
| **비교** | **MCTS (순수)**<br>- Rollout: 무작위 시뮬레이션, 깊은 트리에서 품질 저하<br>- 탐색 효율: UCT 기반이나 노이즈 큼<br><br>**AlphaGo형 MCTS (딥러닝 결합)**<br>- Rollout: 정책 네트워크가 유망한 수 추천, 가치 네트워크가 상태가치 직접 추정<br>- 탐색 효율: 무작위 노이즈 대폭 감소, 탐색 효율 극대화 |
| **차별화** | **AI 근본 한계 극복을 위한 하이브리드 접근 전략**<br>1. **탐색-학습 결합 설계**: 순수 MCTS의 Rollout 품질 저하를 방지하기 위해 정책/가치 네트워크(딥러닝)를 MCTS에 결합하는 AlphaZero류 아키텍처를 자원 스케줄링·자율주행 시나리오 탐색에 확장 적용.<br>2. **고차원 데이터 파이프라인 전처리 표준화**: 거리 기반 알고리즘(KNN, SVM) 적용 전 PCA/오토인코더로 차원을 축소해 차원의 저주로 인한 성능 저하를 사전 방지.<br>3. **인간-AI 협업형 시스템 설계**: 모라벡의 역설을 고려해 고차원 인지·논리 추론은 AI(LLM)에 위임하고, 물리적 조작·현장 판단은 인간이 담당하는 협업 모델을 로봇공학·현장 자동화에 적용하며, ANI 모듈들을 단계적으로 통합해 AGI로의 점진적 확장 로드맵 수립. |
