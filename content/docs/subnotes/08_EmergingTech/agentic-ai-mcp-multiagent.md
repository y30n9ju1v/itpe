# 에이전틱 AI, MCP 및 다중 에이전트 시스템(MAS) 서브노트

> **두음 머리에 박기 🧠**
> - **자·도·장·계·적** (에이전틱 AI 5대 핵심 특성: **자**율성, **도**구사용, **장**기기억, **계**획수립(ReAct/CoT), **적**응성)
> - **T·R·P** (MCP 3대 기본 요소: **T**ools(실행함수), **R**esources(데이터), **P**rompts(재사용 템플릿))
> - **오·전·검·실** (MAS 4대 에이전트 역할: **오**케스트레이터(태스크 분해·할당), **전**문 에이전트, **검**증 에이전트(Critic), **실**행 에이전트)
> - **입·권·체·유·붕** (에이전틱 AI 5대 보안위협: **입**력조작(프롬프트인젝션·환각), **권**한남용(과도한 권한위임), **체**인공격(툴 체이닝 익스플로잇), **유**출(메모리/맥락 유출), **붕**괴(다중에이전트 오염·신뢰경계 붕괴))

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **에이전틱 AI (Agentic AI), MCP (Model Context Protocol) 및 다중 에이전트 시스템 (MAS)** |
| **정의** | 스스로 계획을 세우고 도구를 사용해 자율적으로 목표를 달성하는 **에이전틱 AI**, 이를 위한 AI-도구 연동 표준 **MCP**, 그리고 복수 에이전트가 협업하는 **MAS** |
| **키워드** | 자·도·장·계·적, ReAct/CoT, JSON-RPC 2.0, M×N 문제, T·R·P, 프롬프트 인젝션, PoLP/RBAC, Human-in-the-loop |
| **개념도** | **[ 에이전틱 AI 아키텍처 루프 ]**<br>`[사용자 목표] → [계획 모듈: CoT/ReAct 하위작업 분해] → [실행 모듈: 도구 호출(API/Code/Browser)] → [메모리 모듈: 단기+장기(VectorDB)] → [반성/검증: 결과 평가·재계획]`<br><br>**[ MCP M×N → M+N 구조 전환 ]**<br>`(기존) M개 AI × N개 서비스 = M×N개 커스텀 통합`<br>`(MCP) [MCP Client(Claude 등)] ←JSON-RPC→ [MCP Server(파일시스템/DB/GitHub 등)] = M+N개 표준 연동`<br><br>**[ MAS 협업 구조 ]**<br>`[오케스트레이터] → 하위 태스크 할당 → [전문 에이전트1][전문 에이전트2] → [검증 에이전트(Critic)] → [실행 에이전트(도구 호출)]` |
| **구성요소** | 1. **에이전틱 AI 5대 특성**: 자율성·도구사용·장기기억·계획수립·적응성 → 단순챗봇과 구별<br>2. **MCP 3대 요소**: Tools(함수실행)·Resources(데이터접근)·Prompts(재사용템플릿), JSON-RPC 2.0 기반<br>3. **MAS 4대 역할**: 오케스트레이터(분해·통합)·전문에이전트(특화수행)·검증에이전트(품질평가)·실행에이전트(도구호출)<br>4. **MAS 필요성**: 단일LLM 컨텍스트·전문성 한계극복, 병렬처리 효율화, 역할분리 오류감소<br>5. **에이전틱 AI 5대 보안위협**: 프롬프트인젝션(악성지시은닉)·환각 오작동, 과도권한위임(파일삭제·결제 오남용), 툴체이닝 익스플로잇(연쇄우회공격), 메모리/맥락 유출(민감정보노출), 다중에이전트 오염(협업체계 전파)<br>6. **관리·기술 보안대책 2×2**: [권한통제] PoLP+RBAC스코프, [입력검증] 가이드라인+인젝션탐지, [모니터링] 감사체계+행동로깅·이상탐지, [승인절차] HITL+민감작업 승인게이트, [격리] 업무별분리+샌드박스·망세그멘테이션, [데이터보호] 보존/파기정책+암호화·PII마스킹 |
| **비교** | **단일 에이전트**<br>- 구조: LLM 1개+도구, 처리: 순차적<br>- 검증: 자기검증 어려움, 구현 복잡도 낮음<br><br>**다중 에이전트 시스템(MAS)**<br>- 구조: 복수LLM/에이전트 협력, 처리: 병렬·분산<br>- 검증: 상호검증 가능, 구현 복잡도 높음(조율 오버헤드) |
| **차별화** | **에이전틱 AI 확산 대비 보안·거버넌스 리스크 관리 전략**<br>1. **과도권한(Excessive Agency) 통제**: MCP 서버·도구호출 → PoLP 적용, 비가역작업(삭제·결제)은 HITL 승인 필수<br>2. **MCP 공급망 신뢰성 검증**: 외부서버 코드·권한범위 사전검증 + 행동감사로그 필수화 → 인젝션 확산 차단<br>3. **MAS 책임소재 추적**: 오케스트레이터가 서브에이전트 작업이력 트레이싱 → 오류 시 책임에이전트 즉시식별, 비용대비효과 모니터링<br>4. **자율성 등급별 단계확대**: 완전자동/반자동(승인)/수동 3단계 구분 + MCP 서버·플러그인 화이트리스트·서명검증 병행, 공공부문 저위험→고위험 순 확대(Defense in Depth) |
