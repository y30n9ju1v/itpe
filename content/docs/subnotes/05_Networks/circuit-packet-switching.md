# 회선교환과 패킷교환 서브노트

> **두음 머리에 박기 🧠**
> - **회·패** (교환 방식 2대 분류: **회**선교환 Circuit Switching, **패**킷교환 Packet Switching)
> - **가·데** (패킷교환 내 세부 방식: 논리경로 사전설정 **가**상회선 Virtual Circuit, 패킷별 독립라우팅 **데**이터그램 Datagram)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **회선교환(Circuit Switching)과 패킷교환(Packet Switching)** |
| **정의** | 네트워크에서 데이터를 목적지까지 전달하기 위해 경로와 자원을 할당하는 두 가지 교환 방식으로, 회선교환은 연결 전 전용 경로를 예약하고 패킷교환은 데이터를 분할하여 동적으로 전달함 |
| **키워드** | 전용회선 예약, 가상회선 vs 데이터그램, 실시간 트래픽, IntServ/DiffServ, RSVP |
| **개념도** | `[회선교환] 발신자 ─ 교환기A ─ 교환기B ─ 교환기C ─ 수신자` (전용 회선 지속 점유)<br>`[패킷교환] 데이터 → [패킷1][패킷2][패킷3] 분할` → 패킷1: A→B→D, 패킷2: A→C→D(다른 경로 가능) → 수신측 순서 재조합 |
| **구성요소** | 1. **회선교환**: 회선 설정(Call Setup) → 데이터 전송(독점 대역폭) → 회선 해제(Call Teardown) 3단계, 대표 사례 PSTN·ISDN<br>2. **패킷교환**: 패킷 단위 분할·동적 라우팅, 자원 공유로 효율적, 대표 사례 인터넷(IP)·LTE<br>3. **가상회선(Virtual Circuit)**: 연결 전 논리 경로 설정, 순서 보장, 설정/해제 오버헤드 있음 (ATM, Frame Relay)<br>4. **데이터그램(Datagram)**: 패킷마다 독립 라우팅, 순서 미보장, 오버헤드 없음 (IP)<br>5. **실시간 트래픽 문제**: 지연(Delay)·지터(Jitter)·패킷 손실·순서 역전이 패킷교환망에서 발생 |
| **비교** | **회선교환**<br>- 대역폭: 고정 전용(사용 안 해도 점유)<br>- 지연: 일정(낮은 지연 보장)<br>- 신뢰성: 회선 끊기면 전체 실패<br>- 구축비: 고가<br><br>**패킷교환**<br>- 대역폭: 가변 공유(효율적)<br>- 지연: 가변(큐잉 지연 발생)<br>- 신뢰성: 경로 우회 가능<br>- 구축비: 저렴 |
| **차별화** | **패킷교환망에서 실시간 트래픽 QoS 보장 전략**<br>1. **QoS 아키텍처 3종 대응**: IntServ(개별 흐름별 RSVP 자원 예약, RFC 1633), DiffServ(DSCP EF 마킹 기반 트래픽 분류, RFC 2474), RSVP(Path/Resv 메시지로 경로 자원 예약, RFC 2205)를 문제 특성에 따라 선택 적용<br>2. **실시간 트래픽 문제별 해결 기법**: 지연은 우선순위 큐·RSVP로, 지터는 Playout Buffer로, 패킷 손실은 FEC·RED로, 순서 역전은 시퀀스 번호+버퍼링으로 대응<br>3. **DSCP EF 마킹과 SD-WAN 연계**: 음성·영상 패킷을 DSCP EF(Expedited Forwarding)로 최우선 큐에 배치하고, SD-WAN 애플리케이션 인식 라우팅으로 실시간 트래픽을 저지연 경로에 자동 우회 |
