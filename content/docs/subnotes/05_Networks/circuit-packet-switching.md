# 회선교환과 패킷교환 서브노트

> **두음 머리에 박기 🧠**
> - **회·패** (교환 방식 2대 분류: **회**선교환 Circuit Switching, **패**킷교환 Packet Switching)
> - **가·데** (패킷교환 내 세부 방식: 논리경로 사전설정 **가**상회선 Virtual Circuit, 패킷별 독립라우팅 **데**이터그램 Datagram)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **회선교환(Circuit Switching)과 패킷교환(Packet Switching)** |
| **정의** | 목적지까지 경로·자원 할당하는 2대 교환방식, 회선교환=연결 전 전용경로 예약 / 패킷교환=데이터 분할 후 동적전달 |
| **키워드** | 전용회선 예약, 가상회선 vs 데이터그램, 실시간 트래픽, IntServ/DiffServ, RSVP |
| **개념도** | `[회선교환] 발신자 ─ 교환기A ─ 교환기B ─ 교환기C ─ 수신자` (전용 회선 지속 점유)<br>`[패킷교환] 데이터 → [패킷1][패킷2][패킷3] 분할` → 패킷1: A→B→D, 패킷2: A→C→D(다른 경로 가능) → 수신측 순서 재조합 |
| **구성요소** | 1. **회선교환**: 회선설정(Call Setup) → 데이터전송(독점대역폭) → 회선해제(Call Teardown) 3단계, 대표 PSTN·ISDN<br>2. **패킷교환**: 패킷단위 분할·동적라우팅, 자원공유로 효율적, 대표 인터넷(IP)·LTE<br>3. **가상회선(VC)**: 연결 전 논리경로 설정, 순서보장, 설정/해제 오버헤드 있음 (ATM, Frame Relay)<br>4. **데이터그램**: 패킷마다 독립라우팅, 순서 미보장, 오버헤드 없음 (IP)<br>5. **실시간 트래픽 문제**: 지연·지터·패킷손실·순서역전이 패킷교환망서 발생 |
| **비교** | **회선교환**<br>- 대역폭: 고정전용(미사용 시도 점유)<br>- 지연: 일정(낮은지연 보장)<br>- 신뢰성: 회선 끊기면 전체실패<br>- 구축비: 고가<br><br>**패킷교환**<br>- 대역폭: 가변공유(효율적)<br>- 지연: 가변(큐잉지연 발생)<br>- 신뢰성: 경로우회 가능<br>- 구축비: 저렴 |
| **차별화** | **패킷교환망 실시간 트래픽 QoS 보장 전략**<br>1. **QoS 아키텍처 3종 대응**: IntServ(개별흐름별 RSVP 자원예약, RFC 1633), DiffServ(DSCP EF 마킹기반 트래픽분류, RFC 2474), RSVP(Path/Resv 메시지로 경로자원예약, RFC 2205) → 문제특성별 선택적용<br>2. **실시간 트래픽 문제별 해결기법**: 지연=우선순위큐·RSVP, 지터=Playout Buffer, 패킷손실=FEC·RED, 순서역전=시퀀스번호+버퍼링<br>3. **DSCP EF 마킹+SD-WAN 연계**: 음성·영상 패킷 DSCP EF(Expedited Forwarding)로 최우선큐 배치, SD-WAN 앱인식 라우팅으로 실시간 트래픽 저지연경로 자동우회 |
