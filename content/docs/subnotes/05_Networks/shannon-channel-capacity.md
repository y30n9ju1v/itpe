# 채널용량과 샤논 정리 서브노트

> **두음 머리에 박기 🧠**
> - **소·채·정** (샤논 3대 정리: 압축 하한 **소**스코딩(제1정리), **채**널코딩(제2정리), **정**보용량(제3정리))
> - **씨·비·에스엔** (샤논-하틀리 공식 구성: 채널용량 **C**, 대역폭 **B**, 신호대잡음비 **S/N**)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **채널용량과 샤논 제3정리 (Shannon Information Capacity Theorem)** |
| **정의** | 잡음이 있는 채널에서 달성 가능한 최대 정보 전송 속도(채널 용량)를 정의하는 정보이론의 기본 정리로, C = B × log₂(1+S/N)의 샤논-하틀리 공식으로 표현되며 현대 디지털 통신 시스템 설계의 이론적 상한을 제시 |
| **키워드** | C=B×log₂(1+S/N), 소스코딩/채널코딩/정보용량 정리, Shannon Limit, Turbo Code/LDPC, MIMO |
| **개념도** | **[ 샤논-하틀리 공식과 적용 ]**<br>`C = B × log₂(1 + S/N)`<br>`C: 채널 용량(bps)  B: 대역폭(Hz)  S/N: 신호대잡음비`<br>&nbsp;&nbsp;&nbsp;&nbsp;`↓`<br>`B 증가 → 용량 선형 증가 (예: MIMO로 B 가상 확장)`<br>`S/N 증가 → 용량 로그적 증가 (예: 빔포밍으로 SNR 개선)` |
| **구성요소** | 1. **제1정리(소스 코딩)**: 무손실 압축의 이론적 하한 = 정보 엔트로피 H<br>2. **제2정리(채널 코딩)**: 채널 용량 C 미만의 전송률이면 오류 없는 통신 가능<br>3. **제3정리(정보 용량)**: 잡음 채널에서 최대 용량 = B × log₂(1+S/N)<br>4. **Shannon Limit**: 실제 시스템이 접근은 가능하나 도달할 수 없는 이론적 한계<br>5. **Turbo Code, LDPC**: Shannon Limit에 근접한 오류 정정 코드 |
| **비교** | **대역폭(B) 증가**<br>- 효과: 용량 선형 비례 증가<br>- 적용: MIMO(안테나로 B 가상확장), WiFi 6E(6GHz 대역)<br><br>**신호대잡음비(S/N) 증가**<br>- 효과: 용량 로그적 비례 증가(B증가보다 저효율)<br>- 적용: 5G NR 빔포밍(고SNR확보), 광섬유(저잡음→고C) |
| **차별화** | **이론적 한계의 실제 통신시스템 설계 반영 전략**<br>1. **B/S·N 트레이드오프**: SNR 2배→log₂(2)=1bps/Hz 추가뿐, B 2배→용량 그대로 2배 → 5G/6G는 광대역(mmWave,THz) 확보 우선<br>2. **오류정정코드로 Shannon Limit 근접**: Turbo/LDPC → 제2정리 무오류전송률 C 근접, 상한-실성능 격차 최소화<br>3. **차세대 통신 연계**: 6G AI-Native → AI빔포밍·간섭예측으로 실효SNR 극대화, MIMO·광대역 결합 → 샤논한계 자체 상향 |
