# 5G/6G 이동통신 아키텍처 서브노트

> **두음 머리에 박기 🧠**
> - **광·저·다** (5G 이동통신 3대 서비스 요건: 초**광**대역 eMBB, 초**저**지연 URLLC, **다**연결 mMTC)
> - **에이·유·에스·엔** (SBA 코어망 핵심 기능 컴포넌트: 이동성 관리 **AMF**, 사용자 평면 전송 **UPF**, 세션 제어 **SMF**, 컴포넌트 발견/등록 **NRF**)
> - **티·헤·삼** (6G 이동통신 차세대 물리 규격: 데이터 전송 **T**bps(초당 테라비트), 주파수 대역 **THz**(테라헤르츠), 통신 영역 **3차원** 위성 입체 망)

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **5G/6G 이동통신 코어망 서비스 기반 아키텍처 (SBA) 및 네트워크 슬라이싱** |
| **정의** | 코어망 제어평면 기능을 마이크로서비스화 → REST API 연동 **SBA**, 5G요건(광·저·다) 만족 위해 물리망을 용도별 가상분할하는 **네트워크 슬라이싱** |
| **키워드** | eMBB / URLLC / mMTC, SBA (AMF / SMF / UPF / NRF), Network Slicing, 테라헤르츠 (THz), 위성통신 융합 |
| **개념도** | **[ 5G/6G 네트워크 슬라이싱 및 분산 UPF 엣지 아키텍처 ]**<br>`[ 단말 (차량, 스마트폰, 센서) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;`│ (5G 무선기지국 RAN)`<br>&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[ 물리 네트워크 (Physical Infrastructure) ] ➔ SDN / NFV 가상 가상화 연동`<br>&nbsp;&nbsp;&nbsp;&nbsp;`├── [ 슬라이스 A : URLLC (자율주행용) ] ──➔ [ 분산 배치 UPF ] ➔ [ MEC 서버 (5ms 극저지연) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;`├── [ 슬라이스 B : eMBB (4K/8K 미디어) ] ──➔ [ 중앙 코어 UPF ] ➔ [ 인터넷 / CDN ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;`└── [ 슬라이스 C : mMTC (스마트 계량기) ] ──➔ [ IoT 관리 서버 ]` |
| **구성요소** | 1. **SBA**: 모놀리식 코어 탈피 → 제어평면 각 기능을 독립 NF 단위로 모듈화한 구조<br>2. **AMF**: 단말 인증, 무선망 접속 및 기지국 간 이동성관리 담당<br>3. **SMF**: 가입자 IP할당, 세션 수립/해제 + 충전/과금정책 + UPF 라우팅룰 제어<br>4. **UPF**: 제어부와 분리 → 가입자 패킷데이터 고속라우팅+캡슐화 전송 기능장치<br>5. **NRF**: 각 NF 서비스인스턴스 상태등록 + 타 NF 발견/바인딩 돕는 레지스트리 |
| **비교** | **5G 이동통신 (IMT-2020)**<br>- **최대속도/지연**: 20 Gbps / 1 ms (URLLC 수준 보증)<br>- **주파수대역**: Sub-6 GHz 및 밀리미터파 (28 GHz 등)<br>- **핵심아키텍처**: SBA, 네트워크슬라이싱, CUPS(제어-전송 분리)<br><br>**6G 이동통신 (IMT-2030, 차세대)**<br>- **최대속도/지연**: 1 Tbps(50배 증가) / 0.1 ms(1/10 단축)<br>- **주파수대역**: 테라헤르츠(THz, 100GHz~10THz 초고주파)<br>- **핵심아키텍처**: AI-Native 무선망, 저궤도(LEO) 위성 3차원 입체통신 |
| **차별화** | **초저지연(URLLC) 서비스 위한 UPF 분산배치 및 MEC 활성화 전략**<br>1. **UPF 기지국 전진배치**: 원격 코어센터 왕복 시 백홀망 지연(20~50ms) 우회 위해 **UPF**를 무선기지국(RAN) 인접·지사단위 엣지로 전진배치<br>2. **MEC 연동 로컬 트래픽 오프로딩**: 로컬 UPF가 자율주행센서·공장제어 패킷 수신 시 인터넷망 우회 없이 기지국 하단 **MEC 가속서버**로 직접 바이패스 → 지연 2ms 이내 실현<br>3. **SBA 서비스버스 REST API 보안통제**: NF 간 통신이 평문 HTTP/2 JSON 기반 → 가로채기·스푸핑 노출위험, 모든 NF 연동 시 OAuth 2.0 토큰발급+mTLS 암호화 통로 의무화 |
