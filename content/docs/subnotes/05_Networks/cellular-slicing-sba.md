# 5G/6G 이동통신 아키텍처 서브노트

> **두음 머리에 박기 🧠**
> - **광·저·다** (5G 이동통신 3대 서비스 요건: 초**광**대역 eMBB, 초**저**지연 URLLC, **다**연결 mMTC)
> - **에이·유·에스·엔** (SBA 코어망 핵심 기능 컴포넌트: 이동성 관리 **AMF**, 사용자 평면 전송 **UPF**, 세션 제어 **SMF**, 컴포넌트 발견/등록 **NRF**)
> - **티·헤·삼** (6G 이동통신 차세대 물리 규격: 데이터 전송 **T**bps(초당 테라비트), 주파수 대역 **THz**(테라헤르츠), 통신 영역 **3차원** 위성 입체 망)

| :--- | :--- |
| **토픽명** | **5G/6G 이동통신 코어망 서비스 기반 아키텍처 (SBA) 및 네트워크 슬라이싱** |
| **정의** | 코어망의 제어 평면 기능들을 마이크로서비스화하여 REST API로 연동하는 **SBA**와, 5G 요건(광·저·다) 만족을 위해 물리 망을 용도별 가상 분할하는 **네트워크 슬라이싱 기술** |
| **키워드** | eMBB / URLLC / mMTC, SBA (AMF / SMF / UPF / NRF), Network Slicing, 테라헤르츠 (THz), 위성통신 융합 |
| **개념도** | **[ 5G/6G 네트워크 슬라이싱 및 분산 UPF 엣지 아키텍처 ]**<br>`[ 단말 (차량, 스마트폰, 센서) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;`│ (5G 무선기지국 RAN)`<br>&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>`[ 물리 네트워크 (Physical Infrastructure) ] ➔ SDN / NFV 가상 가상화 연동`<br>&nbsp;&nbsp;&nbsp;&nbsp;`├── [ 슬라이스 A : URLLC (자율주행용) ] ──➔ [ 분산 배치 UPF ] ➔ [ MEC 서버 (5ms 극저지연) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;`├── [ 슬라이스 B : eMBB (4K/8K 미디어) ] ──➔ [ 중앙 코어 UPF ] ➔ [ 인터넷 / CDN ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;`└── [ 슬라이스 C : mMTC (스마트 계량기) ] ──➔ [ IoT 관리 서버 ]` |
| **구성요소** | 1. **SBA (Service-Based Architecture)**: 모놀리식 코어를 탈피해 제어 평면의 각 기능을 독립된 NF 단위로 모듈화한 구조<br>2. **AMF (Access and Mobility Management)**: 사용자 단말의 인증, 무선망 접속 및 기지국 간 이동성 관리를 담당<br>3. **SMF (Session Management)**: 가입자의 IP 할당, 세션 수립/해제 및 충전/과금 정책과 UPF의 라우팅 룰 제어<br>4. **UPF (User Plane Function)**: 제어부와 차단되어 실제 가입자의 패킷 데이터를 고속 라우팅 및 캡슐화 전송하는 기능 장치<br>5. **NRF (Network Repository Function)**: 각 NF 서비스 인스턴스의 상태 등록 및 타 NF의 발견/바인딩을 돕는 레지스트리 |
| **비교** | **5G 이동통신 (IMT-2020)**<br>- **최대 속도 / 지연**: 20 Gbps / 1 ms (URLLC 수준 보증)<br>- **주파수 대역**: Sub-6 GHz 및 밀리미터파 (28 GHz 대역 등)<br>- **핵심 아키텍처**: SBA, 네트워크 슬라이싱, CUPS (제어-전송 분리)<br><br>**6G 이동통신 (IMT-2030 - 차세대)**<br>- **최대 속도 / 지연**: 1 Tbps (50배 증가) / 0.1 ms (10분의 1 단축)<br>- **주파수 대역**: 테라헤르츠 (THz, 100GHz~10THz 초고주파)<br>- **핵심 아키텍처**: AI-Native 인공지능 무선망, 저궤도(LEO) 위성 3차원 입체 통신 |
| **차별화** | **초저지연(URLLC) 서비스를 위한 UPF 분산 배치 및 모바일 엣지 컴퓨팅(MEC) 활성화 전략**<br>1. **UPF의 기지국 전진 배치**: 원격지 코어 센터까지 패킷 왕복 시 발생하는 백홀망 네트워크 지연(20~50ms)을 우회하기 위해, 사용자 트래픽 처리 장치인 **UPF**를 무선 기지국(RAN) 바로 옆 또는 지사 단위 엣지로 전진 배치.<br>2. **MEC 연동을 통한 로컬 트래픽 오프로딩**: 로컬 UPF가 자율주행 센서나 공장 제어 패킷을 수신하면 인터넷망으로 내보내지 않고, 해당 기지국 하단에 동거하는 **MEC (Mobile Edge Computing) 가속 서버**로 직접 바이패스하여 지연시간 2ms 이내 실현.<br>3. **SBA 서비스 버스의 REST API 보안 통제**: NF 간의 통신이 평문 HTTP/2 JSON 기반으로 작동함에 따라 API 가로채기 및 스푸핑에 노출될 수 있으므로, 모든 NF 상호 연동 시 OAuth 2.0 기반 토큰 발급 및 mTLS 암호화 통로 연동 의무화. |
