# 기능점수(FP) 및 소프트웨어 비용 산정방법 서브노트

> **두음 머리에 박기 🧠**
> - **EI·EO·EQ·ILF·EIF** (기능점수 5대 요소: 외부입력 **EI**, 외부출력 **EO**, 외부조회 **EQ**, 내부논리파일 **ILF**, 외부인터페이스파일 **EIF**)
> - **규·언·연·품·애** (개발원가 5가지 보정 계수: **규**모보정, **언**어보정, **연**도보정, **품**질·특성보정, **애**플리케이션유형보정)
> - **하·상·알** (SW 비용 산정 3대 분류: **하**향식(전문가·델파이), **상**향식(WBS), **알**고리즘(COCOMO/FP)) |

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **기능점수(Function Point) 방식 및 소프트웨어 개발비/비용 산정 방법론** |
| **정의** | **기능점수(FP)**는 사용자가 요청·인식하는 기능적 요구사항의 양을 측정하는 사용자 관점·언어 독립적 SW 규모 산정 방법(IFPUG, ISO/IEC 20926)이며, **SW 비용 산정**은 하향식(전문가·델파이)·상향식(WBS)·알고리즘(COCOMO·FP) 방식을 프로젝트 진행 단계별 불확실성 콘(Cone of Uncertainty)에 맞춰 복합 활용하여 개발 비용을 예측하는 활동 |
| **키워드** | FP(EI·EO·EQ·ILF·EIF), UFP/AFP, 「SW사업 대가산정 가이드」, COCOMO II, 불확실성의 콘, WBS 상향식 |
| **개념도** | `[측정 범위 설정]` → `[5대 기능요소 분류·복잡도 결정]` → `[UFP = Σ(개수×가중치)]` → `[AFP = UFP×보정계수]` → `[개발원가 = AFP×FP단가]` → `[SW개발비 = 보정원가+직접경비+이윤]`<br>&nbsp;&nbsp;&nbsp;&nbsp;불확실성 콘: `초기(오차 ±4배, 하향식)` → `요구사항(±2배, COCOMO II Early Design)` → `설계(±1.5배, 상세FP)` → `구현(±1.25배, 상향식WBS)` |
| **구성요소** | 1. **FP 5대 요소**: EI(외부입력)·EO(외부출력,계산 있음)·EQ(외부조회,단순)·ILF(내부유지 데이터)·EIF(외부참조 데이터), 복잡도별 가중치(Low/Avg/High) 적용해 UFP 산정<br>2. **5가지 보정 계수**: 규모보정(FP↑→단가↓), 언어보정, 연도보정(물가), 품질·특성보정(비기능요구), 애플리케이션유형보정(임베디드>일반)<br>3. **FP 산정방식 종류**: IFPUG(정교, 상세설계 이후), NESMA(간이, 초기단계), COSMIC(실시간·임베디드, 데이터 움직임 Entry/Exit/Read/Write 기반)<br>4. **비용 산정 3분류**: 하향식(전문가판단/델파이), 상향식(WBS 세부산정), 알고리즘(COCOMO II 공수=A×Size^E×Π(EMi), 17개 비용동인)<br>5. **COCOMO II 3모델**: Application Composition(Object Points, ±4배), Early Design(UFP, ±2배), Post-Architecture(LOC/FP, ±1.5배) |
| **비교** | **FP 방식**<br>- **측정 기준**: 기능(사용자 관점), 언어 독립적<br>- **측정 시점**: 요구사항 단계부터 가능<br><br>**LOC 방식**<br>- **측정 기준**: 코드 줄 수(개발자 관점), 언어 의존적<br>- **측정 시점**: 구현 완료 후에만 측정 가능<br><br>**하향식(전문가/델파이) vs 상향식(WBS)**<br>- 하향식: 초기 적용, 정확도 낮음, 빠른 산정<br>- 상향식: 중~후기 적용, 정확도 높음, 상세 요구사항 필요 |
| **차별화** | **FP 측정 신뢰성 확보 및 복합 산정 실무 전략**<br>1. **CFPS 인증 측정 및 독립 검증**: 측정자 간 20~30% 편차를 통제하기 위해 IFPUG 인증 측정사(CFPS)가 산정하고, 발주자·수급자 간 독립 검증 프로세스를 계약에 명시.<br>2. **교차 검증 기반 신뢰성 확보**: 상향식 WBS 산정과 FP 기반 COCOMO II 알고리즘 산정을 병행하여 결과 차이가 15% 이내면 신뢰, 초과 시 원인 분석 후 재산정.<br>3. **애자일-FP 하이브리드 계약**: 초기 FP는 에픽(Epic) 수준으로 산정하고 스프린트별 완성 FP 누적 또는 스토리포인트×FP전환계수로 변동형 계약(Time & Material)을 적용해 공공 대가산정 기준과 애자일 변경성을 조화.<br>4. **AI 서비스 도입 사업 대가산정(「SW사업 대가산정 가이드」2025 개정)**: SaaS형 AI 도입·온프레미스 AI 모델·AI 기능 내재화·AI 솔루션 커스터마이징 4유형으로 사업을 우선 식별하고, AI 이용료(토큰·API 호출 기반)·인프라비용·개발비(파인튜닝·RAG구축)·운영비를 FP/COCOMO와 분리 산정하여 사용량 기반 원가의 변동성 리스크를 예산에 반영. |
