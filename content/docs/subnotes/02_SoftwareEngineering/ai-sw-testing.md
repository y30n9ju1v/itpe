# AI 소프트웨어 품질 보증 테스트 기법 서브노트

> **두음 머리에 박기 🧠**
> - **메·뉴·안** (AI SW 품질보증 3대 축: **메**타모픽 테스트, **뉴**런 커버리지, **안**전 반경 최대화/형식 검증)
> - **K·N·S·T** (DeepGauge 4대 뉴런 커버리지: **K**MNC 구간분할, **N**BC 경계이탈, **S**NAC 초과활성화, **T**KNC 상위k뉴런)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **AI 소프트웨어 품질 보증을 위한 테스트 기법** |
| **정의** | AI SW는 확률적·데이터의존 특성 → 기존 오라클기법 적용난해 → 입력관계 검증 **메타모픽 테스트**, 뉴런활성화 측정 **뉴런 커버리지(DeepGauge)**, 적대적강건성 검증 **안전반경최대화/형식검증** 3대 특화기법 필요 |
| **키워드** | 테스트 오라클 문제, 메타모픽 관계(MR), KMNC/NBC/SNAC/TKNC, FGSM/PGD, SMT Solver |
| **개념도** | `[ 입력 x ]` → `f(x)` = 고양이<br>`[ 변환 입력 x'(좌우반전) ]` → `f(x')` = 고양이 (메타모픽 관계 성립 검증)<br><br>`[ 딥러닝 모델 뉴런 층 ]` ── 활성화 값 분석 ──▶ `[ KMNC / NBC / SNAC / TKNC 지표 측정 ]`<br><br>`[ 입력 x ]` ± `ε(섭동)` → `[ SMT Solver 형식 검증 ]` → `출력 오차 없음을 수학적으로 증명` |
| **구성요소** | 1. **메타모픽 테스트**: 오라클 없이 입력간 예상관계(MR)로 출력일관성 검증 (예: 좌우반전해도 분류결과 동일)<br>2. **DeepGauge 4대 지표**: KMNC(활성화구간 분할비율), NBC(훈련범위 이탈감지), SNAC(초과활성화 정도), TKNC(상위k뉴런 활성화비율)<br>3. **기본 뉴런커버리지(DeepXplore)**: 활성뉴런수/전체뉴런수 — 품질상관성 낮음, DeepGauge와 병행<br>4. **안전반경 최대화**: FGSM/PGD 적대적예제 → 출력반전 최소임계거리(ε) 산출·최대화<br>5. **형식검증**: SMT Solver(Reluplex/Marabou) → 섭동범위 내 출력오차 없음 수학적 증명 |
| **비교** | **메타모픽 테스트 (블랙박스)**<br>- 목적: 오라클 없는 검증<br>- 접근: 관계기반 일관성 확인<br><br>**뉴런 커버리지 (화이트박스)**<br>- 목적: 모델내부 탐색<br>- 접근: 활성화상태 다각도 측정<br><br>**안전반경/형식검증 (강건성)**<br>- 목적: 적대적공격 저항성 측정·증명<br>- 접근: 통계적테스트(안전반경) + 수학적증명(형식검증) |
| **차별화** | **AI SW 품질보증 통합 파이프라인 전략**<br>1. **단계적 결합 적용**: 초기 메타모픽테스트로 오라클문제 우회·회귀오류 조기포착 → 안정화단계 DeepGauge 4대지표로 화이트박스 커버리지 정량확보 → 배포전 형식검증으로 Safety-Critical 영역 수학적 보증<br>2. **한계 보완**: 높은 뉴런커버리지≠결함없음 → 메타모픽·안전성검증과 반드시 결합판정<br>3. **고위험 도메인 우선 적용**: SMT Solver 형식검증은 고비용 → ASIL 상위 안전필수모듈 우선, 일반모듈은 메타모픽·뉴런커버리지로 비용효율 검증 |
