# AI 소프트웨어 품질 보증 테스트 기법 서브노트

> **두음 머리에 박기 🧠**
> - **메·뉴·안** (AI SW 품질보증 3대 축: **메**타모픽 테스트, **뉴**런 커버리지, **안**전 반경 최대화/형식 검증)
> - **K·N·S·T** (DeepGauge 4대 뉴런 커버리지: **K**MNC 구간분할, **N**BC 경계이탈, **S**NAC 초과활성화, **T**KNC 상위k뉴런)

| 분류 | 기술 기술사 서브노트 작성 예시 (1교시형 포맷) |
| :--- | :--- |
| **토픽명** | **AI 소프트웨어 품질 보증을 위한 테스트 기법** |
| **정의** | AI 소프트웨어는 결정론적이 아닌 확률적·데이터 의존적 특성으로 기존 테스트 오라클 기반 기법 적용이 어려워, 입력 간 관계로 검증하는 **메타모픽 테스트**, 모델 내부 뉴런 활성화를 측정하는 **뉴런 커버리지(DeepGauge)**, 적대적 노이즈 강건성을 검증하는 **안전 반경 최대화/형식 검증**의 3대 AI 특화 테스트 기법이 필요하다 |
| **키워드** | 테스트 오라클 문제, 메타모픽 관계(MR), KMNC/NBC/SNAC/TKNC, FGSM/PGD, SMT Solver |
| **개념도** | `[ 입력 x ]` → `f(x)` = 고양이<br>`[ 변환 입력 x'(좌우반전) ]` → `f(x')` = 고양이 (메타모픽 관계 성립 검증)<br><br>`[ 딥러닝 모델 뉴런 층 ]` ── 활성화 값 분석 ──▶ `[ KMNC / NBC / SNAC / TKNC 지표 측정 ]`<br><br>`[ 입력 x ]` ± `ε(섭동)` → `[ SMT Solver 형식 검증 ]` → `출력 오차 없음을 수학적으로 증명` |
| **구성요소** | 1. **메타모픽 테스트**: 오라클 없이 입력 간 예상 관계(메타모픽 관계, MR)로 출력 일관성 검증 (예: 이미지 좌우 반전해도 분류 결과 동일)<br>2. **DeepGauge 뉴런 커버리지 4대 지표**: KMNC(활성화 구간 분할 비율), NBC(사전 훈련 범위 이탈 감지), SNAC(초과 활성화 정도), TKNC(상위 k개 지배 뉴런 활성화 비율)<br>3. **기본 뉴런 커버리지(DeepXplore)**: 활성화된 뉴런 수/전체 뉴런 수 — 품질 상관성 낮아 DeepGauge와 병행<br>4. **안전 반경 최대화**: FGSM/PGD 적대적 예제로 출력이 반전되는 최소 임계 거리(ε)를 구해 최대화<br>5. **형식 검증**: SMT Solver(Reluplex, Marabou 등)로 섭동 범위 내 출력 오차 없음을 수학적으로 증명 |
| **비교** | **메타모픽 테스트 (블랙박스)**<br>- **목적**: 오라클 없는 검증<br>- **접근**: 관계 기반 일관성 확인<br><br>**뉴런 커버리지 (화이트박스)**<br>- **목적**: 모델 내부 탐색<br>- **접근**: 활성화 상태 다각도 측정<br><br>**안전 반경/형식 검증 (강건성)**<br>- **목적**: 적대적 공격 저항성 측정·증명<br>- **접근**: 통계적 테스트(안전반경) + 수학적 증명(형식 검증) |
| **차별화** | **AI SW 품질 보증 통합 파이프라인 전략**<br>1. **단계적 결합 적용**: 개발 초기엔 메타모픽 테스트로 오라클 문제를 우회해 빠르게 회귀 오류를 잡고, 모델 안정화 단계에서 DeepGauge 4대 지표로 화이트박스 커버리지를 정량 확보한 뒤, 배포 전 형식 검증으로 안전 필수(Safety-Critical) 영역의 수학적 보증을 확보.<br>2. **한계 보완**: 높은 뉴런 커버리지가 결함 없음을 보장하지 않으므로 반드시 메타모픽·안전성 검증과 결합해 판정.<br>3. **자율주행·의료 등 고위험 도메인 우선 적용**: SMT Solver 기반 형식 검증은 연산 비용이 크므로, ASIL 등급이 높은 안전 필수 모듈에 우선 적용하고 일반 모듈은 메타모픽·뉴런 커버리지로 비용 효율적 검증. |
