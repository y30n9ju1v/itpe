# MCDC & 커버리지 서브노트

> **두음 머리에 박기 🧠**
> - **구·결·조·조건결·M·다** (화이트박스 커버리지 강도: **구**문 ➔ **결**정 ➔ **조**건 ➔ **조**건/**결**정 ➔ **M**CDC ➔ **다**중조건)
> - **N + 1** (MCDC 테스트 케이스 수: 개별 조건 수 $n$개일 때 필요한 최소 테스트 케이스 수는 $n+1$개)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **변경 조건/결정 커버리지 (MCDC, Modified Condition/Decision Coverage)** |
| **정의** | 복합조건식 내 각 개별조건이 타조건 영향없이 **전체결정 결과에 독립적으로 영향미치는 경로 검증** → 고신뢰성 화이트박스 커버리지 기법 |
| **키워드** | 구문/결정/조건 커버리지, MCDC ($n+1$ 케이스), 독립적 영향력, DO-178C Level A, ISO 26262 ASIL D |
| **개념도** | `[ 결정 식 : (A or B) and C ]`  (개별 조건 A, B, C 총 3개 ➔ 다중 조건 조합 2³ = 8개 필요)<br>&nbsp;&nbsp;&nbsp;&nbsp;`│ MCDC 적용 (n+1 = 4개 케이스 도출)`<br>&nbsp;&nbsp;&nbsp;&nbsp;`▼`<br>| 번호 | A | B | C | 결과 | 독립성 검증 타겟 |<br>|:---:|:---:|:---:|:---:|:---:|:---|<br>| ① | **T** | F | **T** | **T** | (①, ③) 쌍으로 A의 독립적 결정 영향 증명 |<br>| ② | F | **T** | **T** | **T** | (②, ③) 쌍으로 B의 독립적 결정 영향 증명 |<br>| ③ | **F** | **F** | T | **F** | A와 B가 F일 때 결과 F |<br>| ④ | T | F | **F** | **F** | (①, ④) 쌍으로 C의 독립적 결정 영향 증명 | |
| **구성요소** | 1. **구문커버리지**: 모든 실행문 최소1회 실행 설계<br>2. **결정커버리지(Decision/Branch)**: 각 결정문(IF 등) T/F 최소1회 실행 설계<br>3. **조건커버리지**: 결정문내 개별 조건식 T/F 최소1회 실행 설계<br>4. **MCDC 조건**: 개별조건 $n$개 → 독립적 영향력 검증 테스트케이스 세트 $n+1$개 구성 |
| **비교** | **결정커버리지**<br>- 초점: 분기문 전체결과(T/F) 만족여부<br>- 단점: 개별조건 오류 묻힐가능성<br><br>**조건커버리지**<br>- 초점: 개별조건식 각각 T/F 만족여부<br>- 단점: 개별조건 만족해도 전체결정 결과 한쪽만 실행가능<br><br>**MCDC**<br>- 초점: 개별조건 독립적 영향력 증명<br>- 단점: 케이스수($n+1$) 제어로 조합폭발 방지, 최고수준 품질보증 |
| **차별화** | **고신뢰성 임베디드 SW 표준컴플라이언스·도구연계 전략**<br>1. **국제표준 컴플라이언스**: ISO 26262 ASIL D, 항공 DO-178C Level A, 원자력 IEC 60880 등에서 MCDC 100% 의무규정<br>2. **정적/동적 검증도구(VectorCAST, LDRA) 자동화**: 수작업 CFG그리기·케이스쌍 도출 병목 해소 → 상용도구 IDE연동, 컴파일타임 MCDC 미충족경로 자동탐지<br>3. **결함주입(TFI, SFI) 결합**: SW Fault Injection 시 MCDC 커버경로 위주 결함주입 → 예외처리 로직 강건성 동시검증 |
