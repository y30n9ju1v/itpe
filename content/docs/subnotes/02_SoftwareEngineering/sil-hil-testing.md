# SIL과 HIL 테스팅 서브노트

> **두음 머리에 박기 🧠**
> - **M·S·P·H** (임베디드 검증 4단계 순서: **M**IL(모델) → **S**IL(소프트웨어) → **P**IL(프로세서) → **H**IL(하드웨어), 점진적으로 실물에 근접)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **SIL(Software-in-the-Loop)과 HIL(Hardware-in-the-Loop) 테스팅** |
| **정의** | 임베디드·실시간 제어시스템(자동차, 항공)에서 실제환경 대신 시뮬레이션/실물 하드웨어를 검증루프에 포함하는 기법<br>**SIL**: SW+가상환경모델 PC에서 함께 실행 / **HIL**: 실제 ECU를 실시간 시뮬레이터 연결 → V-모델 통합·시스템테스트 단계 수행 |
| **키워드** | V-모델, ECU, 실시간(Hard Real-Time), MIL/PIL, dSPACE, CAN 통신 |
| **개념도** | `요구사항 ─────────────────────── 인수 테스트`<br>`&nbsp;&nbsp;시스템 설계 ─────────── 시스템 테스트 (HIL)`<br>`&nbsp;&nbsp;&nbsp;&nbsp;SW 설계 ─────── 통합 테스트 (SIL)`<br>`&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;구현 ─── 단위 테스트`<br><br>`[ MIL(모델) ] → [ SIL(SW+가상환경, PC) ] → [ PIL(타겟 프로세서+시뮬레이션) ] → [ HIL(실제 ECU+실시간 플랜트) ]` |
| **구성요소** | 1. **SIL**: 하드웨어 불필요, 비실시간, 저비용, 알고리즘/SW로직 검증, 프로토타입 초기적용<br>2. **HIL**: 실제 ECU 필요, Hard Real-Time, 중~고비용, HW-SW 통합·실시간응답 검증, 양산직전 적용<br>3. **MIL**: 제어알고리즘 모델 자체 시뮬레이션 (SIL 이전단계)<br>4. **PIL**: 타겟 프로세서에서 코드실행, 환경은 시뮬레이션 (SIL·HIL 사이단계)<br>5. **도구**: SIL=MATLAB/Simulink·dSPACE SimulationDesk / HIL=dSPACE SCALEXIO·NI PXI |
| **비교** | **SIL(Software-in-the-Loop)**<br>- 위치: V-모델 통합테스트<br>- 목적: SW로직·알고리즘 자체 정확성 검증<br><br>**HIL(Hardware-in-the-Loop)**<br>- 위치: V-모델 시스템테스트<br>- 목적: 실제 ECU·하드웨어 실시간응답·CAN통신 검증 |
| **차별화** | **자율주행·항공 도메인의 점진적 검증 전략**<br>1. **MIL→SIL→PIL→HIL 단계적 적용**: MIL로 초기 제어알고리즘 신속검증 → C코드생성 후 SIL로 가상 주행시나리오 수만km 저비용 반복검증 → PIL로 타겟 프로세서성능 확인 → 최종 HIL로 실제 ECU CAN통신·실시간응답 검증 (4단계 리스크저감)<br>2. **비용-신뢰도 트레이드오프**: 초기단계일수록 저비용·고반복으로 SIL에서 다양한 시나리오 커버, HIL은 양산직전 핵심시나리오로 최소화 → 검증비용 최적화<br>3. **인증 대응**: 항공분야는 HIL 테스트결과를 FAA 등 인증기관 제출자료로 활용 → 규제대응력 확보 |
