# SIL과 HIL 테스팅 서브노트

> **두음 머리에 박기 🧠**
> - **M·S·P·H** (임베디드 검증 4단계 순서: **M**IL(모델) → **S**IL(소프트웨어) → **P**IL(프로세서) → **H**IL(하드웨어), 점진적으로 실물에 근접)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **SIL(Software-in-the-Loop)과 HIL(Hardware-in-the-Loop) 테스팅** |
| **정의** | 임베디드·실시간 제어 시스템(자동차, 항공)에서 실제 환경 대신 시뮬레이션 또는 실제 하드웨어를 검증 루프에 포함하는 기법으로, **SIL**은 SW와 가상 환경 모델을 PC에서 함께 실행하고 **HIL**은 실제 ECU를 실시간 시뮬레이터에 연결하여 V-모델의 통합·시스템 테스트 단계를 수행한다 |
| **키워드** | V-모델, ECU, 실시간(Hard Real-Time), MIL/PIL, dSPACE, CAN 통신 |
| **개념도** | `요구사항 ─────────────────────── 인수 테스트`<br>`&nbsp;&nbsp;시스템 설계 ─────────── 시스템 테스트 (HIL)`<br>`&nbsp;&nbsp;&nbsp;&nbsp;SW 설계 ─────── 통합 테스트 (SIL)`<br>`&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;구현 ─── 단위 테스트`<br><br>`[ MIL(모델) ] → [ SIL(SW+가상환경, PC) ] → [ PIL(타겟 프로세서+시뮬레이션) ] → [ HIL(실제 ECU+실시간 플랜트) ]` |
| **구성요소** | 1. **SIL**: 하드웨어 불필요, 비실시간, 낮은 비용, 알고리즘/SW 로직 검증, 프로토타입 초기 적용<br>2. **HIL**: 실제 ECU 필요, Hard Real-Time, 중~높은 비용, HW-SW 통합 및 실시간 응답 검증, 양산 직전 적용<br>3. **MIL**: 제어 알고리즘 모델 자체 시뮬레이션 (SIL 이전 단계)<br>4. **PIL**: 타겟 프로세서에서 코드 실행, 환경은 시뮬레이션 (SIL과 HIL 사이 단계)<br>5. **도구**: SIL은 MATLAB/Simulink·dSPACE SimulationDesk, HIL은 dSPACE SCALEXIO·NI PXI |
| **비교** | **SIL (Software-in-the-Loop)**<br>- **위치**: V-모델의 통합 테스트<br>- **목적**: SW 로직·알고리즘 자체의 정확성 검증<br><br>**HIL (Hardware-in-the-Loop)**<br>- **위치**: V-모델의 시스템 테스트<br>- **목적**: 실제 ECU와 하드웨어의 실시간 응답·CAN 통신 검증 |
| **차별화** | **자율주행·항공 도메인의 점진적 검증 전략**<br>1. **MIL→SIL→PIL→HIL 단계적 적용**: 초기 제어 알고리즘은 MIL로 빠르게 검증하고, C코드 생성 후 SIL로 가상 주행 시나리오 수만 km를 저비용 반복 검증한 뒤, PIL로 타겟 프로세서 성능을 확인하고, 최종 HIL로 실제 ECU의 CAN 통신·실시간 응답을 검증하는 4단계 리스크 저감 전략.<br>2. **비용-신뢰도 트레이드오프 관리**: 초기 단계일수록 저비용·고반복으로 다양한 시나리오를 SIL에서 커버하고, HIL은 양산 직전 핵심 시나리오로 최소화하여 검증 비용을 최적화.<br>3. **인증 대응**: 항공 분야는 HIL 테스트 결과를 FAA 등 인증 기관 제출 자료로 활용하여 규제 대응력 확보. |
