# ISMP와 ISP, EA/ITA 비교 서브노트

> **두음 머리에 박기 🧠**
> - **착·방·요·구·이** (ISMP 수행 5단계: **착**수 및 참여자 결정, **방**향성 수립, **요**건 분석, **구**조 및 요건 정의, **이**행 방안 수립)
> - **목·요·서·상** (ISP/ISMP 분기점 사전준비도 4대 체크: **목**표 모델 설명 가능, **요**구사항 파악, **서**비스 구체성, **상**세 기능 제시 가능)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **정보시스템 마스터플랜(ISMP, Information System Master Plan)과 ISP, EA/ITA 비교** |
| **정의** | 특정 SW사업 상세분석·RFP마련 위해 업무·IT현황·요구사항 분석 → **FP 도출가능수준**까지 기능·기술요건 상세기술, 구축전략·이행계획 수립 → 전사로드맵 **ISP**의 추상전략을 SI발주 직전 정밀요건으로 구체화하는 징검다리 |
| **키워드** | ISMP, ISP(정보전략계획), EA/ITA(전사아키텍처), 기능점수(FP), RFP, SW사업 대가산정 가이드 |
| **개념도** | `[ ISP — 전사 전략 ]` (3~5년 로드맵, 거시적)<br>&nbsp;&nbsp;&nbsp;&nbsp;`↓`<br>`[ EA/ITA — 전사 구조 ]` (참조모델·표준 상시 관리)<br>&nbsp;&nbsp;&nbsp;&nbsp;`↓`<br>`[ ISMP — 단일 사업 ]` (FP 산출·RFP 작성, 미시적)<br>&nbsp;&nbsp;&nbsp;&nbsp;`↓`<br>`[ SI 본 사업 발주 ]` (대가산정 완료 후 계약) |
| **구성요소** | 1. **ISMP 5단계**: ①착수/참여자결정(PM·아키텍트 배정)→②방향성수립(ISP/EA연계, 범위획정)→③업무·IT요건분석(As-Is 해체)→④구조·요건정의(To-Be설계, 기능/비기능요구사항)→⑤이행방안수립(FP산출, RFP작성)<br>2. **핵심목적**: ISP한계극복(추상전략→구체요건), 부실발주근절(모호RFP 방지), 객관예산확보(FP기반 과업변경 최소화)<br>3. **수행원칙**: 반복주기 없는 **단년도 단일사이클**, 1회완결<br>4. **산출물**: RFP, 정보시스템 요건기술서, FP산출 내역서 |
| **비교** | **ISP (정보전략계획)**<br>- 관점: 거시적(Macro), 조직전체 3~5년 로드맵<br>- FP도출: 불가(규모추정만)<br><br>**EA/ITA (전사아키텍처)**<br>- 관점: 통제적(Governance), 참조모델·표준 주기적 상시관리<br>- FP도출: 불가(구조관리 집중)<br><br>**ISMP (마스터플랜)**<br>- 관점: 미시적(Micro), 개별시스템 SI발주 직전 필수단계<br>- FP도출: 가능(정밀대가산정 필수) — ISP→EA→ISMP 순 분석범위↓·요건정밀도↑ 계층구조 |
| **차별화** | **부실발주 방지 ISMP 실무 방어전략**<br>1. **사전준비도 체크리스트 기반 분기점 선정**: 목표모델 설명가능·요구사항파악·서비스구체성·기능상세제시 4대지표 전충족 시만 ISMP 직행, 미흡 시 ISP 선행 거버넌스통제<br>2. **FP기반 객관 예산방어**: 「SW사업 대가산정 가이드」 FP산출근거 ↔ 「HW 규모산정 지침」 견적 매핑 → 이행과제 비용합 100%일치 검증<br>3. **DPG 원칙 선제매핑**: 방향성수립·기술요건분석 단계에서 클라우드네이티브·Open API 구조검증 매트릭스 강제연계 → 정책준거성 확보 |
