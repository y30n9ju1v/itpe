# ISMP와 ISP, EA/ITA 비교 서브노트

> **두음 머리에 박기 🧠**
> - **착·방·요·구·이** (ISMP 수행 5단계: **착**수 및 참여자 결정, **방**향성 수립, **요**건 분석, **구**조 및 요건 정의, **이**행 방안 수립)
> - **목·요·서·상** (ISP/ISMP 분기점 사전준비도 4대 체크: **목**표 모델 설명 가능, **요**구사항 파악, **서**비스 구체성, **상**세 기능 제시 가능)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **정보시스템 마스터플랜(ISMP, Information System Master Plan)과 ISP, EA/ITA 비교** |
| **정의** | 특정 SW 개발 사업의 상세 분석과 RFP 마련을 위해 업무·IT 현황과 요구사항을 분석하고 **기능점수(FP) 도출 가능 수준까지** 기능적·기술적 요건을 상세 기술하여 구축 전략 및 이행 계획을 수립하는 활동으로, 전사 정보화 로드맵인 **ISP**의 추상적 전략을 본 사업(SI) 발주 직전 정밀 요건으로 구체화하는 징검다리 |
| **키워드** | ISMP, ISP(정보전략계획), EA/ITA(전사아키텍처), 기능점수(FP), RFP, SW사업 대가산정 가이드 |
| **개념도** | `[ ISP — 전사 전략 ]` (3~5년 로드맵, 거시적)<br>&nbsp;&nbsp;&nbsp;&nbsp;`↓`<br>`[ EA/ITA — 전사 구조 ]` (참조모델·표준 상시 관리)<br>&nbsp;&nbsp;&nbsp;&nbsp;`↓`<br>`[ ISMP — 단일 사업 ]` (FP 산출·RFP 작성, 미시적)<br>&nbsp;&nbsp;&nbsp;&nbsp;`↓`<br>`[ SI 본 사업 발주 ]` (대가산정 완료 후 계약) |
| **구성요소** | 1. **ISMP 5단계**: ①착수/참여자 결정(PM·아키텍트 배정) → ②방향성 수립(ISP/EA 연계, 범위 획정) → ③업무·IT 요건 분석(As-Is 해체) → ④구조 및 요건 정의(To-Be 설계, 기능/비기능 요구사항) → ⑤이행 방안 수립(FP 산출, RFP 작성)<br>2. **핵심 목적**: ISP 한계 극복(추상 전략→구체 요건), 부실 발주 근절(모호한 RFP 방지), 객관적 예산 확보(FP 기반 과업변경 최소화)<br>3. **수행 원칙**: 반복 주기 없는 **단년도 단일 사이클**로 1회 완결 수행<br>4. **산출물**: 제안요청서(RFP), 정보시스템 요건기술서, FP 산출 내역서 |
| **비교** | **ISP (정보전략계획)**<br>- **관점**: 거시적(Macro), 조직 전체 3~5년 로드맵<br>- **FP 도출**: 불가능(규모 추정만)<br><br>**EA/ITA (전사아키텍처)**<br>- **관점**: 통제적(Governance), 참조모델·표준의 주기적 상시 관리<br>- **FP 도출**: 불가능(구조 관리 집중)<br><br>**ISMP (마스터플랜)**<br>- **관점**: 미시적(Micro), 개별 시스템의 SI 발주 직전 필수 단계<br>- **FP 도출**: 가능(정밀 대가산정 필수) — ISP→EA→ISMP 순으로 분석 범위는 좁아지고 요건 정밀도는 높아지는 계층 구조 |
| **차별화** | **부실 발주 방지를 위한 ISMP 실무 방어 전략**<br>1. **사전준비도 체크리스트 기반 ISP/ISMP 분기점 선정**: 목표 모델 설명 가능 여부·사용자 요구사항 파악·서비스 구체성·구현 기능 상세 제시 4대 지표가 모두 충족될 때만 ISMP를 바로 추진하고, 하나라도 미흡하면 ISP를 선행하는 거버넌스 통제.<br>2. **FP 기반 객관적 예산 방어**: 「SW사업 대가산정 가이드」의 FP 산출 근거와 「정보시스템 HW 규모산정 지침」 견적을 매핑하여 이행과제 비용 합이 100% 일치하도록 데이터 무결성을 검증.<br>3. **DPG(디지털플랫폼정부) 원칙 선제 매핑**: 방향성 수립·기술 요건 분석 단계에서 클라우드 네이티브, Open API 기반 구조 검증 매트릭스를 프로세스에 강제 연계하여 정책 준거성 확보. |
