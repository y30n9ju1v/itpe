# 품질보증(QA)/품질통제(QC)와 QC 7도구 서브노트

> **파·특·히·산·체·층·관** (구 QC 7도구: **파**레토도, **특**성요인도, **히**스토그램, **산**점도, **체**크시트, **층**별, **관**리도)
> - **친·연·계·매·PDPC·애·매** (신 QC 7도구: **친**화도, **연**관도, **계**통도, **매**트릭스도, **PDPC**, **애**로우다이어그램, **매**트릭스 데이터 해석)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **품질보증(QA)/품질통제(QC)의 구분과 QC 7도구** |
| **정의** | **QA**: SW 품질목표 달성 위해 개발프로세스 계획·수행·감시하는 예방중심 활동(프로세스 지향)<br>**QC**: 산출물의 품질기준 충족여부 검사 → 결함 발견·수정 활동(제품 지향)<br>**QC 7도구**: 품질데이터 수집·시각화·분석하는 구7도구(수치)+신7도구(언어) 통계기법 집합 |
| **키워드** | QA(프로세스), QC(제품), Barry Boehm 결함비용법칙, 파레토도, 특성요인도, 관리도, Shift-Left |
| **개념도** | `[품질 계획]` → `[QA: 프로세스 감시]`("올바른 방법으로 개발하는가?") → `[개발/테스트/빌드]` → `[QC: 결과물 검사]`("올바른 것을 만들었는가?") → `[품질 개선 PDCA]`<br>&nbsp;&nbsp;&nbsp;&nbsp;QC 7도구 흐름: `체크시트(수집)` → `파레토도(우선순위 80-20)` → `특성요인도(근본원인)` → `관리도(지속 모니터링)` |
| **구성요소** | 1. **QA 주요 활동**: 프로세스감사·요구사항/설계검토·테스트계획검토·형상감사 (독립QA팀, ISO 9001/90003)<br>2. **QC 주요 기법**: 인스펙션(Fagan), 워크스루, 테스팅(동적), 정적분석<br>3. **결함수정비용 법칙(Boehm)**: 요구사항×1 → 설계×5 → 구현×10 → 테스트×25 → 릴리즈후×100<br>4. **구 QC 7도구(수치)**: 파레토도(우선순위)·특성요인도/피시본(근본원인)·히스토그램(분포)·산점도(상관관계)·체크시트(집계)·층별(그룹분리)·관리도(UCL/CL/LCL 이상탐지)<br>5. **신 QC 7도구(언어)**: 친화도(KJ법)·연관도·계통도·매트릭스도(QFD)·PDPC(리스크대응)·애로우다이어그램(PERT/CPM)·매트릭스 데이터해석(유일 수치분석) |
| **비교** | **QA(품질보증)**<br>- 대상/시점: 프로세스 / 개발 전과정, 능동적(Proactive)<br>- 비용효과: 조기예방 → 저비용<br><br>**QC(품질통제)**<br>- 대상/시점: 제품·산출물 / 산출물 완성후, 수동적(Reactive)<br>- 비용효과: 후기발견 → 고비용 — QA·QC는 상호보완 관계 |
| **차별화** | **애자일/DevSecOps 환경의 QA·QC 자동화 통합 전략**<br>1. **CI/CD 파이프라인 내재화**: SonarQube Quality Gate·SAST/DAST를 push마다 자동실행 → QA(표준준수)+QC(결함탐지) 동시자동수행, 스프린트 회고를 QA 개선채널로 활용<br>2. **QC 7도구의 DevOps 대체**: Jira/GitHub Issues 태그통계로 파레토도 자동생성 + Grafana/Datadog으로 관리도 실시간구현 → 수작업 데이터수집 한계 극복<br>3. **Shift-Left 품질비용 절감**: TDD/BDD로 QC를 요구사항·설계단계로 앞당김 → Boehm 결함비용법칙 후행비용 폭증 차단, 특성요인도를 5-Why 기반 RCA템플릿 연계해 장애 재발방지 |
