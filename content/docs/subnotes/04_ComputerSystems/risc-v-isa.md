# RISC-V 오픈소스 명령어 집합 구조 서브노트

> **두음 머리에 박기 🧠**
> - **I·M·A·F·D** (RISC-V 기본/확장 모듈 5종: **I** 기본 정수 연산, **M** 곱셈/나눗셈, **A** Atomic, **F** 단정도 부동소수점, **D** 배정도 부동소수점)
> - **U·S·M** (RISC-V 3대 권한 레벨: **U**ser, **S**upervisor, **M**achine)
> - **단·로·엘** (RISC 설계 3대 특징: **단**순·고정 길이 명령어, **로**드/스토어 구조, **엘**(1)사이클 목표 실행)

| :--- | :--- |
| **토픽명** | **RISC-V (오픈소스 명령어 집합 구조, Instruction Set Architecture)** |
| **정의** | UC Berkeley가 2010년 공개한 **오픈소스 ISA** → 특허·라이선스 비용無, 누구나 칩 설계·제조·판매 가능 → x86·ARM 대안으로 부상하는 **모듈식 RISC 아키텍처** |
| **키워드** | 오픈소스 ISA, 모듈식 확장(I/M/A/F/D), RV32/RV64/RV128, U/S/M 권한 레벨, RISC vs CISC |
| **개념도** | `[ RISC-V 기본 정수 ISA (I) ]`<br>&nbsp;&nbsp;&nbsp;&nbsp;`├─ + M (곱셈/나눗셈) 확장 모듈 선택 추가`<br>&nbsp;&nbsp;&nbsp;&nbsp;`├─ + A (Atomic) 확장 모듈 선택 추가`<br>&nbsp;&nbsp;&nbsp;&nbsp;`├─ + F/D (부동소수점) 확장 모듈 선택 추가`<br>&nbsp;&nbsp;&nbsp;&nbsp;`└─ 워드 길이 선택: RV32I / RV64I / RV128I` |
| **구성요소** | 1. **모듈식 설계**: 기본정수(I) + M/A/F/D 등 확장모듈 선택조합 → 레고식 ISA 구조<br>2. **워드길이**: RV32I/RV64I/RV128I → 32/64/128비트 지원<br>3. **권한레벨 분리**: 비특권(U)-특권(S/M) → 보안·가상화 지원<br>4. **오픈소스 라이선스**: 로열티無 → 누구나 칩 설계·제조·판매 가능 |
| **비교** | **RISC (RISC-V 포함)**<br>- 명령어: 단순·고정길이<br>- 실행: 단일클럭 목표<br>- 파이프라인: 용이<br>- 메모리접근: Load/Store 구조(연산은 레지스터간)<br><br>**CISC (x86)**<br>- 명령어: 복잡·가변길이<br>- 실행: 다수클럭<br>- 파이프라인: 어려움<br>- 메모리접근: 메모리 직접연산 가능 |
| **차별화** | **오픈소스 ISA 채택의 실무적 파급 효과와 생태계 전략**<br>1. **비용·자유도 vs 생태계 성숙도**: 로열티無 → IoT·AI칩 스타트업 진입장벽↓, but ARM 대비 컴파일러·OS·툴체인 생태계 미성숙 → 검증리스크 고려필요<br>2. **국내외 적용동향**: SiFive·GigaDevice(IoT/임베디드MCU), 화웨이·알리바바(AI가속기 NPU), Ventana·Eswin(서버용칩), 삼성·SK하이닉스(스토리지컨트롤러) → 저전력·특수목적 반도체부터 확산<br>3. **RISC vs CISC가 파이프라인에 미치는 영향**: RISC-V 고정길이·단순명령어 → IF단계 디코딩 복잡도↓ → 파이프라인 해저드 발생빈도 감소 |
