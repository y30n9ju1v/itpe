# 유전 알고리즘 서브노트

> **두음 머리에 박기 🧠**
> - **초·적·선·교·돌** (유전 알고리즘 5단계 절차: **초**기 개체군 생성 → **적**합도 평가 → **선**택 → **교**차 → **돌**연변이)
> - **룰·토·엘** (선택(Selection) 3대 방식: **룰**렛 휠, **토**너먼트, **엘**리트)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **유전 알고리즘 (Genetic Algorithm)** |
| **정의** | 다윈의 진화론(자연선택·유전·돌연변이)을 모방한 메타휴리스틱 최적화 알고리즘으로, 복잡한 탐색 공간에서 그래디언트 정보 없이도 전역 최적해(Global Optimum)를 근사 탐색 |
| **키워드** | 염색체/유전자/적합도/개체군, 선택/교차/돌연변이, 엘리트주의, 지역 최적해 탈출, NAS |
| **개념도** | `[ 초기 개체군 생성(무작위) ] → [ 적합도 평가 ]`<br>`→ [ 선택(우수 개체) ] → [ 교차(유전자 교환) ] → [ 돌연변이(무작위 변경) ]`<br>`→ [ 새 개체군 생성 ] → 종료조건? 아니오→적합도 평가 재귀 / 예→최적해 반환` |
| **구성요소** | 1. **기본 용어**: 염색체(해의 인코딩), 유전자(염색체 개별 요소), 적합도(목적함수 값), 개체군(현세대 해 집합)<br>2. **선택**: 룰렛 휠(적합도 비례 확률), 토너먼트(무작위 k개 중 최우수), 엘리트(상위 개체 직접 보존)<br>3. **교차**: 1점/2점/균일 교차로 부모 유전자 교환<br>4. **돌연변이**: 낮은 확률(1~5%)로 유전자 무작위 변경, 지역 최적해 탈출 수단 |
| **비교** | **엘리트주의 (Elitism)**<br>- **역할**: 최우수 개체를 다음 세대로 무조건 보존<br>- **효과**: 수렴 속도·안정성 향상, 최적해 손실 방지<br><br>**돌연변이 (Mutation)**<br>- **역할**: 낮은 확률로 유전자를 무작위 변경<br>- **효과**: 지역 최적해(Local Optimum)에 갇히는 것을 방지, 탐색 다양성 확보 |
| **차별화** | **탐색-활용 균형(Exploration-Exploitation)을 위한 실무 튜닝 전략**<br>1. **적응적 연산자로 세대별 균형 조정**: 초기 세대에는 돌연변이 확률을 높여 넓은 탐색 공간을 커버(Exploration)하고, 수렴이 진행될수록 교차 위주로 전환해 우수해 주변을 정밀 탐색(Exploitation)하는 적응적 연산자 설계.<br>2. **하이브리드(Memetic Algorithm) 결합**: 유전 알고리즘의 전역 탐색 능력에 그래디언트 기반 지역 탐색을 결합하여, 대략적 최적해 후보를 유전 알고리즘으로 찾고 이를 지역 탐색으로 정밀화하는 2단계 전략.<br>3. **다목적 최적화(NSGA-II) 적용**: 스케줄링·라우팅처럼 비용과 시간처럼 상충하는 여러 목적 함수를 동시에 고려해야 하는 실무 문제에는 NSGA-II 같은 다목적 유전 알고리즘으로 파레토 최적해 집합을 도출. |
