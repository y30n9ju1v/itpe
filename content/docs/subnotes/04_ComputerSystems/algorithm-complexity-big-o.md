# 알고리즘 복잡도와 O-Notation 서브노트

> **두음 머리에 박기 🧠**
> - **오·오메가·세타** (점근 표기법 3종: **O**(Big-O, 최악 상한), **Ω**(Big-Omega, 최선 하한), **Θ**(Big-Theta, 평균/상하한 동일))
> - **1·로그·엔·엔로그엔·엔제곱·엔세제곱·이엔·엔팩토리얼** (복잡도 성능 순서: O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!))

---

| 분류 | 기술 기술사 서브노트 작성 예시 (1교시형 포맷) |
| :--- | :--- |
| **토픽명** | **알고리즘 복잡도 (시간·공간복잡도) 및 O-Notation** |
| **정의** | 입력 크기 n에 따른 연산 횟수(시간복잡도) 또는 메모리 사용량(공간복잡도)을 수학적으로 표현하는 알고리즘 복잡도와, 최악의 경우 성능 상한선을 나타내는 알고리즘 비교의 표준 표기법 **O-Notation(Big-O)** |
| **키워드** | O/Ω/Θ, 시간복잡도/공간복잡도, 정렬 알고리즘 복잡도, 안정성(Stable), 분할 정복 |
| **개념도** | `성능 우수 ← O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!) → 성능 저하`<br>`[ 예시 ] O(1): 해시 조회 / O(log n): 이진탐색 / O(n log n): 퀵·병합정렬(평균) / O(n²): 버블·삽입정렬 / O(2ⁿ): 완전탐색` |
| **구성요소** | 1. **시간복잡도**: 입력 크기에 따른 비교·대입 연산 횟수의 증가 양상<br>2. **공간복잡도**: 입력 크기에 따른 메모리(변수·자료구조) 사용량의 증가 양상<br>3. **O-Notation 3종**: O(최악 상한, 실무 표준), Ω(최선 하한), Θ(평균, 상하한 일치)<br>4. **복잡도 계산 규칙**: 상수 제거(O(3n)→O(n)), 낮은 차수 제거(O(n²+n)→O(n²)), 최고 차수 항만 유지 |
| **비교** | **퀵 정렬 (Quick Sort)**<br>- **평균 시간복잡도**: O(n log n)<br>- **최악 시간복잡도**: O(n²) (이미 정렬된 배열에서 피벗 선택 불량 시)<br>- **안정성**: 불안정(Unstable)<br>- **공간복잡도**: O(log n)<br><br>**병합 정렬 (Merge Sort)**<br>- **평균 시간복잡도**: O(n log n)<br>- **최악 시간복잡도**: O(n log n) (항상 일정)<br>- **안정성**: 안정(Stable)<br>- **공간복잡도**: O(n) (추가 배열 필요) |
| **차별화** | **복잡도 분석의 실무 답안 작성 전략**<br>1. **최악/최선/평균 구분의 실무적 의미**: 실시간 시스템처럼 최악의 경우 응답시간이 SLA에 직결되는 환경에서는 O(최악)이 곧 설계 기준이 되며, 평균 성능이 좋아도 최악 시나리오(퀵 정렬의 O(n²))가 발생 가능하면 병합 정렬 등 최악 보장 알고리즘을 대안으로 채택.<br>2. **안정 정렬이 필요한 상황 판단**: 동일 키를 가진 레코드의 원래 순서를 보존해야 하는 다중 필드 정렬(예: 이름순 정렬된 데이터를 부서순으로 재정렬)에는 안정 정렬(병합·삽입·버블)을 선택.<br>3. **지수/팩토리얼 복잡도 회피 전략**: 배낭 문제·TSP처럼 완전탐색이 O(2ⁿ)·O(n!)에 이르는 NP-난해 문제는 동적 계획법·근사 알고리즘·메타휴리스틱(유전 알고리즘 등)으로 다항 시간에 근사해를 구하는 전략 병행. |
