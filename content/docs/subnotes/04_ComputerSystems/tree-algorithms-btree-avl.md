# 트리 자료구조 알고리즘 서브노트

> **두음 머리에 박기 🧠**
> - **전·중·후** (이진트리 3대 순회 방식: **전**위순회 N→L→R, **중**위순회 L→N→R, **후**위순회 L→R→N)
> - **엘·알·엘알·알엘** (AVL Rotation 4대 유형: **LL**(단순 우회전), **RR**(단순 좌회전), **LR**(좌회전 후 우회전), **RL**(우회전 후 좌회전))

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **트리 자료구조 알고리즘 — B트리(B-Tree), 이진트리 순회, AVL 트리** |
| **정의** | 모든 리프 동일깊이 유지하는 자가균형 다진탐색트리 **B트리**, 정해진 순서규칙으로 방문하는 **이진트리 순회**(전위/중위/후위), 균형인수(BF) -1~1 유지 자기균형 이진탐색트리 **AVL 트리**의 총칭 |
| **키워드** | 균형(Balance), 분할/병합, 회전(Rotation), 균형인수(BF), 전위/중위/후위 |
| **개념도** | `[B트리(m=3)] 노드당 키 1~2개, 자식 0 또는 2~3개, 모든 리프 동일 레벨`<br>`&nbsp;&nbsp;삽입: 오버플로우(키>m-1) → 중앙값 부모로 승격 분할`<br>`&nbsp;&nbsp;삭제: 언더플로우(키<⌈m/2⌉-1) → 형제 여유 有: 회전 / 無: 병합`<br>`&nbsp;`<br>`[이진트리 순회 3요소] N(루트), L(왼쪽), R(오른쪽)`<br>`&nbsp;&nbsp;전위 N→L→R, 중위 L→N→R, 후위 L→R→N`<br>`&nbsp;`<br>`[AVL] BF=height(좌)-height(우), \|BF\|≤1 유지 → 위반 시 LL/RR/LR/RL 회전` |
| **구성요소** | 1. **B트리 삽입**: 리프탐색후 정렬삽입 → 키개수 m-1 초과(오버플로우) 시 중앙값 부모로 승격분할, 루트전파 시 높이+1<br>2. **B트리 삭제**: 리프키 즉시삭제, 내부노드키는 선행자/후행자 대체후 리프삭제, 언더플로우 시 형제여유따라 회전/병합<br>3. **이진트리 순회**: 전위(트리복제·디렉터리 상위→하위), 중위(BST 오름차순), 후위(트리/디렉터리 삭제, 후위표기식 계산)<br>4. **AVL 삽입 불균형 처리**: 삽입경로 조상노드 BF 역추적 → \|BF\|=2 발생 시 자식BF로 LL/RR/LR/RL 4분기 판별후 회전 |
| **비교** | **B트리 트레이스**(m=3, 26,57,5,33,72,45 순차삽입 후 72,33,45 순차삭제)<br>- 삽입최종: 루트[26,57]/자식[5],[33,45],[72]<br>- 삭제최종: 루트[26], 좌측자식[5], 우측자식[57]<br><br>**이진트리 순회 트레이스**(F루트, 좌 B(A,D(C,E)), 우 G(I(H)))<br>- 전위: F-B-A-D-C-E-G-I-H / 중위: A-B-C-D-E-F-G-H-I / 후위: A-C-E-D-B-H-I-G-F<br><br>**AVL 트레이스**(2,1,8,9,7,3,6,4,5 순차삽입)<br>- 3삽입 시 RL회전(7이 새 루트로 승격), 4삽입 시 RR 단순좌회전(4가 자리대체)<br>- 최종트리: 루트 7(L:4(L:2(L:1,R:3),R:6),R:8(R:9)), 전노드 \|BF\|≤1 성립 |
| **차별화** | **트리 자료구조 적용 전략**<br>1. **B트리 삭제 시 언더플로우 처리 생략→인덱스 파편화 방지**: 검증된 B+Tree 라이브러리·DBMS 구현 참고, 자체구현 지양<br>2. **차수(m) 작을때 높이증가→I/O 과다 대응**: 디스크 페이지크기(4KB 등) 맞춰 차수설계(RDBMS 인덱스·파일시스템 근간)<br>3. **삭제 시 전위순회 오용→참조끊김 방지**: 자식먼저 정리하는 후위순회를 삭제표준 적용<br>4. **LR/RL을 LL/RR로 오판→트리붕괴 방지**: 자식BF까지 확인하는 4분기 판별로직 단위테스트 검증<br>5. **AVL vs Red-Black Tree 선택기준**: 조회위주→회전적은 AVL, 삽입/삭제빈번→완화균형 Red-Black Tree, 디스크인덱스→B-Tree 계열 |
