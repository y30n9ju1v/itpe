# 정렬 알고리즘 서브노트

> **두음 머리에 박기 🧠**
> - **선·삽·퀵** (3대 비교 기반 정렬: **선**택정렬, **삽**입정렬, **퀵**정렬)
> - **피·분·재** (퀵정렬 3단계 절차: **피**벗 선정 → **분**할(좌/우 그룹) → **재**귀 정렬)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **정렬 알고리즘 — 선택정렬(Selection Sort), 삽입정렬(Insertion Sort), 퀵정렬(Quick Sort)** |
| **정의** | 선택정렬은 최솟값 탐색 후 교환, 삽입정렬은 정렬구간에 삽입, 퀵정렬은 피벗 분할을 반복 적용하는 비교 기반 정렬 기법으로, 미정렬 데이터를 특정 기준(최솟값/삽입위치/피벗)에 따라 정렬하는 구조 |
| **키워드** | 비교 기반 정렬, 분할정복, 피벗(Pivot), 안정성(Stable), O(n log n) |
| **개념도** | `선택정렬: [최솟값 탐색] → [맨앞과 교환] → 미정렬 구간 축소, 반복`<br>`삽입정렬: [현재 원소] → [정렬 구간 삽입 위치 탐색] → 이동 후 삽입, 반복`<br>`퀵정렬  : [피벗 선정] → [작은/큰 그룹 분할] → 분할정복 재귀 정렬` |
| **구성요소** | 1. **선택정렬**: 미정렬 구간에서 최솟값을 찾아 맨 앞과 교환, 미정렬 구간을 하나씩 축소<br>2. **삽입정렬**: 현재 원소를 이미 정렬된 구간의 알맞은 위치에 삽입<br>3. **퀵정렬**: 피벗을 기준으로 작은/큰 그룹으로 분할 후 분할정복 재귀 정렬(Hoare 분할 방식)<br>4. **퀵정렬 분할 트레이스**(배열 [50,80,20,90,40,10,30,60], 피벗=arr[0]=50, Hoare 방식): 1회전 swap(80,30) → 2회전 swap(90,10) → i≥j 종료 → 피벗 배치 swap(arr[0],arr[4])로 결과 [40,30,20,10,**50**,90,80,60], 피벗 50이 인덱스 4로 확정 배치되어 좌측[40,30,20,10](50 미만)·우측[90,80,60](50 초과)로 분할 완료 |
| **비교** | **3대 정렬 알고리즘 비교**<br>- 핵심 동작: 선택정렬(최솟값 찾아 맨앞 교환) / 삽입정렬(알맞은 위치 삽입) / 퀵정렬(피벗 기준 좌우 분할 후 재귀)<br>- 평균 시간복잡도: 선택정렬 O(n²) / 삽입정렬 O(n²) / 퀵정렬 O(n log n)<br>- 최악 시간복잡도: 선택정렬 O(n²) / 삽입정렬 O(n²) / 퀵정렬 O(n²)<br>- 안정성: 선택정렬 불안정 / 삽입정렬 안정 / 퀵정렬 불안정<br>- 추가 메모리: 선택정렬 O(1) / 삽입정렬 O(1) / 퀵정렬 O(log n)(재귀 스택) |
| **차별화** | **정렬 알고리즘의 실무 적용 전략**<br>1. **첫 원소 피벗 고정 시 정렬/역순 데이터에서 O(n²)로 저하되는 문제 방지**: 무작위 피벗 또는 Median-of-Three 기법 적용.<br>2. **편중 재귀로 스택이 O(n)까지 증가해 오버플로우 위험이 발생하는 문제 대응**: 작은 그룹 우선 재귀 + 큰 그룹 꼬리 재귀(Tail Recursion) 최적화.<br>3. **불안정 정렬로 동순위 레코드의 상대 순서가 뒤바뀌는 문제 대응**: 안정성이 필요한 다중 필드 정렬에는 병합정렬 채택 또는 보조 키 추가.<br>4. **대규모 배치 정렬 최적화 트렌드**: Randomized Pivot 및 정렬 크기별로 알고리즘을 혼합하는 하이브리드(Introsort) 기법 적용 증대. |
