# 정렬 알고리즘 서브노트

> **두음 머리에 박기 🧠**
> - **선·삽·퀵** (3대 비교 기반 정렬: **선**택정렬, **삽**입정렬, **퀵**정렬)
> - **피·분·재** (퀵정렬 3단계 절차: **피**벗 선정 → **분**할(좌/우 그룹) → **재**귀 정렬)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **정렬 알고리즘 — 선택정렬(Selection Sort), 삽입정렬(Insertion Sort), 퀵정렬(Quick Sort)** |
| **정의** | 선택정렬(최솟값 탐색후 교환)/삽입정렬(정렬구간에 삽입)/퀵정렬(피벗 분할 반복) → 미정렬 데이터를 기준(최솟값/삽입위치/피벗)별 정렬하는 비교기반 기법 |
| **키워드** | 비교 기반 정렬, 분할정복, 피벗(Pivot), 안정성(Stable), O(n log n) |
| **개념도** | `선택정렬: [최솟값 탐색] → [맨앞과 교환] → 미정렬 구간 축소, 반복`<br>`삽입정렬: [현재 원소] → [정렬 구간 삽입 위치 탐색] → 이동 후 삽입, 반복`<br>`퀵정렬  : [피벗 선정] → [작은/큰 그룹 분할] → 분할정복 재귀 정렬` |
| **구성요소** | 1. **선택정렬**: 미정렬구간 최솟값 탐색→맨앞 교환, 미정렬구간 축소 반복<br>2. **삽입정렬**: 현재 원소를 정렬구간 알맞은 위치에 삽입<br>3. **퀵정렬**: 피벗 기준 작은/큰 그룹 분할 → 분할정복 재귀(Hoare 방식)<br>4. **퀵정렬 분할 트레이스**([50,80,20,90,40,10,30,60], 피벗=arr[0]=50, Hoare): 1회전 swap(80,30)→2회전 swap(90,10)→i≥j 종료→피벗배치 swap(arr[0],arr[4]) → [40,30,20,10,**50**,90,80,60], 인덱스4 확정, 좌[40,30,20,10](50미만)·우[90,80,60](50초과) 분할완료 |
| **비교** | **3대 정렬 비교**<br>- 핵심동작: 선택(최솟값→맨앞교환)/삽입(알맞은위치삽입)/퀵(피벗기준 좌우분할후재귀)<br>- 평균시간: 선택 O(n²)/삽입 O(n²)/퀵 O(n log n)<br>- 최악시간: 선택 O(n²)/삽입 O(n²)/퀵 O(n²)<br>- 안정성: 선택 불안정/삽입 안정/퀵 불안정<br>- 추가메모리: 선택 O(1)/삽입 O(1)/퀵 O(log n)(재귀스택) |
| **차별화** | **정렬 알고리즘 적용 전략**<br>1. **첫원소 피벗고정 시 정렬/역순데이터 O(n²) 저하 방지**: 무작위 피벗 또는 Median-of-Three 적용<br>2. **편중재귀로 스택 O(n) 증가·오버플로우 대응**: 작은그룹 우선재귀+큰그룹 꼬리재귀(Tail Recursion) 최적화<br>3. **불안정정렬로 동순위 레코드 순서역전 대응**: 안정성필요 다중필드 정렬엔 병합정렬 채택 또는 보조키 추가<br>4. **대규모 배치정렬 최적화 트렌드**: Randomized Pivot + 크기별 혼합 하이브리드(Introsort) 적용 증대 |
