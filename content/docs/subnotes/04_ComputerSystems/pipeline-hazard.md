# 파이프라인 및 해저드 서브노트

> **두음 머리에 박기 🧠**
> - **구·데·제** (파이프라인 3대 해저드: **구**조적 해저드 Structural, **데**이터 해저드 Data, **제**어 해저드 Control)
> - **알·오·더블유** (데이터 해저드 RAW: **R**ead **A**fter **W**rite - 아직 쓰지 않은 레지스터를 읽으려 할 때의 해저드)
> - **아·디·이·엠·더블유** (MIPS 5단계 파이프라인: **I**F 명령어 인출 ➔ **I**D 명령어 해독 ➔ **E**X 실행 ➔ **M**EM 메모리 액세스 ➔ **W**B 쓰기 되돌리기)

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **CPU 명령어 파이프라이닝 (Pipelining) 및 파이프라인 해저드 (Hazard)** |
| **정의** | CPU 명령어처리 과정을 여러단계(IF-ID-EX-MEM-WB)로 분할, 중첩실행하는 **파이프라이닝** + 명령어간 의존성으로 정지되는 **해저드(구·데·제) 통제 기술** |
| **키워드** | 5단계 파이프라인, 구조적/데이터/제어 해저드, 포워딩 (Fowarding), 지연 분기, 분기 예측, 1사이클 클록 |
| **개념도** | **[ 5단계 파이프라인 중첩 실행 구조 및 해저드 버블(Stall) ]**<br>시간 (Time) ➔<br>명령어 1: `[ IF ] ➔ [ ID ] ➔ [ EX ] ➔ [ MEM ] ➔ [ WB ]`<br>명령어 2: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`[ IF ] ➔ [ ID ] ➔ [ EX ] ➔ [ MEM ] ➔ [ WB ]`<br>명령어 3: &nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;`[ IF ] ➔ [  Bubble (Stall)  ] ➔ [ ID ] ➔ [ EX ] ➔ [ MEM ] ➔ [ WB ]` (의존성 발생으로 지연) |
| **구성요소** | 1. **MIPS 5단계**: IF(명령어인출), ID(해독/레지스터읽기), EX(연산실행), MEM(메모리참조), WB(레지스터기록)<br>2. **구조적 해저드**: 2개 이상 명령어가 동일HW자원(예: 메모리버스) 동시요구 → 발생 (해결: 메모리/캐시 분리)<br>3. **데이터 해저드**: 이전명령어 결과 미반영 상태에서 다음명령어 참조 → 발생 (RAW, WAR, WAW)<br>4. **제어 해저드**: 분기명령어(Branch)로 다음 명령어주소 미확정 → 발생 (Stall 유발) |
| **비교** | **구조적 해저드 해결책**<br>- 기법: 하드웨어 자원분리<br>- 방법: I-Cache/D-Cache 물리적 분리<br><br>**데이터 해저드 해결책**<br>- 기법: 포워딩(Forwarding)/우회(Bypassing)<br>- 방법: WB 대기없이 EX 결과를 다음EX로 직접 바이패스<br><br>**제어 해저드 해결책**<br>- 기법: 분기예측(Branch Prediction)/지연분기<br>- 방법: 분기결과 가정실행 또는 지연슬롯(Delay Slot) 활용 |
| **차별화** | **고성능 Out-of-Order 실행 아키텍처 및 분기예측 고도화 방안**<br>1. **토마술로 알고리즘 동적스케줄링**: 데이터해저드(WAR/WAW) 방지 → HW 레지스터 리네이밍 + 예약스테이션 도입 → 순서무관 즉시실행<br>2. **하이브리드 분기예측기**: 1-Bit/2-Bit 전역예측기 한계극복 → 지역이력+글로벌이력 혼합 토너먼트식 2단계 예측<br>3. **소프트웨어 루프풀기**: 루프조건제어(제어해저드 빈발) 분기오버헤드↓ → 컴파일러단 루프내부 복사전개 → 조건분기 횟수 정적수축 |
