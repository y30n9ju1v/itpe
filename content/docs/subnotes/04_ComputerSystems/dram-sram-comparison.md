# DRAM과 SRAM 비교 서브노트

> **두음 머리에 박기 🧠**
> - **1T1C·6T** (셀 구조: DRAM은 트랜지스터1개+커패시터1개(**1T1C**), SRAM은 트랜지스터6개 교차결합 인버터(**6T**))

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **DRAM(Dynamic RAM)과 SRAM(Static RAM) 비교** |
| **정의** | 임의의 주소에 동일한 속도로 읽기/쓰기가 가능한 휘발성 반도체 메모리(RAM)로서, 저장 셀 구조에 따라 커패시터 전하로 데이터를 저장하고 주기적 리프레시가 필요한 **DRAM(1T1C)**과, 쌍안정 래치(플립플롭)로 저장해 리프레시가 불필요한 **SRAM(6T)**으로 분류됨 |
| **키워드** | 1T1C/6T 셀 구조, 리프레시(Refresh), 접근시간, 집적도, 메모리 계층구조 |
| **개념도** | `메모리 계층(위로 갈수록 빠름·비쌈)`<br>`CPU 레지스터(SRAM) → L1/L2/L3 캐시(SRAM, ~1~20ns) → 주기억장치(DRAM, ~100ns) → SSD/HDD`<br>`DRAM: 워드선─트랜지스터─커패시터(C), 전하 충전=1/방전=0, 수십ms마다 리프레시`<br>`SRAM: 교차결합 인버터 쌍(P1-P2, N1-N2), 전원 공급 시 데이터 영구 유지` |
| **구성요소** | 1. **DRAM 특성**: 1T1C 셀, 접근시간 40~100ns, 집적도 높음(대용량), 비용 저렴, 리프레시 전력 소비, 주기억장치·DDR5/HBM3에 사용<br>2. **SRAM 특성**: 6T 셀, 접근시간 1~10ns, 집적도 낮음(소용량), 비용 비쌈, 대기전력 낮음, CPU L1/L2/L3 캐시·TLB·레지스터 파일에 사용<br>3. **리프레시 메커니즘**: DRAM은 커패시터 전하가 자연 방전되므로 수십 ms마다 재충전 필요, 리프레시 동안 접근 불가로 성능 영향, ECC로 오류 정정 |
| **비교** | **DRAM**<br>- **저장원리**: 커패시터 전하<br>- **셀 구성**: 1T1C(소형)<br>- **리프레시**: 필요(수십ms 주기)<br>- **접근시간**: 40~100ns(느림)<br>- **용도**: 주기억장치<br><br>**SRAM**<br>- **저장원리**: 쌍안정 래치(플립플롭)<br>- **셀 구성**: 6T(대형, DRAM 대비 6배 면적)<br>- **리프레시**: 불필요<br>- **접근시간**: 1~10ns(빠름)<br>- **용도**: CPU 캐시, 레지스터 |
| **차별화** | **메모리 계층 설계와 AI 인프라 적용 실무**<br>1. **AI 가속기 메모리 대역폭 전략**: LLM 추론 시 수백 GB 모델 가중치 로드가 병목이 되므로, HBM3(TSV로 DRAM 다이를 수직 적층, ~1.2TB/s)을 채택해 대역폭 병목을 완화(H100 HBM3은 A100 대비 추론 처리량 2~3배 향상).<br>2. **서버 메모리 안정성**: 서버용 DRAM은 ECC 메모리를 의무 적용해 단일 비트 오류를 자동 정정하고, 메모리 채널 이중화(Mirrored Channel)·스페어 랭크로 DIMM 장애 시 무중단 운영을 보장.<br>3. **캐시 지역성 최적화**: L1/L2(SRAM) 캐시 지역성을 극대화하는 캐시 라인 정렬·AoS→SoA 변환과 프리페치 전략으로 DRAM 접근 대기(Memory Wall)를 은폐. |
