# DRAM과 SRAM 비교 서브노트

> **두음 머리에 박기 🧠**
> - **1T1C·6T** (셀 구조: DRAM은 트랜지스터1개+커패시터1개(**1T1C**), SRAM은 트랜지스터6개 교차결합 인버터(**6T**))

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **DRAM(Dynamic RAM)과 SRAM(Static RAM) 비교** |
| **정의** | 임의주소 동일속도 읽기/쓰기 휘발성 반도체메모리(RAM) → 셀구조별 커패시터전하 저장·주기리프레시 필요 **DRAM(1T1C)** vs 쌍안정래치(플립플롭) 저장·리프레시 불필요 **SRAM(6T)** |
| **키워드** | 1T1C/6T 셀 구조, 리프레시(Refresh), 접근시간, 집적도, 메모리 계층구조 |
| **개념도** | `메모리 계층(위로 갈수록 빠름·비쌈)`<br>`CPU 레지스터(SRAM) → L1/L2/L3 캐시(SRAM, ~1~20ns) → 주기억장치(DRAM, ~100ns) → SSD/HDD`<br>`DRAM: 워드선─트랜지스터─커패시터(C), 전하 충전=1/방전=0, 수십ms마다 리프레시`<br>`SRAM: 교차결합 인버터 쌍(P1-P2, N1-N2), 전원 공급 시 데이터 영구 유지` |
| **구성요소** | 1. **DRAM 특성**: 1T1C셀, 접근시간 40~100ns, 집적도↑(대용량), 저비용, 리프레시전력 소비, 주기억장치·DDR5/HBM3<br>2. **SRAM 특성**: 6T셀, 접근시간 1~10ns, 집적도↓(소용량), 고비용, 대기전력↓, CPU L1/L2/L3캐시·TLB·레지스터파일<br>3. **리프레시 메커니즘**: 커패시터 자연방전 → 수십ms마다 재충전 필요, 리프레시 중 접근불가(성능영향), ECC로 오류정정 |
| **비교** | **DRAM**<br>- **저장원리**: 커패시터 전하<br>- **셀 구성**: 1T1C(소형)<br>- **리프레시**: 필요(수십ms 주기)<br>- **접근시간**: 40~100ns(느림)<br>- **용도**: 주기억장치<br><br>**SRAM**<br>- **저장원리**: 쌍안정 래치(플립플롭)<br>- **셀 구성**: 6T(대형, DRAM 대비 6배 면적)<br>- **리프레시**: 불필요<br>- **접근시간**: 1~10ns(빠름)<br>- **용도**: CPU 캐시, 레지스터 |
| **차별화** | **메모리 계층 설계 및 AI 인프라 적용 실무**<br>1. **AI가속기 대역폭 전략**: LLM추론 시 수백GB 가중치로드 병목 → HBM3(TSV 수직적층, ~1.2TB/s) 채택 → H100 추론처리량 A100대비 2~3배↑<br>2. **서버 메모리 안정성**: 서버DRAM ECC 의무적용 → 단일비트오류 자동정정, 채널이중화(Mirrored)·스페어랭크 → DIMM장애 무중단<br>3. **캐시 지역성 최적화**: L1/L2(SRAM) 캐시라인정렬·AoS→SoA변환·프리페치 → DRAM 접근대기(Memory Wall) 은폐 |
