# 병렬 컴퓨팅 및 GPU·NPU AI 가속기 서브노트

> **두음 머리에 박기 🧠**
> - **SISD·SIMD·MISD·MIMD** (Flynn 분류 4종: 명령어/데이터 스트림 단일·다중 조합 - **S**ingle/**M**ultiple **I**nstruction, **S**ingle/**M**ultiple **D**ata)
> - **비·명·작·데** (병렬 처리 구현 4수준: **비**트 수준, **명**령어 수준(ILP), **작**업 수준(TLP), **데**이터 병렬)
> - **맥·온·디·활·양** (NPU 5대 구성요소: **맥** MAC 어레이, **온**칩 SRAM, **디**MA 컨트롤러, **활**성화 함수 유닛, **양**자화 지원)
> - **큐·에스·와·텐** (GPU 4대 구성요소: **큐**다코어(CUDA Core), **에스**엠(SM, Streaming Multiprocessor), **와**프(Warp), **텐**서코어(Tensor Core))

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **병렬 컴퓨팅 (Parallel Computing, Flynn 분류), GPU/GPGPU 및 신경망 처리장치 (NPU)** |
| **정의** | 여러 프로세서·코어가 하나의 문제를 동시에 분할 처리하여 성능을 높이는 **병렬 컴퓨팅**과, 수천~수만 개의 단순 코어로 대규모 병렬 데이터 처리에 특화된 **GPU**(그 병렬 연산력을 그래픽 이외 범용 컴퓨팅에 활용하는 것이 **GPGPU**), 딥러닝 신경망의 행렬 곱셈·컨볼루션 연산에 특화되어 전력 효율(TOPS/W)이 뛰어난 전용 병렬 프로세서 **NPU**의 총칭 |
| **키워드** | Flynn 분류(SISD/SIMD/MISD/MIMD), 암달의 법칙, MAC 어레이, TOPS/W, SIMT, CUDA Core/SM/Warp |
| **개념도** | `[ Flynn 분류 ]`<br>`SISD(단일코어) → SIMD(GPU/벡터연산, NPU 유사) → MIMD(멀티코어/클러스터)`<br>`[ CPU vs GPU 설계철학 ]`<br>`CPU: 소수의 강력한 코어(4~64개)+대형캐시+분기예측(직렬·저지연 최적화)`<br>`GPU: SM(Streaming Multiprocessor) 다수 × CUDA Core 수천~수만개(병렬·고처리량 최적화)`<br>`[ NPU 데이터 흐름 ]`<br>`외부 메모리 --DMA--> [ 온칩 SRAM (가중치/활성화값) ] → [ MAC 어레이 병렬 연산 ] → [ 활성화 함수 유닛 ] → 출력` |
| **구성요소** | 1. **Flynn 분류**: SISD(단일 코어), SIMD(GPU·벡터프로세서), MISD(이론적), MIMD(멀티코어·클러스터)<br>2. **암달의 법칙**: S = 1/(P+(1-P)/N), 직렬 부분(P) 비율이 병렬화 성능 향상의 상한을 결정<br>3. **GPU 아키텍처**: CUDA Core(단순 연산 코어, 수천~수만개), SM(Streaming Multiprocessor, 수십~수백 CUDA코어 묶음), SIMT(하나의 명령어를 Warp 단위 32개 스레드가 동시 실행, 분기 시 Warp Divergence로 성능저하), Tensor Core(행렬곱 전용 하드웨어)<br>4. **GPGPU 활용영역**: AI/ML 학습·추론, 과학계산(CFD·분자동역학), 암호화폐 해시, 몬테카를로 시뮬레이션 — 프레임워크는 CUDA(NVIDIA)/OpenCL(벤더중립)/ROCm(AMD)<br>5. **NPU 핵심 요소**: MAC(Multiply-Accumulate) 어레이가 행렬곱 기본 단위, 온칩 SRAM이 메모리 대역폭 절약, 양자화(INT8/INT4)로 전력·메모리 절감<br>6. **메모리 구조 분류**: 공유 메모리(SMP, 캐시 일관성 이슈) vs 분산 메모리(클러스터, 메시지 패싱 MPI, 높은 확장성) |
| **비교** | **CPU**<br>- **코어 수/설계**: 4~64개, 복잡(분기예측·OoO실행)<br>- **캐시**: 크고 지능적(수십MB L3)<br>- **적합 워크로드**: 순차적·복잡분기·저지연<br><br>**GPU**<br>- **코어 수/설계**: 수천~수만개, 단순(SIMT 실행)<br>- **캐시**: 작고 단순(공유 L2), 메모리대역폭 ~4TB/s(HBM3)<br>- **적합 워크로드**: 대규모 병렬·규칙적 데이터(행렬곱)<br><br>**NPU (AI 추론 특화)**<br>- **코어 수**: 수백~수천 MAC 유닛<br>- **용도**: 온디바이스 AI 추론(Edge AI), 전력 효율(TOPS/W) 최우선 |
| **차별화** | **온디바이스 AI 구현을 위한 병렬 아키텍처 선택 전략**<br>1. **병렬화 한계 인식과 하드웨어 선택**: 암달의 법칙에 따라 직렬 처리 비율이 높은 워크로드는 코어 수를 늘려도 성능 향상이 제한되므로, AI 추론처럼 병렬화 친화적(SIMD/SIMT) 워크로드에는 NPU/GPU를, 제어 로직 중심 워크로드에는 CPU를 배치하는 이기종 컴퓨팅(Heterogeneous Computing) 설계.<br>2. **Warp Divergence 방지로 GPU 효율 극대화**: CUDA 커널 내 if-else 분기가 Warp 내 스레드마다 다른 경로를 타면 성능이 최대 32배 저하되므로, 브랜치리스 코드 패턴이나 동일 분기 방향 스레드를 사전 정렬해 Warp Efficiency를 확보.<br>3. **NPU의 전력 효율 우위 활용**: 자율주행 ECU·스마트팩토리 엣지 비전 검사처럼 100ms 이하 응답과 저전력이 동시에 요구되는 환경에서, GPU 대비 TOPS/W가 높은 NPU를 채택해 배터리·발열 제약을 해소.<br>4. **공유 메모리 vs 분산 메모리 확장성 트레이드오프**: 대규모 AI 학습 클러스터는 확장성이 높은 분산 메모리(메시지 패싱) 구조를 채택하되, 단일 노드 내 다중 코어 간에는 공유 메모리로 빠른 통신을 확보하는 하이브리드 설계가 일반적. |
