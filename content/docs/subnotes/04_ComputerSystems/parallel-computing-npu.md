# 병렬 컴퓨팅 및 NPU AI 가속기 서브노트

> **두음 머리에 박기 🧠**
> - **SISD·SIMD·MISD·MIMD** (Flynn 분류 4종: 명령어/데이터 스트림 단일·다중 조합 - **S**ingle/**M**ultiple **I**nstruction, **S**ingle/**M**ultiple **D**ata)
> - **비·명·작·데** (병렬 처리 구현 4수준: **비**트 수준, **명**령어 수준(ILP), **작**업 수준(TLP), **데**이터 병렬)
> - **맥·온·디·활·양** (NPU 5대 구성요소: **맥** MAC 어레이, **온**칩 SRAM, **디**MA 컨트롤러, **활**성화 함수 유닛, **양**자화 지원)

---

| 분류 | 기술 기술사 서브노트 작성 예시 (1교시형 포맷) |
| :--- | :--- |
| **토픽명** | **병렬 컴퓨팅 (Parallel Computing, Flynn 분류) 및 신경망 처리장치 (NPU)** |
| **정의** | 여러 프로세서·코어가 하나의 문제를 동시에 분할 처리하여 성능을 높이는 **병렬 컴퓨팅**과, 딥러닝 신경망의 행렬 곱셈·컨볼루션 연산에 특화되어 전력 효율(TOPS/W)이 뛰어난 전용 병렬 프로세서 **NPU** |
| **키워드** | Flynn 분류(SISD/SIMD/MISD/MIMD), 암달의 법칙, 공유/분산 메모리, MAC 어레이, TOPS/W |
| **개념도** | `[ Flynn 분류 ]`<br>`SISD(단일코어) → SIMD(GPU/벡터연산, NPU 유사) → MIMD(멀티코어/클러스터)`<br>`[ NPU 데이터 흐름 ]`<br>`외부 메모리 --DMA--> [ 온칩 SRAM (가중치/활성화값) ] → [ MAC 어레이 병렬 연산 ] → [ 활성화 함수 유닛 ] → 출력` |
| **구성요소** | 1. **Flynn 분류**: SISD(단일 코어), SIMD(GPU·벡터프로세서), MISD(이론적), MIMD(멀티코어·클러스터)<br>2. **암달의 법칙**: S = 1/(P+(1-P)/N), 직렬 부분(P) 비율이 병렬화 성능 향상의 상한을 결정<br>3. **NPU 핵심 요소**: MAC(Multiply-Accumulate) 어레이가 행렬곱 기본 단위, 온칩 SRAM이 메모리 대역폭 절약, 양자화(INT8/INT4)로 전력·메모리 절감<br>4. **메모리 구조 분류**: 공유 메모리(SMP, 캐시 일관성 이슈) vs 분산 메모리(클러스터, 메시지 패싱 MPI, 높은 확장성) |
| **비교** | **범용 병렬 프로세싱 (CPU/GPU, MIMD·SIMD)**<br>- **특화 연산**: 범용 순차 또는 그래픽 병렬<br>- **코어 수**: CPU 수십 개, GPU 수천~수만 개<br>- **용도**: OS 제어, 학습·렌더링<br><br>**NPU (AI 추론 특화)**<br>- **특화 연산**: 신경망 행렬 연산 전용<br>- **코어 수**: 수백~수천 MAC 유닛<br>- **용도**: 온디바이스 AI 추론(Edge AI), 전력 효율(TOPS/W) 최우선 |
| **차별화** | **온디바이스 AI 구현을 위한 병렬 아키텍처 선택 전략**<br>1. **병렬화 한계 인식과 하드웨어 선택**: 암달의 법칙에 따라 직렬 처리 비율이 높은 워크로드는 코어 수를 늘려도 성능 향상이 제한되므로, AI 추론처럼 병렬화 친화적(SIMD) 워크로드에는 NPU/GPU를, 제어 로직 중심 워크로드에는 CPU를 배치하는 이기종 컴퓨팅(Heterogeneous Computing) 설계.<br>2. **NPU의 전력 효율 우위 활용**: 자율주행 ECU·스마트팩토리 엣지 비전 검사처럼 100ms 이하 응답과 저전력이 동시에 요구되는 환경에서, GPU 대비 TOPS/W가 높은 NPU를 채택해 배터리·발열 제약을 해소.<br>3. **공유 메모리 vs 분산 메모리 확장성 트레이드오프**: 대규모 AI 학습 클러스터는 확장성이 높은 분산 메모리(메시지 패싱) 구조를 채택하되, 단일 노드 내 다중 코어 간에는 공유 메모리로 빠른 통신을 확보하는 하이브리드 설계가 일반적. |
