# 운영체제 스케줄링 (CPU·디스크) 서브노트

> **두음 머리에 박기 🧠**
> - **에프·에스·라·엠** (주요 CPU 스케줄링 4종: **F**CFS, **S**JF/**S**RT, **R**ound **R**obin, **M**LQ/MLFQ)
> - **S·S·T·F·vs·S·L·T·F** (디스크 스케줄링 2대 기준: **S**hortest **S**eek **T**ime **F**irst(탐색시간) vs **S**hortest **L**atency **T**ime **F**irst(회전지연))

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **운영체제 스케줄링 (CPU 스케줄링 및 디스크 스케줄링)** |
| **정의** | 제한된 CPU·디스크 자원을 여러 프로세스·I/O 요청에 효율적으로 배분하는 정책으로, CPU 스케줄링은 프로세스 실행 순서를, 디스크 스케줄링은 I/O 요청 처리 순서(탐색시간·회전지연)를 결정 |
| **키워드** | SJF/SRT, FCFS, Round Robin, MLQ/MLFQ, SSTF/SLTF, 기아(Starvation), Aging |
| **개념도** | `[ CPU 스케줄링 ]`<br>`FCFS(도착순) → SJF(최단작업, 비선점) → SRT(SJF 선점형) → Round Robin(시간할당량 순환) → MLFQ(다단계 큐)`<br>`[ 디스크 스케줄링 ]`<br>`현재 헤드 위치 → SSTF(탐색시간 최소 트랙 선택) → SLTF(동일 트랙 내 회전지연 최소 섹터 선택)` |
| **구성요소** | 1. **SJF (Shortest Job First)**: CPU 버스트 최단 우선, 비선점형, 평균 대기시간 최적이나 긴 프로세스 기아 발생<br>2. **SRT (Shortest Remaining Time)**: SJF의 선점형 버전, 새 프로세스 도착 시 남은시간 비교 선점, 더 낮은 평균대기시간이나 잦은 컨텍스트 스위칭<br>3. **SSTF**: 헤드에서 탐색시간 최소 요청 우선, 원거리 요청 기아 가능<br>4. **SLTF**: SSTF로 트랙 선택 후 동일 트랙 내 회전지연 최소 섹터 순서 결정 |
| **비교** | **SJF (비선점)**<br>- **기준**: 전체 CPU 버스트 시간<br>- **오버헤드**: 낮음<br>- **평균 대기시간**: 낮음<br><br>**SRT (선점)**<br>- **기준**: 남은 CPU 버스트 시간<br>- **오버헤드**: 높음 (빈번한 컨텍스트 스위칭)<br>- **평균 대기시간**: SJF보다 더 낮음 (이론적 최적) |
| **차별화** | **기아 현상 방지와 스케줄링 정책 조합 전략**<br>1. **기아(Starvation)와 Aging 대응**: SJF·SSTF·Priority 스케줄링 모두 특정 프로세스·요청이 계속 밀리는 기아 문제를 공통적으로 안고 있어, 대기 시간에 비례해 우선순위를 점진적으로 높이는 Aging 기법을 결합해 보완.<br>2. **CPU와 디스크 스케줄링의 목적 차이 인식**: CPU 스케줄링은 CPU 사용률·응답시간 최적화가 목표인 반면 디스크 스케줄링은 기계적 탐색시간·회전지연 최소화가 목표이므로, 답안 작성 시 두 영역을 먼저 구분한 뒤 세부 알고리즘을 비교.<br>3. **MLFQ를 통한 실무 절충**: 다단계 피드백 큐(MLFQ)는 짧은 작업에는 SJF와 유사한 이점을, 긴 작업에는 Round Robin의 공정성을 부여하는 방식으로 이론적 알고리즘의 한계를 절충하여 현대 범용 OS(Linux CFS 등)에 적용. |
