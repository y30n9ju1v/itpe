| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **운영체제 스케줄링 (CPU 스케줄링·디스크 스케줄링·실시간 스케줄링 RM/EDF)** |
| **정의** | 한정된 CPU·디스크 자원을 프로세스·I/O요청에 배분하는 정책 → CPU스케줄링(실행순서), 디스크스케줄링(탐색시간·회전지연 기준 처리순서), 실시간스케줄링(RM/EDF, Deadline 준수 최우선 우선순위) |
| **키워드** | SJF/SRT, FCFS, Round Robin, MLQ/MLFQ, SSTF/SLTF, 기아(Starvation), Aging, RM/EDF, WCET |
| **개념도** | `[ CPU 스케줄링 ]`<br>`FCFS(도착순) → SJF(최단작업, 비선점) → SRT(SJF 선점형) → Round Robin(시간할당량 순환) → MLFQ(다단계 큐)`<br>`[ 디스크 스케줄링 ]`<br>`현재 헤드 위치 → SSTF(탐색시간 최소 트랙 선택) → SLTF(동일 트랙 내 회전지연 최소 섹터 선택)`<br>`[ 실시간 스케줄링 ]`<br>`태스크 τ=(C,T,D) → RM(주기 짧을수록 고정 우선순위↑) / EDF(마감 임박 순 동적 우선순위)` |
| **구성요소** | 1. **SJF**: CPU버스트 최단 우선, 비선점 → 평균대기시간 최적, 긴프로세스 기아발생<br>2. **SRT**: SJF 선점형 → 새프로세스 도착시 남은시간 비교선점, 낮은평균대기 but 잦은 컨텍스트스위칭<br>3. **SSTF**: 헤드-탐색시간 최소요청 우선 → 원거리요청 기아가능<br>4. **SLTF**: SSTF 트랙선택 후 동일트랙 내 회전지연 최소섹터 순서결정<br>5. **RM**: 주기(T)↓ → 정적우선순위↑, 활용률상한 U≤n(2^(1/n)-1)(n→∞시 ln2≈69.3%) 충분조건, WCET 정적분석 용이<br>6. **EDF**: 마감임박 태스크 → 동적우선순위, 활용률상한 U=Σ(Ci/Ti)≤1 필요충분조건(이론적최적), 구현복잡도↑ |
| **비교** | **SJF (비선점)**<br>- 기준: 전체 CPU버스트시간<br>- 오버헤드: 낮음<br>- 평균대기시간: 낮음<br><br>**SRT (선점)**<br>- 기준: 남은 CPU버스트시간<br>- 오버헤드: 높음(잦은 컨텍스트스위칭)<br>- 평균대기시간: SJF보다↓(이론적최적)<br><br>**RM (정적)**<br>- 우선순위: 주기기반 고정<br>- 최대활용률: ~69.3%(n→∞)<br>- 적합: Hard Real-Time(정적분석 용이, 항공기·에어백)<br><br>**EDF (동적)**<br>- 우선순위: 마감시간기반 동적재계산<br>- 최대활용률: 100%<br>- 적합: Firm/Soft Real-Time(활용률 최대화, Linux SCHED_DEADLINE) |
| **차별화** | **기아 현상 방지와 스케줄링 정책 조합 전략**<br>1. **기아/Aging 대응**: SJF·SSTF·Priority 공통적으로 기아문제 존재 → 대기시간 비례 우선순위 점진상승 Aging으로 보완<br>2. **CPU vs 디스크 목적차이**: CPU스케줄링 = 사용률·응답시간 최적화 / 디스크스케줄링 = 기계적 탐색시간·회전지연 최소화 → 답안작성 시 영역 구분 우선<br>3. **MLFQ 실무절충**: 짧은작업 → SJF유사 이점, 긴작업 → RR 공정성 → 현대범용OS(Linux CFS) 적용<br>4. **Hard Real-Time RM 선호 이유**: 자율주행ECU(ISO 26262 ASIL-D) → 활용률 EDF보다↓에도 WCET 정적분석·예측가능성으로 RM채택, Linux SCHED_DEADLINE(EDF)은 CBS로 과부하태스크 격리 |
