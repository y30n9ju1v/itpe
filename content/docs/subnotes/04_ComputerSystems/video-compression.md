# 영상압축기법 (무손실·손실·혼합) 서브노트

> - **무·손·혼** (영상압축 3대 분류: **무**손실 Lossless, **손**실 Lossy, **혼**합 Hybrid)
> - **알·허·엘·산** (무손실 압축 4대 기법: **알**RLE 런-렝스, **허**프만 코딩, **엘**LZW, **산**술 코딩)
> - **아이·피·비** (영상 프레임 3종: **I** Intra(독립), **P** Predicted(이전참조), **B** Bidirectional(양방향참조))

| :--- | :--- |
| **토픽명** | **영상압축기법 (Video Compression: 무손실·손실·혼합)** |
| **정의** | 멀티미디어 데이터의 저장·전송 효율을 높이기 위해 데이터 크기를 줄이는 기법으로, 원본 완전 복원이 가능한 **무손실 압축**, 지각 특성을 활용해 데이터를 버리는 **손실 압축**, 둘을 결합한 **혼합 압축(H.264/HEVC 등)**으로 분류 |
| **키워드** | RLE/허프만/LZW, DCT/웨이블릿 변환, 모션 보상, H.264(AVC)/HEVC/AV1/VVC, I/P/B 프레임 |
| **개념도** | `[ 원본 영상 ]`<br>`├─ 무손실: RLE/허프만/LZW/산술코딩 → 완전 복원 가능, 낮은 압축률`<br>`├─ 손실: DCT/웨이블릿/예측부호화/모션보상 → 복원 불가, 높은 압축률`<br>`└─ 혼합(H.264 등): DCT + 모션보상 + CABAC(무손실 엔트로피 코딩) 결합`<br>`[ I프레임(독립) ] → [ P프레임(이전 참조) ] → [ B프레임(양방향 참조, 최고압축) ]` |
| **구성요소** | 1. **무손실 압축**: RLE(반복패턴 압축), 허프만 코딩(빈도 기반 가변길이), LZW(딕셔너리 압축), 산술 코딩(확률모델)<br>2. **손실 압축**: DCT(공간→주파수 변환, 고주파 제거), 웨이블릿 변환(다해상도), 예측 부호화(인접 픽셀 차분), 모션 보상(움직임 벡터)<br>3. **혼합 압축 표준**: H.264(DCT+모션보상+CABAC), HEVC(H.264 대비 50% 향상, 4K/8K), AV1(오픈소스, HEVC 대비 20% 효율), VVC/H.266(차세대, HEVC 대비 50% 향상)<br>4. **프레임 구조**: I(독립 기준점), P(이전 프레임 차분), B(앞뒤 프레임 참조, 최고 압축률) |
| **비교** | **무손실 압축**<br>- **복원**: 완전 복원 가능<br>- **압축률**: 낮음<br>- **적용**: PNG, ZIP, TIFF (품질 손실 불허 데이터)<br><br>**손실 압축**<br>- **복원**: 불가능<br>- **압축률**: 높음<br>- **적용**: JPEG, MPEG, H.264 (사람 지각 특성(HVS) 활용) |
| **차별화** | **혼합 압축 표준의 세대별 진화와 스트리밍 적용 전략**<br>1. **DCT+모션보상+엔트로피코딩 삼중 결합**: H.264/HEVC는 프레임 내에서는 DCT로 공간적 중복을, 프레임 간에는 모션 보상으로 시간적 중복을 제거한 뒤, CABAC 같은 무손실 엔트로피 코딩으로 한 번 더 압축하는 다단계 구조로 높은 압축률과 화질을 동시 확보.<br>2. **세대별 코덱 전환 전략**: OTT·UHD 방송 사업자는 대역폭 절감 효과(HEVC의 H.264 대비 50% 절감)와 라이선스 비용, 재생 기기 호환성을 함께 고려하여 코덱을 선택하며, YouTube·Netflix는 로열티 프리인 AV1로 점진 전환.<br>3. **B프레임의 지연 시간 트레이드오프**: B프레임은 압축률이 가장 높지만 미래 프레임을 참조해야 하므로 인코딩·디코딩 지연이 커져, 실시간 화상회의처럼 저지연이 중요한 경우 B프레임 비중을 낮추거나 배제하는 설계 적용. |
