# 컴퓨터 기본구조와 폰노이만·하버드 아키텍처 서브노트

> **두음 머리에 박기 🧠**
> - **입·출·기·연·제** (컴퓨터시스템 5대 구성요소: **입**력장치, **출**력장치, **기**억장치, **연**산장치(ALU), **제**어장치(CU))
> - **페·디·이** (명령어 처리 사이클 3단계: **Fe**tch 인출, **D**ecode 해독, **E**xecute 실행)
> - **캐·파·와·채** (폰노이만 병목 4대 해결책: **캐**시메모리 계층, **파**이프라인/슈퍼스칼라, **와**이드 메모리 버스, **채**널 인터리빙)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **컴퓨터시스템 5대 구성요소·Stored-program 개념 및 폰노이만(von Neumann) vs 하버드(Harvard) 아키텍처** |
| **정의** | 입력·출력·기억·연산·제어 5대 장치가 버스로 연결되어 명령어와 데이터를 메모리에 저장하고 순차 인출·실행하는 **Stored-program 방식**의 **폰노이만 아키텍처**와, 명령어·데이터 메모리·버스를 물리적으로 분리하여 동시 접근을 가능케 한 **하버드 아키텍처**의 총칭 |
| **키워드** | 5대 구성요소, Stored-program, Fetch-Decode-Execute, 폰노이만 병목, 하버드 아키텍처, 수정된 하버드 |
| **개념도** | `[폰노이만] CPU(ALU+CU) ↔ 단일버스(명령어+데이터 공유) ↔ 단일 주기억장치`<br>`→ IF와 MEM 단계 동시 불가 (구조적 해저드)`<br>`[하버드] CPU(ALU+CU) ↔ 명령어버스 ↔ 명령어메모리`<br>`&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;↔ 데이터버스 ↔ 데이터메모리`<br>`→ IF와 MEM 단계 동시 수행 가능` |
| **구성요소** | 1. **5대 구성요소**: 입력장치(키보드 등), 출력장치(모니터 등), 기억장치(RAM/ROM), 연산장치(ALU, 산술·논리연산), 제어장치(CU, 명령어 해독 후 제어신호 전송)<br>2. **Stored-program (폰노이만, 1945)**: 명령어를 데이터와 함께 메모리에 2진수로 저장해 즉시 교체 가능(ENIAC의 물리적 배선 방식 대비 혁신)<br>3. **명령어 처리 사이클**: ① Fetch(PC가 가리키는 명령어를 IR에 로드, PC 증가) ② Decode(CU가 IR 해독) ③ Execute(ALU 연산 또는 메모리 R/W)<br>4. **하버드 아키텍처**: 명령어 메모리·버스와 데이터 메모리·버스를 물리적으로 분리(DSP·MCU 계열 PIC/AVR/TMS320 적용) |
| **비교** | **폰노이만 아키텍처**<br>- **버스 구조**: 단일 버스(명령어·데이터 공유)<br>- **장점**: 프로그래밍 용이(단일 주소공간)<br>- **단점**: 폰노이만 병목(IF·MEM 직렬화)<br>- **적용**: 초기 PC, 범용 서버<br><br>**하버드 아키텍처**<br>- **버스 구조**: 명령어·데이터 버스 분리(2계통)<br>- **장점**: IF·MEM 동시 수행, 파이프라인 효율↑, WCET 예측 용이<br>- **단점**: 주소공간 분리로 프로그래밍 복잡<br>- **적용**: DSP, MCU, 임베디드 |
| **차별화** | **폰노이만 병목 해결과 수정된 하버드 아키텍처 실무 전략**<br>1. **수정된 하버드 아키텍처**: 현대 x86·ARM Cortex-A CPU는 L1 캐시만 I-Cache/D-Cache로 분리하고 외부 메모리는 단일 버스(폰노이만)를 유지하는 절충안을 채택해 캐시 히트 시 동시 IF+MEM을 달성.<br>2. **폰노이만 병목 5대 해결기법**: 캐시메모리 계층(L1/L2/L3), 파이프라인·슈퍼스칼라·OoOE, 와이드 메모리 버스(HBM/DDR5), 채널 인터리빙, NX/DEP(데이터 영역 코드 실행 하드웨어 차단)를 계층적으로 적용.<br>3. **Hard Real-Time 시스템의 아키텍처 선택**: 자동차 ECU·의료기기처럼 WCET(최악 실행 시간) 예측이 중요한 영역은 캐시 미스의 불확정성을 제거하기 위해 순수 하버드 구조 또는 스크래치패드 메모리(ARM CCM)를 채택해 결정론적 실행 시간을 보장. |
