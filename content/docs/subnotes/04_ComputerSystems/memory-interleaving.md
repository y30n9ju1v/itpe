# 메모리 인터리빙(Memory Interleaving) 서브노트

> **두음 머리에 박기 🧠**
> - **저·고** (인터리빙 2대 유형: **저**위 인터리빙 Low-Order — 하위 비트로 뱅크 결정·연속접근 최적, **고**위 인터리빙 High-Order — 상위 비트로 뱅크 결정·독립접근 최적)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **메모리 인터리빙 (Memory Interleaving)** |
| **정의** | 주기억장치를 k개의 독립 뱅크(Bank)로 분할해 연속 주소를 각 뱅크에 분산 배치함으로써 동시 접근을 가능하게 하는 메모리 대역폭 향상 기법으로, 단일 뱅크 접근 시간(t)이 동일하더라도 k-way 인터리빙 시 이론적으로 k배 대역폭 향상이 가능함 |
| **키워드** | 저위/고위 인터리빙, 뱅크(Bank), 대역폭 향상, 뱅크 충돌, DDR 채널 인터리빙 |
| **개념도** | `4-Way 저위 인터리빙: 주소0→Bank0, 주소1→Bank1, 주소2→Bank2, 주소3→Bank3`<br>`→ t=0 동시 읽기 시작 → t=40ns 동시 완료 → 4워드를 단일 뱅크의 1/4 시간에 획득`<br>`고위 인터리빙: 주소0~3→Bank0(집중), 주소4~7→Bank1(집중)` |
| **구성요소** | 1. **저위 인터리빙(Low-Order)**: Bank번호=주소 mod k(하위비트) → 연속주소 분산배치, 캐시라인채우기·파이프라인 최적, stride=k 시 뱅크충돌<br>2. **고위 인터리빙(High-Order)**: Bank번호=주소/뱅크크기(상위비트) → 연속주소 동일뱅크 집중, 멀티프로세서 독립뱅크 전담 적합, 뱅크충돌 낮음<br>3. **파이프라인 연계접근**: 뱅크접근시간(40ns)보다 짧은간격(10ns)으로 순차개시 → 매 10ns마다 1워드 공급, 캐시미스 시 라인채우기 효과적 |
| **비교** | **저위 인터리빙**<br>- 주소결정: 하위비트(주소 mod k)<br>- 연속접근성능: 우수(병렬접근)<br>- 독립접근성능: 충돌가능(stride=k)<br>- 현대적용: DDR 채널인터리빙, RAID 0<br><br>**고위 인터리빙**<br>- 주소결정: 상위비트<br>- 연속접근성능: 불량(동일뱅크 직렬)<br>- 독립접근성능: 우수(뱅크독립)<br>- 현대적용: NUMA 메모리노드 분리, GPU VRAM 독립파티션 |
| **차별화** | **AI 서버·스토리지 영역 인터리빙 응용실무**<br>1. **AI 학습서버 채널 인터리빙**: DIMM 불균등 장착 → 채널인터리빙 비활성화, 대역폭 절반이하↓ → 채널별 균등장착+`dmidecode -t memory`로 활성채널 확인, 8채널 DDR5 완전활성 시 20~50%↑<br>2. **GPU VRAM 뱅크충돌 최소화**: CUDA stride 접근이 특정뱅크 집중 → 충돌발생 → 패딩(Padding) 추가 or stride=1 재설계로 방지<br>3. **SSD NAND 다이 인터리빙**: 단일 Die 접근지연(70~100μs) 병목 → 컨트롤러가 여러 Die 인터리빙 동시R/W → 처리량 Die수 비례 향상 (스토리지에도 동일원리 적용) |
