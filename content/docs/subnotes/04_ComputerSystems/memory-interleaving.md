# 메모리 인터리빙(Memory Interleaving) 서브노트

> **두음 머리에 박기 🧠**
> - **저·고** (인터리빙 2대 유형: **저**위 인터리빙 Low-Order — 하위 비트로 뱅크 결정·연속접근 최적, **고**위 인터리빙 High-Order — 상위 비트로 뱅크 결정·독립접근 최적)

---

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **메모리 인터리빙 (Memory Interleaving)** |
| **정의** | 주기억장치를 k개의 독립 뱅크(Bank)로 분할해 연속 주소를 각 뱅크에 분산 배치함으로써 동시 접근을 가능하게 하는 메모리 대역폭 향상 기법으로, 단일 뱅크 접근 시간(t)이 동일하더라도 k-way 인터리빙 시 이론적으로 k배 대역폭 향상이 가능함 |
| **키워드** | 저위/고위 인터리빙, 뱅크(Bank), 대역폭 향상, 뱅크 충돌, DDR 채널 인터리빙 |
| **개념도** | `4-Way 저위 인터리빙: 주소0→Bank0, 주소1→Bank1, 주소2→Bank2, 주소3→Bank3`<br>`→ t=0 동시 읽기 시작 → t=40ns 동시 완료 → 4워드를 단일 뱅크의 1/4 시간에 획득`<br>`고위 인터리빙: 주소0~3→Bank0(집중), 주소4~7→Bank1(집중)` |
| **구성요소** | 1. **저위 인터리빙(Low-Order)**: Bank번호=주소 mod k(하위 비트), 연속 주소가 다른 뱅크에 분산되어 캐시 라인 채우기·파이프라인 메모리 단계에 최적, stride=k 패턴에서 뱅크 충돌 발생<br>2. **고위 인터리빙(High-Order)**: Bank번호=주소/뱅크크기(상위 비트), 연속 주소가 같은 뱅크에 집중되어 멀티프로세서의 독립 뱅크 전담에 적합, 뱅크 충돌 낮음<br>3. **파이프라인 연계 접근**: 뱅크 접근시간(40ns)보다 짧은 간격(10ns)으로 뱅크를 순차 개시해 매 10ns마다 1워드씩 공급, 캐시 미스 시 캐시 라인 채우기에 효과적 |
| **비교** | **저위 인터리빙**<br>- **주소 결정**: 하위 비트(주소 mod k)<br>- **연속 접근 성능**: 우수(병렬 접근)<br>- **독립 접근 성능**: 충돌 가능(stride=k)<br>- **현대 적용**: DDR 채널 인터리빙, RAID 0<br><br>**고위 인터리빙**<br>- **주소 결정**: 상위 비트<br>- **연속 접근 성능**: 불량(동일 뱅크 직렬)<br>- **독립 접근 성능**: 우수(뱅크 독립)<br>- **현대 적용**: NUMA 메모리 노드 분리, GPU VRAM 독립 파티션 |
| **차별화** | **AI 서버·스토리지 영역의 인터리빙 응용 실무**<br>1. **AI 학습 서버 채널 인터리빙**: DIMM 슬롯을 불균등하게 채우면 채널 인터리빙이 비활성화되어 대역폭이 절반 이하로 떨어지므로, 채널별 DIMM 균등 장착과 `dmidecode -t memory`로 활성 채널 수를 확인해 8채널 DDR5를 완전 활성화하면 AI 워크로드 성능이 20~50% 향상.<br>2. **GPU VRAM 뱅크 충돌 최소화**: CUDA 커널의 stride 접근 패턴이 특정 뱅크에 집중되면 뱅크 충돌이 발생하므로 패딩(Padding) 추가 또는 stride=1 재설계로 공유 메모리 성능 저하를 방지.<br>3. **SSD NAND 다이 인터리빙**: 단일 NAND Die 접근 지연(70~100μs)이 병목이 되므로 컨트롤러가 여러 Die를 인터리빙해 동시 R/W를 수행하면 처리량이 Die 수에 비례해 향상 — 메모리 인터리빙 원리가 스토리지 영역까지 동일하게 적용됨. |
