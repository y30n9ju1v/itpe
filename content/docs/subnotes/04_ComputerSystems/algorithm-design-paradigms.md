# 알고리즘 설계기법과 그래프 순회 서브노트

> **두음 머리에 박기 🧠**
> - **분·동·탐·백** (4대 알고리즘 설계 기법: **분**할정복, **동**적계획법, **탐**욕법, **백**트래킹)
> - **선·속** (탐욕법 최적해 보장 2대 조건: 탐욕 **선**택 속성(Greedy Choice Property), 최적 부분구조(Optimal Sub**속**tructure))
> - **디·비** (그래프 순회 2대 방식: **D**FS(깊이우선, 스택), **B**FS(너비우선, 큐))

| 항목 | 내용 |
| :--- | :--- |
| **토픽명** | **알고리즘 설계기법(분할정복/동적계획법/탐욕법/백트래킹) 및 그래프 순회(DFS/BFS)** |
| **정의** | 부분문제 분할·조합 전략 **분할정복·DP·탐욕법·백트래킹** + 그래프 전 정점(또는 목표정점) 방문 탐색법 **그래프 순회(DFS/BFS)** 총칭 |
| **키워드** | 부분문제 중복, 메모이제이션, 최적 부분구조, 가지치기(Pruning), 스택/큐 |
| **개념도** | `[문제 해결 전략]`<br>`  ├─ 분할정복(D&C)  : 독립된 부분 문제로 나눠 재귀 해결 후 병합`<br>`  ├─ 동적계획법(DP): 중복 부분 문제를 메모이제이션으로 재사용`<br>`  ├─ 탐욕법(Greedy): 매 단계 국소 최적 선택, 전역 최적 기대`<br>`  └─ 백트래킹      : 해 공간 탐색 중 조건 불만족 시 되돌아감(가지치기)`<br>`&nbsp;`<br>`[그래프 순회]`<br>`  ├─ DFS: 한 방향 최대한 깊이 탐색 후 후퇴, 스택(재귀) 기반`<br>`  └─ BFS: 시작 정점에서 가까운 정점부터 레벨 단위 탐색, 큐 기반` |
| **구성요소** | 1. **분할정복**: 독립된 부분 문제로 분할, 재귀 해결 후 결합 (예: 병합정렬, 퀵정렬, 이진탐색)<br>2. **동적계획법**: 부분 문제 해를 메모이제이션 후 재사용 (예: 피보나치, 0/1 배낭문제, LCS)<br>3. **탐욕법**: 매 단계 국소 최선 선택, 번복 없음 (예: 크루스칼/프림 MST, 다익스트라, 허프만 코딩)<br>4. **백트래킹**: 해 후보 구성 중 제약 위반 시 이전 단계로 회귀 (예: N-Queen, 부분집합 합, 그래프 색칠)<br>5. **BFS 큐 상태변화 예시**(1→6 탐색, 인접리스트 1:{2,3},2:{1,4},3:{1,4},4:{2,3,5},5:{4,6},6:{5}): 큐 [1]→[2,3]→[3,4]→[4]→[5]→[6]→[], 방문 순서 1→2→3→4→5→6, 최단 홉 수 4단계 |
| **비교** | **분할정복 vs 동적계획법**<br>- 부분문제 독립성: 분할정복=독립(중복無, 저장불필요) / DP=중복 반복 → 캐싱 필요<br>- 예: 피보나치 순수재귀 O(2ⁿ) → 메모이제이션 O(n)<br><br>**DFS vs BFS**<br>- 자료구조: DFS=스택(재귀) / BFS=큐<br>- 최단경로 보장: DFS=불가 / BFS=가능(비가중치 그래프 한정)<br>- 대표활용: DFS=위상정렬·사이클검출 / BFS=최단홉탐색·레벨순회 |
| **차별화** | **알고리즘 설계기법·그래프 순회 실무 적용 전략**<br>1. **탐욕선택속성 미성립 오적용 방지**: 속성 사전증명 → DP·ILP 결과와 벤치마크 비교<br>2. **DP 상태공간 다차원 확장 메모리 폭증 대응**: Bitmask DP, 롤링배열(Rolling Array)로 차원축소<br>3. **백트래킹 가지치기 느슨 → 탐색시간 폭발 방지**: 제약전파(Constraint Propagation), 휴리스틱 순서 조기 가지치기<br>4. **대규모 그래프 BFS 메모리 폭증(OOM) 대응**: 양방향 BFS, 분산 그래프 프레임워크(Pregel 등)<br>5. **Visited 관리 누락 → 무한루프 방지**: Enqueue 시점 방문표시 + 순회 타임아웃 안전장치 |
