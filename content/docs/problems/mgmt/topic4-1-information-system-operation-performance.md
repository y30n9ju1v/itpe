## 해설

### 출제 배경 및 의도

공공부문은 매년 수백 개의 정보시스템을 신규 구축하지만, 노후화되거나 활용도가 낮은 시스템의 존치 여부를 판단할 명확한 기준이 없어 예산 낭비가 지속되어 왔다. 행정안전부는 이러한 문제를 해결하기 위해 "정보시스템 운영 성과측정 매뉴얼"을 마련하여 시스템의 계속유지·기능고도화·폐기(단순화) 여부를 객관적으로 판단하는 절차를 제도화하였다.

이 문제는 공공 정보화 사업 관리자가 실제 행정 실무에서 반드시 알아야 하는 제도 기반 지식을 묻는다. 채점위원은 성과관리의 개념적 이해(가)를 넘어 실제 측정 기준(나)과 방법론(다)까지 구체적으로 설명할 수 있는지를 평가하며, 이는 최근 강조되는 디지털서비스 정비·클라우드 전환 정책과도 직결된다.

### 1. 가. 정보시스템 운영 성과관리의 개념

정 의 • 정보시스템 운영 성과관리란 구축이 완료되어 운영 중인 정보시스템의 활용도, 효율성, 비용 대비 효과를 정기적으로 측정하여 시스템의 존속·고도화·폐기 여부를 의사결정하는 관리 활동이다(행정안전부 「정보시스템 운영 성과측정 매뉴얼」).

| 목적 | 내용 |
|------|------|
| 예산 효율화 | 활용도 낮은 시스템 통폐합으로 운영비 절감 |
| 서비스 품질 확보 | 저성과 시스템의 조기 발견 및 개선 |
| 의사결정 지원 | 계속유지/기능고도화/폐기 판단 근거 마련 |
| 정보자원 최적화 | 범정부 정보자원 현황과 연계한 중복 제거 |

```
[정보시스템 운영 성과관리 프로세스]
성과지표 설정 → 데이터 수집 → 성과 측정/분석
   → 등급 판정(우수/보통/미흡) → 조치계획 수립(유지/고도화/폐기)
   → 차년도 예산·정보화계획 반영
```

### 2. 나. 정보시스템 운영 성과측정 기준

| 측정 영역 | 세부 기준 | 내용 |
|---------|---------|------|
| 활용성 | 이용률, 접속자 수 | 시스템 실제 이용 빈도, 목표 대비 실적 |
| 효율성 | 운영비용 대비 효과 | 유지보수 비용 대비 서비스 산출 비율 |
| 안정성 | 장애율, 가용률 | 장애 발생 빈도, 시스템 가동률 |
| 만족도 | 이용자 만족도 조사 | 사용자 설문을 통한 정성적 평가 |
| 노후도 | 시스템 노후연한 | 하드웨어/소프트웨어 사용연한 초과 여부 |

```
[등급 판정 매트릭스 예시]
        활용도 높음        활용도 낮음
효율 높음  계속유지          기능고도화 검토
효율 낮음  기능고도화 필요    폐기/통폐합 검토
```

### 3. 다. 정보시스템 운영 성과측정 방법

| 측정 방법 | 설명 |
|---------|------|
| 정량 측정 | 접속 로그, 트랜잭션 건수, 장애이력 등 시스템 로그 기반 자동 수집 |
| 정성 측정 | 이용자 만족도 설문조사, 담당자 인터뷰 |
| 비교 분석 | 유사기관 시스템과의 벤치마킹, 전년 대비 추세 분석 |
| 종합 평가 | 정량+정성 지표를 가중합산하여 등급(우수/보통/미흡) 산정 |

```
[성과측정 절차 흐름]
① 측정계획 수립(지표·주기 정의)
        ↓
② 데이터 수집(로그 자동수집 + 설문조사)
        ↓
③ 지표별 점수화 및 가중치 적용
        ↓
④ 종합등급 산정 및 위원회 심의
        ↓
⑤ 결과 환류(예산 반영, 정비계획 수립)
```

- 측정 결과 "미흡" 등급 시스템은 정보시스템 존치 타당성 재검토 대상으로 분류되어, 클라우드 전환 또는 폐기 대상으로 우선 검토된다.  "끝"

### 실무 제언

**정량 지표 편중에 따른 실질 가치 왜곡**
- **챌린지**: 접속률·트랜잭션 건수와 같은 정량 지표만으로 평가하면, 이용 빈도는 낮지만 법정 의무·재난 대응용으로 반드시 유지해야 하는 시스템이 폐기 대상으로 오판될 수 있다.
- **제언**: 법적 의무 유지 시스템, 재난·안전 관련 시스템은 별도의 예외 평가 트랙으로 분리하고, 정성 지표(정책적 필요성)에 대한 가중치를 별도로 부여해야 한다.

**부처 간 성과측정 기준의 비일관성**
- **챌린지**: 기관별로 측정 주기와 지표 가중치가 상이하여 범정부 차원의 비교·통합 관리가 어려운 경우가 많다.
- **제언**: 행정안전부 매뉴얼을 기반으로 한 표준 성과측정 템플릿을 전 기관에 의무 적용하고, 범정부 정보자원 관리시스템(EA포털)과 연계해 통합 대시보드로 관리해야 한다.

**클라우드 전환과 성과측정 체계의 연계**
- **챌린지**: 디지털플랫폼정부 정책에 따라 노후 시스템의 클라우드 전환이 가속화되고 있으나, 기존 온프레미스 중심 성과지표로는 클라우드 전환 후 비용효율성을 제대로 평가하기 어렵다.
- **제언**: 클라우드 환경에 맞는 신규 지표(오토스케일링 활용률, 종량제 비용 최적화율)를 추가하여 성과측정 매뉴얼을 클라우드 네이티브 시대에 맞게 고도화해야 한다.
