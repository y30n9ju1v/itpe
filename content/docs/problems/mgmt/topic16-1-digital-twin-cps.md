## 문제

우리나라는 2018년에 도시혁신 및 미래성장동력 창출을 위한 스마트시티 추진전략이 발표되었다. 스마트시티 추진전략에서 미래혁신 기술로 디지털 트윈(Digital Twin)을 분류하고 있다. 다음의 질문에 대하여 설명하시오.

## 해설

### 출제 배경 및 의도

디지털트윈은 물리적 실체와 가상 모델을 실시간으로 동기화하여 시뮬레이션·예측·최적화를 수행하는 CPS(Cyber-Physical System)의 핵심 구현체이다. 정부는 2018년 스마트시티 국가전략(세종 5-1, 부산 에코델타시티)에서 디지털트윈을 도시 단위 운영 플랫폼의 핵심 기술로 지정하였다.

출제자는 제조 현장 중심으로 알려진 디지털트윈 개념을 "도시" 단위로 확장 적용할 수 있는지를 검증하고자 한다. 단일 공장 설비 시뮬레이션과 달리 도시 디지털트윈은 교통·에너지·재난·환경 등 이종 데이터의 통합, 대규모 3D 공간정보(BIM, GIS) 처리, 실시간 IoT 센서 연동이라는 훨씬 복잡한 요구사항을 갖는다. 이는 최신 스마트시티·메타버스 정책 트렌드와 직결되는 시의성 있는 주제이다.

### 1. 디지털트윈(Digital Twin) 및 CPS 개념

정 의  • 디지털트윈이란 현실 세계의 사물·공간·프로세스를 가상 공간에 동일하게 복제하고, 실시간 데이터로 동기화하여 시뮬레이션·분석·예측을 수행하는 기술을 의미한다.
       - CPS(Cyber-Physical System)는 물리 세계와 사이버 세계를 센서·네트워크로 긴밀히 결합한 시스템으로, 디지털트윈은 CPS를 구현하는 대표 수단이다.

```
[디지털트윈 동작 원리]

물리 세계(Physical)  ──센서 데이터 수집(IoT)──▶  가상 세계(Virtual/Cyber)
     ▲                                                  │
     │                                                  ▼
  제어/피드백 반영  ◀── 시뮬레이션·분석·예측 결과 ── 디지털 모델(3D/AI)
```

### 2. 가. 디지털 트윈 플랫폼의 특징

| 특징 | 설명 |
|------|------|
| 실시간 동기화(Mirroring) | IoT 센서로 물리 객체의 상태를 실시간 수집하여 가상 모델에 반영 |
| 3D 시각화 | BIM, GIS 기반 공간정보를 3D로 렌더링하여 직관적 모니터링 제공 |
| 시뮬레이션·예측 | What-if 시나리오 분석으로 사전 검증 및 최적 대안 도출 |
| 양방향 상호작용 | 가상 모델에서의 제어 결과가 실제 물리 객체에 피드백되어 반영 |
| 데이터 통합 | 이기종 센서·행정 데이터·민간 데이터의 통합 수집·연계 |

### 3. 나. 스마트시티를 위한 디지털트윈 기술 및 다. 기술적용 방안

1) 나. 스마트시티 디지털트윈 핵심 기술

```
[스마트시티 디지털트윈 계층 구조]

Layer 4. 서비스   : 교통제어, 재난대응, 에너지관리, 도시계획 시뮬레이션
Layer 3. 분석/AI  : 빅데이터 분석, 예측 모델링, 시나리오 시뮬레이션
Layer 2. 플랫폼   : 3D 공간정보(BIM/GIS) 통합, 데이터허브(도시데이터센터)
Layer 1. 수집     : IoT 센서, CCTV, 드론 매핑, GPS/GNSS
```

| 기술 요소 | 역할 |
|---------|------|
| 3D 공간정보(BIM/GIS) | 도시 건물·지형·인프라의 정밀 3D 모델 구축 |
| IoT 센서 네트워크 | 교통량·대기질·에너지 사용량 등 실시간 수집 |
| 데이터허브(도시데이터센터) | 이기종 데이터 표준화·통합·연계 관리 |
| AI/빅데이터 분석 | 교통 혼잡 예측, 재난 확산 시뮬레이션 |
| 5G/엣지컴퓨팅 | 대용량 실시간 데이터 저지연 처리 |

2) 다. 디지털트윈 기술적용 방안

| 적용 영역 | 활용 방안 |
|---------|----------|
| 교통 | 실시간 교통 시뮬레이션으로 신호체계 최적화, 자율주행 테스트베드 |
| 에너지 | 스마트그리드 연계로 에너지 수요 예측 및 분산자원 최적화 |
| 재난안전 | 침수·화재 확산 시뮬레이션으로 사전 대피 경로 수립 |
| 도시계획 | 신도시 개발 전 일조권·조망권·교통영향 사전 시뮬레이션 |
| 환경 | 대기질 확산 모델링으로 미세먼지 저감 정책 사전 검증 |

- 스마트시티 디지털트윈은 물리적 도시 인프라와 가상 모델을 실시간 연동하여, 정책 결정 이전에 시뮬레이션 검증을 거치는 데이터 기반 도시운영 체계로 발전하고 있다.  "끝"

### 실무 제언

**이기종 데이터 표준화 부재**
- **챌린지**: 지자체·공공기관마다 서로 다른 데이터 포맷과 좌표계를 사용하여 도시 디지털트윈 구축 시 데이터 통합에 막대한 비용이 소요된다.
- **제언**: 국토교통부의 '디지털트윈국토' 표준(3D 공간정보 표준, CityGML 등)을 의무 적용하고, 데이터허브 단계에서 ETL 표준화 파이프라인을 선행 구축해야 한다.

**대규모 실시간 처리 인프라 부담**
- **챌린지**: 도시 전체의 IoT 센서 데이터를 실시간으로 3D 렌더링하고 시뮬레이션하려면 막대한 컴퓨팅·네트워크 자원이 필요하다.
- **제언**: 5G 특화망과 엣지컴퓨팅을 결합하여 현장에서 1차 필터링·전처리를 수행하고, 중앙 클라우드에는 요약 데이터만 전송하는 계층적 아키텍처를 설계해야 한다.

**시민 참여형 디지털트윈으로의 확장**
- **챌린지**: 관 주도 디지털트윈은 행정 효율화에 그쳐 시민 체감도가 낮다.
- **제언**: 메타버스 플랫폼과 연계하여 시민이 가상 공간에서 도시계획안에 직접 의견을 제시하는 리빙랩(Living Lab)형 거버넌스로 확장해야 한다.
