## 문제

IT 투자평가 기법에 대하여 다음 물음에 답하시오.

- 가. IT 투자 평가의 정량적 및 정성적 평가 항목 및 내용을 설명하시오
- 나. 매출증대의 재무적 목표 달성을 위해 고객에게 배송시간 절감과 만족도 증가를 제공하려는 기업의 BSC(Balanced Score Card) 전략맵을 작성하시오.

## 해설

### 출제 배경 및 의도

이 문제는 IT 투자평가 기법을 다루는 다른 문제(122회)와 달리, 정량·정성 평가항목의 개념 설명(가)에서 나아가 실제 사례에 BSC 전략맵을 "작성"하도록 요구하는 응용형 문제이다. 즉 이론 지식을 실제 비즈니스 시나리오(배송시간 절감, 고객만족 증가 → 매출증대)에 적용하는 능력을 평가한다.

전자상거래·물류 산업에서 배송 리드타임 단축은 곧 고객 이탈 방지와 매출 증대의 핵심 동인이다. 채점위원은 응시자가 Kaplan & Norton의 BSC 4대 관점(재무, 고객, 내부프로세스, 학습과 성장)의 인과관계 사슬(Cause-Effect Chain)을 실제 전략맵으로 도식화할 수 있는지를 중점적으로 평가한다.

### 1. 가. IT 투자평가의 정량적/정성적 평가항목

정 의 • IT 투자평가란 IT 투자의 경제적 타당성과 전략적 기여도를 재무적·비재무적 관점에서 종합 판단하는 활동이다.

| 구분 | 항목 | 산식/내용 |
|------|------|---------|
| 정량적 평가 | ROI | (효과-비용)/비용 × 100 |
| | NPV | Σ(현금흐름/(1+r)^t) - 초기투자 |
| | IRR | NPV=0이 되는 할인율 |
| | TCO | 도입+운영+유지보수 총비용 |
| 정성적 평가 | 고객가치 | 고객만족도, 충성도, 브랜드 이미지 |
| | 조직역량 | 프로세스 혁신, 직원 역량 강화 |
| | 전략기여도 | 사업전략과의 정렬성, 시장 대응력 |
| | 리스크 관리 | 규제준수, 보안 리스크 완화 |

- 정량적 평가는 투자의 경제성을 객관적으로 검증하지만, 정성적 평가 없이는 브랜드 가치·고객경험 개선과 같은 전략적 효과를 놓치게 되므로 양자의 균형이 필수적이다.

### 2. 나. BSC 4대 관점과 전략맵의 인과관계 구조

정 의 • BSC(Balanced Scorecard)는 재무 관점 외 고객, 내부프로세스, 학습과 성장 관점을 포함하여 조직의 전략을 균형 있게 측정·관리하는 성과관리 체계이다(Kaplan & Norton).

```
[BSC 4대 관점 인과관계 구조]

  재무(Financial)         "매출증대"
        ▲
  고객(Customer)          "배송시간 절감" + "고객만족도 증가"
        ▲
  내부프로세스(Internal)   "물류 프로세스 최적화" (IT 시스템 활용)
        ▲
  학습과성장(Learning&Growth) "물류관리시스템(WMS/TMS) 역량 확보"
```

### 3. 배송시간 절감·만족도 증가 기업의 BSC 전략맵 작성

```
[전략맵: 배송 리드타임 단축을 통한 매출증대 전략]

┌─────────────────────────────────────────────┐
│ 재무 관점(Financial)                          │
│   ▶ 목표: 매출 증대                            │
│   ▶ 지표: 매출성장률, 재구매율                 │
└───────────────────▲───────────────────────────┘
┌───────────────────┴───────────────────────────┐
│ 고객 관점(Customer)                            │
│   ▶ 목표: 배송시간 절감 / 고객만족도 증가       │
│   ▶ 지표: 평균 배송 리드타임, NPS, 고객이탈률   │
└───────────────────▲───────────────────────────┘
┌───────────────────┴───────────────────────────┐
│ 내부프로세스 관점(Internal Business Process)   │
│   ▶ 목표: 물류/배송 프로세스 최적화             │
│   ▶ 지표: 오배송률, 물류센터 처리시간,          │
│            실시간 배송추적 정확도                │
│   ▶ IT 수단: WMS, TMS, 라스트마일 최적화 알고리즘│
└───────────────────▲───────────────────────────┘
┌───────────────────┴───────────────────────────┐
│ 학습과 성장 관점(Learning & Growth)             │
│   ▶ 목표: 물류 IT 시스템 및 데이터 분석 역량 확보│
│   ▶ 지표: 물류데이터 분석 인력 비율,             │
│            시스템 가동률, 예측모델 정확도        │
└─────────────────────────────────────────────┘
```

| 관점 | 전략목표 | KPI 예시 | IT 투자 요소 |
|------|---------|---------|-------------|
| 재무 | 매출 증대 | 매출성장률 | - |
| 고객 | 배송시간 절감, 만족도 증가 | 리드타임, NPS | 배송추적 앱 |
| 내부프로세스 | 물류 프로세스 최적화 | 오배송률, 처리시간 | WMS/TMS 도입 |
| 학습과 성장 | IT/데이터 역량 확보 | 인력 비율, 시스템 가동률 | AI 수요예측 시스템 |

- 하위 관점(학습과 성장)의 IT 투자가 상위 관점(재무)의 매출증대로 이어지는 인과사슬을 명확히 하는 것이 전략맵 작성의 핵심이다.  "끝"

### 실무 제언

**후행지표와 선행지표의 혼동**
- **챌린지**: 다수 기업이 재무 관점의 매출(후행지표)만 관리하고, 내부프로세스·학습성장 관점의 선행지표를 소홀히 하여 문제 발생 후에야 대응하는 경우가 많다.
- **제언**: 배송 리드타임, 시스템 가동률과 같은 선행지표를 실시간 모니터링하는 IT 대시보드를 구축하여 사전적(Proactive) 경영관리를 실현해야 한다.

**IT 투자와 BSC 지표의 연계 부재**
- **챌린지**: IT 부서가 WMS/TMS를 도입하고도 이를 BSC 지표(오배송률, NPS)와 연결하지 못해 투자 효과를 입증하지 못하는 경우가 있다.
- **제언**: IT-BSC를 전사 BSC의 내부프로세스·학습성장 관점과 명시적으로 매핑하여 IT 투자의 재무적 기여를 정량적으로 추적·보고해야 한다.

**공급망 가시성 확보를 위한 실시간 데이터 활용**
- **챌린지**: 라스트마일 배송 지연은 예측이 어려워 고객 만족도 저하로 직결된다.
- **제언**: IoT 기반 실시간 위치추적과 AI 수요예측을 결합한 스마트 물류 플랫폼에 투자하여 학습과성장 관점의 역량을 고도화하고 이를 전략맵 전체에 파급시켜야 한다.
