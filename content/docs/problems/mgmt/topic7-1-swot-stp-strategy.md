## 문제

글로벌 회사인 K전자(스마트폰 제조 회사)의 경우, 대만, 베트남 등의 부품 공급망을 통해 가격차별화에 성공하면서, 매출액이 증가했었다. 그러나, 최근 들어 경쟁업체인 중국 제조사들의 값싼 스마트폰이 대거 출시되면서 판매량이 급감하고 있다. 이러한 위기를 극복하기 위해 새로운 전략을 수립하고자 한다. SWOT분석 및 마케팅 STP를 활용하여 새로운 전략을 제시하시오.

## 해설

### 출제 배경 및 의도

이 문제는 정보처리기술사 시험에서 드물게 순수 경영전략 프레임워크의 실제 적용 사례를 요구하는 응용형 문제이다. 스마트폰 산업은 중국 제조사의 저가 공세로 가격 경쟁이 치열해진 대표적 레드오션 사례이며, K전자와 같은 기업이 가격이 아닌 다른 축(기술 차별화, 시장 세분화)으로 경쟁우위를 재정립해야 하는 상황을 다룬다.

채점위원은 SWOT 분석으로 현재 상황을 구조화하고, 이를 근거로 STP(Segmentation, Targeting, Positioning) 전략을 논리적으로 도출하는 연계 능력을 평가한다. 단순히 두 프레임워크를 따로 설명하는 것이 아니라, SWOT의 분석 결과가 STP 전략 수립의 입력값이 되는 인과적 흐름을 구성할 수 있는지가 핵심 평가 포인트다.

### 1. SWOT 분석 프레임워크

정 의 • SWOT 분석이란 조직의 내부 강점(Strengths)·약점(Weaknesses)과 외부 기회(Opportunities)·위협(Threats)을 매트릭스로 정리하여 전략 방향을 도출하는 경영전략 분석기법이다.

```
[K전자 SWOT 분석 매트릭스]

              강점(S)                    약점(W)
        ┌──────────────────┬──────────────────┐
        │ - 대만/베트남 공급망  │ - 저가 경쟁력 열위   │
        │   기반 원가 경쟁력    │ - 브랜드 프리미엄     │
        │ - 글로벌 유통망      │   포지셔닝 부족       │
        ├──────────────────┼──────────────────┤
 기회(O) │ SO전략            │ WO전략             │
        │ 프리미엄 라인        │ 중저가 라인 R&D      │
        │ 확대로 신흥시장 공략  │ 투자로 원가 추가절감  │
        ├──────────────────┼──────────────────┤
 위협(T) │ ST전략            │ WT전략             │
        │ 공급망 강점 활용해    │ 신흥국 전용 초저가    │
        │ 프리미엄 차별화 강화  │ 라인업 별도 런칭     │
        └──────────────────┴──────────────────┘

기회(O): 신흥시장 스마트폰 수요 증가, 5G/폴더블 신기술 수요
위협(T): 중국 제조사 저가 공세, 가격 경쟁 심화
```

### 2. 마케팅 STP 전략

정 의 • STP란 시장을 세분화(Segmentation)하고, 공략할 목표시장을 선정(Targeting)하며, 자사 제품의 차별적 위치를 설정(Positioning)하는 마케팅 전략 수립 프로세스이다.

```
[STP 프로세스]
① Segmentation(세분화) → ② Targeting(표적화) → ③ Positioning(포지셔닝)
```

| 단계 | K전자 적용 내용 |
|------|----------------|
| Segmentation | 가격민감층(저가 시장) / 기술혁신 추구층(프리미엄 시장) / 실용중시층(중가 시장)으로 세분화 |
| Targeting | 중국 저가 경쟁이 치열한 저가 세그먼트 대신, 기술혁신 추구층(프리미엄) + 실용중시층(중가) 이중 타겟팅 |
| Positioning | "가격이 아닌 기술과 품질의 스마트폰" 포지셔닝 - 폴더블/5G 등 차별화 기술 강조 |

```
[포지셔닝 맵]
        고가격
          │
  프리미엄 K전자(신규) ● 
          │        ● 애플 등 선도 브랜드
──────────┼────────────── 고기술
  중국제조사 ●      │
          │        
        저가격
```

### 3. SWOT-STP 연계 전략 도출

| SWOT 도출 전략 | STP 연계 | 최종 전략 방향 |
|--------------|---------|--------------|
| ST전략(공급망 강점 → 프리미엄 차별화) | Targeting: 기술혁신 추구층 | 폴더블/5G 프리미엄 라인 강화, 고마진 확보 |
| WO전략(중저가 R&D 투자) | Segmentation: 실용중시층 신설 | 가성비 중가 라인 별도 런칭으로 볼륨 방어 |
| WT전략(신흥국 초저가 라인) | Targeting: 신흥시장 가격민감층 | 로컬 생산기지 활용한 초저가 서브 브랜드 |

- 결론적으로 K전자는 저가 경쟁에서 정면 대응하기보다, 공급망 강점을 활용한 프리미엄 차별화와 신흥시장 전용 서브 브랜드의 투트랙(Two-track) 전략을 구사해야 한다.  "끝"

### 실무 제언

**가격 경쟁의 함정 회피**
- **챌린지**: 중국 저가 제조사와 동일한 가격 경쟁 축에서 대응하면 원가 구조상 지속가능하지 않은 출혈 경쟁에 빠지게 된다.
- **제언**: 가격이 아닌 기술 혁신(폴더블, AI 기능)과 브랜드 경험으로 경쟁 축을 전환하는 차별화 전략이 장기적으로 지속가능하다.

**SWOT 분석의 정기적 갱신 필요성**
- **챌린지**: 다수 기업이 SWOT 분석을 일회성 워크숍으로 끝내고 시장 변화에 따라 갱신하지 않아 전략이 현실과 괴리되는 경우가 많다.
- **제언**: 분기별 SWOT 재분석 프로세스를 정례화하고, 시장 데이터(점유율, 경쟁사 신제품 출시)를 실시간 반영하는 전략 대시보드를 구축해야 한다.

**로컬 시장별 STP 세분화**
- **챌린지**: 글로벌 시장을 하나의 STP로 접근하면 신흥국과 선진국의 이질적 소비 패턴을 놓칠 수 있다.
- **제언**: 국가/지역별로 별도의 세분화(Segmentation) 기준을 적용하는 다지역 STP 전략을 수립하여 신흥시장에는 가성비, 선진시장에는 프리미엄 포지셔닝을 병행해야 한다.
