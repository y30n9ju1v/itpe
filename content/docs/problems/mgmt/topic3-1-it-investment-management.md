## 해설

### 출제 배경 및 의도

기업의 IT 투자 규모가 매년 증가하고 있으나, 스탠디시 그룹의 카오스 리포트에 따르면 상당수 IT 프로젝트가 예산 초과·일정 지연·목표 미달을 경험한다. 이는 IT 투자를 단순 비용지출이 아닌 "관리되어야 할 자산"으로 인식하지 못한 결과이며, 이에 따라 체계적인 IT투자관리(ITIM: IT Investment Management) 프로세스의 필요성이 대두되었다.

이 문제는 개념(가)부터 추진단계(나), 평가항목(다), 기대효과(라)까지 IT투자관리의 전주기(Full Lifecycle)를 종합적으로 묻는 대표적 관리형 문제이다. 채점위원은 응시자가 IT투자를 재무적 관점(ROI)뿐 아니라 정성적 가치(고객만족, 조직역량)까지 균형있게 평가할 수 있는 프레임워크 지식을 보유하고 있는지를 확인한다.

### 1. 가. IT투자관리의 개념 및 필요성

정 의 • IT투자관리란 IT 투자의 계획-실행-평가 전 과정을 체계적으로 관리하여 투자 대비 최대의 사업가치를 실현하고 위험을 최소화하는 경영관리 활동이다(미국 GAO의 Val IT, IT투자관리 5단계 모델 근거).

| 필요성 | 내용 |
|--------|------|
| 투자 효율성 | 한정된 예산의 우선순위 배분 |
| 위험 최소화 | 대규모 IT 실패 프로젝트 사전 예방 |
| 전략 정렬 | IT투자가 사업전략 목표에 기여하는지 검증 |
| 책임성 확보 | 투자 성과에 대한 사후 평가·책임 추적 |

### 2. 나. IT투자관리 추진단계별 주요 활동

```
[IT투자관리 3단계 프로세스]

  ① 선정(Select)
     └─ 후보사업 발굴 → 비용/편익 분석 → 우선순위 결정 → 포트폴리오 구성
              │
  ② 통제(Control)
     └─ 진척도 점검 → 마일스톤 리뷰 → 위험 모니터링 → 계획 대비 실적 관리
              │
  ③ 평가(Evaluate)
     └─ 사업 완료 후 성과 측정 → 목표 대비 실적 비교 → 교훈(Lessons Learned) 도출
              │
              └────────► 차기 투자 선정(①)에 피드백 반영
```

| 단계 | 주요 활동 | 산출물 |
|------|---------|--------|
| 선정 | 사업 발굴, 비용편익분석(CBA), 포트폴리오 우선순위화 | 투자 포트폴리오, 사업계획서 |
| 통제 | 진도관리, 위험관리, 변경관리 | 진척보고서, 위험대장 |
| 평가 | 성과측정, 사후평가, 환류 | 성과평가보고서, 개선안 |

### 3. 다. IT투자 평가 항목(정량적/정성적) 및 라. 기대효과

| 구분 | 평가 항목 | 세부 내용 |
|------|---------|---------|
| 정량적 평가 | ROI(투자수익률) | (효과-투자비용)/투자비용 |
| | NPV(순현재가치) | 미래 현금흐름 현재가치 - 투자비용 |
| | IRR(내부수익률) | NPV=0이 되는 할인율 |
| | Payback Period | 투자 회수 소요기간 |
| 정성적 평가 | 고객만족도 | 서비스 품질, 응답시간 개선 체감 |
| | 조직 역량 강화 | 업무 프로세스 개선, 직원 생산성 |
| | 전략적 적합성 | 사업전략과의 정렬 정도 |
| | 리스크 감소 | 규제 준수, 보안 강화 효과 |

```
[기대효과 체계]
재무적 효과: 비용절감, 매출증대, 투자수익 실현
운영적 효과: 프로세스 효율화, 의사결정 속도 향상
전략적 효과: 신사업 기회 창출, 경쟁우위 확보
사회적 효과: 고객·이해관계자 신뢰 제고
```

- 정량적 평가만으로는 IT의 간접적·장기적 가치(조직 학습, 혁신역량)를 포착하기 어려우므로, IT-BSC와 같은 균형 잡힌 평가체계와 병행이 필요하다.  "끝"

### 실무 제언

**정량 평가 만능주의의 함정**
- **챌린지**: 재무 부서 주도로 ROI/NPV 등 정량 지표만으로 IT 투자를 평가하면, 인프라 현대화·보안 강화처럼 정량화하기 어려운 필수 투자가 후순위로 밀린다.
- **제언**: 투자 포트폴리오를 "전략적 투자, 정보적 투자, 거래적 투자, 인프라 투자"로 유형화하고 유형별 상이한 평가 가중치를 적용하는 Ross & Weill의 IT 투자 포트폴리오 모델을 도입해야 한다.

**사후평가(Evaluate) 단계의 형식화**
- **챌린지**: 많은 조직이 선정·통제 단계에는 집중하나 사업 종료 후 성과평가와 교훈 환류를 소홀히 하여 동일한 실패가 반복된다.
- **제언**: 사업 종료 6개월~1년 후 정기적으로 사후평가를 의무화하고, 그 결과를 차기 사업 선정 기준에 정량적으로 반영하는 환류 거버넌스를 구축해야 한다.

**AI/클라우드 투자의 새로운 평가 프레임 필요성**
- **챌린지**: 생성형 AI, 클라우드 구독형(SaaS) 투자는 초기 투자비용은 낮으나 지속적 운영비용(FinOps)이 발생해 전통적 CBA로는 정확한 평가가 어렵다.
- **제언**: TCO(총소유비용) 기반의 지속적 비용 모니터링과 FinOps 원칙을 IT투자관리 프로세스에 통합하여 클라우드 시대에 맞는 투자평가 체계로 고도화해야 한다.
