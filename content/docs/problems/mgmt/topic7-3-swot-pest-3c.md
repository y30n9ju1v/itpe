## 문제

경영환경을 분석하는 방법인 SWOT(Strengths, Weakness, Opportunities, Threats), 3C(Customer, Competitor, Company), PEST(Political, Economical, Social, Technological) 분석에 대하여 각 방법의 특성과 적용을 위한 조건, 그리고 분석방법에 대하여 설명하시오.

## 해설

### 출제 배경 및 의도

이 문제는 앞선 K전자 사례(합숙_2017.01)가 SWOT/STP의 실전 적용을 요구했던 것과 달리, SWOT·3C·PEST 세 가지 경영환경 분석 프레임워크 자체의 특성, 적용조건, 분석방법을 비교론적으로 설명하도록 요구하는 개념 정립형 문제이다. 세 프레임워크는 분석 대상의 범위(거시 vs 미시, 내부 vs 외부)가 서로 달라 상호 보완적으로 사용되어야 한다.

채점위원은 응시자가 각 프레임워크를 단순 암기가 아니라 "언제, 어떤 상황에" 적용해야 하는지 구분할 수 있는지, 그리고 IT 전략 수립 시 이들을 통합적으로 활용하는 실무 감각을 갖췄는지를 평가한다.

### 1. SWOT 분석의 특성, 적용조건, 분석방법

정 의 • SWOT는 조직의 내부 강점·약점과 외부 기회·위협을 매트릭스로 정리하여 전략 대안을 도출하는 분석기법이다.

| 구분 | 내용 |
|------|------|
| 특성 | 내부(S,W) + 외부(O,T) 환경을 통합적으로 다루는 종합 분석틀 |
| 적용조건 | 조직의 전략 방향(신규진출, 위기극복 등) 수립이 필요한 시점 |
| 분석방법 | SO/ST/WO/WT 매트릭스 조합으로 전략 대안 도출 |

```
[SWOT 매트릭스]
       기회(O)         위협(T)
강점(S) SO전략(공격)    ST전략(다각화)
약점(W) WO전략(보완)    WT전략(방어)
```

### 2. 3C 분석의 특성, 적용조건, 분석방법

정 의 • 3C는 자사(Company), 고객(Customer), 경쟁사(Competitor)의 3자 관점에서 시장에서의 자사 위치를 파악하는 미시적 마케팅 환경 분석기법이다(오마에 겐이치).

| 구분 | 내용 |
|------|------|
| 특성 | 시장 내 3주체(자사·고객·경쟁사)의 상대적 역학관계 분석 |
| 적용조건 | 신제품/신서비스 출시 전 시장 포지셔닝 결정이 필요한 시점 |
| 분석방법 | 각 주체별 핵심 질문에 답하며 경쟁우위 요인 도출 |

```
[3C 분석 프레임]
Customer(고객) : 고객 니즈는 무엇인가? 시장 규모/성장성은?
Competitor(경쟁사) : 경쟁사의 전략과 강점은? 시장점유율은?
Company(자사) : 자사의 핵심역량은? 경쟁사 대비 차별점은?

           Customer
              △
             ╱ ╲
            ╱   ╲
   Company ─────── Competitor
   (상대적 경쟁우위 도출)
```

### 3. PEST 분석의 특성, 적용조건, 분석방법

정 의 • PEST는 정치(Political), 경제(Economic), 사회(Social), 기술(Technological) 4대 거시환경 요인이 사업에 미치는 영향을 분석하는 기법이다.

| 구분 | 내용 |
|------|------|
| 특성 | 기업 외부의 거시적, 통제 불가능한 환경변수 분석 |
| 적용조건 | 신규 시장/국가 진출, 장기 전략 수립 시 거시환경 리스크 점검 |
| 분석방법 | 4대 요인별 현황과 전망을 조사하여 기회·위협 요인 도출 |

```
[PEST 분석 프레임]
Political(정치)    : 규제, 정책, 무역장벽, 세제
Economic(경제)     : 금리, 환율, 경기, 소비심리
Social(사회)       : 인구구조, 라이프스타일, 소비트렌드
Technological(기술) : 신기술 등장, 기술표준, R&D 동향
```

### 4. 세 프레임워크 종합 비교

| 구분 | SWOT | 3C | PEST |
|------|------|-----|------|
| 분석 범위 | 내부+외부 통합 | 시장 내 미시적 3주체 | 거시적 외부환경 |
| 초점 | 전략 대안 도출 | 시장 포지셔닝 | 장기 리스크/기회 |
| 분석 수준 | 중간(내부+외부) | 미시(Micro) | 거시(Macro) |
| 주 활용 시점 | 전략 수립 전반 | 마케팅 전략, 신제품 출시 | 신시장 진출, 장기계획 |
| 상호관계 | PEST/3C 결과가 SWOT의 O/T 입력값이 됨 |

```
[통합 분석 흐름]
PEST(거시환경) ─┐
                ├──► SWOT의 기회(O)/위협(T) 도출
3C(미시/경쟁)  ─┘
                        │
              SWOT의 강점(S)/약점(W)과 결합
                        │
                  종합 전략 대안 수립
```

- PEST와 3C는 SWOT의 기회·위협 및 강점·약점 분석에 객관적 근거를 제공하는 상호 보완적 도구로, 세 프레임워크를 통합할 때 전략 수립의 완성도가 높아진다.  "끝"

### 실무 제언

**분석 프레임워크의 형식적 나열에 그치는 문제**
- **챌린지**: 실무에서 PEST, 3C, SWOT를 각각 독립적으로 수행하고 결과를 통합하지 않아 최종 전략이 논리적 일관성을 잃는 경우가 많다.
- **제언**: PEST와 3C의 분석 결과를 SWOT의 기회/위협 항목에 명시적으로 연결하는 통합 분석 워크플로우를 표준 컨설팅 절차로 정착시켜야 한다.

**거시환경 변화의 실시간 반영 부족**
- **챌린지**: PEST 분석이 연 1회성 보고서로 끝나 실제 규제 변화, 기술 트렌드 변화 속도를 따라가지 못하는 경우가 있다.
- **제언**: 규제 모니터링, 기술 스카우팅을 상시화하고 분기별 PEST 업데이트를 통해 전략의 민첩성(Agility)을 확보해야 한다.

**IT 전략 수립에서의 프레임워크 활용 확대**
- **챌린지**: IT 부서가 기술 스택 선정에만 집중하고 경영환경 분석 프레임워크를 활용하지 않아 기술 투자가 시장 상황과 괴리되는 경우가 있다.
- **제언**: 신기술(AI, 클라우드) 도입 의사결정 시에도 PEST(기술 트렌드, 규제)와 3C(경쟁사 기술 채택 현황)를 결합한 IT 전략 캔버스를 활용하여 기술투자와 경영전략의 정합성을 높여야 한다.
