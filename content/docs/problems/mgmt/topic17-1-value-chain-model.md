## 해설

### 출제 배경 및 의도

데이터는 "21세기의 원유"로 비유되며, 데이터 자체가 부가가치를 창출하는 핵심 자원이 되는 경제 패러다임을 데이터 경제(Data Economy)라 한다. EU의 GDPR·데이터 거버넌스법, 미국의 오픈데이터 정책 등 선진국은 이미 데이터 유통·활용 생태계를 국가 전략으로 육성하고 있으나, 국내는 개인정보보호 규제와의 상충, 데이터 소유권 불명확성 등으로 활성화가 더딘 상황이었다.

이 문제는 마이클 포터(Michael Porter)의 전통적 가치사슬 모델을 데이터라는 새로운 자원에 적용하여, 데이터가 수집부터 활용까지 어떤 단계를 거쳐 부가가치를 창출하는지 설명할 것을 요구한다. 출제 당시(2019년) 데이터 3법 개정 논의가 한창이었던 시대적 배경과 맞물려, 데이터 경제의 구조적 이해와 정책적 활성화 방안을 균형있게 서술하는 능력을 평가한다.

### 1. 데이터 경제(Data Economy)의 개념과 범위

정 의  • 데이터 경제란 데이터의 생산·수집·유통·분석·활용 전 과정에서 경제적 가치가 창출되고, 데이터 자체가 핵심 생산요소로 기능하는 경제 체제를 의미한다.

```
[데이터 경제의 범위]

① 데이터 생산 : IoT, 모바일, SNS 등에서 발생하는 원천 데이터
② 데이터 유통 : 데이터 거래소, 오픈 API, 데이터 플랫폼을 통한 공유·거래
③ 데이터 분석 : 빅데이터·AI 기술을 통한 인사이트 도출
④ 데이터 활용 : 신규 비즈니스 모델, 서비스 혁신에 활용
```

| 구분 | 전통 경제 | 데이터 경제 |
|------|---------|-----------|
| 핵심 자원 | 노동, 자본, 토지 | 데이터 |
| 가치 창출 | 물리적 생산·유통 | 데이터 수집·분석·활용 |
| 대표 사업자 | 제조·유통 기업 | 플랫폼 기업(구글, 네이버 등) |
| 규제 이슈 | 독과점, 노동 | 개인정보보호, 데이터 주권 |

### 2. 데이터 가치사슬(Data Value Chain) 모델

마이클 포터의 가치사슬 개념을 데이터에 적용하면, 데이터가 원재료에서 완제품(서비스)으로 전환되는 단계별 부가가치 창출 과정을 설명할 수 있다.

```
[데이터 가치사슬 5단계]

수집(Collect) → 저장/관리(Store) → 분석(Analyze) → 유통(Distribute) → 활용(Utilize)
   │                │                  │                │                │
 IoT센서,          데이터레이크,       AI/ML,           데이터거래소,      신사업,
 크롤링,           클라우드 스토리지    빅데이터분석      오픈API           의사결정 지원
 오픈데이터
```

| 단계 | 주요 활동 | 관련 산업/주체 |
|------|---------|--------------|
| 수집 | 센서, 로그, 설문 등 원천 데이터 확보 | IoT 기업, 플랫폼 기업 |
| 저장/관리 | 데이터 정제, 표준화, 저장 인프라 운영 | 클라우드 사업자, DB 벤더 |
| 분석 | 통계·AI 기반 인사이트 도출 | 데이터 분석 기업, AI 스타트업 |
| 유통 | 데이터 거래소, API 마켓플레이스 | 데이터 바우처, 금융 데이터거래소 |
| 활용 | 신규 서비스, 정책 의사결정에 반영 | 전 산업 분야 |

- 각 단계마다 별도의 사업자·기술이 개입하여 부가가치가 누적되는 구조이며, 국내는 특히 '유통' 단계(데이터 거래·개방)가 취약하다는 것이 진단이다.

### 3. 데이터 경제 활성화 전략

| 전략 영역 | 활성화 방안 |
|---------|-----------|
| 제도/법 | 데이터 3법(개인정보보호법·정보통신망법·신용정보법) 개정으로 가명정보 활용 근거 마련 |
| 인프라 | 공공 데이터 개방 확대, 분야별 빅데이터 플랫폼(금융·환경·교통 등) 구축 |
| 유통 시장 | 데이터 거래소 활성화, 데이터 바우처 지원사업으로 중소기업 데이터 구매 지원 |
| 인력 | 데이터 사이언티스트 양성, 산학 협력 커리큘럼 확대 |
| 신뢰 기반 | 마이데이터(MyData) 제도로 개인의 데이터 자기결정권 보장 |

- 제도·인프라·시장·인력·신뢰 기반이 유기적으로 결합될 때 데이터 경제의 선순환 생태계가 조성된다.  "끝"

### 실무 제언

**데이터 소유권과 활용의 딜레마**
- **챌린지**: 데이터 활용을 지나치게 규제하면 산업 활성화가 저해되고, 반대로 완화하면 개인정보 침해 우려가 커지는 트레이드오프가 존재한다.
- **제언**: 가명정보·익명정보 개념을 명확히 구분하고, 통계 작성·연구 목적에 한해 가명정보 활용을 허용하는 균형점을 법제도에 반영해야 한다.

**데이터 유통 시장의 신뢰 부재**
- **챌린지**: 데이터 품질과 출처를 신뢰할 수 없어 데이터 거래소 이용률이 저조하다.
- **제언**: 데이터 품질 인증제, 블록체인 기반 데이터 이력 추적(Data Provenance)을 도입하여 거래 신뢰성을 확보해야 한다.

**대기업-중소기업 간 데이터 격차 해소**
- **챌린지**: 데이터를 대량 보유한 플랫폼 대기업과 데이터가 부족한 중소기업 간 활용 격차가 심화되고 있다.
- **제언**: 정부 주도의 데이터 바우처, 마이데이터 개방 표준화를 통해 중소기업도 양질의 데이터에 접근할 수 있는 생태계를 조성해야 한다.
