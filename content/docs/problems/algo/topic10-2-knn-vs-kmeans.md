## 모범답안

### 1. K-NN과 K-means 개요

정 의  • K-NN: 새 데이터를 가장 가까운 K개 이웃의 다수결로 분류/예측하는 지도학습
       - K-means: 데이터를 K개 군집으로 나눠 중심점(Centroid)까지 거리를 최소화하는 비지도학습

```
[K-NN]                         [K-means]
   ●                              ●   ●
  ● ○ ●   ← 새 데이터 분류         ●  [C1]  ●
   ●
   K=3 이웃 다수결 → 분류         ○ ○ [C2] ○ ○
                                  반복적으로 중심점 갱신 → 군집화
```

- 두 알고리즘 모두 K는 하이퍼파라미터이나 의미가 전혀 다름(이웃 개수 vs 군집 개수).

### 2. K-NN과 K-means 상세 비교

| 구분 | K-NN(K-Nearest Neighbor) | K-means |
|------|---------------------------|---------|
| 학습 방식 | 지도학습(Supervised) | 비지도학습(Unsupervised) |
| 목적 | 분류(Classification)/회귀 | 군집화(Clustering) |
| K의 의미 | 참조할 이웃의 개수 | 생성할 군집의 개수 |
| 학습 과정 | Lazy Learning(예측 시 전체 탐색) | Eager Learning(반복적 중심점 갱신) |
| 알고리즘 절차 | 거리계산→K개 이웃선정→다수결/평균 | 초기중심설정→할당→중심갱신 반복 |
| 거리 척도 | 유클리드, 맨해튼, 코사인 유사도 | 유클리드 거리(제곱합) |
| 정답 레이블 | 필요(Label 존재) | 불필요(Label 없음) |
| 시간복잡도 | 예측 시 O(N) | 학습 시 O(N·K·I·d) |
| 대표 활용 | 추천시스템 유사도 분류, 이상탐지 | 고객 세분화, 이미지 압축 |

- K-NN은 예측 시점에 전체 데이터를 탐색하는 게으른 학습, K-means는 사전에 모델을 구축하는 적극적 학습이 본질적 차이.

### 3. K값 선정 및 활용·트렌드

| 구분 | K-NN | K-means |
|------|------|---------|
| K값 과소/과다 | 과적합(노이즈 민감) / 과소적합(경계 과평활) | 과소 세분화 / 세분화 과다·비용↑ |
| 선정 기법 | 교차검증(Cross Validation) | 엘보우 기법, 실루엣 계수 |
| 공통 한계 | 차원의 저주(고차원 거리 왜곡) | 초기 중심점 따라 결과 상이(Local Optimum) |
| 대응 기법 | KD-Tree/Ball-Tree 탐색 가속 | K-means++ 초기화로 수렴 안정성 확보 |

- 최근 PCA 등 차원축소·정규화를 전처리에 병행해 거리 기반 알고리즘의 차원의 저주 대응 증대.  "끝"
