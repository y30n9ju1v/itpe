## 모범답안

1. 양자 머신러닝(QML) 개요

   정 의  • 양자컴퓨팅의 중첩(Superposition)·얽힘(Entanglement) 원리를
            활용해 머신러닝의 연산(특징추출·최적화 등)을 가속하거나
            고전 방식으로 불가능한 고차원 특징공간을 탐색하는 융합 기술
          - 큐비트 기반 양자회로(Quantum Circuit)로 데이터 인코딩·연산 수행

```
[고전 데이터] → 양자 인코딩(Encoding) → [큐비트 상태]
                                            ↓
                              양자 게이트 연산(변분회로)
                                            ↓
                          측정(Measurement) → [고전 출력]
                                            ↓
                    고전 옵티마이저가 파라미터 업데이트 (Hybrid Loop)
```

- 현재는 대부분 '양자-고전 하이브리드(Hybrid)' 구조로 구현되는 것이 현실적 형태.

2. QML 주요 기술 및 알고리즘

| 구분 | 알고리즘/기술 | 설명 |
|------|--------------|------|
| 데이터 인코딩 | 양자 특징 맵(Quantum Feature Map) | 고전 데이터를 큐비트 상태로 인코딩, 고차원 힐베르트 공간 활용 |
| 분류 | 양자 서포트벡터머신(QSVM) | 양자 커널을 이용해 커널트릭을 양자 회로로 계산 |
| 최적화 | 변분양자회로(VQC/VQE) | 파라미터화된 양자회로 + 고전 옵티마이저의 하이브리드 학습 |
| 최적화 | QAOA | 조합 최적화 문제(Combinatorial Optimization)에 특화 |
| 신경망 | 양자 신경망(QNN) | 양자게이트를 뉴런처럼 배열해 학습 가능한 회로 구성 |
| 생성모델 | 양자 GAN(QGAN) | 양자 생성자·판별자로 확률분포 학습 |

- 현재 기술은 NISQ(Noisy Intermediate-Scale Quantum) 환경의 잡음 한계로 소규모 문제·PoC 단계에 머물러 있음.

3. 기존(고전) 머신러닝과 QML 비교

| 구분 | 고전 머신러닝 | 양자 머신러닝(QML) |
|------|--------------|---------------------|
| 연산 단위 | 비트(0 또는 1) | 큐비트(중첩 상태, 0과 1 동시 표현) |
| 특징공간 | 다항식적 확장 | 큐비트 수에 지수적으로 확장(2^n 차원) |
| 하드웨어 | GPU/TPU 등 고전 컴퓨터 | 양자 컴퓨터(초전도, 이온트랩 등), 현재 NISQ 수준 |
| 강점 분야 | 범용적, 대규모 데이터에 성숙 | 조합 최적화, 고차원 커널 계산에 이론적 우위 |
| 성숙도 | 상용화 완료, 생태계 성숙 | 연구·PoC 단계, 상용화 초기 |
| 한계 | 대규모 연산 시 시간·전력 소모 | 큐비트 잡음, 디코히런스, 확장성 제약 |
| 학습 방식 | 역전파(Backpropagation) | 파라미터 시프트 규칙 등 양자 그래디언트 추정 |

- 조합 최적화·고차원 커널 계산에서 이론적 우위가 기대되나, 하드웨어 제약으로 실질적 '양자 우위(Quantum Advantage)' 입증 사례는 제한적.
- 최근 고전-양자 하이브리드(VQE, QAOA) 중심 실증과 양자-AI 융합 인력 양성 병행 증대.  "끝"
