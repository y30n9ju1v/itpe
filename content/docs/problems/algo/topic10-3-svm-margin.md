## 모범답안

### 1. SVM 마진(Margin)의 개념

정 의  • 마진: 결정경계(초평면, Hyperplane)와 가장 가까운 데이터(서포트 벡터) 간의 거리
       - 마진을 최대화하는 결정경계를 찾아 일반화 성능을 확보하는 지도학습 분류기

```
        ●          ○
      ●   ●      ○   ○
  ─────────┼─────────────  ← 결정 경계(Hyperplane)
      ●   ●      ○   ○
   ↑margin↑    ↑margin↑
   서포트벡터가 경계선까지의 최단거리 = 마진
```

- 마진이 클수록 새로운 데이터에 대한 오분류 가능성이 낮아져 일반화 성능 향상.

### 2. 마진 분류 방법 2가지: 하드 마진 vs 소프트 마진

| 구분 | 하드 마진(Hard Margin) | 소프트 마진(Soft Margin) |
|------|--------------------------|----------------------------|
| 정의 | 오분류를 전혀 허용 않고 완벽 분리하는 마진 | 일부 오분류(여유변수)를 허용하는 마진 |
| 전제조건 | 데이터가 선형적으로 완벽 분리 가능 | 노이즈·이상치가 존재하는 현실 데이터 |
| 목적함수 | min(1/2)‖w‖² s.t. yᵢ(w·xᵢ+b)≥1 | min(1/2)‖w‖²+C·Σξᵢ s.t. yᵢ(w·xᵢ+b)≥1-ξᵢ, ξᵢ≥0 |
| 여유변수 | 없음 | 슬랙 변수(Slack Variable, ξ) 도입 |
| 규제 파라미터 | 없음 | C(패널티 계수)로 오분류 허용 정도 제어 |
| 과적합 위험 | 이상치에 매우 민감, 과적합 위험 높음 | C값 조절로 과적합/과소적합 균형 조절 |
| 실무 적용성 | 낮음(현실 데이터는 노이즈 포함) | 높음(대부분 실무 SVM은 소프트 마진) |

- ξᵢ는 데이터가 마진을 위반한 정도, C는 '마진 최대화'와 '오분류 최소화' 사이 트레이드오프 조절 하이퍼파라미터.

### 3. 규제 파라미터 C 및 확장 방안

| C값 | 특징 | 결과 |
|-----|------|------|
| C 클 때 | 오분류 패널티 강함(하드 마진에 근접) | 마진 좁아짐, 과적합 위험↑ |
| C 작을 때 | 오분류 허용도 높음 | 마진 넓어짐, 과소적합 위험↑ |

- 최적 C값은 교차검증(Grid Search)으로 탐색하며, 선형 분리 불가 데이터는 커널 트릭(RBF/Polynomial)으로 고차원 매핑해 비선형 결정경계 확장.  "끝"
