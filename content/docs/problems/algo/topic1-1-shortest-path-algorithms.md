## 모범답안

1. 최단경로 알고리즘의 유형

    정 의  • 그래프의 두 정점 간 간선 가중치 합이 최소가 되는 경로를 구하는 기법을
             출발/목적 범위·가중치 부호에 따라 계산하는 알고리즘군
           - 단일출발/전체쌍/휴리스틱 탐색 등을 목적에 맞게 선택 적용하는 구조

    ```
    [최단경로 문제]
       │
       ├─ 단일출발(Single-Source)
       │     ├─ Dijkstra    : 음수 가중치 불가, Greedy+우선순위 큐
       │     └─ Bellman-Ford: 음수 가중치 가능, 음수 사이클 탐지, DP 기반
       │
       ├─ 전체쌍(All-Pairs)
       │     └─ Floyd-Warshall: 3중 반복 DP, 음수 가중치 가능(음수 사이클 無 전제)
       │
       └─ 휴리스틱 탐색
             └─ A* : f(n)=g(n)+h(n), 목적지 지정 탐색
    ```

    | 구분 | 범위 | 음의 가중치 |
    |------|------|--------------|
    | Dijkstra | 단일출발 | 불가 |
    | Bellman-Ford | 단일출발 | 가능(사이클 탐지) |
    | Floyd-Warshall | 전체쌍 | 가능(사이클 無 전제) |
    | A* | 단일출발-단일목적 | 불가(휴리스틱 전제) |

    - 그래프 특성(음수 여부, 노드 수, 출발/목적 범위)에 따라 알고리즘을 선택.

2. 그래프(A~E, A출발 E목적) 4가지 알고리즘 계산방법

    그래프: A-B=4, A-C=1, C-B=2, B-D=3, C-D=7, B-E=6, D-E=5

    1) Dijkstra 계산

    | 단계 | 처리 노드 | A | B | C | D | E |
    |------|----------|---|---|---|---|---|
    | 1 | 초기화 | 0 | ∞ | ∞ | ∞ | ∞ |
    | 2 | A 방문 | 0 | 4 | 1 | ∞ | ∞ |
    | 3 | C 방문(최소=1) | 0 | 3 | 1 | 8 | ∞ |
    | 4 | B 방문(최소=3) | 0 | 3 | 1 | 6 | 9 |
    | 5 | D 방문(최소=6) | 0 | 3 | 1 | 6 | 9 |
    | 6 | E 방문(최소=9) | 0 | 3 | 1 | 6 | |9| |

    - A→E 최단거리 = |9|, 경로 A-C-B-E. 미방문 노드 중 최소거리 노드를 그리디 선택.

    2) Bellman-Ford / Floyd-Warshall / A* 계산

    | 구분 | 계산 과정 | 결과 |
    |------|-----------|------|
    | Bellman-Ford | 전간선 \|V\|-1(=4)회 반복 이완, A-C-B-E 경로 순차 발견 | dist[E]=|9| (4회 내 수렴) |
    | Floyd-Warshall | k=C 경유 D[A][B]=min(4,1+2)=3, k=B 경유 D[A][E]=min(∞,3+6)=9 | D[A][E]=|9| |
    | A* | f(n)=g(n)+h(n), h는 과소추정(Admissible) 가정, E와 먼 노드 확장 후순위 | 경로 A-C-B-E, 비용 |9| (탐색량 최소) |

    - 4가지 계산 모두 동일 경로/비용에 수렴, 각기 다른 자료구조·절차로 도출.

3. 4가지 알고리즘 계산결과 비교

    | 구분 | Dijkstra | Bellman-Ford | Floyd-Warshall | A* |
    |------|----------|--------------|----------------|-----|
    | 시간복잡도 | O((V+E)logV) | O(V·E) | O(V³) | 휴리스틱 의존 |
    | 음의 사이클 탐지 | 불가 | 가능 | 불가(별도 검사) | 불가 |
    | 자료구조 | 우선순위 큐 | 배열 반복 | 인접행렬 DP | 큐+휴리스틱 |
    | A→E 결과 | |9| | |9| | |9| | |9|(탐색량 최소) |
    | 용도 | OSPF 라우팅 | RIP, 사이클 탐지 | 전체쌍 사전계산 | 내비게이션·게임 |

    - 4개 알고리즘 모두 A→E=9로 수렴, 음의 가중치가 없어 알고리즘 간 정합성 성립.

4. 실무 적용 시 고려사항

    | 이슈 | 대응방안 |
    |------|----------|
    | 비용을 음수(이익)로 모델링 시 다익스트라 오탐지 | 벨만포드 계열 채택 + 음수사이클 탐지 배치 병행 |
    | 대규모 그래프에 O(V³) Floyd-Warshall 적용 시 연산 폭증 | 계층적 라우팅(Contraction Hierarchies)으로 연산량 절감 |
    | A* 휴리스틱 과대평가 시 최적해 미보장 | h값 과소추정 검증 + 다익스트라 교차검증 자동화 |

    - 최근 대규모 지도·SDN 라우팅에서 계층적 최단경로 및 A* 휴리스틱 최적화 적용 증대 예상.  "끝"
