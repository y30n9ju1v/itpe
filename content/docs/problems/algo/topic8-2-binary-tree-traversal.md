## 문제

이진트리를 순회하는 방식은 전위순회, 중위순회, 후위순회 등으로 나눈다. 모든 순회방식은 루트로부터 순회를 시작하여 트리의 모든 노드들을 반드시 한 번씩 방문하여 순회를 종료한다. 이와 관련하여 다음을 설명하시오.

가. 전위순회 중위순회, 후위순회 방식

## 모범답안

1. 이진트리 순회 개요

    정 의  • 이진트리의 모든 노드를 특정 순서 규칙에 따라 정확히 한 번씩
             방문하는 절차
           - 루트(N) 방문 시점을 기준으로 전위/중위/후위 3가지로 구분하는 구조

    ```
    [순회 3요소]  N(루트), L(왼쪽 서브트리), R(오른쪽 서브트리)

      전위순회(Preorder)  : N → L → R
      중위순회(Inorder)   : L → N → R
      후위순회(Postorder) : L → R → N
    ```

    - AST 처리, 파일시스템 순회, 파서 구현 등 트리 다루는 소프트웨어 전반의 기초.

2. "가" 전위/중위/후위순회 방식 상세

    | 구분 | 방문 순서 | 대표 활용 |
    |------|-----------|-----------|
    | 전위순회 | 루트→왼쪽→오른쪽 | 트리 구조 복제, 디렉터리 상위→하위 출력 |
    | 중위순회 | 왼쪽→루트→오른쪽 | BST의 오름차순 정렬 출력 |
    | 후위순회 | 왼쪽→오른쪽→루트 | 트리/디렉터리 삭제, 후위표기식 계산 |

    - 세 방식 모두 왼쪽을 오른쪽보다 먼저 방문, "루트를 언제 방문하는가"만 차이.

3. "나" 예시 이진트리 방문순서 트레이스

    ```
                     F
                   /   \
                  B      G
                /   \       \
               A     D        I
                    / \       /
                   C   E     H
    ```

    | 순회 방식 | 방문 순서 |
    |-----------|-----------|
    | 전위순회 | |F-B-A-D-C-E-G-I-H| |
    | 중위순회 | |A-B-C-D-E-F-G-H-I| |
    | 후위순회 | |A-C-E-D-B-H-I-G-F| |

    - 중위순회 결과가 A~I 알파벳 순서로 정렬되는 것은 이 예시 트리가 BST 성질을 만족하기 때문.

4. 실무 적용 시 고려사항

    | 이슈 | 대응방안 |
    |------|----------|
    | 편향 트리 재귀 순회 시 스택 오버플로우 | 명시적 스택 기반 반복(Iterative) 순회로 구현 |
    | 삭제 시 전위순회 사용 시 참조 끊김/누수 | 후위순회(자식 정리 후 루트 정리) 표준 적용 |
    | BST 무결성 훼손 시 O(log n) 성능 상실 | 중위순회 결과 오름차순 검증 배치 상시 모니터링 |

    - 최근 대용량 트리 구조에서 반복 기반 순회 및 자체 무결성 진단 적용 증대 예상.  "끝"
