## 모범답안

1. 경사하강법의 개념

    정 의  • 비용함수 J(W)의 기울기(Gradient, ∇J) 반대 방향으로 파라미터를
             반복 갱신하여 손실을 최소화하는 1차 최적화 알고리즘
           - 학습률 η이 부적절하면 오버슈팅·지역최소점 정체가 발생

    ```
    갱신식:  W_new = W_old - η · ∇J(W_old)

    η(학습률) 크기에 따른 수렴 양상:
      η 너무 작음 → 수렴은 하나 매우 느림 (Local optimum 근처서 정체 가능)
      η 적정      → 안정적으로 최소점 수렴
      η 너무 큼   → 최소점을 지나쳐 진동/발산 (Overshooting)
    ```

    | 종류 | 갱신 단위 | 특징 |
    |------|-----------|------|
    | Batch GD | 전체 데이터 | 안정적이나 느림, 메모리 부담 |
    | SGD | 데이터 1건 | 빠르나 진동(Noise) 큼 |
    | Mini-batch GD | 소규모 배치(32~256 등) | 속도·안정성 절충, 실무 표준 |

    - 실제 학습 실패(미수렴·정체) 시 어떤 기법을 적용할지가 실무 핵심 역량.

2. 오버슈팅(Overshooting) 방지 방법

    정 의  • 학습률이 과도하게 커서 파라미터가 최소점을 지나쳐 반대편으로
             튕겨나가며 손실이 진동·발산하는 현상

    | 기법 | 방식 | 효과 |
    |------|------|------|
    | 학습률 감소(LR Decay) | Epoch/Step 진행에 따라 η 점차 축소 | 초반 빠르게, 후반 정밀 수렴 |
    | 적응적 학습률 | AdaGrad/RMSProp/Adam이 파라미터별 학습률 자동 조정 | 파라미터별 최적 보폭 확보 |
    | 워밍업(Warm-up) | 초기 학습률을 작게 시작해 서서히 증가 | 학습 초기 불안정성 방지 |
    | 그래디언트 클리핑 | 기울기가 임계값 초과 시 스케일 조정 | 기울기 폭주로 인한 급격한 갱신 방지 |
    | 배치 정규화 | 층별 입력 분포 정규화 | 손실 지형을 완만하게 해 큰 학습률에도 안정 |

    - 학습률 스케줄과 정규화를 병행해 오버슈팅을 구조적으로 예방.

3. 지역 최소점(Local Minimum) 회피 기법

    정 의  • 손실 함수 지형에서 전역 최소점이 아닌 국소적으로 낮은 지점에
             갇혀 더 이상 개선되지 않는 현상
           - 고차원 신경망은 지역 최소점보다 기울기가 0에 가까운 안장점
             (Saddle Point)이 더 빈번한 정체 원인

    | 기법 | 방식 | 효과 |
    |------|------|------|
    | Momentum | 이전 기울기 방향을 관성처럼 누적 | 얕은 지역 최소점을 관성으로 통과 |
    | SGD(확률적 특성) | 미니배치마다 노이즈 섞인 기울기 사용 | 국소 지형 요철을 무작위성으로 탈출 |
    | Warm Restart(SGDR) | 주기적으로 학습률을 크게 재상승 | 정체된 지점에서 재탐색 유도 |
    | 다중 초기화 | 서로 다른 초기 가중치로 복수 학습 후 최적 선택 | 초기값 의존성 완화 |
    | Adam 등 2차 모멘텀 | 파라미터별 적응적 스텝으로 평탄 구간 통과 가속 | 정체 구간 빠른 통과 |

    - 심층 신경망은 지역 최소점보다 안장점 문제가 지배적이며, Momentum·Adam 계열이 이를 효과적으로 통과.

4. 실무 적용 시 고려사항

    | 이슈 | 대응방안 |
    |------|----------|
    | 고정 학습률 감소 공식이 데이터·모델별 최적 아님 | Cosine Annealing, Step Decay, OneCycle 등을 검증 손실로 비교 실험 |
    | 손실 정체를 지역 최소점으로 오판, 실제 원인은 데이터·용량 부족 | 학습곡선·검증손실·그래디언트 노름 종합 진단으로 원인 구분 |
    | 대규모 분산 학습에서 그래디언트 동기화 지연·폭주 | 클리핑 + 선형 스케일링 규칙(Linear Scaling Rule) + 충분한 워밍업 |

    - 최근 Cosine Annealing, OneCycle 등 학습률 스케줄링과 분산 학습 안정화 기법 적용 증대 예상.  "끝"
