## 모범답안

### 1. SVM(Support Vector Machine)의 개념 및 배경

정 의  • 클래스 간 마진(Margin)을 최대화하는 최적의 결정경계(초평면)를 찾아
       데이터를 분류하는 지도학습 기반 이진 분류 알고리즘
      - 서포트 벡터: 결정경계에 가장 가까이 위치해 경계 형성에 직접 관여하는 데이터

```
      ●   ●         ○   ○
    ●   ●   ★     ★   ○   ○
  ─────────────┼─────────────  ← 최적 결정경계(초평면)
    ●   ★         ★   ○
      ●               ○
   ★ = 서포트 벡터(경계 결정에 기여하는 데이터만)
```

- 딥러닝 시대에도 고차원·소량 데이터(텍스트, 유전자 데이터) 환경에서는 SVM이 여전히 우수한 일반화 성능 보유.

### 2. SVM의 동작방식

1) 동작 절차

| 단계 | 내용 |
|------|------|
| ① 마진 최대화 | 클래스 간 거리(마진)가 최대가 되는 초평면 탐색 |
| ② 소프트 마진 적용 | 슬랙 변수(ξ)와 규제 C로 노이즈·이상치 허용 |
| ③ 커널 트릭 적용 | 선형 분리 불가 시 커널 함수로 고차원 공간에 매핑 |
| ④ 최적화 | 라그랑주 승수법으로 쌍대문제 변환 후 QP로 해 도출 |

2) 커널 함수 종류

```
저차원(선형 분리 불가) --φ(x) 매핑(커널 트릭)--> 고차원(선형 분리 가능)
      ○●○●                        ●●●  ○○○
      ●○●○         →              ●●●  ○○○
```

| 커널 함수 | 특징 | 활용 |
|-----------|------|------|
| Linear | 선형 분리 데이터 | 텍스트 분류 |
| Polynomial | 다항식 형태 경계 | 이미지 특징 |
| RBF(Gaussian) | 비선형 복잡 경계, 가장 범용적 | 대부분의 비선형 문제 |
| Sigmoid | 신경망과 유사한 경계 | 특수 목적 |

- 커널 트릭은 실제 고차원 매핑 없이 커널 함수(내적)만으로 계산량을 줄이는 것이 핵심 원리.

### 3. SVM의 장단점 및 활용사례

| 구분 | 장점 | 단점 |
|------|------|------|
| 성능 | 고차원·소량 데이터에서 높은 일반화 성능 | 대용량 데이터 학습속도 저하(O(N²)~O(N³)) |
| 과적합 | 마진 최대화로 과적합에 강함 | 커널·C·감마 튜닝 복잡 |
| 해석성 | 서포트 벡터만으로 결정경계 설명 가능 | 다중 클래스는 확장 필요(One-vs-Rest) |
| 노이즈 | 소프트 마진으로 어느 정도 대응 | 클래스 불균형 데이터에 취약 |

| 활용사례 | 설명 |
|----------|------|
| 텍스트/문서 분류 | 스팸 필터링, 감성 분석(고차원 희소 벡터) |
| 이미지 인식 | 얼굴 인식, 필기체 숫자 인식(초기 OCR) |
| 생물정보학 | 유전자 발현 데이터 기반 암 진단 분류 |
| 이상탐지 | One-Class SVM 기반 금융 이상거래 탐지 |

### 4. 실무 적용 시 고려사항

| 이슈 | 대응방안 |
|------|----------|
| 대용량 데이터 확장성 한계(O(N²) 이상 급증) | SGD 기반 Linear SVC, 근사 커널(Nystrom) 적용 |
| 하이퍼파라미터 튜닝 비효율 | Grid/Bayesian Optimization+교차검증 자동화, class_weight 조정 |

- 최근 대용량 환경에서는 근사 커널 기법과 자동화된 하이퍼파라미터 탐색 적용 증대.  "끝"
