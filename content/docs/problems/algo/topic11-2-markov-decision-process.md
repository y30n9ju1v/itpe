## 문제

마르코프 특성(Markov Property)은 미래 상태의 조건부 확률분포가 과거 상태와는 독립적으로 현재 상태에 의해서만 결정된다는 것을 뜻한다. 이와 관련하여 다음을 설명하시오.
가. 마르코프 결정 프로세스(Markov Decision Process)와 전이확률(Transition Probability)
나. 상태가치함수(State Value Function)와 액션가치함수(State-Action Value Function)
다. 벨만기대방정식(Bellman Expectation Equation)과 벨만최적방정식(Bellman Optimality Equation)

## 모범답안

### 1. MDP와 전이확률 개요

정 의  • MDP: 순차적 의사결정 문제를 (S, A, P, R, γ) 튜플로 정형화한 수학적 프레임워크
       - 전이확률 P(s'|s,a): 상태 s에서 행동 a를 취했을 때 다음 상태 s'로 이동할 확률

```
P(s'|s,a) = Pr[Sₜ₊₁=s' | Sₜ=s, Aₜ=a]
```

| 구성요소 | 기호 | 설명 |
|----------|------|------|
| 상태집합 | S | 가능한 모든 상태 |
| 행동집합 | A | 가능한 모든 행동 |
| 전이확률 | P(s'\|s,a) | 상태 s, 행동 a 시 s'로 전이될 확률 |
| 보상함수 | R(s,a) | 상태·행동에 대한 즉각 보상 |
| 할인율 | γ(0≤γ≤1) | 미래 보상을 현재가치로 환산하는 계수 |

- 마르코프 특성상 전이확률은 과거 이력과 무관하게 현재 상태 s와 행동 a만으로 결정.

### 2. 가치함수(개념+비교) 및 벨만방정식(1도1표)

1) 상태가치함수 V(s)와 액션가치함수 Q(s,a) 비교

| 구분 | 상태가치함수 V(s) | 액션가치함수 Q(s,a) |
|------|---------------------|------------------------|
| 정의 | 상태 s에서 정책 π를 따랐을 때 기대 누적보상 | 상태 s에서 행동 a 이후 정책 π를 따랐을 때 기대 누적보상 |
| 수식 | Vπ(s)=Eπ[Gₜ\|Sₜ=s] | Qπ(s,a)=Eπ[Gₜ\|Sₜ=s,Aₜ=a] |
| 관계 | Vπ(s)=Σₐπ(a\|s)·Qπ(s,a) | Qπ(s,a)=R(s,a)+γΣP(s'\|s,a)Vπ(s') |
| 활용 | 정책 평가(현재 정책 가치 측정) | 행동 선택(정책 개선의 직접 기준) |

2) 벨만기대방정식 / 벨만최적방정식

```
[벨만기대방정식] - 정책 π 하의 가치 평가
  V(s) = Σₐ π(a|s) Σₛ' P(s'|s,a) [ R(s,a) + γV(s') ]
  Q(s,a) = E[ R(s,a) + γ Σₐ' π(a'|s')Q(s',a') ]

[벨만최적방정식] - 최적 정책 π*의 가치(최댓값 선택)
  V*(s) = maxₐ [ R(s,a) + γ Σₛ' P(s'|s,a) V*(s') ]
  Q*(s,a) = R(s,a) + γ Σₛ' P(s'|s,a) maxₐ' Q*(s',a')
```

- Q함수는 정책을 몰라도 argmax Q(s,a)로 최적행동 선택 가능해 Q-Learning 등에서 핵심 활용.

### 3. 벨만기대방정식 vs 벨만최적방정식 비교

| 구분 | 벨만기대방정식 | 벨만최적방정식 |
|------|----------------|-----------------|
| 목적 | 정책 π의 가치평가(Policy Evaluation) | 최적 정책 탐색(Policy Optimization) |
| 연산 | 정책에 따른 기대값(Σπ(a\|s)) 계산 | 모든 행동 중 최댓값(max) 선택 |
| 선형성 | 선형 방정식(연립방정식 직접 풀이) | 비선형(max 연산, 반복적 근사 필요) |
| 대표 알고리즘 | 정책반복(Policy Iteration)의 평가단계 | 가치반복(Value Iteration), Q-Learning |

- 강화학습 과정은 벨만방정식을 반복 적용해 V/Q를 참값에 수렴시키는 과정(DP, TD Learning).

### 4. 실무 적용 시 고려사항

| 이슈 | 대응방안 |
|------|----------|
| 대규모/연속 상태공간에서 Tabular V(s),Q(s,a) 저장 불가 | DQN 등 함수근사(Function Approximation) 도입 |
| 할인율 γ 설정 오류(근시안적/발산 위험) | 도메인 의사결정 주기에 맞춰 γ 설계, 보상 스케일링 병행 |

- 최근 자율주행·로보틱스 등 연속 상태공간에서 심층신경망 기반 가치함수 근사(DQN) 적용 증대.  "끝"
