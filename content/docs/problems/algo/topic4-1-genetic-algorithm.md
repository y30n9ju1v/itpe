## 모범답안

1. 유전자 알고리즘(GA) 개요

    정 의  • 자연선택과 유전학 원리(적자생존, 교배, 돌연변이)를 모사해
             해 후보 집단을 세대별로 진화시키는 확률적 탐색 기법
           - 정확한 최적해가 아닌 근사 최적해(Near-Optimal)를 빠르게 탐색하는 구조

    ```
    [초기 개체군 생성]
           ↓
       [적합도 평가]
           ↓
       [선택] → 우수 개체 생존확률↑
           ↓
       [교배] → 부모 유전자 결합, 자식 생성
           ↓
       [돌연변이] → 유전자 일부 무작위 변경(지역해 탈출)
           ↓
       [세대 교체/종료 검사] → 미충족 시 반복
    ```

    - NP-Hard 문제(물류 경로, AutoML 하이퍼파라미터 탐색 등)에 실무적으로 널리 활용.

2. GA 연산 과정 및 선택/교배 기법

    1) GA 연산 과정

    | 단계 | 명칭 | 내용 |
    |------|------|------|
    | 1 | 초기화 | 염색체로 표현된 해 후보 무작위 생성 |
    | 2 | 적합도 평가 | 목적함수로 개체별 적합도 점수 산출 |
    | 3 | 선택 | 적합도 높은 개체의 부모 선택 확률 증대 |
    | 4 | 교배 | 부모 염색체 유전자 교환·결합, 자식 생성 |
    | 5 | 돌연변이 | 저확률로 유전자 일부 변경, 다양성 확보 |
    | 6 | 세대 교체 | 자식으로 개체군 대체, 종료조건 충족 시 종료 |

    2) 선택기법·교배기법 비교

    | 구분 | 기법 | 특징 |
    |------|------|------|
    | 선택 | 룰렛휠 | 적합도 비례 확률, 편차 크면 조기수렴 위험 |
    | 선택 | 토너먼트 | k개 중 최우수 선택, 실무 최다 사용 |
    | 선택 | 엘리트주의 | 최우수 개체 무조건 보존, 다양성 저하 가능 |
    | 교배 | 단일점 교차 | 한 지점 기준 유전자 교환, 연쇄 파괴 위험 |
    | 교배 | 균등 교차 | 자리마다 확률적 선택, 탐색 다양성 최대 |
    | 교배 | 순서 교차(OCX) | 순열(TSP) 문제에서 순서 보존 교차 |

    - 선택은 "누가 부모가 될 것인가", 교배는 "유전자를 어떻게 섞을 것인가"를 결정하는 보완적 연산.

3. 조기수렴 및 적합도 함수 설계 이슈

    | 이슈 | 원인 | 영향 |
    |------|------|------|
    | 조기수렴 | 선택압 과다, 엘리트주의 과다 적용 | 개체군 다양성 소실, 지역 최적해 함몰 |
    | 적합도 함수 설계 오류 | 제약조건 미반영 | 실현 불가능한 해로 수렴, 탐색 왜곡 |
    | 계산 비용 누적 | 세대수·개체군 크기 증가 | 실시간 서비스 적용 부적합 |

    - 조기수렴 방지를 위한 적응형 돌연변이, 다양성 모니터링이 GA 설계의 핵심 관리 포인트.

4. 실무 적용 방안

    | 이슈 | 대응방안 |
    |------|----------|
    | 조기수렴 | Adaptive Mutation + 다양성 지표 모니터링, 무작위 개체 강제 투입 |
    | 제약 위반 해 수렴 | 페널티 함수 또는 Repair Function 병행 |
    | 실시간 서비스 부적합 | GA로 초기해 배치 도출 후 경량 지역탐색(2-opt)으로 보정하는 하이브리드 전략 |

    - 최근 AutoML·NAS 등 AI 자동화 도구에서 GA 백엔드 재조명, 하이브리드 적용 증대 예상.  "끝"
