## 모범답안

1. 파라미터·하이퍼파라미터 개요

    정 의  • 파라미터는 학습을 통해 모델이 스스로 결정하는 값을, 하이퍼파라미터는
             학습 시작 전 사람(또는 탐색 알고리즘)이 사전 설정해 학습 과정 자체를
             제어하는 값을 의미
           - 동일 모델 구조라도 하이퍼파라미터 설정에 따라 수렴 여부·성능이 좌우

    ```
    [하이퍼파라미터 설정] → [학습 프로세스 제어] → [파라미터(W,b) 최적화] → [모델 성능]
       Learning Rate              Forward/Backward         Weight, Bias
       Batch Size                 Gradient Descent
       Epoch, Optimizer 종류
    ```

    - 하이퍼파라미터가 학습 과정을 통제하고, 그 결과 파라미터가 자동 결정.

2. 파라미터와 하이퍼파라미터 비교

    | 구분 | 파라미터(Parameter) | 하이퍼파라미터(Hyperparameter) |
    |------|----------------------|----------------------------------|
    | 결정 주체 | 학습 알고리즘(역전파)이 자동 결정 | 사람 또는 튜닝 알고리즘이 사전 결정 |
    | 예시 | 가중치(Weight), 편향(Bias) | 학습률, 배치 크기, 은닉층 수, epoch |
    | 변경 시점 | 매 학습 스텝마다 갱신 | 학습 시작 전 고정(탐색 시 반복 조정) |
    | 최적화 방법 | 경사하강법(Gradient Descent) | Grid/Random Search, Bayesian Optimization 등 |

    | 분류 | 예시 | 설명 |
    |------|------|------|
    | 학습 제어 | 학습률, Batch Size, Epoch | 수렴 속도·안정성 결정 |
    | 모델 구조 | 은닉층 수, 노드 수, 커널 크기 | 모델 표현력·용량 결정 |
    | 정규화 | Dropout 비율, L1/L2 계수 | 과적합 방지 |
    | 최적화 알고리즘 | Optimizer 종류, Momentum 계수 | 파라미터 갱신 방식 결정 |

    - 학습 전 결정되는 하이퍼파라미터가 학습 중 결정되는 파라미터의 품질을 좌우.

3. 하이퍼파라미터 튜닝 방법 비교

    | 기법 | 방식 | 장점 | 단점 |
    |------|------|------|------|
    | Grid Search | 사전 정의 값 조합 전수 탐색 | 구현 단순, 재현성 높음 | 차원 증가 시 비용 폭증 |
    | Random Search | 탐색 공간 무작위 샘플링 | Grid 대비 효율적, 병렬화 용이 | 최적점 보장 안 됨 |
    | Bayesian Optimization | 대리모델로 성능 예측 후 유망 지점 탐색 | 적은 시도로 효율적 수렴 | 구현 복잡, 병렬화 제약 |
    | Hyperband/ASHA | 조기 종료로 저성능 후보 제거 | 자원 효율적, 대규모 탐색 적합 | 짧은 평가로 조기 판단 오류 가능 |

    - 탐색 공간이 작으면 Grid, 크면 Random/Bayesian, 대규모 딥러닝은 Hyperband로 저성능 후보 조기 제거.

4. 실무 적용 시 고려사항

    | 이슈 | 대응방안 |
    |------|----------|
    | 탐색마다 전체 학습 반복 → GPU 비용 폭증 | Random Search로 광역 탐색 후 Bayesian으로 정밀화(Coarse-to-Fine) |
    | 수십~수백 실험의 재현성 추적 곤란 | MLflow/W&B로 하이퍼파라미터-성능 자동 로깅, Seed 고정 |
    | AutoML 완전 자동 탐색의 비효율 구간 탐색 | 도메인 전문가가 범위를 좁힌 뒤 자동 탐색 위임(Human-in-the-loop) |

    - 최근 AutoML/NAS 결합형 자동 하이퍼파라미터 최적화가 MLOps 플랫폼 핵심 기능으로 적용 증대 예상.  "끝"
