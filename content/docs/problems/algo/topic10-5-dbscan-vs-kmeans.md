## 모범답안

### 1. DBSCAN과 K-means 개요

정 의  • K-means: 군집 개수 K를 사전 지정하고 중심점과의 거리를 최소화하도록 반복 갱신하는 분할 기반 군집화
       - DBSCAN(Density-Based Spatial Clustering): 밀도 높은 영역을 군집, 낮은 점을 노이즈로 분류하는 밀도 기반 군집화

```
[K-means]                    [DBSCAN]
  구형 군집만 탐색               임의 모양 군집 탐색
   ● ●  ○ ○                    ●●●●        ○○
  ●[C1]● ○[C2]○                ●●●●○○    ○○○
   ● ●  ○ ○                     ●●●     ×  (노이즈로 분류)
```

- K-means는 중심 기반, DBSCAN은 밀도 기반이라는 근본적인 군집화 철학의 차이.

### 2. DBSCAN과 K-means 상세 비교

| 구분 | K-Means | DBSCAN |
|------|---------|--------|
| 군집화 방식 | 중심점(Centroid) 기반 분할 | 밀도(Density) 기반 확장 |
| 필요 파라미터 | 군집 개수 K | 반경 ε(epsilon), 최소점 MinPts |
| 군집 개수 사전 지정 | 필요 | 불필요(자동 결정) |
| 군집 형태 | 원형/구형(Convex) 유리 | 임의 형태(비선형 경계) 탐색 가능 |
| 이상치(Noise) 처리 | 모든 점을 강제 군집 할당 | 밀도 낮은 점을 노이즈로 별도 분류 |
| 초기값 민감도 | 초기 중심점 따라 결과 상이 | 초기값 영향 적음 |
| 시간복잡도 | O(N·K·I) | O(N log N)(공간 인덱스 활용 시) |
| 대표 활용 | 고객 세분화, 이미지 색상 압축 | 지리공간 데이터 군집, 이상거래 탐지 |

- K-means는 이상치가 중심을 왜곡시켜 강건성 낮음, DBSCAN은 이상치를 자동 배제해 강건성 높음.

### 3. 핵심 파라미터, 한계 및 선택기준

```
DBSCAN 점 분류:
  Core Point   : 반경 ε 내 MinPts 이상의 이웃 보유
  Border Point : Core Point의 이웃이나 자신은 MinPts 미달
  Noise Point  : 어느 군집에도 속하지 않는 이상치
```

| 구분 | K-means | DBSCAN |
|------|---------|--------|
| 핵심 개념 | 엘보우 기법으로 최적 K 탐색 | Core/Border/Noise Point 3분류 |
| 한계 | 군집 크기/밀도 다르면 성능 저하 | ε·MinPts에 민감, 밀도 편차 큰 데이터 취약 |
| 대응 | 군집 균일·대용량 속도 중요 시 우선 검토 | k-distance 그래프로 ε 산정, HDBSCAN 대안 |

- 최근 밀도 편차 큰 실무 데이터 대응 위해 HDBSCAN 등 계층적 밀도기반 확장 기법 적용 증대.  "끝"
