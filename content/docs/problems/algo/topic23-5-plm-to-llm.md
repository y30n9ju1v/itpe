## 문제

자연어 언어모델에서의 PLM(Pre-trained Language Model)의 특성을 설명하고, 이 모델이 최종 LLM(Large Language Model)으로 만들어지는 과정에 대하여 훈련 특성을 중심으로 설명하시오.

## 모범답안

```
1. ChatGPT 이후 범용 LLM 요구, PLM 개요

   정 의  • 레이블 없는 대규모 텍스트 말뭉치로 자기지도학습(Self-
            Supervised Learning)을 통해 언어의 통계적 패턴/문맥 지식을
            사전 습득한 범용 언어모델 (예: BERT, GPT, T5)
          - MLM/CLM 등을 통해 다운스트림 전이(Transfer)를 목적하는 구조

   [대규모 비정형 텍스트] → Self-Supervised Learning
        → [PLM] → Fine-tuning(Downstream Task별)
        → 감성분석/개체명인식/번역 등

   - 초기 PLM은 태스크별 Fine-tuning 필요, 지시 이해/대화 능력은 부족.
```

| 특성 | 설 명 |
|------|-------|
| • 자기지도학습 | - 레이블 없는 원시 텍스트에서 학습 신호 자체 생성 |
| • 학습 목표 | - MLM(BERT, 양방향), CLM(GPT, 단방향 자기회귀) |
| • 범용성/전이학습 | - 특정 태스크 비종속, 사전학습 가중치 다운스트림 전이 |
| • 한계 | - 지시 이해력/대화 능력 부족, 태스크마다 별도 Fine-tuning 필요 |

```
2. PLM → LLM 훈련 파이프라인

   정 의  • PLM을 기반으로 지시 이해력과 인간 선호 정렬 능력을 순차
            추가 학습시켜 범용 대화/추론 가능한 LLM으로 완성하는 과정
          - Pre-training/SFT/RLHF 3단계를 통해 정렬(Alignment) 달성

   1단계 Pre-training → 2단계 SFT(Instruction Tuning) → 3단계 RLHF/Alignment
   (TB급 비정형 텍스트)   (지시-응답 쌍, 수만~수십만건)   (인간 선호 데이터, Reward Model)
        ↓                        ↓                          ↓
    Base PLM 생성        Instruction-tuned Model        RLHF 정렬 LLM
```

| 단계 | 목적 | 학습 방식 |
|------|------|-----------|
| ① Pre-training | • 언어 통계 구조/세계 지식 습득 | - 자기지도학습(MLM/CLM), 전체 비용의 90%↑ |
| ② SFT | • 지시 이해/형식 준수 조정 | - 지도학습(지시-모범답변 쌍) |
| ③ RLHF | • 인간 선호(유용/안전) 정렬 | - Reward Model 학습 + PPO/DPO 강화학습 |

- 3단계를 거치며 "다음 단어 예측 모델"에서 "사람이 원하는 방식으로 답하는 모델"로 진화.

```
3. PLM vs LLM 비교
```

| 구분 | PLM(Base) | LLM(정렬 후) |
|------|-----------|---------------|
| 능력 | • 언어 패턴/세계 지식 습득 | • 지시 이해 + 대화 + 선호 정렬 |
| 활용 | - 태스크별 Fine-tuning 필요 | - 범용 지시 수행(Zero/Few-shot) |
| 리스크 | - 다운스트림 적응 비용↑ | - 보상 해킹, 정렬 왜곡 가능성 |

- RLHF는 KL 페널티로 SFT 모델에서 과도하게 벗어나지 않도록 제약, 최근 저비용 DPO도 채택 확대.

```
4. 실무 적용 시사점
```

| 구분 | 이슈 | 대응 |
|------|------|------|
| 데이터 품질 | • 웹크롤링 데이터 편향/오류 → 환각 근본 원인 | - 필터링/중복제거/품질 스코어링 + RAG 결합 |
| 보상 해킹 | • 보상 모델을 속이는 장황한 응답 최적화 | - 다수 평가자 기반 보상모델, KL 페널티 |
| 구축 전략 | • 자체 Pre-training 시 비용/시간 과다 | - 오픈소스 Base(LLaMA, Qwen) + 도메인 SFT/DPO 집중 |

- 최근 사내 LLM 구축 시 오픈소스 PLM 기반 경량 정렬(SFT/DPO) 적용 증대 예상.  "끝"
