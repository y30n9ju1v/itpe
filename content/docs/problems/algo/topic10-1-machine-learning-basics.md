## 모범답안

### 1. 기계학습(Machine Learning)의 정의 및 배경

정 의  • 명시적 프로그래밍 없이 데이터로부터 패턴을 학습하여 입력에 대한
       출력을 예측·분류·군집화하는 AI의 하위 분야
      - 경험(E)으로 과업(T)의 성능지표(P)가 향상되는 시스템(Tom Mitchell 정의)

```
[학습 데이터] → [특징 추출/전처리] → [모델 학습(가설함수 최적화)]
                                            ↓
                                     [손실함수 최소화]
                                            ↓
                                  [학습된 모델] → 예측/분류
```

- 딥러닝 AI 서비스 확산으로 개별 알고리즘 암기보다 학습방식 선택 근거를 묻는 응용형 출제 증가.

### 2. 기본 알고리즘 및 학습데이터 제공방식별 분류

1) 기본 알고리즘

| 구분 | 대표 알고리즘 | 핵심 원리 |
|------|-------------|----------|
| 회귀 | 선형회귀, 릿지/라쏘 | 오차제곱합(SSE) 최소화 |
| 분류 | 로지스틱회귀, SVM, 결정트리 | 결정경계·정보이득 기반 분류 |
| 군집 | K-means, DBSCAN | 거리·밀도 기반 그룹화 |
| 앙상블 | Random Forest, XGBoost | 다수 약학습기 결합 |

2) 학습데이터 제공방식별 분류

| 구분 | 지도학습(Supervised) | 비지도학습(Unsupervised) | 강화학습(Reinforcement) |
|------|----------------------|---------------------------|--------------------------|
| 데이터 | 입력-정답(Label) 쌍 | 레이블 없는 데이터 | 상태-행동-보상 시퀀스 |
| 목적 | 예측·분류 함수 학습 | 구조·패턴 발견 | 누적보상 최대화 정책 학습 |
| 학습기술 | 회귀, SVM, CNN/RNN | 군집화, 차원축소(PCA) | Q-Learning, DQN, Policy Gradient |
| 예시 | 주차 수요 예측, 스팸 필터 | 고객 세분화, 이상탐지 | 신호등 제어, 로봇 경로학습 |

- 준지도·자기지도학습은 소량 레이블+대량 비레이블 결합으로 레이블링 비용 절감.

### 3. 주차 문제 예측 시스템 구현방법

```
[주차장 CCTV/센서 데이터] → [시계열 특징 추출: 요일/시간대/날씨]
        ↓
[지도학습: 회귀(가능대수) or 분류(만차여부)]
        ↓
[모델 서빙 API] → [내비게이션/앱 안내]
        ↓
[실사용 로그 피드백 → 재학습(온라인러닝)]
```

| 구분 | 항목 | 설 명 |
|------|------|-------|
| ① 데이터 수집 | 입출차 로그 | - 시간대/요일/날씨/행사정보 특징화 |
| ② 모델 선정 | LSTM/XGBoost | - 시계열 특성 강해 회귀모델 채택 |
| ③ 검증 | k-fold 교차검증 | - 과적합 방지, RMSE/MAE 평가 |
| ④ 배포 | MLOps 파이프라인 | - 실시간 API화, 주기적 재학습 |

- 초기엔 비지도학습(군집)으로 이용패턴 발견 후, 데이터 축적되면 지도학습으로 전환하는 단계적 접근 필요.

### 4. 실무 적용 시사점

| 이슈 | 대응방안 |
|------|----------|
| 클래스 불균형 | SMOTE 오버샘플링, F1-score/재현율 채택 |
| 컨셉 드리프트 | 드리프트 감지 시 자동 재학습 트리거(CI/CD MLOps) |

- 최근 데이터 분포 변화(Concept Drift) 대응 위한 MLOps 기반 지속 운영체계 적용 증대.  "끝"
