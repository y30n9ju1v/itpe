## 문제

신경망 모델 학습 시 예측 값과 실제 값의 차이를 줄이기 위해 최적화를 수행한다. 딥러닝 모델 학습 최적화에 대해 다음을 설명하시오
가. 비용함수(Cost function) 종류
나. 최적화(Optimizer)알고리즘 종류

## 모범답안

1. 비용함수와 옵티마이저의 관계 개요

    정 의  • 비용함수(Loss/Cost Function)는 예측값과 실제값의 오차를 정량화하고,
             옵티마이저(Optimizer)는 그 값을 최소화하도록 파라미터(W,b)를 갱신하는
             알고리즘
           - 신경망 학습은 오차 정의(비용함수)와 감소 전략(옵티마이저)의 문제로 귀결

    ```
    [예측값 ŷ] vs [실제값 y]
            ↓
       비용함수 L(ŷ,y) 계산
            ↓
       역전파(Backpropagation)로 ∂L/∂W 계산
            ↓
       옵티마이저가 W ← W - η·∂L/∂W 형태로 파라미터 갱신 (η: 학습률)
    ```

    - 비용함수 선택 오류는 학습 방향 왜곡, 옵티마이저 선택 부적절은 수렴 저하로 직결.

2. 가. 비용함수(Cost Function) 종류

    | 비용함수 | 수식 | 적용 태스크 |
    |----------|------|-------------|
    | MSE | (1/n)Σ(y-ŷ)² | 회귀(Regression) |
    | MAE | (1/n)Σ\|y-ŷ\| | 회귀, 이상치에 강건 |
    | Binary Cross-Entropy | -(1/n)Σ[y·log(ŷ)+(1-y)log(1-ŷ)] | 이진 분류 |
    | Categorical Cross-Entropy | -(1/n)ΣΣ y_ij·log(ŷ_ij) | 다중 클래스 분류 |
    | Huber Loss | \|e\|≤δ: 0.5e² / \|e\|>δ: δ(\|e\|-0.5δ) | 회귀, MSE·MAE 절충 |

    - 회귀는 MSE/MAE, 분류는 Cross-Entropy 계열 기본, 이상치 민감도에 따라 Huber로 절충.

3. 나. 최적화(Optimizer) 알고리즘 종류

    ```
    GD(Batch) → SGD → Momentum ─┐
                                  ├─ Adam (Momentum + RMSProp 결합)
                  AdaGrad → RMSProp ┘
    ```

    | 옵티마이저 | 핵심 아이디어 | 특징 |
    |------------|----------------|------|
    | GD | 전체 데이터로 1회 갱신 | 안정적이나 느리고 메모리 부담 큼 |
    | SGD | 미니배치 단위로 갱신 | 빠르나 진동(Noise) 발생 |
    | Momentum | 이전 기울기 방향 관성 누적 | 진동 완화, 수렴 가속 |
    | AdaGrad | 파라미터별 학습률을 누적 기울기 제곱에 반비례 조정 | 희소 데이터 유리, 학습률 과소수렴 문제 |
    | RMSProp | 누적 기울기를 지수이동평균으로 대체 | 학습률 급감 문제 완화 |
    | Adam | Momentum(1차 모멘트)+RMSProp(2차 모멘트) 결합 | 가장 널리 사용, 빠른 수렴·안정성 |

    - Adam은 실무 기본 선택지이나, 최종 일반화 성능 극대화 목표 시 SGD+Momentum 재학습도 병행.

4. 실무 적용 시 고려사항

    | 이슈 | 대응방안 |
    |------|----------|
    | Adam이 SGD+Momentum 대비 일반화 성능 열세 사례 존재 | Adam으로 초기 수렴 확인 후 SGD+Momentum/AdamW로 미세조정(2단계 전략) |
    | 태스크-비용함수 불일치로 학습 발산 | 출력층 활성화-비용함수 표준 매핑표를 코드리뷰 체크리스트化 |
    | 클래스 불균형 시 다수 클래스 편향 학습 | Weighted Cross-Entropy, Focal Loss로 소수 클래스 기여도 보정 |

    - 최근 태스크별 비용함수 자동 매칭과 AdamW 등 개선 옵티마이저 적용 증대 예상.  "끝"
