## 모범답안

1. 4대 알고리즘 설계 기법 개요

    정 의  • 문제를 해결하기 위해 부분 문제로 나누고 조합하는 방식을 규정한
             알고리즘 설계 전략의 총칭
           - 분할정복/DP/탐욕법/백트래킹 등을 문제 특성에 맞게 선택 적용하는 구조

    ```
    [문제 해결 전략]
       │
       ├─ 분할정복(D&C)     : 부분 문제로 나눠 독립적으로 해결 후 병합
       ├─ 동적계획법(DP)    : 중복 부분 문제를 메모이제이션으로 재사용
       ├─ 탐욕법(Greedy)    : 매 단계 국소 최적 선택, 전역 최적 기대
       └─ 백트래킹          : 해 공간 탐색 중 조건 불만족 시 되돌아감(가지치기)
    ```

    - 4가지 모두 "큰 문제를 작은 단위로 나눈다"는 공통점을 갖되, 부분해 재사용 여부·탐색 방식에서 차이.

2. 기법별 개념 및 알고리즘 사례

    | 구분 | 개념 | 대표 사례 |
    |------|------|-----------|
    | 분할정복 | 독립된 부분 문제로 분할, 재귀 해결 후 결합 | 병합정렬, 퀵정렬, 이진탐색 |
    | 동적계획법 | 부분 문제 해를 메모이제이션 후 재사용 | 피보나치, 0/1 배낭문제, LCS |
    | 탐욕법 | 매 단계 국소 최선 선택, 번복 없음 | 크루스칼/프림 MST, 다익스트라, 허프만 코딩 |
    | 백트래킹 | 해 후보 구성 중 제약 위반 시 이전 단계 회귀 | N-Queen, 부분집합 합, 그래프 색칠 |

    1) 분할정복 vs 동적계획법

    - 분할정복은 부분 문제가 독립(중복 無)이라 저장이 불필요하나, DP는 동일 부분 문제가 반복되어 캐싱으로 재계산을 방지.
    - 예: 피보나치 순수 재귀는 O(2ⁿ), 메모이제이션 적용 시 O(n)으로 감소.

    2) 탐욕법 최적해 보장 조건

    ```
    1. 탐욕 선택 속성(Greedy Choice Property): 국소 최적 선택이 전역 최적으로 이어짐
    2. 최적 부분 구조(Optimal Substructure)  : 부분 문제 최적해가 전체 최적해 구성
    ```

    - DP 내부에서 분할정복적 사고를 활용하는 등 4가지 기법은 배타적이지 않고 보완적으로 사용.

3. 4대 기법 종합 비교

    | 비교 항목 | 분할정복 | 동적계획법 | 탐욕법 | 백트래킹 |
    |-----------|----------|------------|--------|----------|
    | 최적해 보장 | O(부분 독립 시) | O(최적부분구조 성립 시) | X(조건부 O) | O(전체 탐색 시) |
    | 부분문제 중복 | 없음 | 있음(핵심 조건) | 해당없음 | 있을 수 있음 |
    | 시간복잡도 경향 | O(n log n) 대 | O(n²)~O(n·W) | O(n log n) | 지수적(가지치기로 완화) |
    | 대표 문제 | 정렬, 탐색 | 배낭문제, 편집거리 | MST, 최단경로 | 조합 탐색, 제약 만족 |

    - 백트래킹은 단순 완전탐색과 달리 제약 위반 시 즉시 분기를 포기해 탐색 공간을 대폭 축소.

4. 실무 적용 시 고려사항

    | 이슈 | 대응방안 |
    |------|----------|
    | 탐욕 선택 속성 미성립 문제에 오적용(근사해 그침) | 속성 성립 여부 사전 증명 + DP/ILP 결과 벤치마크 |
    | DP 상태 공간 다차원 확장 시 메모리 폭증 | Bitmask DP, 롤링 배열로 차원 축소 |
    | 백트래킹 가지치기 느슨 시 탐색 시간 폭발 | 제약 전파, 휴리스틱 순서로 조기 가지치기 강화 |

    - 최근 클라우드 자원 스케줄링·추천 최적화 등에서 기법 혼합형(하이브리드) 적용 증대 예상.  "끝"
