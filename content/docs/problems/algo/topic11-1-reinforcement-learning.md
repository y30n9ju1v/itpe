## 모범답안

### 1. 강화학습(Reinforcement Learning) 개요

정 의  • 에이전트(Agent)가 환경(Environment)과 상호작용하며 시행착오를 통해
       누적 보상(Cumulative Reward)을 최대화하는 정책을 학습하는 방법론
      - 지도학습(정답 제공)과 달리 '보상'이라는 지연된 피드백으로 학습

```
        ┌─────────────┐  Action(aₜ)
        │   Agent     │ ──────────────►┐
        │ (정책 π)     │                │
        └─────────────┘ ◄──────────────┘
              ▲            State(sₜ₊₁), Reward(rₜ₊₁)
              │        ┌─────────────┐
              └────────│ Environment │
                       └─────────────┘
```

- 알파고 이후 로봇제어·자율주행·추천시스템 등 순차적 의사결정 문제로 확산.

### 2. 강화학습의 정책(Policy) 및 MDP 구성요소

1) 구성요소

| 구성요소 | 설명 |
|----------|------|
| Agent | 학습 및 행동 주체 |
| Environment | 에이전트가 상호작용하는 대상 |
| State(s) | 현재 환경의 상태 |
| Action(a) | 에이전트가 취하는 행동 |
| Reward(r) | 행동에 대한 환경의 피드백(보상) |
| Policy(π) | 상태에서 행동을 결정하는 전략(확률분포) |

2) 마르코프 결정과정(MDP) 튜플 (S, A, P, R, γ)

| 구성요소 | 기호 | 설명 |
|----------|------|------|
| 상태집합 | S | 가능한 모든 상태 |
| 행동집합 | A | 가능한 모든 행동 |
| 전이확률 | P(s'\|s,a) | 상태 s에서 행동 a 시 s'로 전이될 확률 |
| 보상함수 | R(s,a) | 상태·행동에 대한 즉각 보상 |
| 할인율 | γ(0≤γ≤1) | 미래 보상을 현재가치로 환산하는 계수 |

```
MDP 순환 구조:
  s₀ --a₀--> (P, R) --> s₁ --a₁--> (P, R) --> s₂ --> ...
       r₀                    r₁
목표: 누적 보상 기대값 최대화
  Gₜ = rₜ + γrₜ₊₁ + γ²rₜ₊₂ + ... = Σ γᵏrₜ₊ₖ
```

- 정책은 결정적/확률적 정책으로 구분, 마르코프 특성으로 '현재 상태'만으로 최적 정책 계산 가능해 계산적으로 효율적.

### 3. 강화학습 알고리즘 분류(비교)

| 구분 | 모델 기반(Model-Based) | 모델 프리(Model-Free) |
|------|--------------------------|--------------------------|
| 전제 | 전이확률 P, 보상함수 R을 알고 있음 | P, R을 모름, 경험으로 추정 |
| 대표 기법 | 가치반복, 정책반복(Policy Iteration) | Q-Learning, SARSA, DQN, Policy Gradient |
| 활용 | 시뮬레이션 가능 환경(체스 등) | 실세계처럼 환경 모델을 모르는 경우 |

- 목표는 누적 보상 기대값을 최대화하는 최적 정책 π*를 찾는 것.

### 4. 실무 적용 시사점

| 이슈 | 대응방안 |
|------|----------|
| 탐험-활용 균형(Exploration vs Exploitation) | ε-greedy, UCB로 학습 초기 탐험 비중↑ 이후 활용 비중↑ |
| 실세계 샘플 효율성 문제 | Sim-to-Real 전략, 모델 기반 강화학습 병행 |

- 최근 시뮬레이터(Digital Twin) 사전학습 후 실환경 전이하는 Sim-to-Real 적용 증대.  "끝"
