## 문제

정렬 알고리즘은 컴퓨터 분야에서 가장 많이 연구된 분야 중 하나이다.

가. 선택정렬(Selection Sort)과 삽입정렬(Insertion Sort), 퀵정렬(Quick Sort) 알고리즘을 설명하시오.
나. 다음 키 값을 갖는 파일을 퀵정렬(Quick Sort) 알고리즘을 사용하여 오름차순으로 정렬하려고 한다. 피벗이 50일 때 수행되는 분할과 정을 단계적으로 설명하시오. (단, n=8: 50, 80, 20, 90, 40, 10, 30, 60)

## 모범답안

1. "가" 3대 정렬 알고리즘 개요

    정 의  • 선택정렬은 최솟값 탐색 교환, 삽입정렬은 정렬구간 삽입, 퀵정렬은
             피벗 분할을 반복 적용하는 비교 기반 정렬 기법
           - 미정렬 데이터를 특정 기준(최솟값/삽입위치/피벗)으로 정렬하는 구조

    ```
    선택정렬: [최솟값 탐색] → [맨앞과 교환] → 미정렬 구간 축소, 반복
    삽입정렬: [현재 원소] → [정렬 구간 삽입 위치 탐색] → 이동 후 삽입, 반복
    퀵정렬  : [피벗 선정] → [작은/큰 그룹 분할] → 분할정복 재귀 정렬
    ```

2. 3대 정렬 알고리즘 상세 비교

    | 구분 | 선택정렬 | 삽입정렬 | 퀵정렬 |
    |------|----------|----------|--------|
    | 핵심 동작 | 최솟값 찾아 맨앞 교환 | 정렬구간에 알맞은 위치 삽입 | 피벗 기준 좌/우 분할 후 재귀 |
    | 평균 시간복잡도 | O(n²) | O(n²) | O(n log n) |
    | 최악 시간복잡도 | O(n²) | O(n²) | O(n²) |
    | 안정성 | 불안정 | 안정 | 불안정 |
    | 추가 메모리 | O(1) | O(1) | O(log n)(재귀 스택) |

    - 선택정렬은 "최솟값을 찾아 앞으로", 삽입정렬은 "새 값을 알맞은 자리로", 퀵정렬은 "기준값으로 나눠서 재귀"라는 전략 차이.

3. "나" 퀵정렬 분할과정 트레이스 (피벗=50, Hoare 방식)

    배열: [50,80,20,90,40,10,30,60], 피벗=arr[0]=50

    | 단계 | i 탐색 | j 탐색 | 교환 | 배열 상태 |
    |------|--------|--------|------|-----------|
    | 초기 | i=1(80) | j=7(60) | - | [50,80,20,90,40,10,30,60] |
    | 1회전 | arr[1]=80≥50 정지 | j=6(30)≤50 정지 | swap(80,30) | [50,30,20,90,40,10,80,60] |
    | 2회전 | i=3(90)≥50 정지 | j=5(10)≤50 정지 | swap(90,10) | [50,30,20,10,40,90,80,60] |
    | 3회전 | i=5(90)≥50 정지 | j=4(40)≤50 정지 | i≥j 종료 | [50,30,20,10,40,90,80,60] |
    | 피벗배치 | - | - | swap(arr[0],arr[4]) | |[40,30,20,10,50,90,80,60]| |

    - 분할 완료: 피벗 50은 인덱스|4|로 확정 배치. 좌측 |[40,30,20,10]|(50 미만), 우측 |[90,80,60]|(50 초과).
    - 좌/우 그룹을 재귀 분할 반복 시 최종 오름차순 |[10,20,30,40,50,60,80,90]| 완성.

4. 실무 적용 시 고려사항

    | 이슈 | 대응방안 |
    |------|----------|
    | 첫 원소 피벗 고정 시 정렬/역순 데이터에서 O(n²) | 무작위 피벗 또는 Median-of-Three 기법 적용 |
    | 편중 재귀로 스택 O(n)까지 증가, 오버플로우 위험 | 작은 그룹 우선 재귀 + 큰 그룹 꼬리 재귀 최적화 |
    | 불안정 정렬로 동순위 레코드 순서 뒤바뀜 | 안정성 필요 시 병합정렬 채택 또는 보조 키 추가 |

    - 최근 대규모 배치 정렬에서 Randomized Pivot 및 하이브리드(Introsort) 적용 증대 예상.  "끝"
