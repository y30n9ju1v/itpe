## 모범답안

1. 인공지능 신뢰성 개념

   정 의  • AI 시스템이 의도한 목적에 맞게 일관되고 안전하게 작동하며,
            그 결과와 의사결정 과정을 사람이 이해·검증·통제할 수 있는
            다차원적 속성의 집합
          - 단일 지표(정확도)가 아닌 복수 속성의 균형으로 평가되는 개념

```
        [인공지능 신뢰성]
   ┌───────┬───────┬───────┬───────┬───────┐
 강건성   설명가능성  공정성   안전성   프라이버시
(Robust) (Explain)  (Fair)  (Safety) (Privacy)
```

- NIST 'Trustworthy AI', EU AI Act 신뢰성 요구사항 등 국제 표준·규제 기관들이 신뢰성을 다차원적 속성 집합으로 정의.

2. 핵심 속성

| 속성 | 설명 | 관련 기법/예시 |
|------|------|-----------------|
| 강건성(Robustness) | 노이즈·적대적 입력·환경 변화에도 안정적 성능 유지 | 적대적 학습, 스트레스 테스트 |
| 설명가능성(Explainability) | 모델의 판단 근거를 사람이 이해할 수 있도록 제시 | XAI(SHAP, LIME), 어텐션 시각화 |
| 투명성(Transparency) | AI 활용 사실, 데이터·모델 정보를 공개 | 모델 카드(Model Card), 데이터시트 |
| 공정성(Fairness) | 특정 집단에 대한 편향·차별 없이 공평한 결과 산출 | 편향 탐지·완화 알고리즘, 균형 데이터셋 |
| 안전성(Safety) | 오작동 시에도 인명·재산 피해를 최소화 | 페일세이프 설계, 안전 검증 테스트 |
| 프라이버시(Privacy) | 학습·추론 과정에서 개인정보 보호 | 차등 프라이버시, 연합학습, 머신 언러닝 |
| 책임성(Accountability) | 문제 발생 시 책임 주체와 소재를 명확히 규명 가능 | 감사로그, 거버넌스 체계 |

- 속성 간 상충 관계 존재: 설명가능성 강화 시 모델 복잡도 제약으로 정확도 저하, 프라이버시 보호(노이즈 추가)는 강건성·정확도와 트레이드오프.

3. 신뢰성 확보를 위한 접근 체계 및 시사점

| 단계 | 접근 방법 |
|------|----------|
| 설계 | Trustworthy by Design - 개발 초기부터 신뢰성 요건을 설계에 반영 |
| 검증 | 속성별 정량 지표(공정성 지표, 강건성 벤치마크) 기반 평가 |
| 운영 | 배포 후 지속적 모니터링과 드리프트(Drift) 탐지 |
| 거버넌스 | 조직 차원의 AI 위험관리 체계(ISO/IEC 42001 등)와 연계 |

- 최근 MLOps 파이프라인에 신뢰성 모니터링(성능·편향·강건성)을 내재화한 지속적 재검증 체계 적용 증대.  "끝"
