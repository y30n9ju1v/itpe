## 모범답안

1. 베이지안 최적화 개요

    정 의  • 목적함수 f(x)의 형태를 알 수 없는 블랙박스 최적화 문제에서 베이즈
             정리 기반 확률 모델로 함수를 근사하고, 획득함수로 다음 탐색 지점을
             결정해 최소 시도 횟수로 전역 최적점에 근접하는 기법
           - 하이퍼파라미터 튜닝, 실험설계(DOE), 신약 화합물 탐색 등에 범용 적용

    ```
    [초기 랜덤 샘플 관측] → [대리모델(Surrogate) 적합]
            ↓                        ↓
      [획득함수로 다음 탐색점 x* 선정] ← [사후분포(Posterior) 갱신]
            ↓
      [f(x*) 실제 평가(모델 학습)] → 반복(Iteration)
    ```

    - 대리모델·획득함수를 반복 갱신하며 유망 영역을 우선 탐색하는 순차적 최적화.

2. 핵심 구성요소 ① 대리모델(Surrogate Model)

    | 대리모델 | 특징 | 적합한 상황 |
    |----------|------|--------------|
    | Gaussian Process(GP) | 불확실성 정량화 우수, 저차원 적합 | 하이퍼파라미터 5~20개 내외 |
    | Random Forest(SMAC) | 고차원·범주형 변수에 강건 | 대규모 조합형 탐색 공간 |
    | TPE | 조건부 분포 기반, 계산 효율적 | 대규모 반복 탐색(Optuna 등) |

    - GP는 관측 지점 근처 분산이 작고 미관측 영역은 분산이 커, 탐색 우선순위 판단 근거로 활용.

3. 핵심 구성요소 ② 획득함수(Acquisition Function)

    | 획득함수 | 수식 개념 | 특징 |
    |----------|-----------|------|
    | Expected Improvement(EI) | 현재 최적값 대비 기대 개선량 최대화 | 가장 널리 사용, 안정적 |
    | Probability of Improvement(PI) | 현재 최적값 개선 확률 최대화 | 보수적, 과도한 활용 경향 |
    | Upper Confidence Bound(UCB) | μ(x)+κ·σ(x) 최대화 | κ로 탐색/활용 비율 직접 조절 |

    - 활용(Exploitation, 좋았던 영역 정밀탐색)과 탐색(Exploration, 불확실 영역 시도)의 균형을 수치화.
    - 고차원(수십 개 이상)에서는 GP의 O(n³) 복잡도가 급증하므로 TPE 기반 도구(Optuna) 또는 사전 민감도 분석으로 차원 축소.
    - 순차 탐색 구조로 병렬화가 제약되므로 Batch BO(q-EI)로 다중 후보 동시 제안, 초기 샘플 편향은 라틴 하이퍼큐브 샘플링으로 완화.
    - 최근 AutoML/MLOps 플랫폼에서 베이지안 최적화 채택 증대 예상.  "끝"
