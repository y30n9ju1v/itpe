## 모범답안

### 1. 연합학습(Federated Learning) 정의

정 의  • 각 디바이스/기관이 보유한 원본 데이터를 중앙 서버로 전송하지 않고
       로컬에서 모델을 학습한 후, 그 결과(가중치/그래디언트)만 서버에 전송해
       통합 모델을 구축하는 분산 협업 학습 기법
      - "데이터는 머물고, 모델이 이동한다"는 프라이버시 보존 원칙

```
[중앙 서버: 글로벌 모델]
        │  ① 초기 모델 배포
   ┌────┼────┬────────┐
   ▼         ▼         ▼
[Device A] [Device B] [Device C]
 로컬학습    로컬학습    로컬학습
 (원본데이터 미이동)
   │         │         │
   └────┬────┴─────────┘
        ▼ ② 가중치/그래디언트만 전송
[중앙 서버: 가중치 집계(Aggregation, 예: FedAvg)]
        │ ③ 통합 모델 갱신 후 재배포
```

### 2. 연합학습의 절차 및 핵심 기술요소

| 단계 | 내용 |
|------|------|
| ① 모델 배포 | 중앙 서버가 초기 글로벌 모델을 각 클라이언트에 전송 |
| ② 로컬 학습 | 각 디바이스가 자체 보유 데이터로 로컬 모델 학습 |
| ③ 파라미터 전송 | 원본 데이터 대신 학습된 가중치/그래디언트만 서버로 전송 |
| ④ 집계(Aggregation) | 서버가 각 클라이언트 결과를 집계(FedAvg 등)해 글로벌 모델 갱신 |
| ⑤ 반복 | 갱신된 모델을 재배포하여 수렴할 때까지 반복 |

| 핵심 기술 | 설명 |
|-----------|------|
| FedAvg(연합평균) | 데이터 수 비례 가중평균으로 클라이언트 가중치 집계 |
| 차등 프라이버시 | 그래디언트에 노이즈 추가해 역추론 공격 방지 |
| 동형암호 | 암호화 상태에서 가중치 집계 연산 수행 |
| Secure Aggregation | 개별 클라이언트 값을 서버가 알 수 없도록 안전 합산 |

- GDPR 등 프라이버시 규제 강화와 엣지 디바이스 연산능력 향상이 맞물려 주목받은 기술.

### 3. 유형, 활용사례 및 확장 방안

| 구분 | 설명 | 사례 |
|------|------|------|
| 수평적 연합학습 | 특징(Feature)은 같고 샘플이 다른 기관 간 학습 | 여러 병원의 유사 진료 데이터 |
| 수직적 연합학습 | 샘플은 같고 특징이 다른 기관 간 학습 | 은행(신용정보)+쇼핑몰(구매정보) |
| 대표 사례 | 구글 Gboard 온디바이스 학습, 병원 간 의료AI 공동개발 | - |

| 이슈 | 대응방안 |
|------|----------|
| 통신 오버헤드/Non-IID 수렴 불안정 | 모델 압축(Quantization), FedProx 등 Non-IID 대응 |
| Gradient Leakage/Poisoning 공격 | 차등 프라이버시+Secure Aggregation, Robust Aggregation |

- 최근 Byzantine-robust FedAvg 등 참여자 신뢰성 관리 기법 적용 증대.  "끝"
