## 문제

## 모범답안

```
1. 비대면 서비스 확산, 워드 임베딩 개요

   정 의  • 자연어의 단어를 컴퓨터가 처리 가능한 실수 벡터로 매핑,
            단어의 의미/문맥적 유사도를 수치로 표현하는 기법
          - 벡터 공간상 거리(Cosine Similarity)로 단어 간 유사도 계산

   [말뭉치] → 토큰화 → [단어] → [임베딩] → [벡터]
                                    ↑
                   희소 표현(Sparse) ↔ 분산 표현(Dense)

   - 챗봇 상담/문서 분석 등 비대면 서비스 확산으로 단어의 벡터화 중요.
```

| 구분 | 희소 표현 | 분산 표현 |
|------|-----------|-----------|
| 정의 | • 단어를 고차원 원-핫 벡터로 표현 | • 저차원 실수 벡터에 의미 분산 저장 |
| 대표 기법 | • One-Hot, TF-IDF, BoW | • Word2Vec, GloVe, FastText |
| 차원/유사도 | - 수만~수십만 차원, 유사도 미반영 | - 100~300차원, 코사인 유사도 반영 |

- 희소 표현은 통계적 빈도 의존, 분산 표현은 신경망 학습으로 의미를 벡터에 압축.

```
2. TF-IDF(Term Frequency-Inverse Document Frequency)

   정 의  • 문서 내 등장 빈도(TF)와 전체 문서군에서의 희소성(IDF)을
            곱해 단어의 문서 내 중요도를 산출하는 통계 기반 가중치 기법

   TF-IDF(t,d) = TF(t,d) × IDF(t)
   TF(t,d) = 문서 d 내 단어 t 등장 횟수 / d의 전체 단어 수
   IDF(t)  = log( N / df(t) )   ※ N: 전체 문서 수, df(t): t가 등장한 문서 수
```

| 구분 | 항목 | 설 명 |
|------|------|-------|
| TF | • Term Frequency | - 문서 내 등장 빈도↑ → 값↑, 중요 단어 강조 |
| IDF | • Inverse Doc. Freq. | - 여러 문서에 흔한 단어일수록 값↓, 불용어 억제 |
| 결과 | • 희소 행렬 | - 문서×어휘 크기, 문서분류/검색랭킹 활용 |

- 불용어는 모든 문서에 등장(df↑)해 IDF가 낮아지므로 자동으로 가중치 감소.

```
3. Word2Vec 개념 및 구조

   정 의  • 얕은 신경망으로 주변 문맥에서 단어를 예측하도록 학습,
            은닉층 가중치를 단어의 분산 표현 벡터로 사용하는 예측 기반 기법

   CBOW: 주변단어 → 중심단어 예측         Skip-gram: 중심단어 → 주변단어 예측
   [w(t-2)..w(t+2)] → 은닉층 → w(t)       w(t) → 은닉층 → [w(t-2)..w(t+2)]
```

| 구분 | CBOW | Skip-gram |
|------|------|-----------|
| 학습 방향 | • 주변→중심 예측 | • 중심→주변 예측 |
| 속도/데이터 | - 빠름, 소규모 데이터 적합 | - 느림, 대규모/희소단어에 강함 |
| 최적화 | • Negative Sampling, Hierarchical Softmax 공통 적용 | 동일 |

- Negative Sampling: 전체 Softmax 대신 오답 단어 일부만 샘플링해 학습 비용 절감.
- 벡터 연산으로 의미 관계 표현: vec(King)-vec(Man)+vec(Woman)≈vec(Queen).

```
4. TF-IDF vs Word2Vec 비교 및 시사점
```

| 구분 | TF-IDF | Word2Vec |
|------|--------|----------|
| 표현 방식 | • 희소/통계 기반 | • 분산/예측 기반 |
| 의미 반영 | - 빈도 기반, 문맥 의미 미반영 | - 신경망 학습, 문맥적 의미 반영 |
| 한계 | - 차원의 저주, OOV 대응 곤란 | - 다의어 구분 불가(정적 임베딩) |
| 실무 활용 | • 1차 검색/필터링 baseline | • 임베딩 기반 유사도/추천 |

- TF-IDF는 FastText/트랜스포머 임베딩과 하이브리드로 재랭킹, Word2Vec은 도메인 말뭉치 재학습으로 보완.
- 최근 BERT 등 문맥적 임베딩(Contextual Embedding) 기반 LLM 임베딩 적용 증대.  "끝"
