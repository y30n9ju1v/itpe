## 모범답안

1. MST(최소신장트리) 개요

    정 의  • N개 정점을 갖는 그래프에서 모든 정점을 포함하며 사이클 없이
             간선 가중치 합이 최소가 되는 부분 그래프
           - 간선 수=정점 수-1, Greedy 알고리즘의 대표적 응용 구조

    ```
    [가중치 그래프 G]
            ↓ MST 알고리즘 적용
    [사이클 없는 N-1개 간선의 트리]
            ↓
       총 가중치 합 최소 보장
    ```

    - 통신망·전력망 설계, 클러스터링 등 최소비용 연결 문제에 적용.
    - MST는 동일 가중치 존재 시 유일하지 않을 수 있으나 최소 총합은 항상 유일.

2. 크루스칼(Kruskal) 알고리즘 vs 프림(Prim) 알고리즘

    1) 알고리즘 절차

    ```
    Kruskal: 간선 정렬 → 최소 간선부터 선택 → Union-Find 사이클 검사 → N-1개 채택 시 종료
    Prim   : 시작 정점 → 인접 최소간선 탐색(우선순위 큐) → 트리 집합 확장 → 전 정점 포함 시 종료
    ```

    2) 비교표

    | 구분 | 크루스칼 | 프림 |
    |------|----------|------|
    | 접근 방식 | 간선(Edge) 중심 | 정점(Vertex) 중심 |
    | 사이클 판별 | Union-Find(Disjoint Set) | 방문 집합으로 자연 배제 |
    | 자료구조 | 간선 리스트+Union-Find | 우선순위 큐+인접리스트 |
    | 시간복잡도 | O(E logE) | O(E logV) |
    | 적합 그래프 | 희소 그래프 | 밀집 그래프 |
    | 트리 성장 | 부분 트리(숲)가 병합 | 하나의 트리가 점진 확장 |

    - 크루스칼은 간선을 전역적으로, 프림은 트리를 정점 단위로 확장한다는 점이 본질적 차이.

3. 알고리즘 선택 기준 비교

    | 판단 기준 | 권장 | 사유 |
    |-----------|------|------|
    | E≈V(희소) | 크루스칼 | 정렬 비용 적고 Union-Find 거의 상수시간 |
    | E≈V²(밀집) | 프림 | 인접행렬+Heap 조합이 정점 확장에 효율적 |
    | 분산/병렬 처리 | 크루스칼 | 간선 정렬 후 독립적 병합, 병렬화 용이 |
    | 실시간 점진 확장 | 프림 | 트리가 항상 연결 집합 유지, 중간 결과 활용 |

    - 그래프 밀도와 처리 방식(분산/실시간)에 따라 알고리즘을 선택 적용.

4. 실무 적용 시 고려사항

    | 이슈 | 대응방안 |
    |------|----------|
    | Union-Find 최적화 누락 시 O(E·V)까지 성능 저하 | 경로 압축+Union by Rank 병행 적용 |
    | 동일 가중치 존재 시 MST 유일해 오인 | 복수 MST 후보 도출 후 복구성 등 2차 기준 적용 |
    | 동적 그래프에서 매번 전체 재계산 비효율 | 증분 갱신형 Dynamic MST 또는 국소 재계산 적용 |

    - 최근 클라우드 인프라의 동적 토폴로지 확대로 증분형 MST 재계산 기법 적용 증대 예상.  "끝"
