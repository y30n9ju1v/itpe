## 모범답안

1. VLA 모델 개요

   정 의  • 시각(Vision) 입력과 언어(Language) 지시를 함께 이해하여
            로봇의 물리적 행동(Action)을 직접 생성하는 통합 파운데이션 모델
          - 기존 '인지→계획→제어' 분리형 파이프라인을 End-to-End로 통합

```
[카메라 이미지] ─┐
                 ├─▶  VLA 모델 (Transformer 기반)  ─▶  [행동 토큰]
[자연어 명령]   ─┘        (VLM 백본 + Action Head)        (관절각/속도 등)
```

- 시각-언어 모델(VLM)에 행동 출력을 위한 액션 헤드(Action Head)를 결합한 구조, 피지컬 AI의 '두뇌' 역할.

2. VLA 모델 핵심 구성요소

| 구분 | 구성요소 | 설명 |
|------|---------|------|
| 입력 | 멀티모달 인코더 | 이미지·자연어를 공통 임베딩 공간으로 인코딩(ViT+LLM) |
| 중간 | 백본(Backbone) | 사전학습된 대규모 VLM(예: PaLI-X, PaLM-E 등) 활용 |
| 출력 | 액션 토큰화 | 연속적 로봇 제어값을 이산 토큰으로 변환해 언어모델처럼 예측 |
| 학습 | 로봇 시연 데이터 | 원격조작(Teleoperation), Open X-Embodiment 등 대규모 로봇 데이터셋 |
| 실행 | 저지연 추론 | 실시간 제어를 위한 경량화·양자화(Distillation, Quantization) |

- 언어모델의 다음 토큰 예측 방식을 로봇 행동 예측으로 확장한 것이 핵심 아이디어.

3. 대표 모델 비교 및 실무 이슈

| 구분 | RT-2 (Google DeepMind) | GR00T (NVIDIA) | OpenVLA (오픈소스) |
|------|------------------------|-----------------|---------------------|
| 특징 | 웹 지식 전이, VQA 결합 학습 | 휴머노이드 특화, 시뮬레이션 연계 | 오픈소스 7B 파라미터 |
| 강점 | 새로운 물체·명령 일반화 | Isaac 플랫폼과 통합 파이프라인 | 접근성, 커스터마이징 용이 |
| 한계 | 폐쇄형, 실시간성 제약 | 특정 하드웨어 종속 | 상용 모델 대비 성능 격차 |

- 로봇 시연 데이터 부족은 시뮬레이션 합성 데이터·오픈 데이터셋 활용, 실시간 지연은 고수준(VLA)/저수준(경량 컨트롤러) 계층적 제어로 대응.
- 최근 안전성 검증(Safety Layer)과 단계적 실환경 배포(Staged Rollout) 등 VLA 신뢰성 확보 기술 적용 증대.  "끝"
