## 모범답안

### 1. 모델 평가 개요

정 의  • k-fold 교차검증: 전체 데이터를 k개 폴드(Fold)로 분할해 각 폴드를 한 번씩 검증셋,
       나머지(k-1개)를 학습셋으로 사용해 k번 학습·평가를 반복하는 검증 기법
      - 데이터 분할에 따른 성능 편차를 줄이고 일반화 성능을 안정적으로 추정

```
전체 데이터를 5개 Fold로 분할 (k=5)
Round1: [검증][학습][학습][학습][학습]
Round2: [학습][검증][학습][학습][학습]
Round3: [학습][학습][검증][학습][학습]
Round4: [학습][학습][학습][검증][학습]
Round5: [학습][학습][학습][학습][검증]
   → 5회 평가 결과의 평균/표준편차로 최종 성능 산정
```

- 학습 데이터에서만 높은 성능(과적합)을 보이는 실패를 막기 위해 '검증'·'평가' 체계가 실무 신뢰성을 좌우.

### 2. k-fold 교차검증 상세

| 구분 | 설명 |
|------|------|
| 목적 | 데이터 분할 운(Sampling Bias)에 따른 성능 편차 최소화, 일반화 성능 추정 |
| 장점 | 전체 데이터를 학습·검증에 모두 활용, 소량 데이터에서 특히 유용 |
| 단점 | k번 반복 학습으로 계산 비용 증가 |
| 변형 기법 | Stratified k-fold(클래스 비율 유지), Leave-One-Out(k=N), Time Series Split |

- Stratified k-fold는 각 폴드의 클래스 비율을 원본과 동일하게 유지해 불균형 데이터에서도 안정적 평가 보장.

### 3. 머신러닝 모델 평가방법(회귀/분류 지표 비교)

1) 회귀(Regression) 평가지표

| 지표 | 수식/의미 |
|------|-----------|
| MAE | 오차 절댓값의 평균, 이상치에 덜 민감 |
| MSE/RMSE | 오차 제곱(합)의 평균, 큰 오차에 페널티 부여 |
| R²(결정계수) | 모델이 설명하는 분산의 비율(1에 가까울수록 우수) |

2) 분류(Classification) 평가지표

| 지표 | 정의 | 활용 상황 |
|------|------|-----------|
| 정확도(Accuracy) | 전체 중 올바르게 예측한 비율 | 클래스 균형 데이터 |
| 정밀도(Precision) | 양성 예측 중 실제 양성 비율 | 오탐 비용 클 때(스팸 필터) |
| 재현율(Recall) | 실제 양성 중 예측 성공 비율 | 미탐 비용 클 때(암 진단) |
| F1-Score | 정밀도·재현율의 조화평균 | 불균형 데이터 |
| ROC-AUC | TPR-FPR 곡선의 하단 면적 | 임계값 무관 전반 성능 비교 |

```
[전체 데이터]
   ├── Train Set ─── k-fold Cross Validation으로 하이퍼파라미터 튜닝
   ├── Validation Set ─── 모델 선택/튜닝 시 사용
   └── Test Set ─── 최종 1회만 사용, 실서비스 성능 추정
```

- 테스트셋은 튜닝 과정에서 사용하지 않고 최종 모델 선정 후 단 한 번만 사용(데이터 누수 방지 원칙).

### 4. 실무 적용 시 고려사항

| 이슈 | 대응방안 |
|------|----------|
| 클래스 불균형에서 정확도 착시 | 비즈니스 비용 기준으로 Precision/Recall/F1/PR-AUC 채택 |
| 시계열에 일반 k-fold 적용 시 데이터 누수 | Time Series Split(전진검증, Walk-Forward Validation) 적용 |

- 최근 시계열 데이터는 시간 순서를 보존하는 Walk-Forward Validation 적용 증대.  "끝"
