## 모범답안

1. 머신러닝 보안 취약점 개요

   정 의  • 머신러닝 모델의 학습·추론 과정에서 공격자가 입력·데이터를
            조작하여 모델의 오작동, 정보 유출, 지식재산 탈취를
            유발하는 일련의 공격 기법
          - 모델 생명주기(수집→학습→배포→서비스) 전 단계가 공격 표면

```
[학습 데이터] ──▶ 오염공격(Poisoning)
      │
      ▼
   [모델 학습] ──▶ (모델 자산)
      │
      ▼
   [배포/서비스] ──▶ 회피공격(Evasion), 추출공격(Extraction), 전도공격(Inversion)
```

- AI가 금융·의료·자율주행 등 안전 필수 영역에 확산되며 모델 자체를 표적으로 하는 적대적 머신러닝이 새로운 보안 위협으로 부상.

2. 적대적 공격 4가지 및 방어기법 (가/나)

| 공격 유형 | 공격 시점 | 공격 방법 | 방어기법 |
|-----------|----------|-----------|----------|
| 회피 공격 (Evasion Attack) | 추론(서비스) 단계 | 입력에 미세 노이즈(Perturbation)를 추가해 오분류 유도(적대적 예제) | 적대적 학습(Adversarial Training), 입력 전처리(Denoising), 그래디언트 마스킹 |
| 오염 공격 (Poisoning Attack) | 학습 단계 | 악성 데이터를 학습셋에 주입해 모델 성능 저하 또는 백도어 삽입 | 데이터 검증·정제(Data Sanitization), 이상치 탐지, 데이터 출처 검증 |
| 모델 추출 공격 (Extraction/Model Stealing) | 추론(API 질의) 단계 | 반복 질의-응답으로 모델의 파라미터·기능을 복제 | 질의 횟수 제한(Rate Limiting), 출력 확률 마스킹, 워터마킹 |
| 모델 전도 공격 (Inversion Attack) | 추론(API 질의) 단계 | 모델 출력을 역산하여 학습에 사용된 원본 데이터·민감정보 추론 | 차등 프라이버시(Differential Privacy), 출력 정보량 제한, 접근 통제 |

- 학습 단계는 오염공격, 추론 단계는 회피·추출·전도 공격이 주로 발생하는 구조.

3. 공격 유형별 위협 대상 비교

| 구분 | 목표(위협 대상) | 대표 사례 |
|------|-----------------|----------|
| 회피 공격 | 무결성(Integrity) 침해 - 오분류 유도 | 표지판 스티커 부착으로 자율주행 오인식 |
| 오염 공격 | 무결성 침해 - 모델 자체 변질 | 학습 데이터에 라벨 오염 데이터 주입 |
| 추출 공격 | 기밀성(Confidentiality) 침해 - 모델 IP 탈취 | API 대량 질의로 대체모델(Surrogate Model) 생성 |
| 전도 공격 | 기밀성 침해 - 개인정보 유출 | 얼굴인식 모델에서 원본 학습 이미지 복원 |

- CIA 3요소 중 무결성·기밀성이 주로 침해되며, 가용성은 대규모 질의를 통한 자원 고갈 공격(DoS)과 연계 가능.

4. 실무 적용 및 시사점

| 이슈 | 대응 방향 |
|------|----------|
| 공격-방어 비대칭성(Arms Race) | 적대적 학습·입력검증·이상행위 탐지를 계층화한 심층방어(Defense in Depth) |
| MLOps 파이프라인 보안 미흡 | 데이터 수집-학습-배포 전 단계 보안 게이트 내재화(MLSecOps), 레드팀 훈련 |
| 조직별 대응 수준 편차 | NIST AI RMF, ISO/IEC 42001과 연계한 AI 보안 성숙도 평가·인증 체계 |

- 최근 NIST AI RMF, ISO/IEC 42001 등 국제 표준 연계한 AI 보안 성숙도 관리체계 적용 증대.  "끝"
