# 콘텐츠 출처·최신성 기준

기술사 답안에서 법령, 정책, 표준, 보안 위협, 제품 사양처럼 변하는 정보는 개념과 최신 사실을 구분해 관리합니다.

## 문서에 남길 최소 정보

| 항목 | 대상 | 예시 |
|---|---|---|
| 발행기관·문서명 | 법령·표준·가이드 | 국가법령정보센터, OWASP, ISO/IEC |
| 버전·시행일 | 표준·Top 10·법령 | OWASP LLM Top 10 2026, 시행 2026-07-21 |
| 원문 링크 | 외부 사실 | 공식 원문 또는 공식 발표 페이지 |
| 최종 검증일 | 변동 가능 정보 | `verified_on: 2026-09-05` |

## 작성 원칙

1. **개념과 규정을 분리**합니다. 일반 원리는 본문에, 의무·기준·숫자는 출처와 함께 씁니다.
2. **버전을 고정**합니다. ‘OWASP Top 10’처럼 판이 바뀌는 자료는 연도를 반드시 붙입니다.
3. **불확실한 수치는 쓰지 않습니다.** 근거가 없으면 정성적 비교나 절차도로 표현합니다.
4. **기출 연도와 현재 사실을 구분**합니다. 과거 버전은 ‘기출용 아카이브’로 표시하고 최신판과 혼용하지 않습니다.

## 검토 우선순위

법령·정책 → 보안 위협 목록 → 국제표준·인증 → 시장 수치·제품 사양 순으로 주기적으로 재검토합니다.
