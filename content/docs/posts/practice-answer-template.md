# 실전 답안 템플릿과 자가 채점표

문제를 읽은 뒤 아래 틀을 빈 종이에 먼저 배치하고, 토픽별 키워드로 채웁니다. 그림과 표는 내용을 설명하기 위한 수단이며, 근거 없는 수치나 장식용 도형을 넣지 않습니다.

## 1교시: 정의형 답안

| 구획 | 2~4줄 안에 쓸 내용 | 점검 |
|---|---|---|
| 1단락 | 배경 한 줄 + 정확한 정의 + 핵심 키워드 | 질문의 대상을 첫 문장에 명시했는가? |
| 2단락 | 구성요소·절차·계층을 보여 주는 개념도 또는 표 | 화살표·관계·입출력이 읽히는가? |
| 3단락 | 유사 개념 비교, 장단점, 적용·개선방안 중 질문에 맞는 것 | ‘왜/어떻게’에 답했는가? |

## 2·3교시: 서술형 답안

1. **요구사항 분해**: 문제의 가·나·다 또는 정의·구성·방안 요구를 번호로 나눈다.
2. **답안 지도**: 첫 단락에 전체 흐름도와 답안 목차를 제시한다.
3. **핵심 설명**: 각 요구마다 정의, 구조/절차, 효과·한계·적용을 한 묶음으로 쓴다.
4. **실무 제언**: 거버넌스·프로세스·기술 통제를 해당 토픽에 맞춰 구체화한다.
5. **결론**: 문제의 목적과 위험/가치를 한 문장으로 다시 연결한다.

## 제출 전 60초 체크

- [ ] 모든 물음에 번호를 맞춰 답했다.
- [ ] 정의에 상위 개념, 대상, 목적 또는 특징이 들어갔다.
- [ ] 개념도·표가 본문과 중복되지 않고 관계를 보여 준다.
- [ ] 비교 대상의 기준 축이 통일돼 있다.
- [ ] 법령·표준·통계·버전은 출처와 기준일을 확인했다.
- [ ] 문제점에는 실행 가능한 통제·개선방안을 제시했다.
- [ ] 시간을 넘기지 않았고, 읽기 쉬운 여백과 제목을 유지했다.
